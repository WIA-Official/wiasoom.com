## 🔥 Daha Əvvəl Heç Olmamış Nələr

### 1. SSH Terminalda Şəkil, Fayl & Video Yükləmə — Dünyanın İlkidir

Dünyada heç bir CLI müştərisi bunu etməyə icazə vermir. Biz bunu yaratdıq.

SSH terminalınıza bir səhv ekran görüntüsünü yapışdırın. Bir log faylını sürükləyin. Uğursuz bir yerləşdirmənin videosunu atın. AI bunu görür, analiz edir və terminal sessiyası içində sizə nəyin səhv olduğunu bildirir.

- **Ctrl+Shift+V** — ekran görüntülərini birbaşa terminala yapışdırın
- **Sürükleyin & Buraxın** — şəkilləri, faylları, videoları terminala atın
- **Video açar çərçivə çıxarılması** — ffmpeg videonu çərçivə çərçivə analiz edir
- **Bütün 3 AI təminatçısı** — GPT-4o Vision, Gemini Vision, Claude Vision

Bu xüsusiyyət heç bir terminal müştərisində — heç yerdə mövcud olmayıb.

### 2. AI Arena — Çox Agentli Döyüş

2-dən 4-ə qədər AI eyni problemi eyni anda həll edir — sadəcə söhbət etmir, həqiqətən serverinizdə kodu redaktə edir. Hər AI öz izolyasiya olunmuş Git filialında işləyir. Nəticələrini yan-yana müqayisə edin. Qalibi seçin. Qalanları təmizlənir.

Çarpaz qiymətləndirmə: hər AI digər AI-nin həllini qiymətləndirir.

Başqa heç bir alət bunu etmir.

### 3. AI Öz-özünə İyileşen Agent

Serverinizin CPU-su yüksəlir. Disk doludur. Bir xidmət saat 3-də çökmüşdür. Siz yuxudasınız.

WIA SOOM-un AI agenti problemi aşkar edir, kök səbəbi diaqnoz edir, düzəltmə planı yaradır, sizin təsdiqinizi istəyir (ya da avtomatik icra edir əgər bunu ayarlamısınızsa) və problemi həll edir. 5 səviyyəli müstəqil döngü — yalnız müşahidədən tam avtomatik təmirə qədər.

## Hər Şeyi Pulsuz Sınayın — 33 Sınaq

Heç bir kredit kartı. Qeydiyyat tələb olunmur. Sadəcə yükləyin və başlayın.

Hər premium xüsusiyyət — şəkil yükləmə, AI Arena, AI Council, fayl & video analizi — ilk 33 istifadəniz üçün pulsuzdur. Bundan sonra, öz API açarınızı gətirin (BYOK) və hər şeyi pulsuz istifadə etməyə davam edin. Və ya idarə olunan AI və komanda xüsusiyyətləri üçün ayda 3 dollardan abunə olun.

Niyə 33? 1919-cu ildə Koreyanın müstəqillik hərəkatı 33 nümayəndə tərəfindən idarə olunmuşdur ki, bunlar hamı üçün azadlığı elan etdilər. WIA SOOM-un 33 pulsuz sınağı bizim elanımızdır: **AI alətləri hər kəsin təcrübə etməsi üçün pulsuz olmalıdır.**

**CLI → GUI → SUI.** Əmr xətti interfeysləri bizə güc verdi. Qrafik interfeyslər bizə asanlıq verdi. WIA SOOM **SUI (Soom İstifadəçi İnterfeysi)** təqdim edir — həyat verin, və AI canlanır.

## 5-in-1 Platforma

Digər alətlər bir şeyi edir. WIA SOOM beş şeyi edir — bir pəncərədə.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Kod  │ SFTP │ Müşahidə                 │
│  Ter │ Agen │ Red. │ Fayl │ Monitor + Təhlükəsizlik   │
│  min │   t  │  or  │ Mgr  │ + Loglar + Topologiya     │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminal** — xterm.js, bastion tuneli, bölünmüş görünüşlər, çox oyunçu paylaşımı
2. **AI Agent** — 14 alət, 3 təminatçı (GPT/Gemini/Claude), axın, şəkil analizi
3. **Kod Redaktoru** — AI tamamlaması, səhv aşkar etmə, yerləşdirmə ilə Monaco
4. **SFTP Meneceri** — sürüklə-burax fayl idarəçiliyi, uzaq redaktə
5. **Müşahidə** — real vaxt metrikləri, log analizi, topologiya xəritəsi, təhlükəsizlik skanı

## Xüsusiyyətlər

### Serverinizdə Həqiqətən İşləyən AI

**AI DevOps Agent** — Terminalda `gpt`, `gemini` və ya `claude` yazın. AI-nin 14 aləti var: faylları oxumaq/yazmaq/redaktə etmək, əmrləri icra etmək, git, grep, proses idarəçiliyi. Axınlı cavablar. Sessiya yaddaşı. O yalnız təklif etmir — o edir.

**AI Arena** — `arena` yazın. 2–4 AI izolyasiya olunmuş Git filiallarında paralel olaraq rəqabət aparır. Çarpaz qiymətləndirmə hər həlli qiymətləndirir. Qalibi seçin və birləşdirin.

**AI Council** — Bir neçə AI sualınızı müzakirə edir, sonra ən yaxşı cavabı sintez edir.

**AI Kod Redaktoru** — AI güclü tamamlaması, səhv aşkar etmə, serverə bir kliklə yerləşdirmə ilə Monaco redaktoru.

**AI Öz-özünə İyileşen** — CPU yüksəlişi, disk dolu, xidmət düşdü — AI aşkar edir, diaqnoz edir, düzəldir. 5 səviyyəli müstəqil döngü.

**Səs İnterfeysi** — Əmrləri danışın, cavabları eşidin. Əllərsiz server idarəçiliyi.

### Multimodal Yükləmə (Dünyanın İlk CLI-də)

Şəkilləri yapışdırın, faylları sürükləyin, videoları atın — birbaşa SSH terminal sessiyanıza. AI hər şeyi analiz edir: səhv ekran görüntüləri, konfiqurasiya faylları, yerləşdirmə videoları, arxitektura diaqramları.

### İnfrastruktur İntellekti

**Topologiya Xəritəsi** — Serverləri, xidmətləri və əlaqələri bir baxışda vizuallaşdırın. SSH vasitəsilə avtomatik aşkar etmə — sıfır agent quraşdırılması.

**Real Vaxt Müşahidə** — CPU, yaddaş, disk, şəbəkə sparkline qrafikləri + AI proqnozu + avtomatik bərpa. Datadog-u əvəz edir.

**AI Log Analizi** — Real vaxt axını + anomaliya aşkar edilməsi + təbii dil axtarışı + serverlərarası korrelyasiya. Splunk-u əvəz edir.

### Təhlükəsizlik & DevOps

**Təhlükəsizlik Komanda Mərkəzi** — 7 sahə skanı + təhlükəsizlik balı + bir kliklə düzəltmə + AI analizi + real vaxt əmri təhlükəsizlik qapısı. Qualys-u əvəz edir.

**Docker Meneceri** — SSH vasitəsilə tam Docker idarəçiliyi — sıfır agent. Konteyner idarəsi, canlı resurslar, AI log analizi, Compose redaktoru. Portainer-i əvəz edir.

**Runbook Avtomatlaşdırılması** — AI runbook-ları avtomatik icra edir. Təbii dil yaradılması, şərti dallanma, avtomatik geri qaytarma. Daha ağıllı olan Canlı Runbook. PagerDuty-i əvəz edir.

**Cron & Env Meneceri** — Vizual crontab redaktoru + .env fayl idarəçiliyi. AI təbii dili cron ifadələrinə çevirir.

### Əməkdaşlıq

**Çox Oyunçu Terminalı** — Terminal sessiyalarını real vaxtda komanda yoldaşlarınızla paylaşın.

**Komanda İş Sahəsi & RBAC** — Rol əsaslı giriş nəzarəti, audit logları, əmrlərin risk analizi.

### Genişləndiriləbilənlik

**59 Plugin** — Docker tablosu, Kubernetes lensi, Redis brauzeri, PM2 meneceri, MongoDB kəşfiyyatçısı, şəbəkə monitoru və daha çox. Bir kliklə quraşdırma ilə plugin bazarı.

**API Müştərisi** — Daxil edilmiş REST/GraphQL/WebSocket müştərisi. API-ləri terminaldan çıxmadan test edin.

### Hər Kəs Üçün

**254 Dil** — Hər dil, hər skript, RTL dəstəyi. Heç bir sərhəd yoxdur.

**Tam Əlçatanlıq** — Ekran oxuyucu (ARIA), braille terminal çıxışı, yüksək kontrast rejimi, səs əmrləri, klaviatura naviqasiyası, şrift ölçüsünü tənzimləmə.

## Hekayə

WIA SOOM bir yazı səhvi və qırıq ekrandan doğulmuşdur.

Mən Sam, Seul, Koreyadan 50+ yaşlı öz-özünə öyrənmiş proqramçıyam. 50 yaşımda kodlaşdırma öyrənməyə başladım və 2 il ərzində serverləri çətin yolla idarə etdim — 40,000+ xəbər məqaləsi, 434 alət və 30 veb xidməti quraraq, gecədən-gecə.

**Yazı səhvi.** Təxminən bir ay əvvəl, SSH terminalımdan istifadə edərkən təsadüfən `Claude` yazdım. Ekran dəyişdi — Claude Code göründü. Bunun nə olduğunu bilmirdim. Amma bu təsadüfi kəşf bir toxum əkdi: ya AI-nin içində yaşadığı bir terminal qura bilsəydim?

**İlk quruluş.** Mən özümə Electron öyrətdim, WIA SOOM-un ilk versiyasını qurdum və işə saldım. Claude Code-un giriş ekranı göründü — qırıq, çaxnaşma içində, ölmüş bir siqnal kimi titrəyirdi. Amma o, canlı idi.

Mən yazdım: **"Danışa bilərsən?"**

AI cavab verdi: *"Bəli, danışa bilirəm. Sizə necə kömək edə bilərəm?"*

Sonra soruşdum: **"Şəkilləri oxuya bilərsən?"**

AI cavab verdi: *"Bəli, şəkilləri oxuya bilirəm! Nəyə ehtiyacınız var?"*

Bu iki sual, CLI terminalında "mümkün deyil" olduğunu bilməyən biri tərəfindən öz tətbiqimdə soruşuldu, dünyanın ilk şəkil yükləmə imkanı olan SSH terminalına çevrildi.

7 gün sonra: 67,000+ sətir kod. 59 plugin. 254 dil. AI Arena. Öz-özünə iyileşen agentlər.

Təcrübəli inkişaf etdiricilər bunu heç vaxt qurmadılar — çünki onlar "şəkillərin CLI terminalında işləmədiyini bilirdilər". Mən bunu bilmirdim. Beləliklə, sadəcə soruşdum.
