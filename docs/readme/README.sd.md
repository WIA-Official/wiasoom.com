## 🔥 نئون ڇا آهي

### 1. تصوير، فائل ۽ وڊيو اپلوڊ SSH Terminal ۾ — دنيا جو پهريون

زمين تي ڪو به CLI ڪلائنٽ توهان کي اهو ڪرڻ جي اجازت نٿو ڏئي. اسان اهو ٺاهيو.

پنهنجي SSH ٽرمينل ۾ هڪ غلطي جو اسڪرين شاٽ پيسٽ ڪريو. هڪ لاگ فائل ڇڪيو. هڪ ناڪام ڊپلائمنٽ جو وڊيو ڇڏيو. AI ان کي ڏسندو آهي، تجزيو ڪندو آهي، ۽ توهان کي ٻڌائيندو آهي ته ڇا غلط آهي — سڀ ڪجهه ٽرمينل سيشن ۾.

- **Ctrl+Shift+V** — اسڪرين شاٽ سڌو ٽرمينل ۾ پيسٽ ڪريو
- **Drag & Drop** — تصويرون، فائلون، وڊيوز ٽرمينل ۾ ڇڪيو
- **وڊيو ڪي فريم جي استخراج** — ffmpeg وڊيو کي فريم به فريم تجزيو ڪري ٿو
- **سڀ 3 AI فراهم ڪندڙ** — GPT-4o Vision، Gemini Vision، Claude Vision

هي خاصيت ڪنهن به ٽرمينل ڪلائنٽ ۾ موجود نه هئي — ڪنهن به جڳهه تي.

### 2. AI Arena — ملٽي ايجنٽ جنگ

2 کان 4 AI هڪ ئي مسئلي کي هڪ ئي وقت حل ڪن ٿا — صرف ڳالهه ٻولهه نه، پر واقعي توهان جي سرور تي ڪوڊ کي ترميم ڪرڻ. هر AI پنهنجي الڳ Git برانچ ۾ ڪم ڪري ٿو. انهن جي نتيجن کي هڪ ٻئي جي ڀيٽ ۾ ڏسو. فاتح چونڊيو. باقي صاف ڪيا وڃن ٿا.

صليب-جائزو: هر AI هر ٻئي AI جي حل کي اسڪور ڪري ٿو.

ٻيو ڪو به اوزار اهو نه ٿو ڪري.

### 3. AI خود شفا Agent

توهان جي سرور جو CPU وڌي رهيو آهي. ڊسڪ مڪمل آهي. هڪ سروس صبح 3 وڳي ڪريش ٿي وئي. توهان سمهڻ ۾ آهيو.

WIA SOOM جو AI ايجنٽ مسئلو ڳولي ٿو، جڙت سبب کي تشخيص ڪري ٿو، هڪ درستگي جو منصوبو ٺاهيندو آهي، توهان جي منظوري لاءِ پڇندو آهي (يا جيڪڏهن توهان ان کي سيٽ ڪيو آهي ته خودڪار طريقي سان عمل ڪري ٿو)، ۽ مسئلو حل ڪري ٿو. 5-سطح خودمختار لوپ — صرف مشاهدو ڪرڻ کان مڪمل خود مرمت تائين.

## سڀ ڪجهه مفت آزمائش ڪريو — 33 آزمائشون

ڪو به ڪريڊٽ ڪارڊ. ڪو به سائن اپ جي ضرورت ناهي. صرف ڊائون لوڊ ڪريو ۽ شروع ڪريو.

هر پريميئم خاصيت — تصوير اپلوڊ، AI Arena، AI Council، فائل ۽ وڊيو تجزيو — توهان جي پهرين 33 استعمال لاءِ مفت آهي. ان کان پوء، پنهنجو API ڪي چلو (BYOK) ۽ سڀ ڪجهه مفت ۾ استعمال ڪندا رهو. يا منظم AI ۽ ٽيم جي خاصيتن لاءِ $3/ماهه مان سبسڪرائب ڪريو.

33 ڇو؟ 1919 ۾، ڪوريا جي آزادي جي تحريڪ 33 نمائندن پاران هلائي وئي جن سڀني لاءِ آزادي جو اعلان ڪيو. WIA SOOM جي 33 مفت آزمائش اسان جو اعلان آهي: **AI اوزار هر ڪنهن لاءِ تجربو ڪرڻ لاءِ مفت هجڻ گهرجن.**

**CLI → GUI → SUI.** ڪمانڊ-لائن انٽرفيس اسان کي طاقت ڏني. گرافڪ انٽرفيس اسان کي سهولت ڏني. WIA SOOM متعارف ڪرائي ٿو **SUI (Soom User Interface)** — زندگي ۾ جان وجھو، ۽ AI زندہ ٿي وڃي ٿو.

## 5-in-1 پليٽ فارم

ٻيا اوزار هڪ ڪم ڪن ٿا. WIA SOOM پنج ڪم ڪري ٿو — هڪ ونڊو ۾.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Observability             │
│  Ter │ Agen │ Edit │ File │ Monitor + Security        │
│  min │   t  │  or  │ Mgr  │ + Logs + Topology         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminal** — xterm.js، bastion tunneling، split views، multiplayer sharing
2. **AI Agent** — 14 اوزار، 3 فراهم ڪندڙ (GPT/Gemini/Claude)، اسٽريمنگ، تصوير تجزيو
3. **Code Editor** — Monaco سان AI مڪمل ٿيڻ، غلطي جي سڃاڻپ، ڊپلائمنٽ
4. **SFTP Manager** — ڇڪڻ ۽ ڇڏڻ واري فائل مينيجمينٽ، ريموٽ ايڊيٽنگ
5. **Observability** — حقيقي وقت جي ميٽرڪس، لاگ تجزيو، ٽاپولوجي نقشو، سيڪيورٽي اسڪين

## خاصيتون

### AI جيڪو واقعي توهان جي سرور تي ڪم ڪري ٿو

**AI DevOps Agent** — ٽرمينل ۾ `gpt`, `gemini`, يا `claude` لکو. AI وٽ 14 اوزار آهن: فائلون پڙهڻ/لکڻ/ترميم ڪرڻ، حڪم هلائڻ، git، grep، پروسيس مينيجمينٽ. اسٽريمنگ جواب. سيشن جي ياداشت. اهو صرف تجويز نه ٿو ڪري — اهو ڪري ٿو.

**AI Arena** — `arena` لکو. 2–4 AI الڳ Git برانچن ۾ متوازي طور تي مقابلو ڪن ٿا. صليب-جائزو هر حل کي اسڪور ڪري ٿو. فاتح چونڊيو ۽ ضم ڪريو.

**AI Council** — ڪيترائي AI توهان جي سوال تي بحث ڪن ٿا، پوءِ بهترين جواب کي گڏ ڪن ٿا.

**AI Code Editor** — Monaco ايڊيٽر AI-طاقت سان مڪمل ٿيڻ، غلطي جي سڃاڻپ، سرور تي هڪ ڪلڪ ڊپلائمنٽ سان.

**AI Self-Healing** — CPU جو وڌڻ، ڊسڪ مڪمل، سروس بند — AI ڳولي ٿو، تشخيص ڪري ٿو، درست ڪري ٿو. 5-سطح خودمختار لوپ.

**Voice Interface** — حڪم ڳالهايو، جواب ٻڌو. هٿ کان آزاد سرور مينيجمينٽ.

### ملٽي موڊل اپلوڊ (CLI ۾ دنيا جو پهريون)

تصويرون پيسٽ ڪريو، فائلون ڇڪيو، وڊيوز ڇڏيو — سڌو توهان جي SSH ٽرمينل سيشن ۾. AI هر شيءِ جو تجزيو ڪري ٿو: غلطي جا اسڪرين شاٽ، ترتيب ڏيڻ واري فائلون، ڊپلائمنٽ وڊيوز، آرڪيٽيڪچر ڊياگرام.

### انفراسٽرڪچر انٽيليجنس

**Topology Map** — سرور، خدمتون، ۽ ڳنڍڻن کي هڪ نظر ۾ بصري بڻايو. SSH ذريعي خودڪار دريافت — صفر ايجنٽ انسٽاليشن.

**حقيقي وقت جي مشاهدي** — CPU، ياداشت، ڊسڪ، نيٽورڪ اسپارڪ لائن گراف + AI اڳڪٿي + خودڪار بحالي. Datadog کي تبديل ڪري ٿو.

**AI لاگ تجزيو** — حقيقي وقت جي اسٽريمنگ + انومالي جي سڃاڻپ + قدرتي زبان جي ڳولا + صليب-سرور هم آهنگي. Splunk کي تبديل ڪري ٿو.

### سيڪيورٽي ۽ DevOps

**سيڪيورٽي ڪمانڊ سينٽر** — 7-علاقو اسڪين + سيڪيورٽي اسڪوئر + هڪ ڪلڪ درستگي + AI تجزيو + حقيقي وقت جي حڪم سيڪيورٽي گيٽ. Qualys کي تبديل ڪري ٿو.

**Docker Manager** — SSH ذريعي مڪمل Docker مينيجمينٽ — صفر ايجنٽ. ڪنٽينر ڪنٽرول، زنده وسيلن، AI لاگ تجزيو، Compose ايڊيٽر. Portainer کي تبديل ڪري ٿو.

**Runbook Automation** — AI خودڪار طريقي سان رن بوڪ هلائي ٿو. قدرتي زبان جي تخليق، مشروط شاخ، خودڪار واپسي. زنده رن بوڪ جيڪو وڌيڪ سمجهدار ٿي وڃي ٿو. PagerDuty کي تبديل ڪري ٿو.

**Cron ۽ Env Manager** — بصري ڪرون ايڊيٽر + .env فائل مينيجمينٽ. AI قدرتي زبان کي ڪرون جي اظهار ۾ تبديل ڪري ٿو.

### تعاون

**ملٽي پليئر ٽرمينل** — حقيقي وقت ۾ ٽيم جي ساٿين سان ٽرمينل سيشن شيئر ڪريو.

**ٽيم جي ڪم جي جڳهه ۽ RBAC** — رول جي بنياد تي رسائي ڪنٽرول، آڊٽ لاگ، حڪم جي خطري جو تجزيو.

### توسيع پذيري

**59 پلگ ان** — Docker ڊيش بورڊ، Kubernetes لينس، Redis برائوزر، PM2 مينيجر، MongoDB ايڪسپلورر، نيٽورڪ مانيٽر، ۽ وڌيڪ. پلگ ان مارڪيٽ جي هڪ ڪلڪ انسٽال سان.

**API ڪلائنٽ** — بلٽ ان REST/GraphQL/WebSocket ڪلائنٽ. ٽرمينل ڇڏڻ کان سواءِ APIs کي جانچيو.

### سڀني لاءِ

**254 ٻوليون** — هر زبان، هر اسڪرپٽ، RTL جي مدد. ڪو سرحدون نه.

**مڪمل رسائي** — اسڪرين ريڊر (ARIA)، برايل ٽرمينل آئوٽ پٽ، هاءِ ڪنٽراسٽ موڊ، آواز جي حڪمن، ڪي بورڊ نيويگيشن، فونٽ جي سائيز جي ترتيب.

## ڪهاڻي

WIA SOOM هڪ ٽائپو ۽ هڪ ٽٽل اسڪرين مان پيدا ٿيو.

مون کي سام چيو وڃي ٿو، هڪ 50+ خود سکي پروگرامر جيڪو سيول، ڪوريا مان آهي. مون 50 کان پوء ڪوڊنگ سکيو ۽ 2 سال تائين سرورز کي سخت طريقي سان منظم ڪيو — 40,000+ خبرن جي آرٽيڪل، 434 اوزار، ۽ 30 ويب سروسز ٺاهڻ ۾، رات کان رات.

**ٽائپو.** هڪ مهينو اڳ، مان پنهنجي SSH ٽرمينل استعمال ڪري رهيو هيس ۽ غلط طور تي `Claude` لکي ڇڏيو. اسڪرين بدلجي وئي — Claude Code ظاهر ٿيو. مون کي خبر نه هئي ته اهو ڇا هو. پر ان حادثاتي دريافت هڪ بيج وجهي ڇڏيو: ڇا جيڪڏهن مان هڪ ٽرمينل ٺاهي سگهان جتي AI اندر رهي؟

**پهريون تعمير.** مون کي Electron سکيو، WIA SOOM جو پهريون ورجن ٺاهيو، ۽ هلائي ڇڏيو. Claude Code جو تعارفي اسڪرين ظاهر ٿيو — ٽٽل، گليچ، مرڻ واري سگنل وانگر چمڪندڙ. پر اهو زندہ هو.

مون لکيو: **"ڇا توهان ڳالهايو ٿا؟"**

AI جواب ڏنو: *"ها، مان ڳالهايو ٿا. مان توهان جي مدد ڪيئن ڪري سگهان ٿو؟"*

پوءِ مون پڇيو: **"ڇا توهان تصويرون پڙهي سگهو ٿا؟"**

AI جواب ڏنو: *"ها، مان تصويرون پڙهي سگهان ٿو! توهان کي ڇا گهرجي؟"*

اهي ٻه سوال، جيڪي منهنجي پنهنجي ايپ ۾ ڪنهن کان پڇيا ويا جن کي خبر نه هئي ته CLI ٽرمينل ۾ "ناممڪن" ڇا آهي، دنيا جي پهرين SSH ٽرمينل سان تصوير اپلوڊ ٿيڻ جو سبب بڻجي ويا.

7 ڏينهن بعد: 67,000+ لائنون ڪوڊ. 59 پلگ ان. 254 ٻوليون. AI Arena. خود شفا ڏيندڙ ايجنٽ.

تجرباتي ڊولپرز اهو نه ٺاهيو — ڇو ته انهن "ڄاڻ" رکيو ته تصويرون CLI ٽرمينلز ۾ ڪم نٿيون ڪن. مون کي ان جي خبر نه هئي. تنهنڪري مون صرف پڇيو.
