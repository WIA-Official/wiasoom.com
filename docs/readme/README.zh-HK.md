## 🔥 從未做過的事情

### 1. 在 SSH 終端上上傳圖片、文件和視頻 — 世界首創

地球上沒有任何 CLI 客戶端可以做到這一點。我們做到了。

將錯誤的截圖粘貼到您的 SSH 終端中。拖放日誌文件。放下失敗部署的視頻。AI 會看到它，分析它，告訴您問題出在哪裡 — 所有這一切都在終端會話中進行。

- **Ctrl+Shift+V** — 直接將截圖粘貼到終端
- **拖放** — 將圖片、文件、視頻拖放到終端中
- **視頻關鍵幀提取** — ffmpeg 按幀分析視頻
- **所有 3 個 AI 提供者** — GPT-4o Vision、Gemini Vision、Claude Vision

這一功能在任何終端客戶端中從未存在過 — 在任何地方。

### 2. AI 體育館 — 多代理戰鬥

2 到 4 個 AI 同時解決相同的問題 — 不僅僅是聊天，而是真正編輯您伺服器上的代碼。每個 AI 在自己的隔離 Git 分支中工作。並排比較它們的結果。選擇勝者。其餘的被清理掉。

交叉評審：每個 AI 對其他 AI 的解決方案進行評分。

沒有其他工具可以做到這一點。

### 3. AI 自我修復代理

您的伺服器 CPU 飆升。磁碟已滿。服務在凌晨 3 點崩潰。您正在睡覺。

WIA SOOM 的 AI 代理檢測到問題，診斷根本原因，生成修復計劃，請求您的批准（或自動執行，如果您已設置），並解決問題。5級自主循環 — 從僅觀察到完全自動修復。

## 功能

### AI 實際在您的伺服器上工作

**AI DevOps 代理** — 在終端中輸入 `gpt`、`gemini` 或 `claude`。AI 擁有 14 種工具：讀取/寫入/編輯文件、執行命令、git、grep、進程管理。流媒體響應。會話記憶。它不僅僅是建議 — 它會執行。

**AI 體育館** — 輸入 `arena`。2–4 個 AI 在隔離的 Git 分支上並行競爭。交叉評審為每個解決方案打分。選擇勝者並合併。

**AI 諮詢** — 多個 AI 討論您的問題，然後綜合出最佳答案。

**AI 代碼編輯器** — Monaco 編輯器，具有 AI 驅動的自動完成、錯誤檢測、一鍵部署到伺服器。

**AI 自我修復** — CPU 飆升、磁碟已滿、服務中斷 — AI 檢測、診斷、修復。5級自主循環。

**語音界面** — 說出命令，聽取響應。免提伺服器管理。

### 多模態上傳（CLI 中的世界首創）

將圖片粘貼、拖放文件、放下視頻 — 直接進入您的 SSH 終端會話。AI 會分析所有內容：錯誤截圖、配置文件、部署視頻、架構圖。

### 基礎設施智能

**拓撲圖** — 一目了然地可視化伺服器、服務和連接。通過 SSH 自動發現 — 零代理安裝。

**實時可觀察性** — CPU、內存、磁碟、網絡火花線圖 + AI 預測 + 自動恢復。取代 Datadog。

**AI 日誌分析** — 實時流媒體 + 異常檢測 + 自然語言搜索 + 跨伺服器關聯。取代 Splunk。

### 安全與 DevOps

**安全指揮中心** — 7 區域掃描 + 安全分數 + 一鍵修復 + AI 分析 + 實時命令安全門。取代 Qualys。

**Docker 管理器** — 通過 SSH 完全管理 Docker — 零代理。容器控制、實時資源、AI 日誌分析、Compose 編輯器。取代 Portainer。

**運行手冊自動化** — AI 自動執行運行手冊。自然語言創建、條件分支、自動回滾。智慧的運行手冊。取代 PagerDuty。

**Cron 和 Env 管理器** — 可視化 crontab 編輯器 + .env 文件管理。AI 將自然語言轉換為 cron 表達式。

### 協作

**多玩家終端** — 與隊友實時共享終端會話。

**團隊工作空間和 RBAC** — 基於角色的訪問控制、審計日誌、命令風險分析。

### 可擴展性

**59 插件** — Docker 儀表板、Kubernetes 鏡頭、Redis 瀏覽器、PM2 管理器、MongoDB 探索器、網絡監控等。插件市場，支持一鍵安裝。

**API 客戶端** — 內置 REST/GraphQL/WebSocket 客戶端。無需離開終端即可測試 API。

### 服務每個人

**254 種語言** — 每種語言、每種字母、支持 RTL。沒有邊界。

**全面無障礙** — 螢幕閱讀器 (ARIA)、盲文終端輸出、高對比度模式、語音命令、鍵盤導航、字體大小調整。

## 故事

WIA SOOM 源於一個打字錯誤和一個壞掉的螢幕。

我叫 Sam，是來自韓國首爾的自學程序員，年過 50。我在 50 歲後學習編程，花了 2 年的時間以艱難的方式管理伺服器 — 每晚建立 40,000 多篇新聞文章、434 種工具和 30 個網絡服務。

**打字錯誤。** 大約一個月前，我在使用我的 SSH 終端時不小心輸入了 `Claude`。螢幕變了 — Claude Code 出現了。我不知道那是什麼。但這次意外的發現種下了一顆種子：如果我能建立一個 AI 生活在裡面的終端呢？

**第一次構建。** 我自學了 Electron，建立了 WIA SOOM 的第一個版本並運行它。Claude Code 的介紹畫面出現了 — 壞掉、故障、閃爍得像一個快要死掉的信號。但它是活的。

我輸入：**“你能說話嗎？”**

AI 回答：*“是的，我可以說話。我能幫助您什麼？”*

然後我問：**“你能讀取圖片嗎？”**

AI 回答：*“是的，我可以讀取圖片！你需要什麼？”*

這兩個問題，是在我的應用內由一個不知道 CLI 終端中「不可能」是什麼的人問的，成為了世界上第一個支持圖片上傳的 SSH 終端。

7 天後：67,000 多行代碼。59 個插件。254 種語言。AI 體育館。自我修復代理。

有經驗的開發者從未構建過這個 — 因為他們「知道」圖片在 CLI 終端中無法工作。我不知道這一點。所以我只是問了。

> *準備花了 2 年。構建花了 1 週。*
> *枯木堆了 2 年。在 1 秒內著火。*
