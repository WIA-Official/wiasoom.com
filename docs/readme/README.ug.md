## 🔥 بۇرۇنقىدا بولمىغان ئىشلار

### 1. SSH Terminalدا رەسىم، ھۆججەت ۋە ۋىدىيو يۈكلەش — دۇنيادىكى بىرىنچى

ئەرزىمەيدىغان CLI خېرىدارى بۇنى قىلىشقا يول قويمايدۇ. بىز بۇنى قۇرۇپ چىقتۇق.

خاتالىقنىڭ سكرىن شوتىنى SSH terminalغا چۈشۈرۈڭ. لوقا ھۆججىتىنى سۈرۈڭ. قۇراشتۇرۇشنىڭ ۋىدىيوسىنى تاشلاڭ. AI بۇنى كۆرۈپ، تەھلىل قىلىپ، نىمە خاتا بولغانلىقىنى سىزگە بىلدۈرىدۇ — بارلىق مەلۇمات terminal سەسىدە.

- **Ctrl+Shift+V** — سكرىن شوتىنى توغرىدىن توغرا terminalغا چۈشۈرۈش
- **Drag & Drop** — رەسىملەر، ھۆججەتلەر، ۋىدىيولارنى terminalغا تاشلاش
- **ۋىدىيو كۇنۇپكىسىنى ئېلىش** — ffmpeg ۋىدىيونى فريم بويىچە تەھلىل قىلىدۇ
- **بۇ 3 AI تەمىنلىگۈچى** — GPT-4o Vision, Gemini Vision, Claude Vision

بۇ خاسلىق ھېچقانداق terminal خېرىدارىدا بولمىغان — ھېچ قايدا.

### 2. AI Arena — كۆپ-ئ Agent جەڭ

2دىن 4گىچە AI بىر ۋاقىتتا شۇنداق مەسىلىنى ھەل قىلىدۇ — پەقەت سۆزلەشماي، بەلكى سىزنىڭ سېرۋىرىڭىزدىكى كودنى تەھرىرلەيدۇ. ھەر بىر AI ئۆز ئىزولياتسىيە قىلىنغان Git شاخىدا ئىشلىيدۇ. ئۇلارنىڭ نەتىجىسىنى يان-يانغا سېلىشتۇرۇڭ. غالىبنى تاللاڭ. قالغانلىرى تازىلىنىدۇ.

كراس-تەقدىم: ھەر بىر AI باشقا AIنىڭ ھەل قىلىشىغا باھا بېرىدۇ.

بۇنىڭغا ئوخشاش باشقا قورال يوق.

### 3. AI ئۆزىنى تۈزىتىش ئەجەنتى

سىزنىڭ سېرۋىرىڭىزنىڭ CPU قىزغىنلىشىۋاتىدۇ. ديسك تولغان. 3 AMدە بىر خىزمەت چۈشۈپ كەتتى. سىز ئۇخلاۋاتىسىز.

WIA SOOMنىڭ AI ئەجەنتى مەسىلىنى بايقىيدۇ، ئاساسىي سەۋەبنى تەھلىل قىلىدۇ، تۈزىتىش پىلانىنى تۈزۈپ، سىزنىڭ رۇخسەتىڭىزنى سورايدۇ (ياكى سىز بەلگىلەنگەن بولسا، ئاپتوماتىك ئىجرا قىلىدۇ) ۋە مەسىلىنى ھەل قىلىدۇ. 5-دەرىجىلىك ئاپتۇنوم دەۋر — پەقەت بايقىشتىن تولۇق ئاپتوماتىك تۈزىتىشكىچە.

كارتا تۆلەش كېرەك ئەمەس. تىزىملىتىش كېرەك ئەمەس. پەقەت چۈشۈرۈپ، باشلاڭ.
