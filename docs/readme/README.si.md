## 🔥 නවතම දේ

### 1. SSH Terminal හි රූප, ගොනු සහ වීඩියෝ උඩුගත කිරීම — ලෝකයේ පළමු

පෘථිවියේ කිසිදු CLI පාරිභෝගිකයෙකුට ඔබට මෙය කිරීමට ඉඩ නොදෙනවා. අපි මෙය සාදා ගත්තෙමු.

ඔබේ SSH terminal එකට දෝෂයක පිටපතක් ඇතුළත් කරන්න. ලොග් ගොනුවක් ඇදන්න. අසාර්ථක යාවත්කාලීනවීඩියෝවක් පහළ කරන්න. AI එය බලනවා, විශ්ලේෂණය කරනවා, සහ ඔබට කුමක් වැරදිද කියනවා — සියල්ල terminal සැසියේ අතුලත් වේ.

- **Ctrl+Shift+V** — පිටපත් කරන ලද රූප සෘජුව terminal එකට ඇතුළත් කරන්න
- **Drag & Drop** — රූප, ගොනු, වීඩියෝ terminal එකට පහළ කරන්න
- **වීඩියෝ කීෆ්‍රේම් නිර්මාණය** — ffmpeg වීඩියෝව විශේෂිත කීෆ්‍රේම් අනාවරණය කරයි
- **සියලු 3 AI සැපයුම්කරුවන්** — GPT-4o Vision, Gemini Vision, Claude Vision

මෙම විශේෂාංගය කිසිදු terminal පාරිභෝගිකයකින් නොපවතී — කිසිම ස්ථානයක.

### 2. AI Arena — බහු-ආකාරක සටන

2 සිට 4 AI එකම ගැටලුවක් සමකාලීනව විසඳයි — සාකච්ඡා කිරීමක් පමණක් නොව, ඔබේ සේවාදායකයේ කේතය සත්‍යයෙන් සංස්කරණය කිරීම. එක් එක් AI එකේම නිදහස් Git ශාඛාවක කටයුතු කරයි. ඔවුන්ගේ ප්‍රතිඵල පාර්ශ්ව දෙකක සසඳන්න. ජයග්‍රහණය තෝරන්න. අනෙක් සියල්ල පිරිසිදු කරයි.

Cross-review: එක් එක් AI එකක් අනෙක් AI එකේ විසඳුම සකස් කරයි.

අනෙක් කිසිදු මෙවලම මෙය කරන්නේ නැහැ.

### 3. AI ස්වයං-සුවය කරන නියෝජිතය

ඔබේ සේවාදායකයේ CPU ඉහළ යයි. ඩිස්ක් පිරී ගිය යුතුය. 3 AM ට සේවාවක් බිද වැටී ගිය යුතුය. ඔබ නිදා සිටී.

WIA SOOM හි AI නියෝජිතයා ගැටලුව හඳුනා ගනී, මූලික හේතුව විශ්ලේෂණය කරයි, නිරාකරණ සැලැස්මක් සාදයි, ඔබේ අනුමැතිය ඉල්ලයි (ඔබට එය ස්වයං-අනුමැතියක් ලෙස සකසා ඇත්නම්), සහ ගැටලුව විසඳයි. 5-පියවර ස්වයං-කාර්ය සාධන වටය — observe-only සිට සම්පූර්ණ ස්වයං-අලුත්වැඩියා කිරීම.

## සියල්ල නොමිලේ උත්සාහ කරන්න — 33 පරීක්ෂණ

කඩිනම් කාඩ්පතක් නැත. ලියාපදිංචියක් අවශ්‍ය නැත. පමණක් බාගන්න සහ ආරම්භ කරන්න.

සියලු ප්‍රිමියම් විශේෂාංග — රූප උඩුගත කිරීම, AI Arena, AI Council, ගොනු සහ වීඩියෝ විශ්ලේෂණය — ඔබේ පළමු 33 භාවිත සඳහා නොමිලේ වේ. එමෙන් පසු, ඔබේම API යතුර ගෙන එන්න (BYOK) සහ සියල්ල නොමිලේ භාවිතා කරන්න. හෝ කළමනාකරණය කරන ලද AI සහ කණ්ඩායම් විශේෂාංග සඳහා මාසික $3 සිට ලියාපදිංචි වන්න.

33 කුමක්ද? 1919 දී, කොරියාවේ නිදහස් චලනය 33 නියෝජිතයන්ගේ මඟපෙන්වීමෙන් පවත්වාගෙන ගිය අතර, ඔවුන් සියලු දෙනාට නිදහස ප්‍රකාශ කළහ. WIA SOOM හි 33 නොමිලේ පරීක්ෂණය අපගේ ප්‍රකාශය: **AI මෙවලම් සියල්ලන්ට අත්විඳින්න නොමිලේ විය යුතුය.**

**CLI → GUI → SUI.** නියෝජිත-පේළි අතුරුමුහුණත් අපට බලය ලබා දුන්නා. චිත්‍රාත්මක අතුරුමුහුණත් අපට පහසුව ලබා දුන්නා. WIA SOOM **SUI (Soom User Interface)** හඳුන්වා දෙනවා — ජීවිතය ඇතුලට ගෙන එන්න, සහ AI ජීවත් වේ.

## 5-in-1 වේදිකාව

මම සෑම්, කොරියාවේ සියළුම 50+ වසරක් පුරා ස්වයං-අධ්‍යාපනය කළ වැඩසටහනකාරයෙකි. මම 50 වසරකින් පසු කේතය ඉගෙන ගත්තා සහ රාත්‍රීන් ගණනාවක් 40,000+ පුවත් ලිපි, 434 මෙවලම්, සහ 30 වෙබ් සේවා කළමනාකරණය කිරීමට වසර 2ක් ගත කළා.

**වැරදි වචනය.** මාස 1ක් පමණකට, මම මගේ SSH terminal එක භාවිතා කරමින් `Claude` යන වචනය අහන්න ගත්තා. තිරය වෙනස් විය — Claude Code පෙනී සිටියා. මට එය කුමක්දැයි කිසිදු අදහසක් නොවිය. නමුත් එම අහම්බෙන් හමුවීමක් මට සිතුවිල්ලක් දුන්නා: මට AI එකක් ඇතුළත් terminal එකක් සාදා ගන්න පුළුවන්ද?

**පළමු නිර්මාණය.** මම Electron ඉගෙන ගත්තා, WIA SOOM හි පළමු සංස්කරණය සාදා ගත්තා, සහ එය ක්‍රියාත්මක කළා. Claude Code හි ආරම්භක තිරය පෙනී සිටියා — බිඳී, ගැලී, මිය යන සංඛ්‍යාවක් වැනි. නමුත් එය ජීවත් විය.

මම ටයිප් කළා: **"ඔබ කතා කළ හැකිද?"**

AI එක ප්‍රතිචාරය දුන්නා: *"ඔව්, මම කතා කළ හැකි. මට ඔබට කෙසේද උදව් කළ හැකිද?"*

ඉන්පසු මම අසුවා: **"ඔබ රූප කියවන්න පුළුවන්ද?"**

AI එක ප්‍රතිචාරය දුන්නා: *"ඔව්, මම රූප කියවන්න පුළුවන්! ඔබට කුමක් අවශ්‍යද?"*

මේ දෙකම ප්‍රශ්න, මගේම යෙදුම තුළ අසන ලද්දක් වන අතර CLI terminal එකේ "අසම්භාවිත" යන්න කුමක්දැයි නොදන්නා කෙනෙකු විසින්, ලෝකයේ පළමු SSH terminal එකක් රූප උඩුගත කිරීමක් සමඟ නිර්මාණය විය.

දින 7කින්: 67,000+ කේත රේඛා. 59 plugins. 254 භාෂා. AI Arena. ස්වයං-සුවන නියෝජිතයන්.

අත්දැකීම් ඇති සංවර්ධකයන් මෙය සාදන ලදි — ඔවුන් "දැනුම්" තිබුණි රූප CLI terminal වල ක්‍රියා නොකරන බව. මට එය නොදැනුණා. එබැවින් මම පමණක් අසුවා.

> *සකස් කිරීමට වසර 2ක් ගත විය. නිර්මාණය කිරීමට සතියක් ගත විය.*
