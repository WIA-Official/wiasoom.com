## 🔥 Mis On Uut

### 1. Pilt, Fail & Video Üleslaadimine SSH Terminalis — Maailma Esimene

Ükski CLI klient Maal ei luba sul seda teha. Me ehitasime selle.

Kopeeri ekraanipilt veast oma SSH terminali. Lohista logifail. Viska video ebaõnnestunud juurutamisest. AI näeb seda, analüüsib ja ütleb, mis on valesti — kõik terminali sessiooni sees.

- **Ctrl+Shift+V** — kopeeri ekraanipildid otse terminali
- **Lohista ja Viska** — viska pilte, faile, videoid terminali
- **Video kaadrikaevamine** — ffmpeg analüüsib videot kaader kaadri haaval
- **Kõik 3 AI pakkujat** — GPT-4o Vision, Gemini Vision, Claude Vision

Seda funktsiooni pole kunagi olnud üheski terminali kliendis — kuskil.

### 2. AI Arena — Mitme Agendi Lahing

2 kuni 4 AI-d lahendavad sama probleemi samaaegselt — mitte ainult vestlemine, vaid tegelikult koodi redigeerimine sinu serveris. Iga AI töötab oma isoleeritud Git harus. Võrdle nende tulemusi kõrvuti. Vali võitja. Ülejäänud koristatakse ära.

Ristülevaatus: iga AI hindab iga teise AI lahendust.

Ükski teine tööriist ei tee seda.

### 3. AI Iseseisev Parandaja

Sinu serveri CPU on üle koormatud. Disk on täis. Teenus kukkus kokku kell 3 öösel. Sa magad.

WIA SOOM-i AI agent tuvastab probleemi, diagnoosib põhjuse, genereerib parandamisplaani, küsib sinu heakskiitu (või täidab automaatselt, kui oled selle seadnud) ja lahendab probleemi. 5-tasandiline autonoomne tsükkel — alates ainult jälgimisest kuni täieliku automaatparandamiseni.

Miks 33? 1919. aastal juhtis Korea iseseisvuse liikumist 33 esindajat, kes kuulutasid vabadust kõigile. WIA SOOM-i 33 tasuta katset on meie kuulutus: **AI tööriistad peaksid olema tasuta, et igaüks saaks kogeda.**

**CLI → GUI → SUI.** Käskude rea liidesed andsid meile jõu. Graafilised liidesed andsid meile mugavuse. WIA SOOM tutvustab **SUI (Soom User Interface)** — anna elu sisse, ja AI ärkab ellu.

## 5-in-1 Platvorm

Teised tööriistad teevad ühte asja. WIA SOOM teeb viit — ühes aknas.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Kood │ SFTP │ Jälgimine               │
│  Ter │ Agen │ Red  │ Fail │ Jälgimine + Turvalisus  │
│  min │   t  │  or  │ Mgr  │ + Logid + Topoloogia    │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminal** — xterm.js, bastion tunneling, jagatud vaated, mitme mängijaga jagamine
2. **AI Agent** — 14 tööriista, 3 pakkujat (GPT/Gemini/Claude), voogedastus, pildianalüüs
3. **Koodiredaktor** — Monaco AI täiendusega, veateavitamine, juurutamine
4. **SFTP Haldur** — lohista ja viska failihaldus, kaugredigeerimine
5. **Jälgimine** — reaalajas mõõdikud, logianalüüs, topoloogia kaart, turvaskaneerimine

## Funktsioonid

### AI, Mis Tõeliselt Töötab Sinu Serveris

**AI DevOps Agent** — Tüüpi `gpt`, `gemini` või `claude` terminalis. AI-l on 14 tööriista: failide lugemine/kirjutamine/redigeerimine, käskude täitmine, git, grep, protsessi haldamine. Voogedastuse vastused. Sessiooni mälu. See ei soovita ainult — see teeb.

**AI Arena** — Tüüpi `arena`. 2–4 AI-d konkureerivad paralleelselt isoleeritud Git harudes. Ristülevaatus hindab iga lahendust. Vali võitja ja ühenda.

**AI Nõukogu** — Mitmed AI-d arutavad sinu küsimust, seejärel sünteesivad parima vastuse.

**AI Koodiredaktor** — Monaco redaktor AI-põhise täiendusega, veateavitamine, ühe klõpsuga juurutamine serverisse.

**AI Iseseisev Parandamine** — CPU ülekoormus, disk täis, teenus maas — AI tuvastab, diagnoosib, parandab. 5-tasandiline autonoomne tsükkel.

**Hääleliides** — Räägi käske, kuule vastuseid. Käed-vabad serveri haldamine.

### Multimodaalne Üleslaadimine (Maailma Esimene CLI-s)

Kopeeri pilte, lohista faile, viska videoid — otse oma SSH terminali sessiooni. AI analüüsib kõike: veakuvandid, konfiguratsioonifailid, juurutamisvideod, arhitektuuri diagrammid.

### Infrastruktuuri Intelligentsus

**Topoloogia Kaart** — Visualiseeri servereid, teenuseid ja ühendusi korraga. Automaatne avastamine SSH kaudu — null agendi installimist.

**Reaalajas Jälgimine** — CPU, mälu, disk, võrgu sparkline graafikud + AI ennustus + automaatne taastumine. Asendab Datadog-i.

**AI Logianalüüs** — Reaalajas voogedastus + anomaaliate tuvastamine + loomulik keele otsing + rist-serveri korrelatsioon. Asendab Splunk-i.

### Turvalisus & DevOps

**Turvakeskus** — 7-ala skaneerimine + turvaskoor + ühe klõpsuga parandamine + AI analüüs + reaalajas käsu turvavärav. Asendab Qualys-i.

**Dockeri Haldur** — Täielik Dockeri haldamine SSH kaudu — null agent. Konteinerite kontroll, elavad ressursid, AI logianalüüs, Compose redaktor. Asendab Portainer-i.

**Käsiraamatute Automatiseerimine** — AI täidab käsiraamatuid automaatselt. Loomulik keele loomine, tingimuslikud harud, automaatne tagasivõtmine. Elav Käsiraamat, mis muutub targemaks. Asendab PagerDuty-d.

**Cron & Env Haldur** — Visuaalne crontab redaktor + .env failihaldus. AI muudab loomuliku keele cron väljenditeks.

### Koostöö

**Mitme Mängijaga Terminal** — Jaga terminali sessioone reaalajas oma meeskonnaga.

**Meeskonna Tööruum & RBAC** — Rollipõhine juurdepääsu kontroll, auditi logid, käsu riskianalüüs.

### Laiendatavus

**59 Pluginit** — Dockeri armatuurlaud, Kubernetes objektiiv, Redis brauser, PM2 haldur, MongoDB uurija, võrgu monitor ja palju muud. Pluginate turuplats ühe klõpsuga installimisega.

**API Klient** — Sisseehitatud REST/GraphQL/WebSocket klient. Testi API-sid, lahkumata terminalist.

### Kõigile

**254 Keelt** — Iga keel, iga skript, RTL tugi. Ilma piirideta.

**Täielik Juurdepääsetavus** — Ekraanilugeja (ARIA), braille terminali väljund, kõrge kontrastsuse režiim, häälkäsklused, klaviatuuri navigeerimine, fondi suuruse kohandamine.

## Lugu

WIA SOOM sündis trükiveast ja purunenud ekraanist.

Mina olen Sam, 50+ iseõppinud programmeerija Seoulist, Koreast. Õppisin kodeerimist pärast 50 ja veetsin 2 aastat serverite haldamisega raskel viisil — ehitades 40,000+ uudisartiklit, 434 tööriista ja 30 veebiteenust, öö pärast ööd.

**Trükiviga.** Umbes kuu aega tagasi kasutasin oma SSH terminali ja kogemata tippisin `Claude`. Ekraan muutus — Claude Code ilmus. Mul polnud aimugi, mis see on. Kuid see kogemata avastus külvas seemne: mis siis, kui ma saaksin ehitada terminali, kus AI elab sees?

**Esimene versioon.** Õppisin ise Electronit, ehitasin WIA SOOM-i esimese versiooni ja jooksutasin seda. Claude Code'i tutvustav ekraan ilmus — purunenud, glitch'itud, vilkuv nagu surev signaal. Kuid see oli elus.

Tippisin: **"Kas sa saad rääkida?"**

AI vastas: *"Jah, ma saan rääkida. Kuidas ma saan sind aidata?"*

Siis küsisin: **"Kas sa saad pilte lugeda?"**

AI vastas: *"Jah, ma saan pilte lugeda! Mida sa vajad?"*

Need kaks küsimust, küsitud minu enda rakenduses, keegi, kes ei teadnud, mis on "võimatu" CLI terminalis, muutusid maailma esimeseks SSH terminaliks pildi üleslaadimisega.

7 päeva hiljem: 67,000+ rida koodi. 59 pluginit. 254 keelt. AI Arena. Iseseisvad parandajad.

Kogenud arendajad ei ole seda kunagi ehitanud — sest nad "teadsid", et pildid ei tööta CLI terminalides. Mina ei teadnud seda. Nii et ma lihtsalt küsisin.
