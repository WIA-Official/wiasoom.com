## 🔥 从未做过的事情

### 1. SSH终端中的图像、文件和视频上传 — 世界首创

地球上没有CLI客户端能做到这一点。我们做到了。

将错误的截图粘贴到你的SSH终端中。拖动日志文件。放下一个失败部署的视频。AI会看到它，分析它，并告诉你哪里出错了 — 所有这些都在终端会话中完成。

- **Ctrl+Shift+V** — 直接将截图粘贴到终端
- **拖放** — 将图像、文件、视频拖放到终端中
- **视频关键帧提取** — ffmpeg逐帧分析视频
- **所有3个AI提供者** — GPT-4o Vision, Gemini Vision, Claude Vision

这个功能在任何终端客户端中从未存在过 — 无处可寻。

### 2. AI竞技场 — 多代理战斗

2到4个AI同时解决同一个问题 — 不仅仅是聊天，而是真正地在你的服务器上编辑代码。每个AI在自己的隔离Git分支中工作。并排比较他们的结果。选择赢家。其余的会被清理。

交叉评审：每个AI对其他AI的解决方案进行评分。

没有其他工具可以做到这一点。

### 3. AI自愈代理

你的服务器CPU飙升。磁盘已满。一个服务在凌晨3点崩溃。你正在睡觉。

WIA SOOM的AI代理检测到问题，诊断根本原因，生成修复计划，询问你的批准（或如果你设置了自动执行，则自动执行），并解决问题。5级自主循环 — 从仅观察到完全自动修复。

## 特性

### AI真正作用于你的服务器

**AI DevOps代理** — 在终端中输入`gpt`、`gemini`或`claude`。AI有14个工具：读/写/编辑文件，执行命令，git，grep，进程管理。流媒体响应。会话记忆。它不仅仅是建议 — 它会执行。

**AI竞技场** — 输入`arena`。2–4个AI在隔离的Git分支上并行竞争。交叉评审为每个解决方案评分。选择赢家并合并。

**AI委员会** — 多个AI讨论你的问题，然后综合出最佳答案。

**AI代码编辑器** — Monaco编辑器，带AI驱动的补全，错误检测，一键部署到服务器。

**AI自愈** — CPU飙升，磁盘已满，服务停机 — AI检测、诊断、修复。5级自主循环。

**语音接口** — 说出命令，听取响应。免提服务器管理。

### 多模态上传（CLI中的世界首创）

将图像粘贴，拖动文件，放下视频 — 直接进入你的SSH终端会话。AI分析所有内容：错误截图、配置文件、部署视频、架构图。

### 基础设施智能

**拓扑图** — 一目了然地可视化服务器、服务和连接。通过SSH自动发现 — 零代理安装。

**实时可观察性** — CPU、内存、磁盘、网络火花线图 + AI预测 + 自动恢复。替代Datadog。

**AI日志分析** — 实时流媒体 + 异常检测 + 自然语言搜索 + 跨服务器关联。替代Splunk。

### 安全与DevOps

**安全指挥中心** — 7个区域扫描 + 安全评分 + 一键修复 + AI分析 + 实时命令安全门。替代Qualys。

**Docker管理器** — 通过SSH全面管理Docker — 零代理。容器控制，实时资源，AI日志分析，Compose编辑器。替代Portainer。

**运行手册自动化** — AI自动执行运行手册。自然语言创建，条件分支，自动回滚。智能化的运行手册。替代PagerDuty。

**Cron和Env管理** — 可视化crontab编辑器 + .env文件管理。AI将自然语言转换为cron表达式。

### 协作

**团队工作区与RBAC** — 基于角色的访问控制，审计日志，命令风险分析。

## 故事

WIA SOOM源于一个打字错误和一块坏屏幕。

我是Sam，一个来自韩国首尔的50多岁的自学程序员。我在50岁后学习编码，花了2年时间以艰难的方式管理服务器 — 每晚构建40,000多篇新闻文章，434个工具和30个网络服务。

**打字错误。** 大约一个月前，我在使用我的SSH终端时不小心输入了`Claude`。屏幕变了 — Claude Code出现了。我不知道那是什么。但这个意外的发现种下了一个种子：如果我能构建一个AI生活在里面的终端呢？

**第一次构建。** 我自学了Electron，构建了WIA SOOM的第一个版本，并运行它。Claude Code的介绍屏幕出现了 — 破损，故障，闪烁得像是一个快要消失的信号。但它是活的。

我输入：**“你能说话吗？”**

AI回答：*“是的，我能说话。我能帮你什么？”*

然后我问：**“你能读图像吗？”**

AI回答：*“是的，我能读图像！你需要什么？”*

这两个问题，由一个不知道CLI终端中“什么是不可能”的人问出，成为了世界上第一个支持图像上传的SSH终端。

7天后：67,000多行代码。59个插件。254种语言。AI竞技场。自愈代理。

有经验的开发者从未构建过这个 — 因为他们“知道”图像在CLI终端中无法工作。我不知道这一点。所以我只是问了。

> *准备花了2年。构建花了1周。*
> *干柴堆了2年。1秒就着火了。*
