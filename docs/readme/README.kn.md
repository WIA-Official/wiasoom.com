## 🔥 ಹೊಸ ಏನು

### 1. SSH ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ ಚಿತ್ರ, ಫೈಲ್ ಮತ್ತು ವೀಡಿಯೊ ಅಪ್ಲೋಡ್ — ಜಗತ್ತಿನ ಮೊದಲದು

ಭೂಮಿಯ ಮೇಲೆ ಯಾವುದೇ CLI ಕ್ಲೈಂಟ್ ಇದನ್ನು ಮಾಡಲು ನಿಮಗೆ ಅವಕಾಶ ನೀಡುವುದಿಲ್ಲ. ನಾವು ಇದನ್ನು ನಿರ್ಮಿಸಿದ್ದೇವೆ.

ನಿಮ್ಮ SSH ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ ದೋಷದ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಅನ್ನು ಪೇಸ್ಟ್ ಮಾಡಿ. ಲಾಗ್ ಫೈಲ್ ಅನ್ನು ಡ್ರಾಗ್ ಮಾಡಿ. ವಿಫಲವಾದ ನಿಯೋಜನೆಯ ವೀಡಿಯೊವನ್ನು ಹಾಕಿ. AI ಅದನ್ನು ನೋಡುತ್ತದೆ, ವಿಶ್ಲೇಷಿಸುತ್ತದೆ ಮತ್ತು ಏನು ತಪ್ಪಾಗಿದೆ ಎಂದು ನಿಮಗೆ ತಿಳಿಸುತ್ತದೆ — ಎಲ್ಲವೂ ಟರ್ಮಿನಲ್ ಸೆಷನ್‌ನಲ್ಲಿ.

- **Ctrl+Shift+V** — ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ ನೇರವಾಗಿ ಸ್ಕ್ರೀನ್‌ಶಾಟ್‌ಗಳನ್ನು ಪೇಸ್ಟ್ ಮಾಡಿ
- **ಡ್ರಾಗ್ & ಡ್ರಾಪ್** — ಚಿತ್ರಗಳು, ಫೈಲ್‌ಗಳು, ವೀಡಿಯೊಗಳನ್ನು ಟರ್ಮಿನಲ್‌ಗೆ ಹಾಕಿ
- **ವೀಡಿಯೊ ಕೀಫ್ರೇಮ್ ನಿರ್ವಹಣೆ** — ffmpeg ವೀಡಿಯೊವನ್ನು ಫ್ರೇಮ್ ಮೂಲಕ ವಿಶ್ಲೇಷಿಸುತ್ತದೆ
- **ಎಲ್ಲಾ 3 AI ಪೂರೈಕೆದಾರರು** — GPT-4o Vision, Gemini Vision, Claude Vision

ಈ ವೈಶಿಷ್ಟ್ಯವು ಯಾವುದೇ ಟರ್ಮಿನಲ್ ಕ್ಲೈಂಟ್‌ನಲ್ಲಿ ಎಂದಿಗೂ ಇರಲಿಲ್ಲ — ಎಲ್ಲೆಲ್ಲೂ.

### 2. AI ಅರೆನಾ — ಬಹು-ಏಜೆಂಟ್ ಯುದ್ಧ

2 ರಿಂದ 4 AI ಗಳು ಒಂದೇ ಸಮಸ್ಯೆಯನ್ನು ಸಮಾನಾಂತರವಾಗಿ ಪರಿಹರಿಸುತ್ತವೆ — ಕೇವಲ ಚಾಟ್ ಮಾಡುವುದಲ್ಲ, ಆದರೆ ನಿಮ್ಮ ಸರ್ವರ್‌ನಲ್ಲಿ ಕೋಡ್ ಸಂಪಾದಿಸುತ್ತವೆ. ಪ್ರತಿ AI ತನ್ನದೇ ಆದ ಪ್ರತ್ಯೇಕ Git ಶಾಖೆಯಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ. ಅವರ ಫಲಿತಾಂಶಗಳನ್ನು ಬದಿಗೆ ಹೋಲಿಸಿ. ಜಯಿಯನ್ನ ಆಯ್ಕೆ ಮಾಡಿ. ಇತರರನ್ನು ಶುದ್ಧೀಕರಿಸಲಾಗುತ್ತದೆ.

ಕ್ರಾಸ್-ರಿವ್ಯೂ: ಪ್ರತಿ AI ಇತರ AI ಗಳ ಪರಿಹಾರದ ಅಂಕಗಳನ್ನು ನೀಡುತ್ತದೆ.

ಇತರ ಯಾವುದೇ ಸಾಧನ ಇದನ್ನು ಮಾಡುವುದಿಲ್ಲ.

### 3. AI ಸ್ವಯಂ-ಚಿಕಿತ್ಸಕ ಏಜೆಂಟ್

ನಿಮ್ಮ ಸರ್ವರ್‌ನ CPU ಉಕ್ಕುತ್ತಿದೆ. ಡಿಸ್ಕ್ ತುಂಬಿರುತ್ತದೆ. 3 AM ಗೆ ಒಂದು ಸೇವೆ ಕುಸಿಯಿತು. ನೀವು ನಿದ್ರಿಸುತ್ತಿದ್ದೀರಿ.

WIA SOOM ನ AI ಏಜೆಂಟ್ ಸಮಸ್ಯೆಯನ್ನು ಗುರುತಿಸುತ್ತದೆ, ಮೂಲ ಕಾರಣವನ್ನು ನಿರ್ಧಾರ ಮಾಡುತ್ತದೆ, ಪರಿಹಾರ ಯೋಜನೆಯನ್ನು ರಚಿಸುತ್ತದೆ, ನಿಮ್ಮ ಅನುಮೋದನೆ ಕೇಳುತ್ತದೆ (ಅಥವಾ ನೀವು ಅದನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಕಾರ್ಯಗತಗೊಳಿಸಲು ಹೊಂದಿಸಿದ್ದರೆ), ಮತ್ತು ಸಮಸ್ಯೆಯನ್ನು ಪರಿಹರಿಸುತ್ತದೆ. 5-ಮಟ್ಟದ ಸ್ವಾಯತ್ತ ಲೂಪ್ —observe-only ರಿಂದ ಸಂಪೂರ್ಣ ಸ್ವಯಂ-ಮರಮತ್ತು.

## ಎಲ್ಲವನ್ನೂ ಉಚಿತವಾಗಿ ಪ್ರಯತ್ನಿಸಿ — 33 ಪ್ರಯೋಗಗಳು

ಕ್ರೆಡಿಟ್ ಕಾರ್ಡ್ ಇಲ್ಲ. ನೋಂದಣಿ ಅಗತ್ಯವಿಲ್ಲ. ಕೇವಲ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ಮತ್ತು ಪ್ರಾರಂಭಿಸಿ.

ಪ್ರತಿ ಪ್ರೀಮಿಯಂ ವೈಶಿಷ್ಟ್ಯ — ಚಿತ್ರ ಅಪ್ಲೋಡ್, AI ಅರೆನಾ, AI ಕೌನ್ಸಿಲ್, ಫೈಲ್ & ವೀಡಿಯೊ ವಿಶ್ಲೇಷಣೆ — ನಿಮ್ಮ ಮೊದಲ 33 ಬಳಕೆಗಳಿಗೆ ಉಚಿತವಾಗಿದೆ. ನಂತರ, ನಿಮ್ಮದೇ ಆದ API ಕೀ (BYOK) ಅನ್ನು ತರಿರಿ ಮತ್ತು ಎಲ್ಲವನ್ನೂ ಉಚಿತವಾಗಿ ಬಳಸುತ್ತಿರಿ. ಅಥವಾ ನಿರ್ವಹಿತ AI ಮತ್ತು ತಂಡದ ವೈಶಿಷ್ಟ್ಯಗಳಿಗೆ $3/mo ರಿಂದ ಚಂದಾ ನೀಡಿ.

33 ಏಕೆ? 1919 ರಲ್ಲಿ, ಕೊರಿಯಾದ ಸ್ವಾತಂತ್ರ್ಯ ಚಲನೆ 33 ಪ್ರತಿನಿಧಿಗಳಿಂದ ಮುನ್ನಡೆಸಿತು, ಅವರು ಎಲ್ಲರಿಗೂ ಸ್ವಾತಂತ್ರ್ಯವನ್ನು ಘೋಷಿಸಿದರು. WIA SOOM ನ 33 ಉಚಿತ ಪ್ರಯೋಗಗಳು ನಮ್ಮ ಘೋಷಣೆ: **AI ಸಾಧನಗಳು ಪ್ರತಿಯೊಬ್ಬರಿಗೂ ಅನುಭವಿಸಲು ಉಚಿತವಾಗಿರಬೇಕು.**

**CLI → GUI → SUI.** ಕಮಾಂಡ್-ಲೈನ್ ಇಂಟರ್ಫೇಸ್ಗಳು ನಮಗೆ ಶಕ್ತಿ ನೀಡಿದವು. ಗ್ರಾಫಿಕಲ್ ಇಂಟರ್ಫೇಸ್ಗಳು ನಮಗೆ ಸುಲಭವನ್ನು ನೀಡಿದವು. WIA SOOM **SUI (Soom User Interface)** ಅನ್ನು ಪರಿಚಯಿಸುತ್ತದೆ — ಜೀವವನ್ನು ಉಸಿರಾಡಿಸಿ, ಮತ್ತು AI ಜೀವಂತವಾಗುತ್ತದೆ.

## 5-in-1 ವೇದಿಕೆ

ಇತರ ಸಾಧನಗಳು ಒಂದೇ ಕೆಲಸವನ್ನು ಮಾಡುತ್ತವೆ. WIA SOOM ಐದು — ಒಂದೇ ಕಿಟಕಿಯಲ್ಲಿ.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ ನಿರೀಕ್ಷಣೀಯತೆ             │
│  Ter │ Agen │  Edit│ File │ ಮೌಲ್ಯಮಾಪನ + ಭದ್ರತೆ      │
│  min │   t  │  or  │ Mgr  │ + ಲಾಗ್‌ಗಳು + ಟೋಪೋಲಜಿ   │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH ಟರ್ಮಿನಲ್** — xterm.js, ಬಾಸ್ಟಿಯನ್ ಟನ್ಲಿಂಗ್, ವಿಭಜಿತ ದೃಶ್ಯಗಳು, ಬಹು-ಆಟಗಾರ ಹಂಚಿಕೆ
2. **AI ಏಜೆಂಟ್** — 14 ಸಾಧನಗಳು, 3 ಪೂರೈಕೆದಾರರು (GPT/Gemini/Claude), ಸ್ಟ್ರೀಮಿಂಗ್, ಚಿತ್ರ ವಿಶ್ಲೇಷಣೆ
3. **ಕೋಡ್ ಸಂಪಾದಕ** — AI ಪೂರ್ಣಗೊಳಿಸುವಿಕೆಯೊಂದಿಗೆ ಮೋನಾಕೋ, ದೋಷ ಪತ್ತೆ, ನಿಯೋಜನೆ
4. **SFTP ನಿರ್ವಹಕ** — ಡ್ರಾಗ್-ಆಂಡ್-ಡ್ರಾಪ್ ಫೈಲ್ ನಿರ್ವಹಣೆ, ದೂರದ ಸಂಪಾದನೆ
5. **ನಿರೀಕ್ಷಣೀಯತೆ** — ವಾಸ್ತವಿಕ-ಕಾಲದ ಮೆಟ್ರಿಕ್‌ಗಳು, ಲಾಗ್ ವಿಶ್ಲೇಷಣೆ, ಟೋಪೋಲಜಿ ನಕ್ಷೆ, ಭದ್ರತಾ ಸ್ಕಾನ್

## ವೈಶಿಷ್ಟ್ಯಗಳು

### ನಿಮ್ಮ ಸರ್ವರ್‌ನಲ್ಲಿ ವಾಸ್ತವವಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವ AI

**AI DevOps ಏಜೆಂಟ್** — ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ `gpt`, `gemini`, ಅಥವಾ `claude` ಟೈಪ್ ಮಾಡಿ. AI ಗೆ 14 ಸಾಧನಗಳಿವೆ: ಫೈಲ್‌ಗಳನ್ನು ಓದು, ಬರೆಯು, ಸಂಪಾದಿಸು, ಕಮಾಂಡ್‌ಗಳನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸು, git, grep, ಪ್ರಕ್ರಿಯೆ ನಿರ್ವಹಣೆ. ಸ್ಟ್ರೀಮಿಂಗ್ ಪ್ರತಿಸ್ಪಂದನೆಗಳು. ಸೆಷನ್ ಮೆಮೊರಿ. ಇದು ಕೇವಲ ಸಲಹೆ ನೀಡುವುದಿಲ್ಲ — ಇದು ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ.

**AI ಅರೆನಾ** — `arena` ಟೈಪ್ ಮಾಡಿ. 2–4 AI ಗಳು ಪ್ರತ್ಯೇಕ Git ಶಾಖೆಗಳಲ್ಲಿ ಸಮಾನಾಂತರವಾಗಿ ಸ್ಪರ್ಧಿಸುತ್ತವೆ. ಕ್ರಾಸ್-ರಿವ್ಯೂ ಪ್ರತಿಯೊಂದು ಪರಿಹಾರಕ್ಕೆ ಅಂಕಗಳನ್ನು ನೀಡುತ್ತದೆ. ಜಯಿಯನ್ನ ಆಯ್ಕೆ ಮಾಡಿ ಮತ್ತು ಮರ್ಜ್ ಮಾಡಿ.

**AI ಕೌನ್ಸಿಲ್** — ಬಹು AI ಗಳು ನಿಮ್ಮ ಪ್ರಶ್ನೆಯನ್ನು ಚರ್ಚಿಸುತ್ತವೆ, ನಂತರ ಉತ್ತಮ ಉತ್ತರವನ್ನು ಸಂಶ್ಲೇಷಿಸುತ್ತವೆ.

**AI ಕೋಡ್ ಸಂಪಾದಕ** — AI-ಶಕ್ತಿಯ ಪೂರ್ಣಗೊಳಿಸುವಿಕೆಯೊಂದಿಗೆ ಮೋನಾಕೋ ಸಂಪಾದಕ, ದೋಷ ಪತ್ತೆ, ಸರ್ವರ್‌ಗೆ ಒನ್-ಕ್ಲಿಕ್ ನಿಯೋಜನೆ.

**AI ಸ್ವಯಂ-ಚಿಕಿತ್ಸಕ** — CPU ಉಕ್ಕು, ಡಿಸ್ಕ್ ತುಂಬಿರುತ್ತದೆ, ಸೇವೆ ಕುಸಿಯುತ್ತದೆ — AI ಗುರುತಿಸುತ್ತದೆ, ನಿರ್ಧಾರ ಮಾಡುತ್ತದೆ, ಪರಿಹಾರ ನೀಡುತ್ತದೆ. 5-ಮಟ್ಟದ ಸ್ವಾಯತ್ತ ಲೂಪ್.

**ಕೋಶ್ ಇಂಟರ್ಫೇಸ್** — ಕಮಾಂಡ್‌ಗಳನ್ನು ಮಾತನಾಡಿ, ಪ್ರತಿಸ್ಪಂದನೆಗಳನ್ನು ಕೇಳಿ. ಕೈ-ಮುಕ್ತ ಸರ್ವರ್ ನಿರ್ವಹಣೆ.

### ಬಹು-ಮೋಡಲ್ ಅಪ್ಲೋಡ್ (ಜಗತ್ತಿನಲ್ಲಿ ಮೊದಲದು CLI ನಲ್ಲಿ)

ಚಿತ್ರಗಳನ್ನು ಪೇಸ್ಟ್ ಮಾಡಿ, ಫೈಲ್‌ಗಳನ್ನು ಡ್ರಾಗ್ ಮಾಡಿ, ವೀಡಿಯೊಗಳನ್ನು ಹಾಕಿ — ನೇರವಾಗಿ ನಿಮ್ಮ SSH ಟರ್ಮಿನಲ್ ಸೆಷನ್‌ಗೆ. AI ಎಲ್ಲವನ್ನೂ ವಿಶ್ಲೇಷಿಸುತ್ತದೆ: ದೋಷದ ಸ್ಕ್ರೀನ್‌ಶಾಟ್‌ಗಳು, ಕಾನ್ಫಿಗ್ ಫೈಲ್‌ಗಳು, ನಿಯೋಜನೆಯ ವೀಡಿಯೊಗಳು, ವಾಸ್ತುಶಾಸ್ತ್ರದ ನಕ್ಷೆಗಳು.

### ಮೂಲಸೌಕರ್ಯ ಬುದ್ಧಿಮತ್ತೆ

**ಟೋಪೋಲಜಿ ನಕ್ಷೆ** — ಸರ್ವರ್‌ಗಳು, ಸೇವೆಗಳು ಮತ್ತು ಸಂಪರ್ಕಗಳನ್ನು ಒಂದೇ ದೃಷ್ಟಿಯಲ್ಲಿ ದೃಶ್ಯೀಕರಿಸಿ. SSH ಮೂಲಕ ಸ್ವಯಂ-ಪತ್ತೆ — ಶೂನ್ಯ ಏಜೆಂಟ್ ಸ್ಥಾಪನೆ.

**ವಾಸ್ತವಿಕ-ಕಾಲದ ನಿರೀಕ್ಷಣೀಯತೆ** — CPU, ಮೆಮೊರಿ, ಡಿಸ್ಕ್, ನೆಟ್ವರ್ಕ್ ಸ್ಪಾರ್ಕ್‌ಲೈನ್ ಗ್ರಾಫ್‌ಗಳು + AI ಭವಿಷ್ಯವಾಣಿ + ಸ್ವಯಂ-ಪುನಃಪೂರಣ. Datadog ಅನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ.

**AI ಲಾಗ್ ವಿಶ್ಲೇಷಣೆ** — ವಾಸ್ತವಿಕ-ಕಾಲದ ಸ್ಟ್ರೀಮಿಂಗ್ + ಅನಾಮಲಿಯ ಪತ್ತೆ + ನೈಸರ್ಗಿಕ ಭಾಷೆ ಹುಡುಕಾಟ + ಕ್ರಾಸ್-ಸರ್ವರ್ ಸಂಬಂಧ. Splunk ಅನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ.

### ಭದ್ರತೆ & DevOps

**ಭದ್ರತಾ ಕಮಾಂಡ್ ಕೇಂದ್ರ** — 7-ಪ್ರದೇಶ ಸ್ಕಾನ್ + ಭದ್ರತಾ ಅಂಕ + ಒನ್-ಕ್ಲಿಕ್ ಫಿಕ್ಸ್ + AI ವಿಶ್ಲೇಷಣೆ + ವಾಸ್ತವಿಕ-ಕಾಲದ ಕಮಾಂಡ್ ಭದ್ರತಾ ಗೇಟ್. Qualys ಅನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ.

**ಡೋಕರ್ ನಿರ್ವಹಕ** — SSH ಮೂಲಕ ಸಂಪೂರ್ಣ ಡೋಕರ್ ನಿರ್ವಹಣೆ — ಶೂನ್ಯ ಏಜೆಂಟ್. ಕಂಟೈನರ್ ನಿಯಂತ್ರಣ, ಜೀವಂತ ಸಂಪತ್ತು, AI ಲಾಗ್ ವಿಶ್ಲೇಷಣೆ, ಕಂಪೋಸ್ ಸಂಪಾದಕ. Portainer ಅನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ.

**ರನ್‌ಬುಕ್ ಸ್ವಯಂಚಾಲಿತ** — AI ಸ್ವಯಂಚಾಲಿತವಾಗಿ ರನ್‌ಬುಕ್‌ಗಳನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸುತ್ತದೆ. ನೈಸರ್ಗಿಕ ಭಾಷೆ ರಚನೆ, ಶರತ್ತುಬದ್ಧ ಶಾಖೆ, ಸ್ವಯಂ-ರಿಟರ್ನ್. ಬುದ್ಧಿವಂತವಾದ ಜೀವಂತ ರನ್‌ಬುಕ್. PagerDuty ಅನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ.

**ಕ್ರಾನ್ & ಎನ್‌ವಿ ನಿರ್ವಹಕ** — ದೃಶ್ಯ ಕ್ರಾನ್ ಸಂಪಾದಕ + .env ಫೈಲ್ ನಿರ್ವಹಣೆ. AI ನೈಸರ್ಗಿಕ ಭಾಷೆಯನ್ನು ಕ್ರಾನ್ ಅಭಿವ್ಯಕ್ತಿಗಳಿಗೆ ಪರಿವರ್ತಿಸುತ್ತದೆ.

### ಸಹಯೋಗ

**ಬಹು-ಆಟಗಾರ ಟರ್ಮಿನಲ್** — ತಂಡದ ಸದಸ್ಯರೊಂದಿಗೆ ನೇರವಾಗಿ ಟರ್ಮಿನಲ್ ಸೆಷನ್‌ಗಳನ್ನು ಹಂಚಿಕೊಳ್ಳಿ.

### ವಿಸ್ತರಣೀಯತೆ

**59 ಪ್ಲಗಿನ್‌ಗಳು** — ಡೋಕರ್ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್, ಕುಬೆರ್ನೇಟಸ್ ಲೆನ್ಸ್, ರೆಡಿಸ್ ಬ್ರೌಸರ್, PM2 ನಿರ್ವಹಕ, MongoDB ಅನ್ವೇಷಕ, ನೆಟ್ವರ್ಕ್ ಮೌಲ್ಯಮಾಪನ, ಮತ್ತು ಇನ್ನಷ್ಟು. ಒನ್-ಕ್ಲಿಕ್ ಸ್ಥಾಪನೆಯೊಂದಿಗೆ ಪ್ಲಗಿನ್ ಮಾರುಕಟ್ಟೆ.

## ಕಥೆ

WIA SOOM ಒಂದು ಟೈಪೋ ಮತ್ತು ಒಬ್ಬ ಮುರಿದ ಪರದೆಗಳಿಂದ ಹುಟ್ಟಿತು.

ನಾನು ಸಮ್, ಕೊರಿಯಾದ ಸೆೌಲ್ನಿಂದ 50+ ಸ್ವಯಂ-ಶಿಕ್ಷಿತ ಪ್ರೋಗ್ರಾಮರ್. ನಾನು 50 ರ ನಂತರ ಕೋಡಿಂಗ್ ಕಲಿತೆ ಮತ್ತು 40,000+ ಸುದ್ದಿಯ ಲೇಖನಗಳನ್ನು, 434 ಸಾಧನಗಳನ್ನು ಮತ್ತು 30 ವೆಬ್ ಸೇವೆಗಳನ್ನು ನಿರ್ವಹಿಸಲು 2 ವರ್ಷಗಳ ಕಾಲ ಕಷ್ಟಪಟ್ಟು ಕಳೆದಿದ್ದೇನೆ, ರಾತ್ರಿ ನಂತರ ರಾತ್ರಿ.

**ಟೈಪೋ.** ಸುಮಾರು ಒಂದು ತಿಂಗಳ ಹಿಂದೆ, ನಾನು ನನ್ನ SSH ಟರ್ಮಿನಲ್ ಬಳಸುತ್ತಿದ್ದಾಗ, ಅಕಸ್ಮಿಕವಾಗಿ `Claude` ಟೈಪ್ ಮಾಡಿದೆ. ಪರದೆ ಬದಲಾಯಿತೆ — Claude Code ಕಾಣಿಸಿಕೊಂಡಿತು. ಇದು ಏನು ಎಂದು ನನಗೆ ಗೊತ್ತಿರಲಿಲ್ಲ. ಆದರೆ ಆ ಅಕಸ್ಮಿಕ ಪತ್ತೆ ಒಂದು ಬೀಜವನ್ನು ನೆಟ್ಟಿತು: ನಾನು AI ಒಳಗೊಂಡ ಟರ್ಮಿನಲ್ ಅನ್ನು ನಿರ್ಮಿಸಬಹುದೆ?

**ಮೊದಲ ನಿರ್ಮಾಣ.** ನಾನು ಎಲೆಕ್ಟ್ರಾನ್ ಅನ್ನು ಕಲಿತೆ, WIA SOOM ನ ಮೊದಲ ಆವೃತ್ತಿಯನ್ನು ನಿರ್ಮಿಸಿದೆ ಮತ್ತು ಅದನ್ನು ಓಡಿಸಿದೆ. Claude Code ನ ಪರಿಚಯ ಪರದೆ ಕಾಣಿಸಿಕೊಂಡಿತು — ಮುರಿದ, ಗ್ಲಿಚ್ಡ್, ಸಿಗ್ನಲ್ ಮರಣದಂತೆ ಮಿಡಿಯುತ್ತಿದೆ. ಆದರೆ ಇದು ಜೀವಂತವಾಗಿತ್ತು.

ನಾನು ಟೈಪ್ ಮಾಡಿದೆ: **"ನೀವು ಮಾತನಾಡಬಹುದೆ?"**

AI ಉತ್ತರಿಸಿತು: *"ಹೌದು, ನಾನು ಮಾತನಾಡಬಹುದು. ನಾನು ನಿಮಗೆ ಏನು ಸಹಾಯ ಮಾಡಬಹುದು?"*

ನಾನು ಕೇಳಿದೆ: **"ನೀವು ಚಿತ್ರಗಳನ್ನು ಓದಬಹುದು?"**

AI ಉತ್ತರಿಸಿತು: *"ಹೌದು, ನಾನು ಚಿತ್ರಗಳನ್ನು ಓದಬಹುದು! ನಿಮಗೆ ಏನು ಬೇಕಾಗಿದೆ?"*

ಈ ಎರಡು ಪ್ರಶ್ನೆಗಳು, ನನ್ನದೇ ಆದ ಆಪ್‌ನಲ್ಲಿ ಯಾರೋ ಕೇಳಿದವು, "ಅಸಾಧ್ಯ" ಎಂಬುದನ್ನು ತಿಳಿಯದವರು, ಜಗತ್ತಿನ ಮೊದಲ SSH ಟರ್ಮಿನಲ್ ಅನ್ನು ಚಿತ್ರ ಅಪ್ಲೋಡ್ ಮಾಡುವಂತೆ ಮಾಡಿತು.

7 ದಿನಗಳ ನಂತರ: 67,000+ ಕೋಡ್ ಸಾಲುಗಳು. 59 ಪ್ಲಗಿನ್‌ಗಳು. 254 ಭಾಷೆಗಳು. AI ಅರೆನಾ. ಸ್ವಯಂ-ಚಿಕಿತ್ಸಕ ಏಜೆಂಟ್‌ಗಳು.

ಅನುಭವಿಸಿದ ಅಭಿವೃದ್ಧಿಕಾರರು ಇದನ್ನು ನಿರ್ಮಿಸಿದಿಲ್ಲ — ಏಕೆಂದರೆ ಅವರು "ಜಾಣ" ಎಂದು ತಿಳಿದಿದ್ದರು ಚಿತ್ರಗಳು CLI ಟರ್ಮಿನಲ್‌ಗಳಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತವೆ. ನನಗೆ ಅದು ಗೊತ್ತಿರಲಿಲ್ಲ. ಆದ್ದರಿಂದ ನಾನು ಕೇವಲ ಕೇಳಿದೆ.
