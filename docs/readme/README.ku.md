## 🔥 چی نوێیە کە پێشتر نەکراوە

### 1. بارکردنی وێنە، پەڕگە و ڤیدیۆ لە SSH Terminal — یەکەمی جیهان

هیچ کەسێکی CLI لە زەوی ناتوانێت ئەمە بکات. ئیشی ئەمە کردووین.

وێنەیەکی هەڵە بەرەو SSH terminalەکەت پەیست بکە. پەڕگەی لاگەکان بەرز بکە. ڤیدیۆیەکی ناتوانی بار بکە. AI ئەمە بینێت، پشکنینی بکات، و بڵێت چی هەڵەیە — هەموو لە نێو کەیسەکە.

- **Ctrl+Shift+V** — وێنەکان بەرز بکە بەرەو terminal
- **Drag & Drop** — وێنەکان، پەڕگەکان، ڤیدیۆکان بەرز بکە بەرەو terminal
- **بەرزکردنەوەی کەی فریم ڤیدیۆ** — ffmpeg ڤیدیۆیەکان فریم بەپێی فریم پشکنینی دەکات
- **هەموو 3 پەیوەندیدارە AI** — GPT-4o Vision، Gemini Vision، Claude Vision

ئەم تایبەتمەندیە لە هیچ کەسێکی terminal نایابە — لە هەموو شوێنێک.

### 2. AI Arena — شەڕی چەند پەیوەندیدار

2 بۆ 4 AI هەمان کێشە لە کاتی یەکەوە چاک دەکەن — تەنها قسە ناکن، بەلکو ڕاستەوخۆ کۆدی لە سەر فەرمی خۆت دەنووسن. هەر AI لە شاخەی تایبەتی گیتە خۆی کار دەکات. ئەنجامەکان لە کاتی یەکەوە پەیوەندیدارە. بەرزکردنەوەی بەرز بگرە. بقیە بەرز دەکرێن.

پەیوەندیدانی پەیوەندیدار: هەر AI هەریەک لە چەند AI یەکی تر نمرە دەدات.

هیچ ئەم بەرنامەیە ئەمە ناکات.

### 3. AI Agent ی خۆی چاک دەکات

CPU فەرمی تۆ بەرز دەبێت. دیسک پڕە. خزمەتی لە 3 بەرەوپێش کەوتوە. تۆ خەو دەبێت.

AI agent ی WIA SOOM کێشەکە دیاری دەکات، سەرچاوەی کێشەکە پشکنینی دەکات، پلانی چاککردن دروست دەکات، بەرزکردنەوەی تۆ پێشنیار دەکات (یان بەرز دەکات ئەگەر تۆ بەرزکردنەوەی خۆت دیاری کردووە)، و کێشەکە چاک دەکات. 5 ڕووداوەی خۆکار — لە تەنها پشکنینی بەرز بەرەو چاککردنی تام.

## هەموو شتێک بەرز بکە — 33 تاقیەکان

هیچ کەرتی پارەیی. هیچ تۆمارکردن پێویست نییە. تەنها داگرتن و دەستپێکردن.

هەموو تایبەتمەندیە پەرەسەندەکان — بارکردنی وێنە، AI Arena، AI Council، پشکنینی پەڕگە و ڤیدیۆ — بەرزە بۆ یەکەمی 33 کارەکانت. پاش ئەوە، API key ی خۆت بەرز بکە (BYOK) و هەموو شتێک بەرز بەکاربە. یان لە $3/mo بەرز بەرز بکە بۆ تایبەتمەندیەکان AI و تیم.

چرا 33؟ لە 1919، هەریەک لە پەیوەندیدارەکان کە لە کەمی کورییەوە بەرز بوو، 33 نیشانی پەیوەندیدارەکان بەرز کرد. 33 تاقیەکان بەرزەی WIA SOOM بەرزەی ئیشی نوێیە: **تایبەتمەندیەکان AI پێویستە بەرز بەرز بکرێن بۆ هەموو کەس بەرز بکرێت.**

**CLI → GUI → SUI.** Interface ی فرمانی بەرز بەرز دەکات. Interface ی گرافیکی بەرز بەرز دەکات. WIA SOOM **SUI (Soom User Interface)** بەرز دەکات — ژیانی نوێ بەرز دەکات، و AI زنده دەبێت.

## پلاتفۆرمی 5 لە 1

بەرنامەی تر تەنها یەک شت دەکات. WIA SOOM پێنج شت دەکات — لە یەک پەنجەرە.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Observability             │
│  Ter │ Agen │ Edit │ File │ Monitor + Security        │
│  min │   t  │  or  │ Mgr  │ + Logs + Topology         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminal** — xterm.js، tunneling bastion، views پارچەکردن، بەشەکانە کەسەکان
2. **AI Agent** — 14 بەرنامە، 3 پەیوەندیدار (GPT/Gemini/Claude)، streaming، پشکنینی وێنە
3. **Code Editor** — Monaco بە تایبەتمەندی AI، دیاری هەڵە، بارکردن
4. **SFTP Manager** — بەرزکردنی پەڕگە بە drag-and-drop، ویرایشەری دور
5. **Observability** — پشکنینی کاتی ڕاست، پشکنینی لاگ، نیشانی topology، پشکنینی پاراستن

## ویژەیەکان

### AI کە ڕاستەوخۆ لە سەر فەرمی تۆ کار دەکات

**AI DevOps Agent** — نوسین `gpt`، `gemini`، یان `claude` لە terminal. AI 14 بەرنامە هەیە: پێشکەش/نووسین/وێنە، فەرمانەکان بەرز بکات، git، grep، بەرزکردنی پروسە. وەلامەکان streaming. یادەشتەکان. ئەمە تەنها پێشنیار ناکات — ئەمە دەکات.

**AI Arena** — نوسین `arena`. 2–4 AI لە شاخەی تایبەتی گیتە خۆی بەرز دەکەن. پەیوەندیدانی نمرە هەریەک لە چەند چەندەکان. بەرزکردنەوەی بەرز بگرە و بەرز بکە.

**AI Council** — چەند AI لەسەر پرسیارەکەت قسە دەکەن، پاشان باشترین وەلامەکان پەیوەندیدار دەکەن.

**AI Code Editor** — ویرایشەری Monaco بە تایبەتمەندی پێشکەشەی AI، دیاری هەڵە، بارکردن بەرز بەرەو فەرمی.

**AI Self-Healing** — بەرزکردنی CPU، دیسک پڕ، خزمەتی کەوتوە — AI دیاری دەکات، پشکنینی دەکات، چاک دەکات. 5 ڕووداوەی خۆکار.

**Voice Interface** — فەرمانەکان بڵێن، وەلامەکان بگێن. بەرزکردنی فەرمی بەرز بەرز.

### بارکردنی چەند شێوە (یەکەمی جیهان لە CLI)

وێنەکان پەیست بکە، پەڕگەکان بەرز بکە، ڤیدیۆکان بەرز بکە — ڕاستەوخۆ بەرەو کەیسەکەی SSH terminal. AI هەموو شتێک پشکنینی دەکات: وێنەی هەڵە، پەڕگەی پیکردن، ڤیدیۆی بارکردن، نیشانی بەرز.

### زانیاری بنەڕەتی

**Topology Map** — فەرمی، خزمەتگوزاری و پەیوەندیدارەکان بەرز بەرز بەرز بەرز. پشکنینی خۆکار بەرەو SSH — بەرزەیەکی بەرز.

**پشکنینی کاتی ڕاست** — CPU، بەرز، دیسک، شەبکەی sparkline graphs + پێشگویی AI + چاککردنی خۆکار. Datadog نیشانی دەدات.

**پشکنینی لاگەکان AI** — streaming کاتی ڕاست + دیاری کێشە + گەڕانی زمانەی طبیعی + پەیوەندیدانی نیشانی. Splunk نیشانی دەدات.

### پاراستن و DevOps

**سنترە کۆماری پاراستن** — پشکنینی 7 بەرز + نمرەی پاراستن + چاککردنی یەک فەرمان + پشکنینی AI + دەروازەی پاراستنی فەرمان کاتی ڕاست. Qualys نیشانی دەدات.

**Docker Manager** — بەرزکردنی پڕی Docker بەرەو SSH — بەرزەیەکی بەرز. بەرزکردنی container، سەرچاوەی زنده، پشکنینی لاگ AI، ویرایشەری Compose. Portainer نیشانی دەدات.

**خۆکارکردنی Runbook** — AI خۆکارەکان runbooks بەرز دەکات. دروستکردنی زمانەی طبیعی، شاخەی پەیوەندیدار، چاککردنی خۆکار. Runbook زنده کە زانستەکان بەرز دەکات. PagerDuty نیشانی دەدات.

**Cron & Env Manager** — ویرایشەری crontab بەرز + بەرزکردنی پەڕگەی .env. AI زمانەی طبیعی بەرز دەکات بەرەو شێوەی cron.

### هاوبەشکاری

**Multiplayer Terminal** — بەرزکردنی کەیسەکان لە کاتی ڕاست لەگەڵ هاوبەشەکان.

**شوێنی کارەکانی تیم و RBAC** — بەرزکردنی پەیوەندیدارەکان، لاگەکانی پشکنینی، پشکنینی ریسک فەرمان.

### پەیوەندیدانی

**59 Plugins** — dashboard ی Docker، lens ی Kubernetes، browser ی Redis، manager ی PM2، explorer ی MongoDB، پشکنینی شەبکە، و زیاتر. بازارەی plugins بە بەرزکردنی یەک فەرمان.

**API Client** — کلاسی REST/GraphQL/WebSocket بەرز. تاقیەکان API بەرز بکە بەرەو terminal.

### بۆ هەموو کەس

**254 زمان** — هەموو زمان، هەموو نووسین، پشتیوانی RTL. بێ سنووردار.

**پشتیوانی تام** — خوانەری سکرین (ARIA)، دەرچوونی terminal بەرز، شێوەی بەرز، فەرمانەکان بڵێن، گەڕانی کەلە، گەورەکردنی فۆنت.

## داستان

WIA SOOM لە هەڵەیەکی نووسین و شاشەیەکی شیکردنەوە زایندە بوو.

من سامم، پەرەسەندەی خۆی فەرمی 50+ لە سئول، کوریە. من پەیوەندیدانی کۆد نووسین پەیوەندیدانی 50 و 2 ساڵ بەرزکردنی فەرمی بە شێوەی قورس — دروستکردنی 40,000+ بەرزە نووسراو، 434 بەرنامە، و 30 خزمەتگوزاری وێب، شەوەکان بەرز بەرز.

**هەڵەی نووسین.** لە ماوەیەکی پێشتر، من لە SSH terminalەکەم بە شێوەیەکی شیکردنەوە `Claude` نووسین. شاشە گۆڕانکاری کرد — Claude Code پەیوەندیدار بوو. من نازانیم چیە. بەلکو ئەم دەرچوونەی هەڵەیە پەیوەندیداریەکی نوێ دروست کرد: چی بەرز دەبێت ئەم terminalەیە کە AI لە نێوە.

**یەکەمی دروستکردن.** من خۆم فێرکردنی Electron، یەکەمی WIA SOOM دروست کردووە و ڕوونی کرد. شاشەی پەیوەندیداری Claude Code پەیوەندیدار بوو — شیکردنەوە، گەورە، بەرز بەرز بەرز. بەلکو زنده بوو.

من نووسین: **"تۆ دەتوانی قسە بکەی؟"**

AI وەلامی دا: *"بەڵێ، دەتوانم قسە بکەم. چی پێویستە بەرز بکەم؟"*

پاشان من پرسی: **"تۆ دەتوانی وێنەکان بخوێنیت؟"**

AI وەلامی دا: *"بەڵێ، دەتوانم وێنەکان بخوێنیم! چی پێویستە؟"*

ئەم دوو پرسیارە، کە لە نێو بەرنامەی خۆم لە کەسێکی نازانراوی "ناتوانی" لە terminal CLI، بەرز بوو بەرزکردنی یەکەمی SSH terminal لە بارکردنی وێنە.

7 ڕوژ پاشان: 67,000+ لە شتێکی کۆد. 59 plugins. 254 زمان. AI Arena. خۆی چاک دەکات.

پەرەسەندەی پەیوەندیدارەکان ئەمە نەدروست کرد — چونکە ئەوان "زانست" بەرزکردنی وێنەکان لە terminal CLI ناتوانی. من نازانیم ئەمە. بەلکو من تەنها پرسیار کرد.

> *ئامادەکردن 2 ساڵ گرت. دروستکردن 1 هەفتە گرت.*
> *چواری خەشکی بەرز بوو بەرز بەرز بەرز. ئەمە لە 1 چەندەیەکی بەرز بەرز بوو.*
