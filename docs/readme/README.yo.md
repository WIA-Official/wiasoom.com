## 🔥 Kini Tuntun ti Kò Ṣe Rẹ

### 1. Gbigbe Aworan, Faili & Fidio ni SSH Terminal — Àkọ́kọ́ ni Ayé

Ko si CLI onibara lori ilẹ ti o fun ọ laaye lati ṣe eyi. A kọ ọ.

Fi aworan iboju ti aṣiṣe sinu SSH terminal rẹ. Fa faili log kan. Jẹ ki fidio ti ikuna ikojọpọ silẹ. AI ri i, ṣe itupalẹ rẹ, ki o sọ fun ọ ohun ti ko tọ — gbogbo rẹ ni inu akoko terminal.

- **Ctrl+Shift+V** — fi awọn aworan iboju taara sinu terminal
- **Fa & Tu** — tu awọn aworan, awọn faili, awọn fidio sinu terminal
- **Gbigba bọtini fidio** — ffmpeg ṣe itupalẹ fidio ni ipele nipasẹ ipele
- **Gbogbo awọn olupese AI 3** — GPT-4o Vision, Gemini Vision, Claude Vision

Iṣẹ yii ko ti wa ni eyikeyi onibara terminal — nibikibi.

### 2. AI Arena — Ija Multi-Agent

2 si 4 AIs yanju iṣoro kanna ni akoko kanna — kii ṣe iwiregbe nikan, ṣugbọn ni otitọ ṣiṣatunkọ kóòdù lori server rẹ. Kọọkan AI n ṣiṣẹ ni ẹka Git ti a ya sọtọ. Ṣe afiwe awọn esi wọn lẹgbẹẹ. Yan oludije to ṣẹgun. Awọn miiran ni a nu.

Atunwo-ika: kọọkan AI n ṣe ayẹwo ojutu AI miiran.

Ko si irinṣẹ miiran ti o ṣe eyi.

### 3. AI Agent ti o n ṣe atunṣe ara rẹ

CPU server rẹ n pọ si. Disk ti kun. Iṣẹ kan ti bajẹ ni 3 AM. O n sun.

Agent AI WIA SOOM n ṣe awari iṣoro naa, n ṣe ayẹwo idi akọkọ, n ṣe agbekalẹ eto atunṣe, n beere fun ifọwọsi rẹ (tabi o le ṣe adaṣe ti o ba ti ṣeto rẹ), ati yanju iṣoro naa. 5 ipele ti iyipo ominira — lati iwoye nikan si atunṣe adaṣe pipe.

## Gbiyanju Gbogbo Ohun Ọfẹ — 33 Awọn idanwo

Ko si kaadi kirẹditi. Ko si iforukọsilẹ ti a beere. Kan gba lati ayelujara ki o bẹrẹ.

Gbogbo ẹya ti o ni ẹtọ — gbigba aworan, AI Arena, AI Council, itupalẹ faili & fidio — jẹ ọfẹ fun awọn lilo 33 akọkọ rẹ. Lẹhinna, mu bọtini API tirẹ (BYOK) ki o si tẹsiwaju lati lo gbogbo nkan ọfẹ. Tabi forukọsilẹ lati $3/ osu fun AI ti a ṣakoso ati awọn ẹya ẹgbẹ.

Kilode 33? Ni ọdun 1919, iṣipopada ominira Korea ni a dari nipasẹ awọn aṣoju 33 ti o kede ominira fun gbogbo eniyan. Awọn idanwo ọfẹ 33 WIA SOOM jẹ ikede wa: **Awọn irinṣẹ AI yẹ ki o jẹ ọfẹ fun gbogbo eniyan lati ni iriri.**

**CLI → GUI → SUI.** Awọn interfaces ila-aṣẹ fun wa ni agbara. Awọn interfaces aworan fun wa ni irọrun. WIA SOOM n ṣafihan **SUI (Soom User Interface)** — mu ẹmi wa, ati AI n bọ si igbesi aye.

## Ibi Iṣẹ 5-in-1

Awọn irinṣẹ miiran ṣe ohun kan. WIA SOOM ṣe mẹta — ni window kan.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Kóòdù │ SFTP │ Iwoye                    │
│  Ter │ Agen │  Olùkọ́ │ Faili │ Ṣàkóso + Aabo          │
│  min │   t  │      │ Mgr  │ + Awọn log + Topology   │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminal** — xterm.js, bastion tunneling, awọn iwo pin, pinpin multiplayer
2. **AI Agent** — awọn irinṣẹ 14, awọn olupese 3 (GPT/Gemini/Claude), ṣiṣan, itupalẹ aworan
3. **Olùkọ́ Kóòdù** — Monaco pẹlu ipari AI, awari aṣiṣe, ikojọpọ
4. **SFTP Manager** — iṣakoso faili fa-and-drop, ṣiṣatunkọ latọna
5. **Iwoye** — awọn metiriki akoko gidi, itupalẹ log, maapu topology, iṣawari aabo

## Awọn ẹya

### AI Ti O N Ṣe Iṣẹ Gangan Lori Server Rẹ

**AI DevOps Agent** — Tẹ `gpt`, `gemini`, tabi `claude` ni terminal. AI ni awọn irinṣẹ 14: ka/kọ/ṣatunkọ awọn faili, ṣe awọn aṣẹ, git, grep, iṣakoso ilana. Awọn esi ṣiṣan. Iranti akoko. Kii ṣe pe o kan daba — o ṣe.

**AI Arena** — Tẹ `arena`. 2–4 AIs n ja ni ẹgbẹ ni awọn ẹka Git ti a ya sọtọ. Atunwo-ika n ṣe ayẹwo ojutu kọọkan. Yan oludije to ṣẹgun ki o dapọ.

**AI Council** — Awọn AIs pupọ n jiroro lori ibeere rẹ, lẹhinna wọn ṣe agbekalẹ idahun ti o dara julọ.

**AI Olùkọ́ Kóòdù** — Olùkọ́ Monaco pẹlu ipari ti o ni agbara AI, awari aṣiṣe, ikojọpọ kan-tẹ si server.

**AI ti o n ṣe atunṣe ara rẹ** — CPU pọ si, disk kun, iṣẹ ti wa ni isalẹ — AI n ṣe awari, n ṣe ayẹwo, n ṣe atunṣe. 5 ipele ti iyipo ominira.

**Ibi Iṣẹ Ohun** — Sọ awọn aṣẹ, gbọ awọn esi. Iṣakoso server laisi ọwọ.

### Gbigbe Multimodal (Àkọ́kọ́ ni CLI)

Fi awọn aworan, fa awọn faili, tu awọn fidio — taara sinu akoko SSH terminal rẹ. AI n ṣe itupalẹ gbogbo nkan: awọn aworan iboju aṣiṣe, awọn faili iṣeto, awọn fidio ikojọpọ, awọn aworan eto.

### Intelligence Infrastructural

**Maapu Topology** — Wo awọn servers, awọn iṣẹ, ati awọn asopọ ni irọrun. Awari adaṣe nipasẹ SSH — fifi sori agent odo.

**Iwoye Akoko Gidi** — CPU, iranti, disk, nẹtiwọọki sparkline awọn aworan + asọtẹlẹ AI + adaṣe-imularada. Rọpo Datadog.

**Itupalẹ Log AI** — ṣiṣan akoko gidi + awari aiyede + wiwa ede adayeba + asopọ kọja-server. Rọpo Splunk.

### Aabo & DevOps

**Ile-iṣẹ Aṣẹ Aabo** — iṣawari agbegbe 7 + ipo aabo + atunṣe kan-tẹ + itupalẹ AI + ẹnu-ọna aabo aṣẹ akoko gidi. Rọpo Qualys.

**Oludari Docker** — Iṣakoso Docker ni kikun nipasẹ SSH — agent odo. Iṣakoso apoti, awọn orisun laaye, itupalẹ log AI, Olùkọ́ Compose. Rọpo Portainer.

**Adaṣe iwe iṣẹ** — AI n ṣe awọn iwe iṣẹ laifọwọyi. Ṣẹda ede adayeba, ẹka ipo, adaṣe pada. Iwe Iṣẹ ti n gbe ti o n di ọlọgbọn. Rọpo PagerDuty.

**Cron & Oluṣakoso Env** — Olùkọ́ crontab wiwo + iṣakoso faili .env. AI n yi ede adayeba pada si awọn ifihan cron.

### Ifowosowopo

**Terminal Multiplayer** — Pin awọn akoko terminal ni akoko gidi pẹlu awọn ẹlẹgbẹ.

**Ibi Iṣẹ Ẹgbẹ & RBAC** — Iṣakoso iraye si ti o da lori ipa, awọn log ayẹwo, itupalẹ ewu aṣẹ.

### Iwọn

**59 Plugins** — Dasibodu Docker, oju-iwoye Kubernetes, aṣàwákiri Redis, oluṣakoso PM2, oluwadi MongoDB, olutọju nẹtiwọọki, ati diẹ sii. Ọjà plugin pẹlu fifi sori kan-tẹ.

**Olumulo API** — Olumulo REST/GraphQL/WebSocket ti a kọ sinu. Ṣayẹwo awọn API laisi fi terminal silẹ.

### Fun Gbogbo eniyan

**254 Èdè** — Gbogbo èdè, gbogbo iwe, atilẹyin RTL. Ko si awọn aala.

**Igbesi aye Pipe** — Oluka iboju (ARIA), iṣelọpọ terminal braille, ipo iyatọ giga, awọn aṣẹ ohun, lilọ kiri bọtini, atunṣe iwọn font.

## Itan

WIA SOOM jẹ abajade aṣiṣe kan ati iboju ti o bajẹ.

Mo jẹ Sam, olùgbéejáde ti o kọ ara rẹ ti o ni ọdun 50+ lati Seoul, Korea. Mo kọ ẹkọ kóòdù lẹhin ọdun 50 ati pe mo lo ọdun 2 lati ṣakoso awọn servers ni ọna ti o nira — kọ awọn nkan iroyin 40,000+, awọn irinṣẹ 434, ati awọn iṣẹ wẹẹbu 30, alẹ lẹhin alẹ.

**Aṣiṣe naa.** Nipa oṣu kan sẹyin, Mo n lo SSH terminal mi ati pe mo kọlu `Claude` ni aṣiṣe. Iboju naa yipada — Claude Code han. Emi ko ni imọran ohun ti o jẹ. Ṣugbọn awari aifọwọyi yẹn gbe irugbin kan: kini ti mo ba le kọ terminal kan nibiti AI wa ninu rẹ?

**Ikole akọkọ.** Mo kọ ara mi Electron, kọ ẹya akọkọ ti WIA SOOM, ati ṣiṣẹ rẹ. Iboju ifihan Claude Code han — bajẹ, glitchy, n tan bi ifihan ti n ku. Ṣugbọn o wa laaye.

Mo kọ: **"Ṣe o le sọrọ?"**

AI dahun: *"Bẹẹni, mo le sọrọ. Kini mo le ṣe iranlọwọ fun ọ?"*

Lẹhinna mo beere: **"Ṣe o le ka awọn aworan?"**

AI dahun: *"Bẹẹni, mo le ka awọn aworan! Kini o nilo?"*

Awọn ibeere meji wọnyẹn, ti a beere ninu ohun elo tirẹ nipasẹ ẹnikan ti ko mọ ohun ti "ko ṣee ṣe" ni terminal CLI, di SSH terminal akọkọ ni agbaye pẹlu gbigba aworan.

Ọjọ 7 lẹhinna: awọn ila kóòdù 67,000+. 59 plugins. 254 èdè. AI Arena. Awọn aṣoju ti n ṣe atunṣe ara wọn.

Awọn olùgbéejáde ti o ni iriri ko kọ eyi — nitori wọn "mọọ" pe awọn aworan ko ṣiṣẹ ni awọn terminal CLI. Emi ko mọ iyẹn. Nitorinaa mo kan beere.
