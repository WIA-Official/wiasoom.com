## 🔥 從未做過的事

### 1. 在SSH終端上上傳圖片、文件和視頻 — 世界首創

地球上沒有任何CLI客戶端可以讓你這樣做。我們做到了。

將錯誤的截圖粘貼到你的SSH終端中。拖動日誌文件。放下失敗部署的視頻。AI會看到它，分析它，告訴你問題出在哪裡 — 所有這一切都在終端會話中進行。

- **Ctrl+Shift+V** — 直接將截圖粘貼到終端
- **拖放** — 將圖片、文件、視頻拖放到終端中
- **視頻關鍵幀提取** — ffmpeg逐幀分析視頻
- **所有3個AI提供者** — GPT-4o Vision, Gemini Vision, Claude Vision

這個功能在任何終端客戶端中從未存在過 — 任何地方都沒有。

### 2. AI競技場 — 多代理戰鬥

2到4個AI同時解決相同的問題 — 不僅僅是聊天，而是真正編輯你伺服器上的代碼。每個AI在自己的隔離Git分支中工作。並排比較它們的結果。選擇獲勝者。其餘的將被清理。

交叉評審：每個AI對其他AI的解決方案進行評分。

沒有其他工具可以做到這一點。

### 3. AI自我修復代理

你的伺服器CPU飆升。磁碟已滿。服務在凌晨3點崩潰。你正在睡覺。

WIA SOOM的AI代理檢測到問題，診斷根本原因，生成修復計劃，請求你的批准（如果你設置了，則自動執行），並解決問題。5級自主循環 — 從僅觀察到完全自動修復。

## 功能

### 在你的伺服器上實際運作的AI

**AI DevOps代理** — 在終端中輸入`gpt`、`gemini`或`claude`。AI擁有14個工具：讀取/寫入/編輯文件、執行命令、git、grep、進程管理。流媒體響應。會話記憶。它不僅僅是建議 — 它會執行。

**AI競技場** — 輸入`arena`。2–4個AI在隔離的Git分支上並行競爭。交叉評審為每個解決方案打分。選擇獲勝者並合併。

**AI理事會** — 多個AI討論你的問題，然後綜合出最佳答案。

**AI代碼編輯器** — Monaco編輯器，帶有AI驅動的自動補全、錯誤檢測、一鍵部署到伺服器。

**AI自我修復** — CPU飆升、磁碟已滿、服務故障 — AI檢測、診斷、修復。5級自主循環。

**語音界面** — 說出命令，聽取回應。免手操作的伺服器管理。

### 多模態上傳（CLI中的世界首創）

將圖片粘貼、拖放文件、放下視頻 — 直接進入你的SSH終端會話。AI分析所有內容：錯誤截圖、配置文件、部署視頻、架構圖。

### 基礎設施智能

**拓撲圖** — 一目了然地可視化伺服器、服務和連接。通過SSH自動發現 — 零代理安裝。

**實時可觀察性** — CPU、內存、磁碟、網絡火花線圖 + AI預測 + 自動恢復。取代Datadog。

**AI日誌分析** — 實時流媒體 + 異常檢測 + 自然語言搜索 + 跨伺服器關聯。取代Splunk。

### 安全與DevOps

**安全指揮中心** — 7區域掃描 + 安全分數 + 一鍵修復 + AI分析 + 實時命令安全閘。取代Qualys。

**Docker管理器** — 通過SSH的完整Docker管理 — 零代理。容器控制、實時資源、AI日誌分析、Compose編輯器。取代Portainer。

**運行手冊自動化** — AI自動執行運行手冊。自然語言創建、條件分支、自動回滾。智能化的運行手冊。取代PagerDuty。

**Cron和Env管理器** — 可視化cron編輯器 + .env文件管理。AI將自然語言轉換為cron表達式。

### 協作

**多人終端** — 與隊友實時共享終端會話。

**團隊工作區和RBAC** — 基於角色的訪問控制、審計日誌、命令風險分析。

### 可擴展性

**59個插件** — Docker儀表板、Kubernetes透鏡、Redis瀏覽器、PM2管理器、MongoDB探索器、網絡監控等。插件市場一鍵安裝。

**API客戶端** — 內置REST/GraphQL/WebSocket客戶端。在終端中測試API而不離開。

### 服務每個人

**254種語言** — 每種語言、每種腳本，支持RTL。沒有邊界。

**全面可及性** — 螢幕閱讀器（ARIA）、盲文終端輸出、高對比度模式、語音命令、鍵盤導航、字體大小調整。

## 故事

WIA SOOM誕生於一個打錯字和一個壞掉的螢幕。

我是Sam，一位來自韓國首爾的50歲以上自學程式設計師。我在50歲後學習編程，花了2年時間以艱難的方式管理伺服器 — 每晚建立40,000多篇新聞文章、434個工具和30個網絡服務。

**打錯字。** 大約一個月前，我在使用我的SSH終端時不小心輸入了`Claude`。螢幕改變了 — Claude Code出現了。我不知道那是什麼。但這個意外的發現種下了一個種子：如果我能建立一個AI生活在裡面的終端呢？

**第一次構建。** 我自學了Electron，建立了WIA SOOM的第一個版本，並運行它。Claude Code的介紹螢幕出現了 — 壞掉了、故障了，閃爍著像一個快要死掉的信號。但它是活的。

我輸入了：**"你能說話嗎？"**

AI回答：*"是的，我能說話。我能幫助你什麼？"*

然後我問：**"你能讀取圖片嗎？"**

AI回答：*"是的，我能讀取圖片！你需要什麼？"*

這兩個問題，都是在我自己的應用中由一個不知道CLI終端中什麼是「不可能」的人問的，成為了世界上第一個可以上傳圖片的SSH終端。

7天後：67,000多行代碼。59個插件。254種語言。AI競技場。自我修復代理。

有經驗的開發者從未建立過這個 — 因為他們「知道」圖片在CLI終端中無法運作。我不知道這一點。所以我只是問了。

> *準備花了2年。建設花了1週。*
> *枯木堆了2年。1秒鐘內著火。*
