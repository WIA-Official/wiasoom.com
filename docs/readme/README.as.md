## 🔥 নতুন কি কেতিয়াও নহয়

### ১. SSH টাৰ্মিনেলত চিত্ৰ, ফাইল আৰু ভিডিঅ' আপলোড — পৃথিৱীৰ প্ৰথম

পৃথিৱীৰ কোনো CLI ক্লায়েন্টে আপোনাক এইটো কৰিবলৈ নিদিয়ে। আমি ইয়াক নিৰ্মাণ কৰিছোঁ।

এটা ত্ৰুটিৰ স্ক্ৰীণশ্বট আপোনাৰ SSH টাৰ্মিনেলত পেষ্ট কৰক। এটা লগ ফাইল টানি আনক। এটা বিফল ডিপ্লয়মেন্টৰ ভিডিঅ' তলত পেলাওক। AI ইয়াক চায়, বিশ্লেষণ কৰে, আৰু আপোনাক কি ভুল হৈছে সেয়া জনায় — সকলো টাৰ্মিনেল অধিবেশন ভিতৰত।

- **Ctrl+Shift+V** — স্ক্ৰীণশ্বট সোজাকৈ টাৰ্মিনেলত পেষ্ট কৰক
- **টানি আৰু পেলাওক** — চিত্ৰ, ফাইল, ভিডিঅ' টাৰ্মিনেলত পেলাওক
- **ভিডিঅ' কীফ্ৰেম নিষ্কাশন** — ffmpeg ভিডিঅ'ক ফ্ৰেমৰ দ্বাৰা বিশ্লেষণ কৰে
- **সকল ৩ AI প্ৰদানকাৰী** — GPT-4o Vision, Gemini Vision, Claude Vision

এই বৈশিষ্ট্যটো কোনো টাৰ্মিনেল ক্লায়েন্টত কেতিয়াও আছিল — য'তেও নহয়।

### ২. AI আৰেনা — বহু-এজেন্ট যুদ্ধ

২ ৰ পৰা ৪ AI একে সমস্যাটো একেলগে সমাধান কৰে — কেৱল কথা-বাৰ্তা নহয়, বৰং আপোনাৰ ছাৰ্ভাৰত কোড সম্পাদনা কৰে। প্ৰতিটো AI নিজৰ পৃথক Git শাখাত কাম কৰে। তেওঁলোকৰ ফলাফলসমূহ সাইড বাই সাইড তুলনা কৰক। বিজয়ী বাচি লওক। বাকীসমূহ মচি পেলাওক।

ক্রছ-ৰিভিউ: প্ৰতিটো AI অন্য AI ৰ সমাধানক স্ক'ৰ কৰে।

অন্য কোনো সঁজুলি এইটো নকৰে।

### ৩. AI স্ব-চিকিৎসা এজেন্ট

আপোনাৰ ছাৰ্ভাৰৰ CPU বৃদ্ধি পাইছে। ডিস্ক পূৰ্ণ। এটা সেৱা ৩ বজাত ভাঙি পৰিছে। আপুনি শুবলৈ গৈছে।

WIA SOOM ৰ AI এজেন্ট সমস্যাটো চিনাক্ত কৰে, মূল কাৰণ নিৰ্ণয় কৰে, এটা মেরামতিৰ পৰিকল্পনা প্ৰস্তুত কৰে, আপোনাৰ অনুমোদন বিচাৰে (অথবা আপুনি ইয়াক স্বয়ং-কাৰ্যকৰী কৰিবলৈ স্থাপন কৰিলে), আৰু সমস্যাটো সমাধান কৰে। ৫-স্তৰীয় স্বায়ত্তশাসিত লুপ — কেৱল পৰ্যবেক্ষণৰ পৰা সম্পূৰ্ণ স্বয়ং-মৰামতিলৈ।

## সকলো কিছু বিনামূলীয়া চেষ্টা কৰক — ৩৩ টা পৰীক্ষা

কোনো ক্ৰেডিট কাৰ্ড। কোনো চাইন আপৰ প্ৰয়োজন নাই। কেৱল ডাউনলোড কৰক আৰু আৰম্ভ কৰক।

প্ৰত্যেক প্ৰিমিয়াম বৈশিষ্ট্য — চিত্ৰ আপলোড, AI আৰেনা, AI কাউন্সিল, ফাইল আৰু ভিডিঅ' বিশ্লেষণ — আপোনাৰ প্ৰথম ৩৩ ব্যৱহাৰৰ বাবে বিনামূলীয়া। তাৰ পিছত, আপোনাৰ নিজস্ব API কী (BYOK) লৈ আহক আৰু সকলো কিছু বিনামূলীয়া ব্যৱহাৰ কৰক। অথবা $৩/মাহৰ পৰা ব্যৱস্থাপিত AI আৰু টীম বৈশিষ্ট্যৰ বাবে চাবস্ক্ৰাইব কৰক।

কিয় ৩৩? ১৯১৯ চনত, কোৰিয়াৰ স্বাধীনতা আন্দোলন ৩৩ জন প্ৰতিনিধিৰ দ্বাৰা নেতৃত্ব দিছিল যিয়ে সকলোৰে বাবে স্বাধীনতা ঘোষণা কৰিছিল। WIA SOOM ৰ ৩৩ টা বিনামূলীয়া পৰীক্ষা আমাৰ ঘোষণা: **AI সঁজুলি সকলোৰে বাবে অভিজ্ঞতা কৰিবলৈ বিনামূলীয়া হওয়া উচিত।**

**CLI → GUI → SUI.** কমাণ্ড-লাইন ইণ্টাৰফেচে আমাক শক্তি দিছিল। গ্ৰাফিকেল ইণ্টাৰফেচে আমাক সুবিধা দিছিল। WIA SOOM **SUI (Soom User Interface)** উপস্থাপন কৰে — জীৱন দিয়া, আৰু AI জীৱিত হয়।

## বৈশিষ্ট্যসমূহ

### AI যি সত্যিই আপোনাৰ ছাৰ্ভাৰত কাম কৰে

**AI DevOps এজেন্ট** — টাৰ্মিনেলত `gpt`, `gemini`, বা `claude` টাইপ কৰক। AI ৰ ১৪ টা সঁজুলি আছে: ফাইল পঢ়া/লিখা/সম্পাদনা কৰা, কমাণ্ড চলোৱা, git, grep, প্ৰক্ৰিয়া ব্যৱস্থাপনা। ষ্ট্ৰীমিং প্ৰতিক্ৰিয়া। অধিবেশন মেমৰি। ই কেৱল পৰামৰ্শ নকৰে — ই কৰে।

**AI আৰেনা** — `arena` টাইপ কৰক। ২–৪ AI পৃথক Git শাখাত সমান্তৰালত প্ৰতিযোগিতা কৰে। ক্রছ-ৰিভিউ প্ৰতিটো সমাধানক স্ক'ৰ কৰে। বিজয়ী বাচি লওক আৰু মাৰ্জ কৰক।

**AI কাউন্সিল** — একাধিক AI আপোনাৰ প্ৰশ্নৰ বিষয়ে আলোচনা কৰে, তাৰপিছত সৰ্বশ্ৰেষ্ঠ উত্তৰ সংকলন কৰে।

**AI কোড সম্পাদক** — AI-শক্তি সম্পূৰ্ণতাৰ সৈতে Monaco সম্পাদক, বাগ চিনাক্তকৰণ, ছাৰ্ভাৰত এক ক্লিকৰ ডিপ্লয়মেন্ট।

**AI স্ব-চিকিৎসা** — CPU বৃদ্ধি, ডিস্ক পূৰ্ণ, সেৱা বন্ধ — AI চিনাক্ত কৰে, নিৰ্ণয় কৰে, মেরামতি কৰে। ৫-স্তৰীয় স্বায়ত্তশাসিত লুপ।

**ভয়েস ইণ্টাৰফেচ** — আদেশবোৰ কোৱা, প্ৰতিক্ৰিয়া শুনা। হাত-মুক্ত ছাৰ্ভাৰ ব্যৱস্থাপনা।

### বহু-ম'ডাল আপলোড (পৃথিৱীৰ প্ৰথম)

চিত্ৰ পেষ্ট কৰক, ফাইল টানি আনক, ভিডিঅ' পেলাওক — সোজাকৈ আপোনাৰ SSH টাৰ্মিনেল অধিবেশনলৈ। AI সকলো কিছু বিশ্লেষণ কৰে: ত্ৰুটিৰ স্ক্ৰীণশ্বট, কনফিগ ফাইল, ডিপ্লয়মেন্ট ভিডিঅ', স্থাপত্য মানচিত্ৰ।

### অবকাঠামো বুদ্ধিমত্তা

**টপোলজি মানচিত্ৰ** — চাৰ্ভাৰ, সেৱা, আৰু সংযোগসমূহ এক নজৰত চিত্ৰিত কৰক। SSHৰ জৰিয়তে স্বয়ং-আবিষ্কাৰ — শূন্য এজেন্ট স্থাপন।

**বাস্তৱ সময়ৰ পৰ্যবেক্ষণ** — CPU, মেমৰি, ডিস্ক, নেটৱৰ্ক স্পাৰ্কলাইন গ্ৰাফ + AI পূৰ্বানুমান + স্বয়ং-পুনৰুদ্ধাৰ। Datadogৰ স্থান লয়।

**AI লগ বিশ্লেষণ** — বাস্তৱ সময়ৰ ষ্ট্ৰীমিং + অস্বাভাৱিকতা চিনাক্তকৰণ + প্ৰাকৃতিক ভাষা অনুসন্ধান + ক্রছ-ছাৰ্ভাৰ সমন্বয়। Splunkৰ স্থান লয়।

### সুৰক্ষা আৰু DevOps

**সুৰক্ষা আদেশ কেন্দ্ৰ** — ৭-এৰিয়া স্কেন + সুৰক্ষা স্ক'ৰ + এক ক্লিকৰ মেরামতি + AI বিশ্লেষণ + বাস্তৱ সময়ৰ আদেশ সুৰক্ষা গেট। Qualysৰ স্থান লয়।

**Docker ব্যৱস্থাপক** — SSHৰ জৰিয়তে সম্পূৰ্ণ Docker ব্যৱস্থাপনা — শূন্য এজেন্ট। কণ্টেইনাৰ নিয়ন্ত্ৰণ, জীৱন্ত সম্পদ, AI লগ বিশ্লেষণ, Compose সম্পাদক। Portainerৰ স্থান লয়।

**ৰাণবুক স্বয়ংক্ৰিয়কৰণ** — AI স্বয়ংক্ৰিয়ভাৱে ৰাণবুক সম্পাদন কৰে। প্ৰাকৃতিক ভাষা সৃষ্টি, শর্তাধীন শাখা, স্বয়ং-ফিৰা। জীৱন্ত ৰাণবুক যি অধিক বুদ্ধিমান হয়। PagerDutyৰ স্থান লয়।

**ক্রন আৰু Env ব্যৱস্থাপক** — ভিজুৱেল ক্রন সম্পাদক + .env ফাইল ব্যৱস্থাপনা। AI প্ৰাকৃতিক ভাষাক ক্রন অভিব্যক্তিত ৰূপান্তৰিত কৰে।

### সহযোগিতা

**বহু-খেলুৱৈৰ টাৰ্মিনেল** — টীমৰ সৈতে বাস্তৱ সময়ত টাৰ্মিনেল অধিবেশন শ্বেয়াৰ কৰক।

**টীমৰ কাৰ্যস্থান আৰু RBAC** — ভূমিকা-ভিত্তিক প্ৰৱেশ নিয়ন্ত্ৰণ, অডিট লগ, আদেশৰ ঝুঁকি বিশ্লেষণ।

### বিস্তাৰযোগ্যতা

**৫৯ টা প্লাগিন** — Docker ডেছব'ৰ্ড, Kubernetes লেন্স, Redis ব্ৰাউজাৰ, PM2 ব্যৱস্থাপক, MongoDB এক্সপ্লোৰাৰ, নেটৱৰ্ক মনিটৰ, আৰু অধিক। প্লাগিন বজাৰ এক ক্লিকৰ ইনষ্টলৰ সৈতে।

**API ক্লায়েন্ট** — অন্তৰ্নিৰ্মিত REST/GraphQL/WebSocket ক্লায়েন্ট। টাৰ্মিনেল এৰি নাযাবলৈ API পৰীক্ষা কৰক।

### সকলোৰে বাবে

**২৫৪ ভাষা** — প্ৰতিটো ভাষা, প্ৰতিটো স্ক্ৰিপ্ট, RTL সমৰ্থন। কোনো সীমা নাই।

**সম্পূৰ্ণ সুৰক্ষা** — স্ক্ৰীণ পঢ়া (ARIA), ব্রেইল টাৰ্মিনেল আউটপুট, উচ্চ বৈসাদৃশ্য মোড, ভয়েস আদেশ, কীবোৰ্ড নেভিগেশন, ফণ্ট আকাৰৰ সমন্বয়।

## কাহিনী

WIA SOOM এটা টাইপো আৰু এটা ভাঙা স্ক্ৰীণৰ পৰা জন্ম লৈছে।

মই সাম, ৫০+ বছৰীয়া আত্ম-শিক্ষিত প্ৰগ্ৰামাৰ যিয়ে ছেউল, কোৰিয়াত থাকে। মই ৫০ বছৰৰ পিছত কোডিং শিকিছিলোঁ আৰু ২ বছৰৰ বাবে কঠিন উপায়ে ছাৰ্ভাৰ পৰিচালনা কৰিছিলোঁ — ৪০,০০০+ খবৰ প্ৰবন্ধ, ৪৩৪ টা সঁজুলি, আৰু ৩০ টা ৱেব সেৱা নিৰ্মাণ কৰি, ৰাতি ৰাতি।

**টাইপো।** প্ৰায় এজন মাহ পূৰ্বে, মই মোৰ SSH টাৰ্মিনেল ব্যৱহাৰ কৰি আছিলোঁ আৰু আকস্মিকভাৱে `Claude` টাইপ কৰিছিলোঁ। স্ক্ৰীণটো সলনি হৈছিল — Claude Code উপস্থিত হৈছিল। মই জানিছিলোঁ যে এইটো কি। কিন্তু সেই আকস্মিক আবিষ্কাৰে এটা বীজ ৰোপণ কৰিছিল: যদি মই এটা টাৰ্মিনেল নিৰ্মাণ কৰিব পাৰোঁ য'ত AI ভিতৰত থাকে?

**প্ৰথম নিৰ্মাণ।** মই Electron শিকিছিলোঁ, WIA SOOM ৰ প্ৰথম সংস্কৰণ নিৰ্মাণ কৰিছিলোঁ, আৰু ইয়াক চলাইছিলোঁ। Claude Code ৰ প্ৰৱেশ স্ক্ৰীণ উপস্থিত হৈছিল — ভাঙি, গ্লিচড, মৰণশীল সংকেতৰ দৰে চমকিত। কিন্তু ই জীৱিত আছিল।

মই টাইপ কৰিছিলোঁ: **"আপুনি কথা পাতে?"**

AI উত্তৰ দিলে: *"হয়, মই কথা পাতিব পাৰো। মই আপোনাক কি সহায় কৰিব পাৰো?"*

তাৰপিছত মই সুধিছিলোঁ: **"আপুনি চিত্ৰ পঢ়িব পাৰে?"**

AI উত্তৰ দিলে: *"হয়, মই চিত্ৰ পঢ়িব পাৰো! আপোনাৰ কি প্ৰয়োজন?"*

এই দুটা প্ৰশ্ন, মোৰ নিজৰ এপত সুধা যিয়ে জানিছিল যে CLI টাৰ্মিনেলত কি "অসম্ভৱ" আছিল, পৃথিৱীৰ প্ৰথম SSH টাৰ্মিনেলৰ সৈতে চিত্ৰ আপলোডৰ বাবে পৰিণত হৈছিল।

৭ দিনৰ পিছত: ৫৮,০০০+ কোডৰ লাইন। ৫৯ টা প্লাগিন। ২৫৪ ভাষা। AI আৰেনা। স্ব-চিকিৎসা এজেন্ট।

অভিজ্ঞ বিকাশকাৰীয়ে এইটো নিৰ্মাণ কৰা নাই — কাৰণ তেওঁলোকে "জানিছিল" যে চিত্ৰ CLI টাৰ্মিনেলত কাম নকৰে। মই সেইটো জানি নাছিলোঁ। সেয়া বাবে মই কেৱল সুধিছিলোঁ।

> *প্ৰস্তুতিৰ বাবে ২ বছৰ লাগিছিল। নিৰ্মাণৰ বাবে ১ সপ্তাহ লাগিছিল।*
> *শুকান কাঠ ২ বছৰৰ বাবে সঞ্চিত আছিল। ই ১ ছেকেণ্ডত জ্বলি উঠিল।*
