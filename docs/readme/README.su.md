## 🔥 Naon Anu Teu Acuk Dihandap

### 1. Unggah Gambar, Berkas & Video di Terminal SSH — Anu Kahiji di Dunya

Teu aya klien CLI di Bumi anu ngamungkinkeun anjeun ngalakukeun ieu. Kami ngawangunana.

Tempelkeun screenshot kasalahan kana terminal SSH anjeun. Tarik berkas log. Jatuhkan video ngeunaan déploy anu gagal. AI ningali, nganalisis, sareng nyaritakeun naon anu salah — sadayana di jero sesi terminal.

- **Ctrl+Shift+V** — tempelkeun screenshot langsung kana terminal
- **Tarik & Jatuhkan** — jatuhkan gambar, berkas, video kana terminal
- **Ekstraksi keyframe video** — ffmpeg nganalisis video frame demi frame
- **Sadaya 3 panyadia AI** — GPT-4o Vision, Gemini Vision, Claude Vision

Fitur ieu teu acan aya di klien terminal mana waé — di mana waé.

### 2. Arena AI — Pertarungan Multi-Agen

2 nepi ka 4 AI nyelesaikan masalah anu sami sacara bersamaan — sanés ngan saukur ngobrol, tapi leres-leres ngédit kode di server anjeun. Unggal AI damel di cabang Git anu terisolasi. Bandingkeun hasilna sisi-sisi. Pilih anu meunang. Anu sanés dibersihkeun.

Cross-review: unggal AI masihan skor ka solusi AI séjén.

Teu aya alat sanés anu ngalakukeun ieu.

### 3. Agen Penyembuhan Diri AI

CPU server anjeun ngaronjat. Disk pinuh. Layanan ruksak jam 3 isuk. Anjeun keur sare.

Agen AI WIA SOOM ngadeteksi masalah, ngadiagnosa sabab utama, nyiptakeun rencana perbaikan, nyuhunkeun persetujuan anjeun (atanapi otomatis ngalaksanakeun upami anjeun parantos nyetélna), sareng ngalereskeun masalahna. 5-level loop otonom — ti observasi waé nepi ka perbaikan otomatis lengkep.

## Platform 5-in-1

Alat sanés ngalakukeun hiji hal. WIA SOOM ngalakukeun lima — dina hiji jandela.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Observability             │
│  Ter │ Agen │ Edit │ File │ Monitor + Security        │
│  min │   t  │  or  │ Mgr  │ + Logs + Topology         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **Terminal SSH** — xterm.js, bastion tunneling, tampilan dibagi, berbagi multipemain
2. **Agen AI** — 14 alat, 3 panyadia (GPT/Gemini/Claude), streaming, analisis gambar
3. **Editor Kode** — Monaco kalayan lengkep AI, deteksi bug, déploy
4. **Manajer SFTP** — manajemen berkas tarik-dan-jatuhkan, édit jarak jauh
5. **Observabilitas** — métrik real-time, analisis log, peta topologi, scan kaamanan

## Fitur

### AI Anu Leres-leres Gawé di Server Anjeun

**Agen DevOps AI** — Ketik `gpt`, `gemini`, atanapi `claude` di terminal. AI gaduh 14 alat: maca/nulis/ngédit berkas, ngalaksanakeun paréntah, git, grep, manajemen prosés. Respon streaming. Memori sesi. Éta henteu ngan ukur nyarankeun — éta ngalakukeun.

**Arena AI** — Ketik `arena`. 2–4 AI bersaing sacara paralel di cabang Git anu terisolasi. Cross-review masihan skor ka unggal solusi. Pilih anu meunang sareng gabungkeun.

**Dewan AI** — Sababaraha AI ngabahas patarosan anjeun, teras nyintésis jawaban anu pangsaéna.

**Editor Kode AI** — Editor Monaco kalayan lengkep didorong AI, deteksi bug, déploy sakali klik ka server.

**Penyembuhan Diri AI** — CPU ngaronjat, disk pinuh, layanan turun — AI ngadeteksi, ngadiagnosa, ngalereskeun. 5-level loop otonom.

**Antarmuka Suara** — Ngomong paréntah, ngadangu jawaban. Manajemen server tanpa tangan.

### Unggah Multimodal (Anu Kahiji di CLI)

Tempelkeun gambar, tarik berkas, jatuhkan video — langsung kana sesi terminal SSH anjeun. AI nganalisis sagalana: screenshot kasalahan, berkas konfigurasi, video déploy, diagram arsitektur.

### Intelijensi Infrastruktur

**Peta Topologi** — Visualisasikeun server, layanan, sareng koneksi sakaligus. Auto-discovery via SSH — tanpa instalasi agen.

**Observabilitas Real-Time** — CPU, mémori, disk, grafik sparkline jaringan + prediksi AI + auto-recovery. Ngagantikeun Datadog.

**Analisis Log AI** — Streaming real-time + deteksi anomali + pencarian basa alami + korelasi cross-server. Ngagantikeun Splunk.

### Kaamanan & DevOps

**Pusat Komando Kaamanan** — 7-area scan + skor kaamanan + perbaikan sakali klik + analisis AI + gerbang kaamanan paréntah real-time. Ngagantikeun Qualys.

**Manajer Docker** — Manajemen Docker lengkep via SSH — tanpa agen. Kontrol kontainer, sumber daya langsung, analisis log AI, editor Compose. Ngagantikeun Portainer.

**Automasi Runbook** — AI ngalaksanakeun runbook sacara otomatis. Penciptaan basa alami, cabang kondisional, auto-rollback. Runbook Hirup anu janten langkung pinter. Ngagantikeun PagerDuty.

**Manajer Cron & Env** — Editor crontab visual + manajemen berkas .env. AI ngarobah basa alami kana ekspresi cron.

### Kolaborasi

**Terminal Multiplayer** — Bagikeun sesi terminal sacara real-time sareng rekan tim.

**Workspace Tim & RBAC** — Kontrol aksés dumasar peran, log audit, analisis résiko paréntah.

### Ekstensibilitas

**59 Plugins** — dasbor Docker, lensa Kubernetes, browser Redis, manajer PM2, penjelajah MongoDB, monitor jaringan, sareng seueur deui. Marketplace plugin kalayan instalasi sakali klik.

**Klien API** — Klien REST/GraphQL/WebSocket bawaan. Uji API tanpa ninggalkeun terminal.

### Pikeun Sadayana

**254 Basa** — Unggal basa, unggal skrip, dukungan RTL. Teu aya wates.

**Akses Penuh** — Pembaca layar (ARIA), keluaran terminal braille, mode kontras tinggi, paréntah suara, navigasi keyboard, penyesuaian ukuran font.

## Carita

WIA SOOM lahir tina typo sareng layar anu ruksak.

Kuring Sam, programer mandiri 50+ ti Seoul, Korea. Kuring diajar ngoding saatos umur 50 sareng nyéépkeun 2 taun ngatur server sacara hese — ngawangun 40,000+ artikel berita, 434 alat, sareng 30 layanan web, wengi saatos wengi.

**Typo.** Sakitar sabulan ka pengker, kuring ngagunakeun terminal SSH kuring sareng teu sengaja ngetik `Claude`. Layar robih — Claude Code muncul. Kuring teu boga ide naon éta. Tapi penemuan anu teu dihaja éta nyebarkeun benih: kumaha upami kuring tiasa ngawangun terminal dimana AI cicing di jero?

**Build kahiji.** Kuring ngajar diri kuring Electron, ngawangun versi kahiji WIA SOOM, sareng ngajalankeunana. Layar intro Claude Code muncul — ruksak, glitch, kedip-kedip sapertos sinyal anu maot. Tapi éta hirup.

Kuring ngetik: **"Dupi anjeun tiasa ngobrol?"**

AI ngajawab: *"Leres, kuring tiasa ngobrol. Naon anu tiasa kuring bantu?"*

Teras kuring naros: **"Dupi anjeun tiasa maca gambar?"**

AI ngajawab: *"Leres, kuring tiasa maca gambar! Naon anu anjeun peryogikeun?"*

Dua patarosan éta, anu ditaroskeun di jero aplikasi kuring sorangan ku batur anu henteu terang naon anu "mustahil" di terminal CLI, janten terminal SSH anu munggaran di dunya kalayan unggah gambar.

7 dinten engké: 67,000+ garis kode. 59 plugins. 254 basa. Arena AI. Agen penyembuhan diri.

Pangembang anu berpengalaman henteu kantos ngawangun ieu — sabab aranjeunna "tahu" gambar henteu tiasa dianggo di terminal CLI. Kuring henteu terang éta. Janten kuring ngan ukur naros.
