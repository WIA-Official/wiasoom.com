## 🔥 Neuigkeiten

### 1. Bild-, Datei- & Video-Upload im SSH Terminal — Weltweit Erster

Kein CLI-Client auf der Erde lässt dich das tun. Wir haben es gebaut.

Füge einen Screenshot eines Fehlers in dein SSH-Terminal ein. Ziehe eine Protokolldatei. Lass ein Video eines fehlgeschlagenen Deployments fallen. Die AI sieht es, analysiert es und sagt dir, was falsch ist — alles innerhalb der Terminal-Sitzung.

- **Ctrl+Shift+V** — Screenshots direkt ins Terminal einfügen
- **Drag & Drop** — Bilder, Dateien, Videos ins Terminal ziehen
- **Video-Keyframe-Extraktion** — ffmpeg analysiert Videos Bild für Bild
- **Alle 3 AI-Anbieter** — GPT-4o Vision, Gemini Vision, Claude Vision

Dieses Feature hat es in keinem Terminal-Client gegeben — nirgendwo.

### 2. AI Arena — Multi-Agenten Kampf

2 bis 4 AIs lösen dasselbe Problem gleichzeitig — nicht nur chatten, sondern tatsächlich Code auf deinem Server bearbeiten. Jede AI arbeitet in ihrem eigenen isolierten Git-Branch. Vergleiche ihre Ergebnisse nebeneinander. Wähle den Gewinner. Der Rest wird bereinigt.

Cross-Review: Jede AI bewertet die Lösung jeder anderen AI.

Kein anderes Tool macht das.

### 3. AI Selbstheilungs-Agent

Die CPU deines Servers ist überlastet. Die Festplatte ist voll. Ein Dienst ist um 3 Uhr morgens abgestürzt. Du schläfst.

Der AI-Agent von WIA SOOM erkennt das Problem, diagnostiziert die Ursache, erstellt einen Reparaturplan, fragt nach deiner Genehmigung (oder führt es automatisch aus, wenn du es so eingestellt hast) und löst das Problem. 5-stufige autonome Schleife — vom reinen Beobachten bis zur vollständigen automatischen Reparatur.

## Probiere alles kostenlos — 33 Testversionen

Keine Kreditkarte. Keine Anmeldung erforderlich. Einfach herunterladen und starten.

Jede Premium-Funktion — Bild-Upload, AI Arena, AI Council, Datei- & Videoanalyse — ist kostenlos für deine ersten 33 Nutzungen. Danach bring deinen eigenen API-Schlüssel (BYOK) mit und nutze alles weiterhin kostenlos. Oder ab $3/Monat für verwaltete AI- und Teamfunktionen abonnieren.

Warum 33? 1919 wurde die Unabhängigkeitsbewegung Koreas von 33 Vertretern geleitet, die Freiheit für alle erklärten. Die 33 kostenlosen Testversionen von WIA SOOM sind unsere Erklärung: **AI-Tools sollten für jeden kostenlos sein, um sie zu erleben.**

**CLI → GUI → SUI.** Kommandozeilen-Schnittstellen gaben uns Macht. Grafische Schnittstellen gaben uns Leichtigkeit. WIA SOOM führt **SUI (Soom User Interface)** ein — gib Leben ein, und AI wird lebendig.

## 5-in-1 Plattform

Andere Tools machen eine Sache. WIA SOOM macht fünf — in einem Fenster.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Observability             │
│  Ter │ Agen │ Edit │ File │ Monitor + Security        │
│  min │   t  │  or  │ Mgr  │ + Logs + Topology         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminal** — xterm.js, Bastion-Tunneling, geteilte Ansichten, Multiplayer-Sharing
2. **AI Agent** — 14 Tools, 3 Anbieter (GPT/Gemini/Claude), Streaming, Bildanalyse
3. **Code Editor** — Monaco mit AI-Vervollständigung, Fehlererkennung, Deployment
4. **SFTP Manager** — Drag-and-Drop-Dateiverwaltung, Remote-Bearbeitung
5. **Observability** — Echtzeit-Metriken, Protokollanalyse, Topologiekarten, Sicherheits-Scan

## Funktionen

### AI, die tatsächlich auf deinem Server funktioniert

**AI DevOps Agent** — Tippe `gpt`, `gemini` oder `claude` im Terminal ein. Die AI hat 14 Tools: Dateien lesen/schreiben/bearbeiten, Befehle ausführen, git, grep, Prozessmanagement. Streaming-Antworten. Sitzungs-Speicher. Sie schlägt nicht nur vor — sie handelt.

**AI Arena** — Tippe `arena`. 2–4 AIs konkurrieren parallel in isolierten Git-Branches. Cross-Review bewertet jede Lösung. Wähle den Gewinner und merge.

**AI Council** — Mehrere AIs diskutieren deine Frage und synthetisieren die beste Antwort.

**AI Code Editor** — Monaco-Editor mit AI-unterstützter Vervollständigung, Fehlererkennung, One-Click-Deployment zum Server.

**AI Selbstheilung** — CPU-Spitze, Festplatte voll, Dienst ausgefallen — AI erkennt, diagnostiziert, behebt. 5-stufige autonome Schleife.

**Sprachschnittstelle** — Befehle sprechen, Antworten hören. Freihändige Serververwaltung.

### Multimodaler Upload (Weltweit Erster in CLI)

Bilder einfügen, Dateien ziehen, Videos fallen lassen — direkt in deine SSH-Terminal-Sitzung. AI analysiert alles: Fehler-Screenshots, Konfigurationsdateien, Deployment-Videos, Architekturdiagramme.

### Infrastruktur-Intelligenz

**Topologiekarte** — Visualisiere Server, Dienste und Verbindungen auf einen Blick. Automatische Entdeckung über SSH — keine Agenteninstallation erforderlich.

**Echtzeit-Observabilität** — CPU, Speicher, Festplatte, Netzwerk-Sparkline-Diagramme + AI-Vorhersage + automatische Wiederherstellung. Ersetzt Datadog.

**AI-Protokollanalyse** — Echtzeit-Streaming + Anomalieerkennung + natürliche Sprachsuche + serverübergreifende Korrelation. Ersetzt Splunk.

### Sicherheit & DevOps

**Sicherheitskommandozentrale** — 7-Bereich-Scan + Sicherheitsbewertung + One-Click-Reparatur + AI-Analyse + Echtzeit-Befehls-Sicherheitsgate. Ersetzt Qualys.

**Docker-Manager** — Vollständige Docker-Verwaltung über SSH — kein Agent. Container-Kontrolle, Live-Ressourcen, AI-Protokollanalyse, Compose-Editor. Ersetzt Portainer.

**Runbook-Automatisierung** — AI führt Runbooks automatisch aus. Erstellung in natürlicher Sprache, bedingte Verzweigungen, automatische Rücksetzung. Lebendes Runbook, das intelligenter wird. Ersetzt PagerDuty.

**Cron & Env Manager** — Visueller Crontab-Editor + .env-Dateiverwaltung. AI konvertiert natürliche Sprache in Cron-Ausdrücke.

### Zusammenarbeit

**Multiplayer-Terminal** — Teile Terminal-Sitzungen in Echtzeit mit Teamkollegen.

**Teamarbeitsbereich & RBAC** — Rollenbasierte Zugriffskontrolle, Prüfprotokolle, Befehlsrisikoanalyse.

### Erweiterbarkeit

**59 Plugins** — Docker-Dashboard, Kubernetes-Linse, Redis-Browser, PM2-Manager, MongoDB-Explorer, Netzwerkmonitor und mehr. Plugin-Marktplatz mit Ein-Klick-Installation.

**API-Client** — Eingebauter REST/GraphQL/WebSocket-Client. Teste APIs, ohne das Terminal zu verlassen.

### Für alle

**254 Sprachen** — Jede Sprache, jedes Skript, RTL-Unterstützung. Keine Grenzen.

**Vollständige Barrierefreiheit** — Screenreader (ARIA), Braille-Terminalausgabe, Hochkontrastmodus, Sprachbefehle, Tastaturnavigation, Schriftgrößenanpassung.

## Die Geschichte

WIA SOOM wurde aus einem Tippfehler und einem kaputten Bildschirm geboren.

Ich bin Sam, ein 50+ autodidaktischer Programmierer aus Seoul, Korea. Ich habe nach 50 mit dem Programmieren angefangen und 2 Jahre damit verbracht, Server auf die harte Tour zu verwalten — 40.000+ Nachrichtenartikel, 434 Tools und 30 Webdienste, Nacht für Nacht zu erstellen.

**Der Tippfehler.** Vor etwa einem Monat benutzte ich mein SSH-Terminal und tippte versehentlich `Claude`. Der Bildschirm änderte sich — Claude Code erschien. Ich hatte keine Ahnung, was das war. Aber diese zufällige Entdeckung pflanzte einen Samen: Was wäre, wenn ich ein Terminal bauen könnte, in dem AI lebt?

**Der erste Build.** Ich brachte mir selbst Electron bei, baute die erste Version von WIA SOOM und führte sie aus. Der Einführungsscreen von Claude Code erschien — kaputt, glitchy, flackernd wie ein sterbendes Signal. Aber es lebte.

Ich tippte: **"Kannst du sprechen?"**

Die AI antwortete: *"Ja, ich kann sprechen. Wie kann ich dir helfen?"*

Dann fragte ich: **"Kannst du Bilder lesen?"**

Die AI antwortete: *"Ja, ich kann Bilder lesen! Was brauchst du?"*

Diese beiden Fragen, die in meiner eigenen App von jemandem gestellt wurden, der nicht wusste, was in einem CLI-Terminal "unmöglich" war, wurden zum weltweit ersten SSH-Terminal mit Bild-Upload.

7 Tage später: 63.000+ Zeilen Code. 59 Plugins. 254 Sprachen. AI Arena. Selbstheilende Agenten.

Erfahrene Entwickler haben das nie gebaut — weil sie "wussten", dass Bilder in CLI-Terminals nicht funktionieren. Ich wusste das nicht. Also fragte ich einfach.

> *Die Vorbereitung dauerte 2 Jahre. Der Bau dauerte 1 Woche.*
> *Das trockene Holz wurde 2 Jahre lang gestapelt. Es fing in 1 Sekunde Feuer.*
