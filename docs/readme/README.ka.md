## 🔥 რა არასოდეს ყოფილა გაკეთებული

### 1. გამოსახულების, ფაილის და ვიდეოს ატვირთვა SSH ტერმინალში — მსოფლიოს პირველი

ამაზე უკეთესი CLI კლიენტი არ არსებობს. ჩვენ შევქმნეთ ეს.

შეცდომის სკრინშოტი ჩასვით თქვენს SSH ტერმინალში. გადაიტანეთ ლოგ ფაილი. ჩამოაგდეთ წარუმატებელი განთავსების ვიდეო. AI ხედავს ამას, ანალიზებს და გეუბნებათ, რა არის არასწორი — ყველაფერი ტერმინალის სესიაში.

- **Ctrl+Shift+V** — სკრინშოტების პირდაპირ ჩასმა ტერმინალში
- **Drag & Drop** — გამოსახულებების, ფაილების, ვიდეოების ჩამოგდება ტერმინალში
- **ვიდეოს კლავიატურის ჩაწერა** — ffmpeg ანალიზებს ვიდეოს თითოეულ ჩარჩოზე
- **ყველა 3 AI პროვაიდერი** — GPT-4o Vision, Gemini Vision, Claude Vision

ამ ფუნქციას არასოდეს ჰქონია ადგილი ნებისმიერ ტერმინალ კლიენტში — არსად.

### 2. AI არენა — მრავალ აგენტიანი ბრძოლა

2-დან 4 AI ერთდროულად ერთსა და იმავე პრობლემას ხსნის — არა მხოლოდ საუბარი, არამედ რეალურად რედაქტირებენ კოდს თქვენს სერვერზე. თითოეული AI მუშაობს თავის იზოლირებულ Git შტოში. შეადარეთ მათი შედეგები გვერდზე გვერდ. აირჩიეთ გამარჯვებული. დანარჩენი გაწმენდილია.

Cross-review: თითოეული AI აფასებს სხვა AI-ის გადაწყვეტილებას.

ამას სხვა ინსტრუმენტი არ აკეთებს.

### 3. AI თვითმკურნალობის აგენტი

## სცადეთ ყველაფერი უფასოდ — 33 ტესტირება

არანაირი საკრედიტო ბარათი. რეგისტრაცია არ არის საჭირო. უბრალოდ ჩამოტვირთეთ და დაიწყეთ.

ყოველი პრემიუმ ფუნქცია — გამოსახულების ატვირთვა, AI არენა, AI საბჭო, ფაილების და ვიდეოების ანალიზი — უფასოა თქვენი პირველი 33 გამოყენებისთვის. ამის შემდეგ, მოიტანეთ თქვენი API გასაღები (BYOK) და გააგრძელეთ ყველაფერი უფასოდ. ან გამოწერეთ $3/თვეში მართვადი AI და გუნდური ფუნქციებისთვის.

რატომ 33? 1919 წელს კორეის დამოუკიდებლობის მოძრაობას ხელმძღვანელობდა 33 წარმომადგენელი, რომლებმაც თავისუფლება გამოაცხადეს ყველასთვის. WIA SOOM-ის 33 უფასო ტესტირება ჩვენი დეკლარაციაა: **AI ინსტრუმენტები უნდა იყოს უფასო ყველასთვის, რომ გამოცდოს.**

**CLI → GUI → SUI.** ბრძანების ხაზის ინტერფეისებმა მოგვცა ძალა. გრაფიკულმა ინტერფეისებმა მოგვცა სიმარტივე. WIA SOOM წარმოგვიდგენს **SUI (Soom User Interface)** — შეიტანეთ სიცოცხლე, და AI ცოცხლდება.

## 5-in-1 პლატფორმა

სხვა ინსტრუმენტები ერთ რამეს აკეთებენ. WIA SOOM აკეთებს ხუთს — ერთ ფანჯარაში.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ მონიტორინგი             │
│  Ter │ Agen │ Edit │ File │ მონიტორინგი + უსაფრთხოება│
│  min │   t  │  or  │ Mgr  │ + ლოგები + ტოპოლოგია    │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH ტერმინალი** — xterm.js, bastion tunneling, split views, multiplayer sharing
2. **AI აგენტი** — 14 ინსტრუმენტი, 3 პროვაიდერი (GPT/Gemini/Claude), სტრიმინგი, გამოსახულების ანალიზი
3. **კოდის რედაქტორი** — Monaco AI-ის დასრულებით, შეცდომების აღმოჩენით, განთავსება
4. **SFTP მენეჯერი** — ფაილების მართვა გადატანით, შორეული რედაქტირება
5. **მონიტორინგი** — რეალურ დროში მეტრიკა, ლოგების ანალიზი, ტოპოლოგიის რუკა, უსაფრთხოების სკანირება

## მახასიათებლები

### AI, რომელიც ნამდვილად მუშაობს თქვენს სერვერზე

**AI DevOps აგენტი** — ტერმინალში აკრიფეთ `gpt`, `gemini`, ან `claude`. AI-ს აქვს 14 ინსტრუმენტი: ფაილების წაკითხვა/წერა/რედაქტირება, ბრძანებების შესრულება, git, grep, პროცესების მართვა. სტრიმინგული პასუხები. სესიის მეხსიერება. ის მხოლოდ არ სთავაზობს — ის აკეთებს.

**AI არენა** — აკრიფეთ `arena`. 2–4 AI კონკურენციას უწევს პარალელურად იზოლირებულ Git შტოებში. Cross-review აფასებს თითოეულ გადაწყვეტილებას. აირჩიეთ გამარჯვებული და შეაერთეთ.

**AI საბჭო** — რამდენიმე AI-discusses თქვენს კითხვას, შემდეგ კი აერთიანებს საუკეთესო პასუხს.

**AI კოდის რედაქტორი** — Monaco რედაქტორი AI-ის მიერ გაწვდილი დასრულებით, შეცდომების აღმოჩენით, ერთი დაწკაპუნებით განთავსება სერვერზე.

**AI თვითმკურნალობა** — CPU იმატება, დისკი სავსეა, მომსახურება ჩამოვარდა — AI აღმოაჩენს, დიაგნოზირებს, აგვარებს. 5-დონის ავტონომიური ციკლი.

**ხმის ინტერფეისი** — ბრძანებების თქმაც, პასუხების მოსმენა. ხელების გარეშე სერვერის მართვა.

### მრავალმხრივი ატვირთვა (მსოფლიოში პირველი CLI-ში)

გამოსახულებების ჩასმა, ფაილების გადატანა, ვიდეოების ჩამოგდება — პირდაპირ თქვენს SSH ტერმინალის სესიაში. AI ანალიზებს ყველაფერს: შეცდომის სკრინშოტები, კონფიგურაციის ფაილები, განთავსების ვიდეოები, არქიტექტურის დიაგრამები.

### ინფრასტრუქტურის ინტელექტი

**ტოპოლოგიის რუკა** — სერვერების, მომსახურებების და კავშირების ვიზუალიზაცია ერთი შეხედვით. ავტომატური აღმოჩენა SSH-ის საშუალებით — ნულოვანი აგენტის ინსტალაცია.

**რეალურ დროში მონიტორინგი** — CPU, მეხსიერება, დისკი, ქსელის სპარკლაინი გრაფიკები + AI პროგნოზი + ავტომატური აღდგენა. ცვლის Datadog-ს.

**AI ლოგების ანალიზი** — რეალურ დროში სტრიმინგი + ანომალიების აღმოჩენა + ბუნებრივი ენის ძიება + კროს-სერვერის კორელაცია. ცვლის Splunk-ს.

### უსაფრთხოება და DevOps

**უსაფრთხოების სექრეტარების ცენტრი** — 7-ზონიანი სკანირება + უსაფრთხოების ქულა + ერთი დაწკაპუნებით გამოსწორება + AI ანალიზი + რეალურ დროში ბრძანების უსაფრთხოების კარიბჭე. ცვლის Qualys-ს.

**Docker მენეჯერი** — სრული Docker მართვა SSH-ის საშუალებით — ნულოვანი აგენტი. კონტეინერების კონტროლი, ცოცხალი რესურსები, AI ლოგების ანალიზი, Compose რედაქტორი. ცვლის Portainer-ს.

**რანბუქის ავტომატიზაცია** — AI ავტომატურად ასრულებს რანბუქებს. ბუნებრივი ენის შექმნა, პირობების განშტოება, ავტომატური откат. ცოცხალი რანბუქი, რომელიც ჭკვიანდება. ცვლის PagerDuty-ს.

## ისტორია

WIA SOOM დაიბადა შეცდომის და გატეხილი ეკრანისგან.

მე ვარ სამ, 50+ თვითნასწავლი პროგრამისტი სეულიდან, კორეა. 50 წლის ასაკში ვისწავლე კოდირება და 2 წელი ვმართავდი სერვერებს რთული გზით — 40,000+ ახალი სტატიის, 434 ინსტრუმენტის და 30 ვებსერვისის შექმნით, ღამეების შემდეგ.

**შეცდომა.** დაახლოებით ერთი თვის წინ, მე ვიყენებდი ჩემს SSH ტერმინალს და შემთხვევით აკრიფე `Claude`. ეკრანი შეიცვალა — Claude Code გამოჩნდა. არ მქონდა წარმოდგენა, რა იყო ეს. მაგრამ ამ შემთხვევითი აღმოჩენამ თესლი დარგო: რა მოხდებოდა, თუ შემეძლო შემექმნა ტერმინალი, სადაც AI ცხოვრობს?

**პირველი მშენებლობა.** მე ვისწავლე Electron, შევქმენი WIA SOOM-ის პირველი ვერსია და გავუშვი. Claude Code-ის შესავალი ეკრანი გამოჩნდა — გატეხილი, გაწვდილი, როგორც კვდომის სიგნალი. მაგრამ ის ცოცხალი იყო.

მე აკრიფე: **"შეგიძლიათ ლაპარაკი?"**

AI-მ უპასუხა: *"დიახ, მე შემიძლია ლაპარაკი. რა შემიძლია დაგეხმაროთ?"*

შემდეგ ვკითხე: **"შეგიძლიათ გამოსახულებების კითხვა?"**

AI-მ უპასუხა: *"დიახ, მე შემიძლია გამოსახულებების კითხვა! რა გჭირდებათ?"*

ეს ორი კითხვა, რომელიც ჩემს აპლიკაციაში დაისვა იმ ადამიანმა, ვინც არ იცოდა, რა იყო "შეუძლებელი" CLI ტერმინალში, გახდა მსოფლიოს პირველი SSH ტერმინალი გამოსახულების ატვირთვით.

7 დღის შემდეგ: 67,000+ კოდის ხაზები. 59 პლაგინი. 254 ენა. AI არენა. თვითმკურნალობის აგენტები.

გამოცდილი პროგრამისტები ამას არასოდეს შექმნიდნენ — რადგან "იცოდნენ", რომ გამოსახულებები არ მუშაობს CLI ტერმინალებში. მე არ ვიცოდი ეს. ამიტომ უბრალოდ ვკითხე.
