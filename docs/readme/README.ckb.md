## 🔥 چی نوێیە کە پێشتر نەکراوە

### 1. بارکردنی وێنە، فایل و ڤیدیۆ لە SSH Terminal — یەکەمی جیهان

هیچ CLI client لە زەویەکەوە ئەمە ناتوانێت بکات. ئیشی ئەمە کردووین.

وێنەیەکی هەڵە بەرەو SSH terminalەکەت بچە. فایلی تۆمار بکە. ڤیدیۆیەکی نیشانی ناتوانی بار بکە. AI ئەمە بینێت، پشکنینی بکات، و بڵێت چی هەڵەیە — هەموو لە ناو کەشەی terminalەکە.

- **Ctrl+Shift+V** — وێنەکان بە شێوەیەکی راستەوخۆ بەرەو terminal بچە
- **Drag & Drop** — وێنەکان، فایلەکان، ڤیدیۆکان بەرەو terminal بچە
- **بەرزکردنەوەی کەی فریم ڤیدیۆ** — ffmpeg ڤیدیۆیەکان فریم بە فریم پشکنینی دەکات
- **هەموو 3 پێشکەشکەری AI** — GPT-4o Vision, Gemini Vision, Claude Vision

ئەم تایبەتمەندیە لە هیچ کەشەی terminal clientەکی تر نەبووە — لە هەموو شوێن.

### 2. AI Arena — شەڕی چەند ئەژەندە

2 بۆ 4 AI کەشەیەکی یەکسان لە کاتی یەکەوە چاک دەکەن — تەنها گۆڤار ناکەن، بەڵکو ڕاستەوخۆ کۆدی سەرڤەرەکەت چاک دەکەن. هەر AI لە شاخەی Git تایبەتی خۆی کار دەکات. ئەنجامەکان لە لایەنەکان بە شێوەیەکی پەیوەندیدار پشکنینی دەکرێت. فەرمی بەرزە. بقیە پاک دەکرێت.

پشکنینی پارە: هەر AI هەریەکی ئەنجامی AI یەکی تر نمرە دەدات.

هیچ ئەم بەرنامەیە تەنها ئەمە ناکات.

### 3. AI Self-Healing Agent

CPU ی سەرڤەرەکەت بەرز دەبێت. دیسک پڕە. خزمەتی لە کاتی 3 ب.ن. بەرز بوو. تۆ خەویدا.

AI agent ی WIA SOOM کێشەکە پشکنینی دەکات، سەرچاوەی کێشەکە دیاری دەکات، پلانی چاککردن دروست دەکات، بەرەوپێش پەسندکردنی تۆ (یەکەیە لەوەی کە تۆ دیاری کردووە)، و کێشەکە چاک دەکات. 5-پەیوەندیدارەی خۆکار — لە پشکنینی تەنها بەرەو چاککردنی تام.

## هەموو شتێک بەرزە بکە — 33 تاقیکردنەوە

هیچ کارتەی قەرز نییە. هیچ پەیوەندیدانی پێویست نییە. تەنها داگرتن و دەستپێکردن.

هەموو تایبەتمەندیە پەرەسەندە — بارکردنی وێنە، AI Arena، AI Council، پشکنینی فایل و ڤیدیۆ — بەرزە بۆ یەکەمی 33 بەکارهێنانی تۆ. پاش ئەوە، API key خۆت بەرزە (BYOK) بەرزە بکە و هەموو شتێک بەرزە بەکاربەرە. یان بەرزە بکە لە $3/mo بۆ تایبەتمەندیەکانی AI و تیم.

چرا 33؟ لە ساڵی 1919، هەریمە کوردیەکان بەرز بوو بەرەو 33 نیشانی کە پەیوەندیدانی ئازادی بەرز کرد. 33 تاقیکردنەوەی بەرزەی WIA SOOM پەیوەندیدانی ئازادیە: **تایبەتمەندیەکانی AI پێویستە بەرزە بۆ هەموو کەس بەرزە بکات.**

**CLI → GUI → SUI.** پەیوەندیدانی فرمانی بەرزە بەرزەمان پێشکەش کرد. پەیوەندیدانی گرافیکی بەرزەمان ئاسان کرد. WIA SOOM **SUI (Soom User Interface)** پێشکەش دەکات — ژیان بدە، و AI زنده دەبێت.

## پلاتفۆرمی 5-لە 1

بەرنامەی تر تەنها یەک شت دەکات. WIA SOOM پێنج شت دەکات — لە یەک پەنجەرە.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Observability             │
│  Ter │ Agen │ Edit │ File │ Monitor + Security        │
│  min │   t  │  or  │ Mgr  │ + Logs + Topology         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminal** — xterm.js, bastion tunneling, split views, multiplayer sharing
2. **AI Agent** — 14 tools, 3 providers (GPT/Gemini/Claude), streaming, image analysis
3. **Code Editor** — Monaco with AI completion, bug detection, deployment
4. **SFTP Manager** — drag-and-drop file management, remote editing
5. **Observability** — real-time metrics, log analysis, topology map, security scan

## تیشکەکان

### AI کە راستەوخۆ لە سەرڤەرەکەت کار دەکات

**AI DevOps Agent** — لە terminal دا `gpt`, `gemini`, یان `claude` بنووسە. AI 14 شت هەیە: پێوەندیدانی فایلی نووسین/نووسین/چاککردن، فرمانەکان جێبەجێ بکە، git، grep، بەرێوەبردنی پڕۆسە. وەڵامەکان بەرزە. یادی کەشە. ئەمە تەنها پێشنیاز ناکات — ئەمە دەکات.

**AI Arena** — لە terminal دا `arena` بنووسە. 2–4 AI لە شاخەی Git تایبەتی خۆی بەرزەیەکی پەیوەندیدار کار دەکەن. پشکنینی پارە هەر ئەنجامێکی پەیوەندیدار نمرە دەدات. فەرمی بەرزە و پەیوەندیدانی پەیوەندیدار.

**AI Council** — چەند AI لەسەر پرسیارەکەت گۆڤار دەکەن، پاشان باشترین وەڵامەکان پەیوەندیدار دەکەن.

**AI Code Editor** — وێنەی Monaco بە پەیوەندیدانی AI، پشکنینی هەڵە، بارکردنی یەک-کلیک بەرەو سەرڤەر.

**AI Self-Healing** — بەرزبوونی CPU، دیسک پڕ، خزمەتی ناتوانی — AI کێشەکە پشکنینی دەکات، سەرچاوەی کێشەکە دیاری دەکات، چاک دەکات. 5-پەیوەندیدارەی خۆکار.

**Voice Interface** — فرمانەکان بڵێن، وەڵامەکان بگێن. بەرزەیەکی بێدەنگ بەرەو سەرڤەر.

### بارکردنی چەند شت (یەکەمی جیهان لە CLI)

وێنەکان بچە، فایلەکان بەرەو بەرزە بکە، ڤیدیۆکان بچە — بەرەو کەشەی SSH terminalەکەت. AI هەموو شت پشکنینی دەکات: وێنەی هەڵە، فایلی پەیوەندیدار، ڤیدیۆی بارکردن، شێوەی پەیوەندیدار.

### زانیاری پەیوەندیدار

**Topology Map** — سەرڤەرەکان، خزمەتەکان، و پەیوەندیدارەکان بەرزەیەکی پەیوەندیدار بگێن. پەیوەندیدانی خۆکار لە ڕووی SSH — بەرزەیەکی بەرز.

**Real-Time Observability** — CPU، بەرز، دیسک، گرافی sparklineی تۆمار + پێشگویی AI + پەیوەندیدانی خۆکار. Datadog بەرزەیەکی بەرز.

**AI Log Analysis** — پشکنینی کاتی ڕاست + پشکنینی کێشە + گەڕانی لە زمانەی طبیعی + پەیوەندیدانی پارە. Splunk بەرزەیەکی بەرز.

### پاراستن و DevOps

**Security Command Center** — پشکنینی 7 هەریم + نمرەی پاراستن + چاککردنی یەک-کلیک + پشکنینی AI + دەروازەی پاراستنی فرمانی کاتی ڕاست. Qualys بەرزەیەکی بەرز.

**Docker Manager** — بەرێوەبردنی پڕ Docker لە ڕووی SSH — بەرزەیەکی بەرز. بەرزەیەکی پەیوەندیدار، سەرچاوەی زنده، پشکنینی فایلی AI، وێنەی Compose. Portainer بەرزەیەکی بەرز.

**Runbook Automation** — AI بەرزەیەکی پەیوەندیدار بە شێوەی خۆکار جێبەجێ دەکات. دروستکردنی زمانەی طبیعی، شاخەی پەیوەندیدار، پەیوەندیدانی خۆکار. Runbookی زنده کە زانیاری بەرزەیەکی پەیوەندیدار دەکات. PagerDuty بەرزەیەکی بەرز.

**Cron & Env Manager** — بەرنامەی وێنەی کرون + بەرێوەبردنی فایلی .env. AI زمانەی طبیعی بەرزەیەکی پەیوەندیدار بەرزەیەکی کرون دەکات.

### پەیوەندیدانی

**Multiplayer Terminal** — کەشەی terminal لە کاتی ڕاستەوخۆ بە تیمەکان پەیوەندیدار بکە.

**Team Workspace & RBAC** — بەرزەیەکی پەیوەندیدار بەرزەیەکی بەرز، تۆمارەکانی پشکنینی فرمان، پشکنینی ریسک.

### پەیوەندیدانی

**59 Plugins** — داشبۆردی Docker، lensی Kubernetes، براوزەری Redis، بەرێوەبردنی PM2، بەرزەی MongoDB، پشکنینی شەبەکە، و زۆرتر. بازارەی پەیوەندیدانی بە شێوەیەکی یەک-کلیک.

**API Client** — کلاسی REST/GraphQL/WebSocketی دروستکراو. API ی تاقی بکە بەرزەیەکی terminal.

### بۆ هەموو کەس

**254 زمان** — هەموو زمان، هەموو نووسین، پەیوەندیدانی RTL. هیچ سرحدی نییە.

**بەرزەیەکی تام** — خوانەری سکرین (ARIA)، دەرچوونی terminalی Braille، شێوەی بەرزەیەکی بەرز، فرمانەکان بڵێن، گەڕانی لە کەی بەرزەیەکی بەرز، گەورەکردنی فۆنت.
