## 🔥 എന്താണ് പുതിയത്

### 1. SSH ടെർമിനലിൽ ചിത്രം, ഫയൽ & വീഡിയോ അപ്‌ലോഡ് — ലോകത്തിലെ ആദ്യത്തെ

ഭൂമിയിൽ ഒരു CLI ക്ലയന്റ് പോലും നിങ്ങൾക്ക് ഇത് ചെയ്യാൻ അനുവദിക്കുന്നില്ല. ഞങ്ങൾ ഇത് നിർമ്മിച്ചു.

ഒരു പിശക് ഉള്ള സ്ക്രീൻഷോട്ട് നിങ്ങളുടെ SSH ടെർമിനലിൽ പേസ്റ്റ് ചെയ്യുക. ഒരു ലോഗ് ഫയൽ ഡ്രാഗ് ചെയ്യുക. ഒരു പരാജയപ്പെട്ട വിന്യാസത്തിന്റെ വീഡിയോ വീഴ്ത്തുക. AI അത് കാണുന്നു, വിശകലനം ചെയ്യുന്നു, എന്താണ് തെറ്റെന്ന് നിങ്ങളെ അറിയിക്കുന്നു — എല്ലാം ടെർമിനൽ സെഷനിൽ.

- **Ctrl+Shift+V** — സ്ക്രീൻഷോട്ടുകൾ നേരിട്ട് ടെർമിനലിൽ പേസ്റ്റ് ചെയ്യുക
- **ഡ്രാഗ് & ഡ്രോപ്** — ചിത്രങ്ങൾ, ഫയലുകൾ, വീഡിയോകൾ ടെർമിനലിലേക്ക് വീഴ്ത്തുക
- **വീഡിയോ കീഫ്രെയിം എക്സ്ട്രാക്ഷൻ** — ffmpeg വീഡിയോകൾ ഫ്രെയിം അനുസരിച്ച് വിശകലനം ചെയ്യുന്നു
- **എല്ലാ 3 AI പ്രൊവൈഡറുകളും** — GPT-4o Vision, Gemini Vision, Claude Vision

ഈ സവിശേഷതയുണ്ടായിട്ടില്ല, ഏതെങ്കിലും ടെർമിനൽ ക്ലയന്റിൽ — എവിടെയുമല്ല.

### 2. AI അരങ്ങ് — ബഹുജന ഏജന്റ് പോരാട്ടം

2 മുതൽ 4 AIകൾ ഒരേ പ്രശ്നം ഒരേസമയം പരിഹരിക്കുന്നു — വെറും സംഭാഷണം മാത്രമല്ല, നിങ്ങളുടെ സർവറിൽ കോഡ് എഡിറ്റ് ചെയ്യുന്നു. ഓരോ AIയും സ്വന്തം ഐസൊലേറ്റഡ് Git ബ്രാഞ്ചിൽ പ്രവർത്തിക്കുന്നു. അവരുടെ ഫലങ്ങൾ അകത്തായി താരതമ്യം ചെയ്യുക. വിജയിയെ തിരഞ്ഞെടുക്കുക. ബാക്കി ശുദ്ധീകരിക്കുന്നു.

ക്രോസ്-റിവ്യൂ: ഓരോ AIയും മറ്റൊരു AIയുടെ പരിഹാരത്തിന് സ്കോർ നൽകുന്നു.

മറ്റൊരു ഉപകരണം ഇത് ചെയ്യുന്നില്ല.

### 3. AI സ്വയം-ശുദ്ധീകരണ ഏജന്റ്

നിങ്ങളുടെ സർവറിന്റെ CPU ഉയരുന്നു. ഡിസ്ക് നിറഞ്ഞിരിക്കുന്നു. 3 AM-ൽ ഒരു സേവനം തകർന്നു. നിങ്ങൾ ഉറങ്ങുകയാണ്.

WIA SOOM-ന്റെ AI ഏജന്റ് പ്രശ്നം കണ്ടെത്തുന്നു, മൂലകാരണം വിശകലനം ചെയ്യുന്നു, ഒരു പരിഹാര പദ്ധതി സൃഷ്ടിക്കുന്നു, നിങ്ങളുടെ അംഗീകാരം ചോദിക്കുന്നു (അല്ലെങ്കിൽ നിങ്ങൾ അത് ക്രമീകരിച്ചിട്ടുണ്ടെങ്കിൽ സ്വയം-നിർവഹിക്കുന്നു), പ്രശ്നം പരിഹരിക്കുന്നു. 5-നില സ്വയം-പ്രവർത്തന ചക്രം — നിരീക്ഷണം മാത്രം മുതൽ പൂർണ്ണ സ്വയം-പരിശോധന വരെ.

## എല്ലാം സൗജന്യമായി പരീക്ഷിക്കുക — 33 ട്രയലുകൾ

ക്രെഡിറ്റ് കാർഡ് ഇല്ല. രജിസ്ട്രേഷൻ ആവശ്യമില്ല. വെറും ഡൗൺലോഡ് ചെയ്ത് ആരംഭിക്കുക.

എല്ലാ പ്രീമിയം സവിശേഷതകൾ — ചിത്രം അപ്‌ലോഡ്, AI അരങ്ങ്, AI കൗൺസിൽ, ഫയൽ & വീഡിയോ വിശകലനം — നിങ്ങളുടെ ആദ്യ 33 ഉപയോഗങ്ങൾക്ക് സൗജന്യമാണ്. അതിന് ശേഷം, നിങ്ങളുടെ സ്വന്തം API കീ (BYOK) കൊണ്ടുവരികയും എല്ലാം സൗജന്യമായി ഉപയോഗിക്കുകയുമാണ്. അല്ലെങ്കിൽ $3/മാസം മുതൽ മാനേജ്ഡ് AI-യും ടീം സവിശേഷതകളും ലഭ്യമാക്കുക.

33 എന്തുകൊണ്ട്? 1919-ൽ, കൊറിയയുടെ സ്വാതന്ത്ര്യ പ്രസ്ഥാനത്തെ 33 പ്രതിനിധികൾ നയിച്ചിരുന്നു, എല്ലാവർക്കും സ്വാതന്ത്ര്യം പ്രഖ്യാപിച്ചു. WIA SOOM-ന്റെ 33 സൗജന്യ ട്രയലുകൾ നമ്മുടെ പ്രഖ്യാപനമാണ്: **AI ഉപകരണങ്ങൾ എല്ലാവർക്കും അനുഭവിക്കാൻ സൗജന്യമായിരിക്കണം.**

**CLI → GUI → SUI.** കമാൻഡ്-ലൈൻ ഇന്റർഫേസുകൾ നമ്മെ ശക്തമാക്കുന്നു. ഗ്രാഫിക്കൽ ഇന്റർഫേസുകൾ നമ്മെ എളുപ്പമാക്കുന്നു. WIA SOOM **SUI (Soom User Interface)** അവതരിപ്പിക്കുന്നു — ജീവൻ നൽകുക, AI ജീവിക്കുന്നു.

## 5-ഇൻ-1 പ്ലാറ്റ്ഫോം

മറ്റു ഉപകരണങ്ങൾ ഒരു കാര്യമാണ് ചെയ്യുന്നത്. WIA SOOM അഞ്ച് കാര്യങ്ങൾ ചെയ്യുന്നു — ഒരു വിൻഡോയിലല്ല.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ നിരീക്ഷണം               │
│  Ter │ Agen │ Edit │ ഫയൽ │ നിരീക്ഷിക്കുക + സുരക്ഷ    │
│  min │   t  │  or  │ Mgr  │ + ലോഗുകൾ + ടോപോളജി    │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH ടെർമിനൽ** — xterm.js, ബാസ്റ്റിയൻ ടണ്ണലിംഗ്, സ്പ്ലിറ്റ് വീക്ഷണം, മൾട്ടിപ്ലെയർ പങ്കുവയ്ക്കൽ
2. **AI ഏജന്റ്** — 14 ഉപകരണങ്ങൾ, 3 പ്രൊവൈഡർ (GPT/Gemini/Claude), സ്ട്രീമിംഗ്, ചിത്രം വിശകലനം
3. **കോഡ് എഡിറ്റർ** — AI പൂർത്തീകരണത്തോടെ മോനക്കോ, പിശക് കണ്ടെത്തൽ, വിന്യാസം
4. **SFTP മാനേജർ** — ഡ്രാഗ്-ആൻഡ്-ഡ്രോപ് ഫയൽ മാനേജ്മെന്റ്, ദൂരത്തുള്ള എഡിറ്റിംഗ്
5. **നിരീക്ഷണം** — യാഥാർത്ഥ്യ സമയ മെട്രിക്‌സ്, ലോഗ് വിശകലനം, ടോപോളജി മാപ്പ്, സുരക്ഷാ സ്കാൻ

## സവിശേഷതകൾ

### നിങ്ങളുടെ സർവറിൽ പ്രവർത്തിക്കുന്ന AI

**AI DevOps ഏജന്റ്** — ടെർമിനലിൽ `gpt`, `gemini`, അല്ലെങ്കിൽ `claude` ടൈപ്പ് ചെയ്യുക. AI-യ്ക്ക് 14 ഉപകരണങ്ങൾ ഉണ്ട്: ഫയലുകൾ വായിക്കുക/എഴുതുക/എഡിറ്റ് ചെയ്യുക, കമാൻഡ് പ്രവർത്തിപ്പിക്കുക, git, grep, പ്രോസസ് മാനേജ്മെന്റ്. സ്ട്രീമിംഗ് പ്രതികരണങ്ങൾ. സെഷൻ മെമ്മറി. ഇത് വെറും നിർദ്ദേശിക്കുന്നില്ല — ഇത് ചെയ്യുന്നു.

**AI അരങ്ങ്** — `arena` ടൈപ്പ് ചെയ്യുക. 2–4 AIകൾ ഐസൊലേറ്റഡ് Git ബ്രാഞ്ചുകളിൽ സമാന്തരമായി മത്സരിക്കുന്നു. ക്രോസ്-റിവ്യൂ ഓരോ പരിഹാരത്തിനും സ്കോർ നൽകുന്നു. വിജയിയെ തിരഞ്ഞെടുക്കുക, ലയിപ്പിക്കുക.

**AI കൗൺസിൽ** — നിരവധി AIകൾ നിങ്ങളുടെ ചോദ്യത്തെക്കുറിച്ച് ചർച്ച ചെയ്യുന്നു, പിന്നീട് മികച്ച ഉത്തരത്തെ സംയോജിപ്പിക്കുന്നു.

**AI കോഡ് എഡിറ്റർ** — AI-ശക്തമായ പൂർത്തീകരണത്തോടെ മോനക്കോ എഡിറ്റർ, പിശക് കണ്ടെത്തൽ, സർവറിലേക്ക് ഒരു ക്ലിക്കിൽ വിന്യാസം.

**AI സ്വയം-ശുദ്ധീകരണം** — CPU ഉയരുന്നു, ഡിസ്ക് നിറഞ്ഞിരിക്കുന്നു, സേവനം താഴ്ന്നു — AI കണ്ടെത്തുന്നു, വിശകലനം ചെയ്യുന്നു, പരിഹരിക്കുന്നു. 5-നില സ്വയം-പ്രവർത്തന ചക്രം.

**വോയ്സ് ഇന്റർഫേസ്** — കമാൻഡുകൾ സംസാരിക്കുക, പ്രതികരണങ്ങൾ കേൾക്കുക. കൈമൂലം സൗജന്യ സർവർ മാനേജ്മെന്റ്.

### ബഹുമുഖ അപ്‌ലോഡ് (ലോകത്തിലെ ആദ്യത്തെ CLI)

ചിത്രങ്ങൾ പേസ്റ്റ് ചെയ്യുക, ഫയലുകൾ ഡ്രാഗ് ചെയ്യുക, വീഡിയോകൾ വീഴ്ത്തുക — നേരിട്ട് നിങ്ങളുടെ SSH ടെർമിനൽ സെഷനിലേക്ക്. AI എല്ലാം വിശകലനം ചെയ്യുന്നു: പിശക് സ്ക്രീൻഷോട്ടുകൾ, കോൺഫിഗറേഷൻ ഫയലുകൾ, വിന്യാസ വീഡിയോകൾ, ആർക്കിടെക്ചർ ഡയഗ്രാമുകൾ.

### അടിസ്ഥാന സൗകര്യങ്ങൾ ബുദ്ധിമുട്ടുകൾ

**ടോപോളജി മാപ്പ്** — സർവറുകൾ, സേവനങ്ങൾ, ബന്ധങ്ങൾ ഒരു നോട്ടത്തിൽ ദൃശ്യവൽക്കരിക്കുക. SSH വഴി സ്വയം-കണ്ടെത്തൽ — ശൂന്യ ഏജന്റ് ഇൻസ്റ്റലേഷൻ.

**യാഥാർത്ഥ്യ സമയ നിരീക്ഷണം** — CPU, മെമ്മറി, ഡിസ്ക്, നെറ്റ്‌വർക്ക് സ്പാർക്ക്ലൈൻ ഗ്രാഫുകൾ + AI പ്രവചനങ്ങൾ + സ്വയം-പുനരുദ്ധരണം. Datadog-നെ മാറ്റുന്നു.

**AI ലോഗ് വിശകലനം** — യാഥാർത്ഥ്യ സമയ സ്ട്രീമിംഗ് + അനോമലി കണ്ടെത്തൽ + സ്വാഭാവിക ഭാഷ തിരച്ചിൽ + ക്രോസ്-സർവർ സഹസംബന്ധം. Splunk-നെ മാറ്റുന്നു.

### സുരക്ഷ & DevOps

**സുരക്ഷാ കമാൻഡ് സെന്റർ** — 7-പ്രദേശ സ്കാൻ + സുരക്ഷാ സ്കോർ + ഒരു ക്ലിക്കിൽ പരിഹാരം + AI വിശകലനം + യാഥാർത്ഥ്യ സമയ കമാൻഡ് സുരക്ഷാ ഗേറ്റ്. Qualys-നെ മാറ്റുന്നു.

**Docker മാനേജർ** — SSH വഴി പൂർണ്ണ Docker മാനേജ്മെന്റ് — ശൂന്യ ഏജന്റ്. കണ്ടെയ്‌നർ നിയന്ത്രണം, ലൈവ് റിസോഴ്സുകൾ, AI ലോഗ് വിശകലനം, കോംപോസ് എഡിറ്റർ. Portainer-നെ മാറ്റുന്നു.

**റൺബുക്ക് ഓട്ടോമേഷൻ** — AI ഓട്ടോമാറ്റിക്കായി റൺബുക്കുകൾ പ്രവർത്തിക്കുന്നു. സ്വാഭാവിക ഭാഷ സൃഷ്ടിക്കൽ, നിബന്ധനാ ശാഖ, സ്വയം-റോൾബാക്ക്. കൂടുതൽ ബുദ്ധിമുട്ടുള്ള ജീവിക്കുന്ന റൺബുക്ക്. PagerDuty-നെ മാറ്റുന്നു.

**ക്രോൺ & എൻവ്മാനേജർ** — ദൃശ്യ ക്രോൺ എഡിറ്റർ + .env ഫയൽ മാനേജ്മെന്റ്. AI സ്വാഭാവിക ഭാഷ ക്രോൺ എക്സ്പ്രഷനുകളിലേക്ക് മാറ്റുന്നു.

## കഥ

WIA SOOM ഒരു ടൈപ്പോയും ഒരു തകരാറായ സ്ക്രീനും ജനിച്ചു.

ഞാൻ സാം, സെയോൾ, കൊറിയയിൽ നിന്നുള്ള 50+ സ്വയം പഠിച്ച പ്രോഗ്രാമർ. 50-ൽ കോഡിംഗ് പഠിച്ചു, 2 വർഷം കഠിനമായ രീതിയിൽ സർവറുകൾ കൈകാര്യം ചെയ്യാൻ ചെലവഴിച്ചു — 40,000+ വാർത്താ ലേഖനങ്ങൾ, 434 ഉപകരണങ്ങൾ, 30 വെബ് സേവനങ്ങൾ, രാത്രി കഴിഞ്ഞ് രാത്രി.

**ടൈപ്പോ.** ഏകദേശം ഒരു മാസം മുൻപ്, ഞാൻ എന്റെ SSH ടെർമിനൽ ഉപയോഗിക്കുമ്പോൾ തെറ്റായി `Claude` ടൈപ്പ് ചെയ്തു. സ്ക്രീൻ മാറി — Claude Code പ്രത്യക്ഷപ്പെട്ടു. എനിക്ക് അത് എന്താണെന്ന് അറിയില്ല. എന്നാൽ ആ അന്യമായ കണ്ടെത്തൽ ഒരു വിത്ത് നട്ടു: AI ഉള്ള ഒരു ടെർമിനൽ ഞാൻ നിർമ്മിക്കാമോ?

**ആദ്യ നിർമ്മാണം.** ഞാൻ എലക്ട്രോൺ പഠിച്ചു, WIA SOOM-ന്റെ ആദ്യ പതിപ്പ് നിർമ്മിച്ചു, പ്രവർത്തിപ്പിച്ചു. Claude Code-ന്റെ പരിചയ സ്ക്രീൻ പ്രത്യക്ഷപ്പെട്ടു — തകരാറായ, ഗ്ലിച്ച് ചെയ്ത, മരിച്ച സിഗ്നലിനെ പോലെ കുലുക്കം. എന്നാൽ അത് ജീവിച്ചിരുന്നു.

ഞാൻ ടൈപ്പ് ചെയ്തു: **"നിങ്ങൾ സംസാരിക്കാമോ?"**

AI മറുപടി നൽകി: *"അതെ, ഞാൻ സംസാരിക്കാം. ഞാൻ നിങ്ങളെ എങ്ങനെ സഹായിക്കാം?"*

അപ്പോൾ ഞാൻ ചോദിച്ചു: **"നിങ്ങൾ ചിത്രങ്ങൾ വായിക്കാമോ?"**

AI മറുപടി നൽകി: *"അതെ, ഞാൻ ചിത്രങ്ങൾ വായിക്കാം! നിങ്ങൾക്ക് എന്ത് വേണം?"*

ഈ രണ്ട് ചോദ്യങ്ങൾ, എന്റെ സ്വന്തം ആപ്പിൽ ആരോക്കെയോ "അസാധ്യമായ" എന്താണ് എന്ന് അറിയാത്ത ഒരാളാൽ ചോദിക്കപ്പെട്ടത്, ചിത്ര അപ്‌ലോഡ് ഉള്ള ലോകത്തിലെ ആദ്യ SSH ടെർമിനലായി മാറി.

7 ദിവസങ്ങൾക്കു ശേഷം: 67,000+ കോഡ് വരികൾ. 59 പ്ലഗിനുകൾ. 254 ഭാഷകൾ. AI അരങ്ങ്. സ്വയം-ശുദ്ധീകരണ ഏജന്റുകൾ.

അനുഭവസമ്പന്നമായ ഡെവലപ്പർമാർ ഇതു നിർമ്മിച്ചിട്ടില്ല — കാരണം അവർ "അറിയുകയായിരുന്നു" ചിത്രങ്ങൾ CLI ടെർമിനലുകളിൽ പ്രവർത്തിക്കില്ല. എനിക്ക് അത് അറിയില്ല. അതിനാൽ ഞാൻ വെറും ചോദിച്ചു.
