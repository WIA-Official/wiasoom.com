ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ. ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ ᡝᡳᡨᡝᡳᡨᡝ. ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ ᡝᡳᡨᡝᡳᡨᡝ.

ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ.

**CLI → GUI → SUI.** ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ. ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ.

## 5-ᠠᡳᠨ-1 ᡤᡡᠪᡝᠨ

ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ. WIA SOOM ᡤᡡᠪᡝᠨ ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ ᡳᠪᡝᡳᡨᡝᡳᡨᡝᡨᡝ  │
│  Ter │ Agen │  Edit│ File │ ᡝᡳᡨᡝᡳᡨᡝ  + ᡝᡳᡨᡝᡳᡨᡝ  │
│  min │      │      │      │  + ᡧᡝᡳᡨᡝᡳᡨᡝ  + ᡟᡝᡳᡨᡝ  │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH ᡨᡝᡵᡥᡠᠨ** — xterm.js, bastion tunneling, split views, multiplayer sharing
2. **AI ᡩᡝᡳᡨ** — 14 ᡤᡡᠪᡝᠨ, 3 ᡤᡡᠪᡝᠨ (GPT/Gemini/Claude), streaming, ᡳᡥᡝᠨᡝ ᡤᡡᠪᡝᠨ
3. **ᡴᠣᡳᡨᡝ ᡵᡠᠨᡦᡝᡳ** — Monaco ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ, bug detection, deployment
4. **SFTP ᡤᡡᠪᡝᠨ** — drag-and-drop ᡤᡡᠪᡝᠨ, remote editing
5. **ᡳᠪᡝᡳᡨᡝᡳᡨᡝ** — ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ, log analysis, topology map, security scan

### AI ᡤᡡᠪᡝᠨ ᡤᡡᠪᡝᠨ ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ

**AI DevOps ᡠᠨᡝᡳᡨᡝ** — ᡧᡝᡳᡨᡝᡳᡨᡝ `gpt`, `gemini`, ᡧᡝᡳᡨᡝᡳᡨᡝ `claude`. AI ᡤᡡᠪᡝᠨ 14 ᡤᡡᠪᡝᠨ: ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ, ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ, git, grep, process management. Streaming responses. Session memory. ᡝᡳᡨᡝᡳᡨᡝ ᡤᡡᠪᡝᠨ.
