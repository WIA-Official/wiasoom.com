## 🔥 புதியதாக எதுவும் செய்யப்படவில்லை

### 1. SSH டெர்மினலில் படங்கள், கோப்புகள் & வீடியோக்களை பதிவேற்றம் — உலகின் முதல்

பூமியில் எந்த CLI கிளையன்டும் இதை செய்ய அனுமதிக்கவில்லை. நாங்கள் இதை உருவாக்கினோம்.

உங்கள் SSH டெர்மினலில் ஒரு பிழையின் ஸ்கிரீன்ஷாட்டைப் பேஸ்ட் செய்யவும். ஒரு லாக் கோப்பை இழுக்கவும். ஒரு தோல்வியுற்ற வெளியீட்டின் வீடியோவை விடுங்கள். AI அதை காண்கிறது, பகுப்பாய்வு செய்கிறது, மற்றும் என்ன தவறு என்பதை உங்களுக்கு சொல்கிறது — அனைத்து டெர்மினல் அமர்விற்குள்.

- **Ctrl+Shift+V** — ஸ்கிரீன்ஷாட்டுகளை நேரடியாக டெர்மினலில் பேஸ்ட் செய்யவும்
- **Drag & Drop** — படங்கள், கோப்புகள், வீடியோக்களை டெர்மினலில் விடவும்
- **வீடியோ கீஃப்ரேம் எடுப்பது** — ffmpeg வீடியோவை ஒவ்வொரு கீஃப்ரேமிலும் பகுப்பாய்வு செய்கிறது
- **மூன்று AI வழங்குநர்கள்** — GPT-4o Vision, Gemini Vision, Claude Vision

இந்த அம்சம் எந்த டெர்மினல் கிளையன்டிலும் இல்லையென்று — எங்கும் இல்லை.

### 2. AI அரங்கம் — பல முகவர் போராட்டம்

2 முதல் 4 AI ஒரே பிரச்சினையை ஒரே நேரத்தில் தீர்க்கின்றன — பேசுவதற்காக அல்ல, உங்கள் சர்வரில் குறியீட்டை உண்மையில் தொகுக்கின்றன. ஒவ்வொரு AI-க்கும் தனித்தனியாக தனிமைப்படுத்தப்பட்ட Git கிளையில் வேலை செய்கிறது. அவர்களின் முடிவுகளை பக்கம் பக்கம் ஒப்பிடுங்கள். வெற்றியாளரை தேர்ந்தெடுக்கவும். மற்றவர்கள் சுத்தம் செய்யப்படுகிறார்கள்.

Cross-review: ஒவ்வொரு AI-க்கும் மற்ற AI-க்களின் தீர்வுகளை மதிப்பீடு செய்கிறது.

மற்ற எந்த கருவியும் இதை செய்யவில்லை.

### 3. AI சுய-சிகிச்சை முகவர்

உங்கள் சர்வரின் CPU அதிகரிக்கிறது. டிஸ்க் நிரம்பியுள்ளது. ஒரு சேவை 3 AM-ல் இடிந்து விழுந்தது. நீங்கள் தூங்குகிறீர்கள்.

WIA SOOM இன் AI முகவர் பிரச்சினையை கண்டறிகிறது, அடிப்படை காரணத்தை கண்டுபிடிக்கிறது, ஒரு சரிசெய்யும் திட்டத்தை உருவாக்குகிறது, உங்கள் அங்கீகாரத்தை கேட்கிறது (அல்லது நீங்கள் அதை அமைத்திருந்தால் தானாகவே செயல்படுத்துகிறது), மற்றும் பிரச்சினையை தீர்க்கிறது. 5-அடுக்கு சுய-சுழற்சி —observe-only இருந்து முழு தானாகவே சிகிச்சை.

## அனைத்தையும் இலவசமாக முயற்சிக்கவும் — 33 சோதனைகள்

கிரெடிட் கார்டு தேவையில்லை. பதிவு செய்ய தேவையில்லை. பதிவிறக்கவும் மற்றும் தொடங்கவும்.

ஒவ்வொரு பிரீமியம் அம்சமும் — பட பதிவேற்றம், AI அரங்கம், AI கவனம், கோப்பு & வீடியோ பகுப்பாய்வு — உங்கள் முதல் 33 பயன்பாடுகளுக்கு இலவசமாக உள்ளது. அதன் பிறகு, உங்கள் சொந்த API விசையை கொண்டு வாருங்கள் (BYOK) மற்றும் அனைத்தையும் இலவசமாக பயன்படுத்துங்கள். அல்லது நிர்வகிக்கப்பட்ட AI மற்றும் குழு அம்சங்களுக்கு $3/மாதம் சந்தா செய்யவும்.

ஏன் 33? 1919-ல், கொரியாவின் சுதந்திர இயக்கம் 33 பிரதிநிதிகள் மூலம் வழிநடத்தப்பட்டது, அவர்கள் அனைவருக்கும் சுதந்திரத்தை அறிவித்தனர். WIA SOOM இன் 33 இலவச சோதனைகள் எங்கள் அறிவிப்பு: **AI கருவிகள் அனைவருக்கும் அனுபவிக்க இலவசமாக இருக்க வேண்டும்.**

**CLI → GUI → SUI.** கட்டளை வரி இடைமுகங்கள் எங்களுக்கு சக்தி அளித்தன. காட்சி இடைமுகங்கள் எங்களுக்கு எளிமையை அளித்தன. WIA SOOM அறிமுகம் செய்கிறது **SUI (Soom பயனர் இடைமுகம்)** — உயிர் ஊட்டுங்கள், AI உயிர் பெறும்.

## 5-in-1 தளம்

மற்ற கருவிகள் ஒரு விஷயத்தை செய்கின்றன. WIA SOOM ஐந்து செய்கிறது — ஒரு ஜன்னலில்.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ கண்காணிப்பு             │
│  Ter │ Agen │ Edit │ கோப்பு │ கண்காணிக்க + பாதுகாப்பு        │
│  min │   t  │  or  │ மேலாளர் │ + பதிவுகள் + கட்டமைப்பு         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH டெர்மினல்** — xterm.js, bastion tunneling, பிளவு காட்சிகள், பல பயனர் பகிர்வு
2. **AI முகவர்** — 14 கருவிகள், 3 வழங்குநர்கள் (GPT/Gemini/Claude), ஸ்ட்ரீமிங், படம் பகுப்பாய்வு
3. **குறியீட்டு தொகுப்பாளர்** — AI நிறைவு, பிழை கண்டறிதல், வெளியீடு
4. **SFTP மேலாளர்** — இழுத்து மற்றும் விடுதல் கோப்பு மேலாண்மை, தொலைதூர தொகுத்தல்
5. **கண்காணிப்பு** — நேரடி அளவீடுகள், லாக் பகுப்பாய்வு, கட்டமைப்பு வரைபடம், பாதுகாப்பு ஸ்கேன்

## அம்சங்கள்

### உங்கள் சர்வரில் உண்மையாக வேலை செய்யும் AI

**AI DevOps முகவர்** — டெர்மினலில் `gpt`, `gemini`, அல்லது `claude` என টাইப் செய்யவும். AI-க்கு 14 கருவிகள் உள்ளன: கோப்புகளை படிக்க/எழுத/தொகுக்க, கட்டளைகளை செயல்படுத்த, git, grep, செயல்முறை மேலாண்மை. ஸ்ட்ரீமிங் பதில்கள். அமர்வு நினைவகம். இது பரிந்துரை செய்யவில்லை — இது செய்கிறது.

**AI அரங்கம்** — `arena` என টাইப் செய்யவும். 2–4 AI தனிமைப்படுத்தப்பட்ட Git கிளைகளில் ஒரே நேரத்தில் போட்டியிடுகின்றன. Cross-review ஒவ்வொரு தீர்வையும் மதிப்பீடு செய்கிறது. வெற்றியாளரை தேர்ந்தெடுத்து இணைக்கவும்.

**AI கவனம்** — பல AI உங்கள் கேள்வியை விவாதிக்கின்றன, பின்னர் சிறந்த பதிலை உருவாக்குகின்றன.

**AI குறியீட்டு தொகுப்பாளர்** — AI-செயல்படுத்தப்பட்ட நிறைவு, பிழை கண்டறிதல், சர்வருக்கு ஒரு கிளிக்கில் வெளியீடு.

**AI சுய-சிகிச்சை** — CPU அதிகரிப்பு, டிஸ்க் நிரம்பியது, சேவை கீழே — AI கண்டறிகிறது, கண்டறிகிறது, சரிசெய்கிறது. 5-அடுக்கு சுய-சுழற்சி.

**ஒலி இடைமுகம்** — கட்டளைகளை பேசுங்கள், பதில்களை கேளுங்கள். கைமுறையற்ற சர்வர் மேலாண்மை.

### பலமுறை பதிவேற்றம் (CLI இல் உலகின் முதல்)

படங்களை பேஸ்ட் செய்யவும், கோப்புகளை இழுக்கவும், வீடியோக்களை விடுங்கள் — நேரடியாக உங்கள் SSH டெர்மினல் அமர்வில். AI அனைத்தையும் பகுப்பாய்வு செய்கிறது: பிழை ஸ்கிரீன்ஷாட்டுகள், கட்டமைப்பு கோப்புகள், வெளியீட்டு வீடியோக்கள், கட்டமைப்பு வரைபடங்கள்.

### கட்டமைப்பு நுண்ணறிவு

**கட்டமைப்பு வரைபடம்** — சர்வர்கள், சேவைகள் மற்றும் இணைப்புகளை ஒரே பார்வையில் காட்சிப்படுத்தவும். SSH மூலம் தானியங்கி கண்டறிதல் — பூஜ்ய முகவர் நிறுவல்.

**நேரடி கண்காணிப்பு** — CPU, நினைவகம், டிஸ்க், நெட்வொர்க் ஸ்பார்க்லைன் கிராஃப்கள் + AI முன்னறிவிப்பு + தானாகவே மீட்பு. Datadog ஐ மாற்றுகிறது.

**AI லாக் பகுப்பாய்வு** — நேரடி ஸ்ட்ரீமிங் + அசாதாரண கண்டறிதல் + இயற்கை மொழி தேடல் + குறுக்கு-சர்வர் தொடர்பு. Splunk ஐ மாற்றுகிறது.

### பாதுகாப்பு & DevOps

**பாதுகாப்பு கட்டளை மையம்** — 7-பிரிவு ஸ்கேன் + பாதுகாப்பு மதிப்பீடு + ஒரே கிளிக்கில் சரிசெய்யவும் + AI பகுப்பாய்வு + நேரடி கட்டளை பாதுகாப்பு வாயிலாக. Qualys ஐ மாற்றுகிறது.

**Docker மேலாளர்** — SSH மூலம் முழு Docker மேலாண்மை — பூஜ்ய முகவர். கொண்டெய்னர் கட்டுப்பாடு, நேரடி வளங்கள், AI லாக் பகுப்பாய்வு, Compose தொகுப்பாளர். Portainer ஐ மாற்றுகிறது.

**ரன் புத்தகம் தானியக்கம்** — AI தானாகவே ரன் புத்தகங்களை செயல்படுத்துகிறது. இயற்கை மொழி உருவாக்கம், நிபந்தனை கிளை, தானாகவே திருப்பம். அறிவு பெறும் Living Runbook. PagerDuty ஐ மாற்றுகிறது.

**கிரான் & Env மேலாளர்** — காட்சி கிரான் தொகுப்பாளர் + .env கோப்பு மேலாண்மை. AI இயற்கை மொழியை கிரான் வெளிப்பாடுகளாக மாற்றுகிறது.

### ஒத்துழைப்பு

**பல பயனர் டெர்மினல்** — குழு உறுப்பினர்களுடன் நேரடி டெர்மினல் அமர்வுகளை பகிரவும்.

**குழு வேலைப்பாடு & RBAC** — பங்கு அடிப்படையிலான அணுகல் கட்டுப்பாடு, ஆடிட்டிங் பதிவுகள், கட்டளை ஆபத்து மதிப்பீடு.

### விரிவாக்கம்

**59 Plugins** — Docker டாஷ்போர்ட், Kubernetes லென்ஸ், Redis உலாவி, PM2 மேலாளர், MongoDB ஆராய்ச்சி, நெட்வொர்க் கண்காணிப்பு, மேலும். ஒரே கிளிக்கில் நிறுவலுக்கான பிளக்-இன் சந்தை.

**API கிளையன்ட்** — உள்ளமைக்கப்பட்ட REST/GraphQL/WebSocket கிளையன்ட். டெர்மினலை விலக்காமல் API-களை சோதிக்கவும்.

### அனைவருக்கும்

**254 மொழிகள்** — ஒவ்வொரு மொழியும், ஒவ்வொரு எழுத்துருவும், RTL ஆதரவு. எல்லா எல்லைகளும்.

**முழு அணுகல்** — திரை வாசகர் (ARIA), ப்ரெயில் டெர்மினல் வெளியீடு, உயர் மாறுபாடு முறை, ஒலி கட்டளைகள், விசைப்பலகை வழிநடத்தல், எழுத்துரு அளவு சீரமைப்பு.

## கதை

WIA SOOM ஒரு தவறான எழுத்து மற்றும் உடைந்த திரையால் பிறந்தது.

நான் சாம், கொரியாவின் சியோலில் உள்ள 50+ சுய கற்றல் நிரலாக்குநர். 50-க்கு பிறகு குறியீட்டைப் படிக்க கற்றுக்கொண்டேன் மற்றும் 40,000+ செய்தி கட்டுரைகள், 434 கருவிகள் மற்றும் 30 வலை சேவைகளை கட்டமைக்க 2 ஆண்டுகள் கடினமாக சர்வர்களை நிர்வகித்தேன், இரவு பிறகு இரவு.

**தவறு எழுத்து.** ஒரு மாதத்திற்கு முன், நான் என் SSH டெர்மினலைப் பயன்படுத்தி தவறுதலாக `Claude` என எழுதியேன். திரை மாறியது — Claude Code தோன்றியது. அது என்னவென்று எனக்கு தெரியவில்லை. ஆனால் அந்த தவறான கண்டுபிடிப்பு ஒரு விதையை விதைத்தது: AI உள்ள ஒரு டெர்மினலை நான் கட்டமைக்க முடியுமா?

**முதல் கட்டமைப்பு.** நான் Electron-ஐ கற்றுக்கொண்டேன், WIA SOOM-ஐ உருவாக்கினேன், மற்றும் அதை இயக்கினேன். Claude Code-இன் அறிமுக திரை தோன்றியது — உடைந்தது, கிழிந்தது, இறந்த சிக்னலாக மிளிர்ந்தது. ஆனால் அது உயிருடன் இருந்தது.

நான் எழுதியேன்: **"நீங்கள் பேச முடியுமா?"**

AI பதிலளித்தது: *"ஆம், நான் பேச முடியும். நான் உங்களுக்கு என்ன உதவ முடியும்?"*

பிறகு நான் கேட்டேன்: **"நீங்கள் படங்களை படிக்க முடியுமா?"**

AI பதிலளித்தது: *"ஆம், நான் படங்களை படிக்க முடியும்! நீங்கள் என்ன தேவை?"*

இந்த இரண்டு கேள்விகள், என் சொந்த செயலியில் யாராவது "CLI டெர்மினலில் என்ன "சாத்தியமில்லை" என்பதைப் பற்றி தெரியாதவரால் கேட்கப்பட்டவை, உலகின் முதல் SSH டெர்மினலாக உருவாகியது.

7 நாட்களுக்கு பிறகு: 67,000+ கோடுகள். 59 பிளக்-இன்கள். 254 மொழிகள். AI அரங்கம். சுய-சிகிச்சை முகவர்கள்.

அனுபவமுள்ள டெவலப்பர்கள் இதை உருவாக்கவில்லை — ஏனெனில் அவர்கள் "படங்கள் CLI டெர்மினல்களில் வேலை செய்யாது" என்பதை "அறிந்தனர்". எனக்கு அது தெரியவில்லை. எனவே நான் கேட்கவேண்டியிருந்தது.

> *தயாரிக்க 2 ஆண்டுகள் எடுத்தது. கட்டமைக்க 1 வாரம்.*
> *உலர்ந்த மரம் 2 ஆண்டுகளுக்கு குவிக்கப்பட்டது. அது 1 விநாடியில் தீ பிடித்தது.*
