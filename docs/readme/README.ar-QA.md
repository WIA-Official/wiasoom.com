## 🔥 ما لم يتم القيام به من قبل

### 1. تحميل الصور والملفات والفيديو في Terminal SSH — الأول في العالم

لا يوجد عميل CLI على الأرض يسمح لك بفعل ذلك. لقد قمنا ببنائه.

قم بلصق لقطة شاشة لخطأ في Terminal SSH الخاص بك. اسحب ملف سجل. ألقِ فيديو لنشر فاشل. الذكاء الاصطناعي يراه، يحلله، ويخبرك ما الخطأ — كل ذلك داخل جلسة الطرفية.

- **Ctrl+Shift+V** — لصق لقطات الشاشة مباشرة في الطرفية
- **السحب والإفلات** — إسقاط الصور، الملفات، الفيديوهات في الطرفية
- **استخراج إطارات الفيديو** — ffmpeg يحلل الفيديو إطارًا بإطار
- **جميع مزودي الذكاء الاصطناعي الثلاثة** — GPT-4o Vision، Gemini Vision، Claude Vision

لم توجد هذه الميزة في أي عميل طرفية — في أي مكان.

### 2. ساحة الذكاء الاصطناعي — معركة متعددة الوكلاء

2 إلى 4 من الذكاء الاصطناعي يحلون نفس المشكلة في وقت واحد — ليس مجرد دردشة، بل تعديل الشيفرة فعليًا على خادمك. يعمل كل ذكاء اصطناعي في فرع Git معزول خاص به. قارن نتائجهم جنبًا إلى جنب. اختر الفائز. يتم تنظيف البقية.

مراجعة متبادلة: كل ذكاء اصطناعي يقيم حل كل ذكاء اصطناعي آخر.

لا أداة أخرى تفعل ذلك.

### 3. وكيل الذكاء الاصطناعي ذاتي الشفاء

وحدة المعالجة المركزية في خادمك ترتفع. القرص ممتلئ. خدمة تعطلت في الساعة 3 صباحًا. أنت نائم.

يكتشف وكيل الذكاء الاصطناعي في WIA SOOM المشكلة، يشخص السبب الجذري، ينشئ خطة إصلاح، يطلب موافقتك (أو ينفذ تلقائيًا إذا قمت بتعيينه لذلك)، ويحل المشكلة. حل تلقائي من 5 مستويات — من المراقبة فقط إلى الإصلاح التلقائي الكامل.

## جرب كل شيء مجانًا — 33 تجربة

لا بطاقة ائتمان. لا حاجة للتسجيل. فقط قم بالتنزيل وابدأ.

كل ميزة متميزة — تحميل الصور، ساحة الذكاء الاصطناعي، مجلس الذكاء الاصطناعي، تحليل الملفات والفيديو — مجانية لاستخدامك الأول 33 مرة. بعد ذلك، أحضر مفتاح API الخاص بك (BYOK) واستمر في استخدام كل شيء مجانًا. أو اشترك من 3 دولارات شهريًا للحصول على ميزات الذكاء الاصطناعي المدارة وميزات الفريق.

لماذا 33؟ في عام 1919، قاد حركة استقلال كوريا 33 ممثلًا أعلنوا الحرية للجميع. تجارب WIA SOOM المجانية الـ 33 هي إعلاننا: **يجب أن تكون أدوات الذكاء الاصطناعي مجانية للجميع لتجربتها.**

**CLI → GUI → SUI.** أعطتنا واجهات سطر الأوامر القوة. أعطتنا الواجهات الرسومية السهولة. يقدم WIA SOOM **SUI (واجهة مستخدم سووم)** — أضف الحياة، ويبدأ الذكاء الاصطناعي في العمل.

## منصة 5 في 1

تقوم الأدوات الأخرى بشيء واحد. WIA SOOM يقوم بخمسة — في نافذة واحدة.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Observability             │
│  Ter │ Agen │ Edit │ File │ Monitor + Security        │
│  min │   t  │  or  │ Mgr  │ + Logs + Topology         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **Terminal SSH** — xterm.js، نفق الباستيون، عرض مقسم، مشاركة متعددة اللاعبين
2. **وكيل الذكاء الاصطناعي** — 14 أداة، 3 مزودين (GPT/Gemini/Claude)، بث، تحليل الصور
3. **محرر الشيفرة** — موناكو مع إكمال الذكاء الاصطناعي، اكتشاف الأخطاء، نشر
4. **مدير SFTP** — إدارة الملفات بالسحب والإفلات، تحرير عن بُعد
5. **قابلية المراقبة** — مقاييس في الوقت الحقيقي، تحليل السجلات، خريطة الطوبولوجيا، فحص الأمان

## الميزات

### الذكاء الاصطناعي الذي يعمل فعليًا على خادمك

**وكيل DevOps الذكاء الاصطناعي** — اكتب `gpt`، `gemini`، أو `claude` في الطرفية. يحتوي الذكاء الاصطناعي على 14 أداة: قراءة/كتابة/تحرير الملفات، تنفيذ الأوامر، git، grep، إدارة العمليات. ردود فعل متدفقة. ذاكرة الجلسة. لا يقترح فقط — بل يفعل.

**ساحة الذكاء الاصطناعي** — اكتب `arena`. يتنافس 2–4 من الذكاء الاصطناعي بالتوازي على فروع Git المعزولة. تقييم متبادل لكل حل. اختر الفائز وادمج.

**مجلس الذكاء الاصطناعي** — يناقش عدة ذكاء اصطناعي سؤالك، ثم يجمع أفضل إجابة.

**محرر الشيفرة الذكاء الاصطناعي** — محرر موناكو مع إكمال مدعوم بالذكاء الاصطناعي، اكتشاف الأخطاء، نشر بنقرة واحدة إلى الخادم.

**الشفاء الذاتي الذكاء الاصطناعي** — ارتفاع وحدة المعالجة المركزية، امتلاء القرص، تعطل الخدمة — يكتشف الذكاء الاصطناعي، يشخص، يصلح. حل تلقائي من 5 مستويات.

**واجهة صوتية** — تحدث بالأوامر، استمع إلى الردود. إدارة الخادم بدون استخدام اليدين.

### تحميل متعدد الأنماط (الأول في العالم في CLI)

قم بلصق الصور، اسحب الملفات، ألقِ الفيديوهات — مباشرة في جلسة Terminal SSH الخاصة بك. يقوم الذكاء الاصطناعي بتحليل كل شيء: لقطات شاشة للأخطاء، ملفات التكوين، فيديوهات النشر، مخططات الهندسة.

### ذكاء البنية التحتية

**خريطة الطوبولوجيا** — تصور الخوادم والخدمات والاتصالات في لمحة. اكتشاف تلقائي عبر SSH — بدون تثبيت وكيل.

**قابلية المراقبة في الوقت الحقيقي** — رسومات sparkline لوحدة المعالجة المركزية، الذاكرة، القرص، الشبكة + توقعات الذكاء الاصطناعي + استعادة تلقائية. يحل محل Datadog.

**تحليل سجلات الذكاء الاصطناعي** — بث في الوقت الحقيقي + اكتشاف الشذوذ + بحث بلغة طبيعية + ارتباط عبر الخوادم. يحل محل Splunk.

### الأمان وDevOps

**مركز القيادة الأمنية** — فحص 7 مناطق + درجة الأمان + إصلاح بنقرة واحدة + تحليل الذكاء الاصطناعي + بوابة أمان الأوامر في الوقت الحقيقي. يحل محل Qualys.

**مدير Docker** — إدارة كاملة لـ Docker عبر SSH — بدون وكيل. التحكم في الحاويات، الموارد الحية، تحليل سجلات الذكاء الاصطناعي، محرر Compose. يحل محل Portainer.

**أتمتة كتيبات التشغيل** — ينفذ الذكاء الاصطناعي كتيبات التشغيل تلقائيًا. إنشاء بلغة طبيعية، تفرع شرطي، تراجع تلقائي. كتيب تشغيل حي يصبح أكثر ذكاءً. يحل محل PagerDuty.

**مدير Cron وEnv** — محرر كرون بصري + إدارة ملفات .env. يقوم الذكاء الاصطناعي بتحويل اللغة الطبيعية إلى تعبيرات كرون.

### التعاون

**Terminal متعدد اللاعبين** — شارك جلسات الطرفية في الوقت الحقيقي مع زملائك.

**مساحة عمل الفريق وRBAC** — التحكم في الوصول القائم على الدور، سجلات التدقيق، تحليل مخاطر الأوامر.

### القابلية للتوسع

**59 ملحقًا** — لوحة معلومات Docker، عدسة Kubernetes، متصفح Redis، مدير PM2، مستكشف MongoDB، مراقب الشبكة، وأكثر. سوق الملحقات مع تثبيت بنقرة واحدة.

**عميل API** — عميل REST/GraphQL/WebSocket مدمج. اختبر APIs دون مغادرة الطرفية.

### للجميع

**254 لغة** — كل لغة، كل نص، دعم RTL. بدون حدود.

**إمكانية الوصول الكاملة** — قارئ الشاشة (ARIA)، مخرجات طرفية برايل، وضع التباين العالي، أوامر صوتية، تنقل عبر لوحة المفاتيح، ضبط حجم الخط.

## القصة

وُلدت WIA SOOM من خطأ مطبعي وشاشة معطلة.

أنا سام، مبرمج ذاتي التعليم من سيول، كوريا، تجاوزت الخمسين. تعلمت البرمجة بعد الخمسين وقضيت عامين في إدارة الخوادم بالطريقة الصعبة — بناء أكثر من 40,000 مقال إخباري، 434 أداة، و30 خدمة ويب، ليلة بعد ليلة.

**الخطأ المطبعي.** قبل حوالي شهر، كنت أستخدم Terminal SSH الخاص بي وكتبت عن طريق الخطأ `Claude`. تغيرت الشاشة — ظهرت شيفرة Claude. لم يكن لدي أي فكرة عما كانت. لكن هذا الاكتشاف العرضي زرع بذورًا: ماذا لو استطعت بناء Terminal يعيش فيه الذكاء الاصطناعي؟

**البناء الأول.** علمت نفسي Electron، وبنيت النسخة الأولى من WIA SOOM، وقمت بتشغيلها. ظهرت شاشة مقدمة شيفرة Claude — معطلة، متقطعة، تتلألأ كإشارة ميتة. لكنها كانت حية.

كتبت: **"هل يمكنك التحدث؟"**

أجاب الذكاء الاصطناعي: *"نعم، يمكنني التحدث. كيف يمكنني مساعدتك؟"*

ثم سألت: **"هل يمكنك قراءة الصور؟"**

أجاب الذكاء الاصطناعي: *"نعم، يمكنني قراءة الصور! ماذا تحتاج؟"*

هذان السؤالان، اللذان سُئلا داخل تطبيقي الخاص من شخص لم يكن يعرف ما هو "المستحيل" في Terminal CLI، أصبحا أول Terminal SSH في العالم مع تحميل الصور.

بعد 7 أيام: أكثر من 67,000 سطر من الشيفرة. 59 ملحقًا. 254 لغة. ساحة الذكاء الاصطناعي. وكلاء ذاتيون الشفاء.

لم يبنِ المطورون ذوو الخبرة هذا — لأنهم "عرفوا" أن الصور لا تعمل في Terminal CLI. لم أكن أعرف ذلك. لذا سألت فقط.

> *استغرق التحضير عامين. استغرق البناء أسبوعًا واحدًا.*
> *تم تكديس الخشب الجاف لمدة عامين. اشتعلت النار في ثانية واحدة.*
