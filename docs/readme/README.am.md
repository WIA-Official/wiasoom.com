## 🔥 አዲስ ምንድነው

### 1. በSSH ተርሚናል ውስጥ የምስል፣ ፋይል እና ቪዲዮ ማስገባት — የዓለም የመጀመሪያው

በዓለም ላይ ምንም CLI የተመለከተ አይታወቅም። እኛ አዘጋጅነው ነን።

በSSH ተርሚናልዎ ውስጥ የእርስዎን የስህተት ምስል ይቀይሩ። የሎግ ፋይል ይስጡ። የተሳካ እንደማይታወቅ ቪዲዮ ይወድቁ። AI ይወዳድር፣ ይቀርባል፣ እና የሚስማማውን ይነግር። — በተርሚናል ስብስ ውስጥ ሁሉም።

- **Ctrl+Shift+V** — ምስል በቀጥታ ወደ ተርሚናል ይቀይሩ
- **Drag & Drop** — ምስሎች፣ ፋይሎች፣ ቪዲዮዎች ወደ ተርሚናል ይወድቁ
- **የቪዲዮ ቁልፍ መውረድ** — ffmpeg ቪዲዮን በአንድ ቁልፍ ይቀይር
- **ሁሉም 3 AI አቅራቢዎች** — GPT-4o Vision, Gemini Vision, Claude Vision

ይህ ባለቤት በምንም ተርሚናል አይኖርም — በምንም ቦታ።
