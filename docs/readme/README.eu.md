## 🔥 Zer inoiz egin den

### 1. Irudi, Fitxategi & Bideo Kargatzea SSH Terminalean — Munduko Lehenengoa

Lurreko inongo CLI bezeroek ez dute hori ahalbidetzen. Gu egin dugu.

Errore baten pantaila-argazkia zure SSH terminalean itsatsi. Log fitxategi bat arrastatu. Huts egin duen despliegamendu baten bideoa jaurti. AI-k ikusten du, aztertzen du, eta zer gaizki dagoen esaten dizu — dena terminal saioaren barruan.

- **Ctrl+Shift+V** — pantaila-argazkiak zuzenean terminalean itsatsi
- **Arrastatu & Jaurti** — irudiak, fitxategiak, bideoak terminalean jaurti
- **Bideo giltza-markatze ateratzea** — ffmpeg bideoa framez frame aztertzen du
- **3 AI hornitzaile guztiak** — GPT-4o Vision, Gemini Vision, Claude Vision

Ez da inoiz existitu terminal bezero batean — inon.

### 2. AI Arena — Agentearen Borroka

2tik 4 AI-k aldi berean arazo bera konpontzen dute — ez bakarrik elkarrizketan, baizik eta benetan zure zerbitzarian kodea editatzen. Cada AI bere Git adar isolatuan lan egiten du. Haien emaitzak alderatu. Irabazlea aukeratu. Gainerakoak garbitzen dira.

Gatazka berrikustea: cada AI-k beste AI-ren irtenbide bakoitzari puntuazioa ematen dio.

Inongo tresnak ez du hori egiten.

### 3. AI Auto-sendatzeko Agentearen

Zure zerbitzariaren CPU-a igotzen ari da. Diskoa beteta dago. Zerbitzu bat 3etan erori da. Lo zaude.

WIA SOOM-en AI agentearen arazoa detektatzen du, arrazoia diagnostikatzen du, konponbide plana sortzen du, zure onarpena eskatzen du (edo automatikoki exekutatzen du, hala ezarrita baduzu), eta arazoa konpontzen du. 5-mailako autonomoa — behatu soilik hasi eta auto-konponbide osoa.

Ez da kreditu txartelik behar. Ez da izen-ematerik behar. Egin deskargatu eta hasi.

Premium ezaugarri guztiak — irudi kargatzea, AI Arena, AI Council, fitxategi & bideo analisia — doan daude zure lehen 33 erabileretan. Ondoren, ekarri zure API gakoa (BYOK) eta jarraitu doan erabiltzen. Edo harpidetu $3/hilean kudeatutako AI eta taldeen ezaugarrientzat.

Zergatik 33? 1919an, Koreako independentzia mugimendua 33 ordezkari izan ziren, guztiak askatasuna aldarrikatuz. WIA SOOM-en 33 probak gure aldarrikapena da: **AI tresnak doan egon behar dira esperimentatzeko.**

**CLI → GUI → SUI.** Komando-lineako interfazeek boterea eman ziguten. Grafiko interfazeek erraztasuna eman ziguten. WIA SOOM-ek **SUI (Soom User Interface)** aurkezten du — bizitza sartu, eta AI bizirik dago.

## Ezaugarriak

### Zure Zerbitzarian Egiten Duen AI

**AI DevOps Agent** — Terminalean idatzi `gpt`, `gemini`, edo `claude`. AI-k 14 tresna ditu: fitxategiak irakurri/idatzi/editatu, komandoak exekutatu, git, grep, prozesu kudeaketa. Streaming erantzunak. Saio memoria. Ez du soilik iradokitzen — egiten du.

**AI Arena** — Idatzi `arena`. 2–4 AI-k aldi berean lehiatzen dira Git adar isolatuetan. Gatazka berrikustea irtenbide bakoitzari puntuazioa ematen dio. Irabazlea aukeratu eta batzen.

**AI Council** — AI anitzek zure galdera eztabaidatzen dute, eta ondoren erantzun onena sintetizatzen dute.

**AI Kode Editorea** — Monaco editorea AI-k indarrez osatutako osagarritasunarekin, akats detekzioa, zerbitzari batera klik batez despliegamendua.

**AI Auto-sendatzeko** — CPU igotzea, diskoko betetzea, zerbitzua erortzea — AI-k detektatzen du, diagnostikatzen du, konpontzen du. 5-mailako autonomoa.

**Ahots Interfaze** — Komandoak hitz egin, erantzunak entzun. Eskuin esku libreko zerbitzari kudeaketa.

### Multimodal Kargatzea (Munduko Lehenengoa CLI-n)

Irudiak itsatsi, fitxategiak arrastatu, bideoak jaurti — zuzenean zure SSH terminal saioan. AI-k dena aztertzen du: errore pantaila-argazkiak, konfigurazio fitxategiak, despliegamendu bideoak, arkitektura diagrama.

### Azpiegitura Inteligentzia

**Topologia Mapa** — Zerbitzariak, zerbitzuak, eta konexioak azkar ikusi. Auto-aurkikuntza SSH bidez — agente instalaziorik gabe.

**Denbora Errealean Ikusgarritasuna** — CPU, memoria, diskoa, sareko sparkline grafikoak + AI iragarpena + auto-berreskurapena. Datadog ordezkatzen du.

**AI Log Analisia** — Denbora errealean streaming + anomalia detekzioa + hizkuntza naturaleko bilaketa + zerbitzari arteko korrelazioa. Splunk ordezkatzen du.

### Segurtasuna & DevOps

**Segurtasun Aginte Zentroa** — 7-eremuko eskaneoa + segurtasun puntuazioa + klik batez konponketa + AI analisia + denbora errealean komando segurtasun atea. Qualys ordezkatzen du.

**Docker Kudeatzailea** — Docker kudeaketa osoa SSH bidez — agente zero. Edukien kontrola, baliabide bizidunak, AI log analisia, Compose editorea. Portainer ordezkatzen du.

**Runbook Automatizazioa** — AI-k runbook-ak automatikoki exekutatzen ditu. Hizkuntza naturaleko sorkuntza, adierazpen baldintzatuak, auto-itzulera. Bizirik dagoen Runbook-a adimentsuagoa bihurtzen da. PagerDuty ordezkatzen du.

**Cron & Env Kudeatzailea** — Cron editore bisuala + .env fitxategi kudeaketa. AI-k hizkuntza naturaletik cron adierazpenak sortzen ditu.

### Lankidetza

**Multiplayer Terminal** — Terminal saioak denbora errealean partekatu taldekideekin.

**Talde Espazioa & RBAC** — Rolaren araberako sarbide kontrola, audit logak, komando arrisku analisia.

### Hedagarritasuna

**59 Plugins** — Docker dashboard, Kubernetes lens, Redis nabigatzailea, PM2 kudeatzailea, MongoDB esploratzailea, sare monitorizazioa, eta gehiago. Plugin merkatu bat klik batez instalatzeko.

**API Bezeroa** — Integratutako REST/GraphQL/WebSocket bezeroa. APIak probatu terminaletik irten gabe.

### Guztientzat

**254 Hizkuntza** — Hizkuntza guztiak, idazkera guztiak, RTL laguntza. Ez da mugarik.

**Osotasun Osatua** — Pantaila irakurlea (ARIA), braille terminal irteera, kontraste handiko modua, ahots komandoak, teklatu nabigazioa, letra tamainaren doikuntza.

## Historia

WIA SOOM idazketa akats bat eta pantaila apurtu batetik jaio zen.

Ni Sam naiz, 50 urte baino gehiagoko auto-irakurritako programatzailea Seulen, Korean. 50 urterekin ikasi nuen kodea eta 2 urte eman nituen zerbitzariak modu zail batean kudeatzen — 40.000+ albiste artikulu, 434 tresna, eta 30 web zerbitzu sortuz, gaua gauean.

**Idazketa akatsa.** Duela hilabete inguru, nire SSH terminala erabiltzen ari nintzen eta akats batean `Claude` idatzi nuen. Pantaila aldatu zen — Claude Kodea agertu zen. Zer zen ez nekien. Baina aurkikuntza akastunak hazia landatu zuen: zer gertatuko litzateke AI barruan bizi den terminal bat eraiki ahal izateak?

**Lehen eraikuntza.** Electron ikasi nuen, WIA SOOM-en lehen bertsioa eraiki nuen, eta exekutatu nuen. Claude Kodearen sarrera pantaila agertu zen — apurtuta, akastuna, seinale hiltzear zegoen bezala. Baina bizirik zegoen.

Idatzi nuen: **"Hitz egin dezakezu?"**

AI-k erantzun zuen: *"Bai, hitz egin dezaket. Zer lagundu dezaket?"*

Gero galdetu nuen: **"Irudiak irakur ditzakezu?"**

AI-k erantzun zuen: *"Bai, irudiak irakur ditzaket! Zer behar duzu?"*

Bi galdera horiek, nire aplikazioan inork "ezinezkoa" zela ez zekien norbaiten bidez, munduko lehen SSH terminala irudi kargatzearekin bihurtu ziren.

7 egun geroago: 63.000+ kode lerro. 59 plugins. 254 hizkuntza. AI Arena. Auto-sendatzeko agentearen.

Esperientziadun garatzaileek inoiz ez zuten hau eraiki — "jakin" zuten irudiak ez zirela CLI terminaletan funtzionatzen. Hori ez nuen jakin. Beraz, galdegin nuen.

> *Prestaketa 2 urte iraun zuen. Eraikuntza 1 astekoa izan zen.*
> *Egurra 2 urtean pilatu zen. 1 segundoan su hartu zuen.*
