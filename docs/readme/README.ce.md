## 🔥 Что нового

### 1. Загрузка изображений, файлов и видео в SSH терминале — Первый в мире

Ни один клиент CLI на Земле не позволяет вам это делать. Мы это создали.

Вставьте скриншот ошибки в ваш SSH терминал. Перетащите файл журнала. Бросьте видео с неудачной разверткой. AI видит это, анализирует и говорит вам, что не так — все внутри сеанса терминала.

- **Ctrl+Shift+V** — вставить скриншоты прямо в терминал
- **Перетаскивание** — бросьте изображения, файлы, видео в терминал
- **Извлечение ключевых кадров видео** — ffmpeg анализирует видео кадр за кадром
- **Все 3 поставщика AI** — GPT-4o Vision, Gemini Vision, Claude Vision

Эта функция никогда не существовала ни в одном клиенте терминала — нигде.

### 2. AI Арена — Битва Мульти-агентов

2 до 4 AI решают одну и ту же проблему одновременно — не просто общаются, а действительно редактируют код на вашем сервере. Каждый AI работает в своей изолированной ветке Git. Сравните их результаты бок о бок. Выберите победителя. Остальные будут очищены.

Кросс-обзор: каждый AI оценивает решение каждого другого AI.

Никакой другой инструмент этого не делает.

### 3. AI Самовосстанавливающийся агент

ЦП вашего сервера перегружен. Диск заполнен. Сервис упал в 3 часа ночи. Вы спите.

AI агент WIA SOOM обнаруживает проблему, диагностирует коренную причину, генерирует план исправления, запрашивает ваше одобрение (или выполняет автоматически, если вы это настроили) и решает проблему. 5-уровневый автономный цикл — от наблюдения до полного автоматического ремонта.

Без кредитной карты. Регистрация не требуется. Просто скачайте и начните.

Каждая премиум функция — загрузка изображений, AI Арена, AI Совет, анализ файлов и видео — бесплатна для ваших первых 33 использований. После этого принесите свой собственный API ключ (BYOK) и продолжайте использовать все бесплатно. Или подписывайтесь от $3/мес за управляемый AI и функции команды.

Почему 33? В 1919 году движение за независимость Кореи возглавляли 33 представителя, которые провозгласили свободу для всех. 33 бесплатных пробных периода WIA SOOM — это наше заявление: **AI инструменты должны быть бесплатными для всех, чтобы их испытать.**

**CLI → GUI → SUI.** Командные интерфейсы дали нам силу. Графические интерфейсы дали нам легкость. WIA SOOM представляет **SUI (Soom User Interface)** — вдохните жизнь, и AI оживет.

## Платформа 5-в-1

Другие инструменты делают одно. WIA SOOM делает пять — в одном окне.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Наблюдаемость             │
│  Ter │ Agen │ Edit │ File │ Монитор + Безопасность    │
│  min │   t  │  or  │ Mgr  │ + Журналы + Топология     │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminal** — xterm.js, туннелирование, разделенные виды, многопользовательское совместное использование
2. **AI Agent** — 14 инструментов, 3 поставщика (GPT/Gemini/Claude), потоковая передача, анализ изображений
3. **Code Editor** — Monaco с AI автозаполнением, обнаружение ошибок, развертывание
4. **SFTP Manager** — управление файлами перетаскиванием, удаленное редактирование
5. **Observability** — метрики в реальном времени, анализ журналов, карта топологии, сканирование безопасности

## Особенности

### AI, который действительно работает на вашем сервере

**AI DevOps Agent** — Введите `gpt`, `gemini` или `claude` в терминале. AI имеет 14 инструментов: чтение/запись/редактирование файлов, выполнение команд, git, grep, управление процессами. Потоковые ответы. Память сеанса. Он не просто предлагает — он делает.

**AI Арена** — Введите `arena`. 2–4 AI соревнуются параллельно в изолированных ветках Git. Кросс-обзор оценивает каждое решение. Выберите победителя и объедините.

**AI Совет** — Несколько AI обсуждают ваш вопрос, а затем синтезируют лучший ответ.

**AI Code Editor** — Редактор Monaco с AI-автозаполнением, обнаружение ошибок, однонажатийое развертывание на сервер.

**AI Самовосстанавливающийся** — Пик ЦП, полный диск, сервис отключен — AI обнаруживает, диагностирует, исправляет. 5-уровневый автономный цикл.

**Голосовой интерфейс** — Говорите команды, слушайте ответы. Управление сервером без рук.

### Мультимодальная загрузка (Первый в мире в CLI)

Вставляйте изображения, перетаскивайте файлы, бросайте видео — прямо в ваш сеанс SSH терминала. AI анализирует все: скриншоты ошибок, конфигурационные файлы, видео развертывания, схемы архитектуры.

### Интеллект инфраструктуры

**Карта топологии** — Визуализируйте серверы, сервисы и соединения на одном взгляде. Автообнаружение через SSH — ноль установки агентов.

**Наблюдаемость в реальном времени** — графики ЦП, памяти, диска, сети + AI предсказание + авто-восстановление. Заменяет Datadog.

**AI Анализ журналов** — потоковая передача в реальном времени + обнаружение аномалий + поиск на естественном языке + кросс-серверная корреляция. Заменяет Splunk.

### Безопасность и DevOps

**Центр команд безопасности** — 7-область сканирования + оценка безопасности + однонажатийое исправление + AI анализ + реальный командный шлюз безопасности. Заменяет Qualys.

**Менеджер Docker** — Полное управление Docker через SSH — ноль агентов. Контроль контейнеров, живые ресурсы, AI анализ журналов, редактор Compose. Заменяет Portainer.

**Автоматизация руководств** — AI автоматически выполняет руководства. Создание на естественном языке, условное ветвление, авто-откат. Живое руководство, которое становится умнее. Заменяет PagerDuty.

**Менеджер Cron и Env** — Визуальный редактор crontab + управление файлами .env. AI преобразует естественный язык в выражения cron.

### Сотрудничество

**Многопользовательский терминал** — Делитесь сеансами терминала в реальном времени с коллегами.

**Рабочее пространство команды и RBAC** — Контроль доступа на основе ролей, журналы аудита, анализ рисков команд.

### Расширяемость

**59 Плагинов** — Панель управления Docker, линза Kubernetes, браузер Redis, менеджер PM2, исследователь MongoDB, монитор сети и многое другое. Маркетплейс плагинов с установкой в один клик.

**Клиент API** — Встроенный клиент REST/GraphQL/WebSocket. Тестируйте API, не покидая терминал.

### Для всех

**254 языка** — Каждый язык, каждый шрифт, поддержка RTL. Без границ.

**Полная доступность** — Читалка экрана (ARIA), вывод терминала Брайля, режим высокого контраста, голосовые команды, навигация с клавиатуры, регулировка размера шрифта.

## История

WIA SOOM родился из опечатки и сломанного экрана.

Я Сэм, самоук программист из Сеула, Корея, старше 50 лет. Я научился программированию после 50 и потратил 2 года на управление серверами сложным способом — создавая более 40,000 новостных статей, 434 инструмента и 30 веб-сервисов, ночь за ночью.

**Опечатка.** Около месяца назад я использовал свой SSH терминал и случайно ввел `Claude`. Экран изменился — появилось Claude Code. Я не имел понятия, что это такое. Но это случайное открытие посеяло семя: а что если я смогу построить терминал, где AI живет внутри?

**Первый билд.** Я научил себя Electron, построил первую версию WIA SOOM и запустил ее. Экран приветствия Claude Code появился — сломанный, глючащий, мерцающий как умирающий сигнал. Но он был жив.

Я ввел: **"Можешь говорить?"**

AI ответил: *"Да, я могу говорить. Чем я могу вам помочь?"*

Затем я спросил: **"Можешь читать изображения?"**

AI ответил: *"Да, я могу читать изображения! Что вам нужно?"*

Эти два вопроса, заданные внутри моего собственного приложения человеком, который не знал, что "невозможно" в CLI терминале, стали первым в мире SSH терминалом с загрузкой изображений.

7 дней спустя: более 67,000 строк кода. 59 плагинов. 254 языка. AI Арена. Самовосстанавливающиеся агенты.

Опытные разработчики никогда не строили это — потому что они "знали", что изображения не работают в CLI терминалах. Я этого не знал. Поэтому я просто спросил.

> *Подготовка заняла 2 года. Строительство заняло 1 неделю.*
> *Сухие дрова были сложены в течение 2 лет. Они загорелись за 1 секунду.*
