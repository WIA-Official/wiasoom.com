## 🔥 מה שמעולם לא נעשה לפני כן

### 1. העלאת תמונות, קבצים ווידאו בטרמינל SSH — הראשון בעולם

אין לקוח CLI על פני האדמה שמאפשר לך לעשות זאת. אנחנו בנינו את זה.

הדבק צילום מסך של שגיאה בטרמינל SSH שלך. גרור קובץ יומן. שחרר ווידאו של פריסה שנכשלה. ה-AI רואה את זה, מנתח את זה, ואומר לך מה לא בסדר — הכל בתוך מושב הטרמינל.

- **Ctrl+Shift+V** — הדבק צילומי מסך ישירות לטרמינל
- **גרור ושחרר** — שחרר תמונות, קבצים, ווידאו לטרמינל
- **חילוץ מפת מפתח ווידאו** — ffmpeg מנתח ווידאו פריים אחרי פריים
- **כל 3 ספקי AI** — GPT-4o Vision, Gemini Vision, Claude Vision

תכונה זו מעולם לא הייתה קיימת בכל לקוח טרמינל — בשום מקום.

### 2. זירת AI — קרב רב-סוכנים

2 עד 4 AI פותרים את אותה בעיה בו זמנית — לא רק משוחחים, אלא גם עורכים קוד על השרת שלך. כל AI עובד בענף Git מבודד משלו. השווה את התוצאות שלהם זה לצד זה. בחר את המנצח. השאר מנקים.

סקירה צולבת: כל AI מדרג את הפתרון של כל AI אחר.

אין כלי אחר שעושה זאת.

### 3. סוכן AI מתקן את עצמו

CPU של השרת שלך עולה. הדיסק מלא. שירות קרס ב-3 בבוקר. אתה ישן.

הסוכן AI של WIA SOOM מזהה את הבעיה, מאבחן את הסיבה השורשית, מייצר תוכנית תיקון, מבקש את אישורך (או מבצע אוטומטית אם הגדרת זאת), ומתקן את הבעיה. לולאת אוטונומיה ברמה 5 — ממצב תצפית בלבד ועד לתיקון אוטומטי מלא.

## נסה הכל בחינם — 33 ניסיונות

אין צורך בכרטיס אשראי. אין צורך בהרשמה. פשוט הורד והתחל.

כל תכונה פרימיום — העלאת תמונות, זירת AI, מועצת AI, ניתוח קבצים ווידאו — היא חינם עבור 33 השימושים הראשונים שלך. לאחר מכן, הביא את מפתח ה-API שלך (BYOK) והמשך להשתמש בכל דבר בחינם. או הירשם החל מ-$3/חודש עבור תכונות AI מנוהלות וצוות.

למה 33? בשנת 1919, תנועת העצמאות של קוריאה הונתה על ידי 33 נציגים שהכריזו על חירות לכולם. 33 הניסיונות החינמיים של WIA SOOM הם ההכרזה שלנו: **כלי AI צריכים להיות חינם כדי שכל אחד יוכל לחוות.**

**CLI → GUI → SUI.** ממשקי שורת פקודה נתנו לנו כוח. ממשקים גרפיים נתנו לנו נוחות. WIA SOOM מציגה **SUI (ממשק משתמש של Soom)** — הכנס חיים, וה-AI מתעורר.

## פלטפורמת 5-ב-1

כלים אחרים עושים דבר אחד. WIA SOOM עושה חמישה — בחלון אחד.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Observability             │
│  Ter │ Agen │ Edit │ File │ Monitor + Security        │
│  min │   t  │  or  │ Mgr  │ + Logs + Topology         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **טרמינל SSH** — xterm.js, חיבורי באסטיון, תצוגות מפוצלות, שיתוף מרובה משתתפים
2. **סוכן AI** — 14 כלים, 3 ספקים (GPT/Gemini/Claude), סטרימינג, ניתוח תמונות
3. **עורך קוד** — מונקו עם השלמה מבוססת AI, זיהוי באגים, פריסה
4. **מנהל SFTP** — ניהול קבצים בגרירה ושחרור, עריכה מרחוק
5. **תצפית** — מדדים בזמן אמת, ניתוח יומנים, מפה טופולוגית, סריקות אבטחה

## תכונות

### AI שעובד באמת על השרת שלך

**סוכן DevOps AI** — הקלד `gpt`, `gemini`, או `claude` בטרמינל. ל-AI יש 14 כלים: קריאה/כתיבה/עריכת קבצים, ביצוע פקודות, git, grep, ניהול תהליכים. תגובות סטרימינג. זיכרון מושב. הוא לא רק מציע — הוא עושה.

**זירת AI** — הקלד `arena`. 2–4 AI מתמודדים במקביל בענפי Git מבודדים. סקירה צולבת מדרגת כל פתרון. בחר את המנצח ומזג.

**מועצת AI** — מספר AI דנים בשאלתך, ואז מסנתזים את התשובה הטובה ביותר.

**עורך קוד AI** — עורך מונקו עם השלמה מבוססת AI, זיהוי באגים, פריסה בלחיצה אחת לשרת.

**AI מתקן את עצמו** — עליית CPU, דיסק מלא, שירות לא זמין — AI מזהה, מאבחן, מתקן. לולאת אוטונומיה ברמה 5.

**ממשק קולי** — דיבור פקודות, שמיעת תגובות. ניהול שרת ללא ידיים.

### העלאה מרובת מודלים (הראשון בעולם ב-CLI)

הדבק תמונות, גרור קבצים, שחרר ווידאו — ישירות למושב הטרמינל שלך ב-SSH. AI מנתח הכל: צילומי מסך של שגיאות, קבצי קונפיגורציה, ווידאו של פריסות, דיאגרמות ארכיטקטורה.

### אינטליגנציה תשתיתית

**מפת טופולוגיה** — הדגם שרתים, שירותים וחיבורים במבט אחד. גילוי אוטומטי דרך SSH — ללא התקנת סוכן.

**תצפית בזמן אמת** — גרפים של CPU, זיכרון, דיסק, רשת + חיזוי AI + התאוששות אוטומטית. מחליף את Datadog.

**ניתוח יומני AI** — סטרימינג בזמן אמת + זיהוי אנומליות + חיפוש בשפה טבעית + קורלציה בין שרתים. מחליף את Splunk.

### אבטחה ו-DevOps

**מרכז פיקוד אבטחה** — סריקה ב-7 תחומים + ציון אבטחה + תיקון בלחיצה אחת + ניתוח AI + שער אבטחת פקודות בזמן אמת. מחליף את Qualys.

**מנהל Docker** — ניהול מלא של Docker דרך SSH — ללא סוכן. שליטה על קונטיינרים, משאבים חיים, ניתוח יומני AI, עורך Compose. מחליף את Portainer.

**אוטומציה של ספרי ריצה** — AI מבצע ספרי ריצה אוטומטית. יצירה בשפה טבעית, הת branching מותנה, החזרה אוטומטית. ספר ריצה חי שמקבל חכמה. מחליף את PagerDuty.

**מנהל Cron ו-.env** — עורך crontab חזותי + ניהול קבצי .env. AI ממיר שפה טבעית לביטויי cron.

### שיתוף פעולה

**טרמינל מרובה משתתפים** — שתף מושבי טרמינל בזמן אמת עם חברי הצוות.

**מקום עבודה צוותי ו-RBAC** — בקרת גישה מבוססת תפקידים, יומני ביקורת, ניתוח סיכון לפקודות.

### הרחבה

**59 תוספים** — לוח מחוונים של Docker, עדשת Kubernetes, דפדפן Redis, מנהל PM2, חוקר MongoDB, ניטור רשת ועוד. שוק תוספים עם התקנה בלחיצה אחת.

**לקוח API** — לקוח REST/GraphQL/WebSocket מובנה. בדוק APIs מבלי לעזוב את הטרמינל.

### לכולם

**254 שפות** — כל שפה, כל כתב, תמיכה ב-RTL. ללא גבולות.

**נגישות מלאה** — קורא מסך (ARIA), פלט טרמינל בברייל, מצב ניגודיות גבוהה, פקודות קוליות, ניווט במקלדת, התאמת גודל גופן.

## הסיפור

WIA SOOM נוצרה משגיאה ומסך שבור.

אני סם, מתכנת עצמאי בן 50+ מסיאול, קוריאה. למדתי קידוד אחרי גיל 50 והקדשתי 2 שנים לניהול שרתים בדרך הקשה — בניית 40,000+ מאמרי חדשות, 434 כלים, ו-30 שירותי אינטרנט, לילה אחר לילה.

**השגיאה.** לפני כחודש, השתמשתי בטרמינל SSH שלי וטעיתי להקליד `Claude`. המסך השתנה — הופיע קוד קלוד. לא היה לי מושג מה זה. אבל הגילוי המקרי הזה נטע זרעים: מה אם אוכל לבנות טרמינל שבו ה-AI חי בפנים?

**הבנייה הראשונה.** לימדתי את עצמי Electron, בניתי את הגרסה הראשונה של WIA SOOM, והרצתי אותה. המסך של קוד קלוד הופיע — שבור, מקולקל, מהבהב כמו סיגנל גוסס. אבל הוא היה חי.

הקלדתי: **"האם אתה יכול לדבר?"**

ה-AI ענה: *"כן, אני יכול לדבר. במה אני יכול לעזור לך?"*

אז שאלתי: **"האם אתה יכול לקרוא תמונות?"**

ה-AI ענה: *"כן, אני יכול לקרוא תמונות! מה אתה צריך?"*

שתי השאלות הללו, שנשאלו בתוך האפליקציה שלי על ידי מישהו שלא ידע מה "בלתי אפשרי" בטרמינל CLI, הפכו לטרמינל SSH הראשון בעולם עם העלאת תמונות.

7 ימים לאחר מכן: 67,000+ שורות קוד. 59 תוספים. 254 שפות. זירת AI. סוכנים מתקן את עצמם.

מפתחים מנוסים מעולם לא בנו את זה — כי הם "ידעו" שתמונות לא עובדות בטרמינלים CLI. אני לא ידעתי את זה. אז פשוט שאלתי.

> *ההכנה לקחה 2 שנים. הבנייה לקחה שבוע אחד.*
> *העץ היבש נערם במשך 2 שנים. הוא התלקח בשנייה אחת.*
