## 🔥 세상에 없던 것들

### 1. SSH 터미널에서 이미지/파일/동영상 업로드 — 세계 최초

지구상 어떤 CLI 클라이언트도 이 기능이 없습니다. 우리가 만들었습니다.

에러 스크린샷을 SSH 터미널에 붙여넣으세요. 로그 파일을 드래그하세요. 배포 실패 동영상을 떨어뜨리세요. AI가 보고, 분석하고, 뭐가 문제인지 알려줍니다 — 전부 터미널 세션 안에서.

- **Ctrl+Shift+V** — 스크린샷을 터미널에 바로 붙여넣기
- **드래그 앤 드롭** — 이미지, 파일, 동영상을 터미널에 드롭
- **동영상 키프레임 추출** — ffmpeg이 프레임 단위로 분석
- **3사 AI 모두 지원** — GPT-4o Vision, Gemini Vision, Claude Vision

그 어떤 터미널 클라이언트에도 없는 기능입니다.

### 2. 다른 어디에도 없는 터미널 단축키

하루에 수천 번의 키 입력을 줄여주는 작지만 강력한 기능들:

- **Ctrl+Shift+Z** — 붙여넣기 되돌리기. 잘못 붙여넣었다면 Enter 전에 되돌리세요.
- **Ctrl+Shift+S** — 터미널 스크린샷. 터미널 화면 전체를 클립보드에 캡처합니다.
- **Ctrl+Shift+A** — 마지막 출력 복사. 마지막 명령의 결과만 깔끔하게 복사. 마우스 드래그 불필요.
- **Ctrl+Shift+E** — 명령어 재편집. 마지막 명령어를 GUI 에디터에서 수정 후 실행.
- **드래그 = 복사** — 텍스트를 선택하면 즉시 클립보드에 복사됩니다. Ctrl+C 불필요.

어떤 SSH 클라이언트, 터미널 에뮬레이터, CLI 도구에도 이 기능들은 없습니다.

### 3. AI Arena — 멀티 에이전트 배틀

2~4개 AI가 동시에 같은 문제를 풉니다 — 채팅이 아니라 실제로 서버의 코드를 수정합니다. 각 AI는 격리된 Git 브랜치에서 작업합니다. 결과를 나란히 비교하세요. 승자를 선택하면 나머지는 정리됩니다.

교차 리뷰: 각 AI가 다른 AI의 솔루션을 평가합니다.

이걸 하는 도구는 세상에 없습니다.

### 4. AI 자율 복구 에이전트

새벽 3시. 서버의 CPU가 폭주합니다. 디스크가 가득 찼습니다. 서비스가 죽었습니다. 당신은 자고 있습니다.

WIA SOOM의 AI 에이전트가 문제를 감지하고, 원인을 진단하고, 수정 계획을 세우고, 당신의 승인을 기다린 후(또는 자동 실행 설정 시), 문제를 해결합니다. 관찰 전용부터 완전 자동 복구까지 5단계 자율 루프.

## 무료로 모든 것을 경험하세요 — 33회

신용카드 없이. 회원가입 없이. 다운로드하고 바로 시작하세요.

이미지 업로드, AI Arena, AI Council, 파일 & 동영상 분석 — 모든 프리미엄 기능을 처음 33회 무료로 체험할 수 있습니다. 이후에는 본인 API 키(BYOK)를 설정하면 계속 무료입니다. 또는 $3/월부터 관리형 AI와 팀 기능을 구독하세요.

왜 33회? 1919년, 대한민국 독립운동은 33인의 민족 대표가 모두의 자유를 선언하면서 시작되었습니다. WIA SOOM의 33회 무료 체험은 우리의 선언입니다: **AI 도구는 모든 사람이 경험할 수 있어야 합니다.**

**CLI → GUI → SUI.** 명령줄 인터페이스는 힘을 주었고, 그래픽 인터페이스는 편리함을 주었습니다. WIA SOOM은 **SUI(Soom User Interface)**를 제시합니다 — 당신이 숨을 불어넣으면, AI가 움직입니다.

## 5-in-1 플랫폼

다른 도구는 하나만 합니다. WIA SOOM은 다섯 가지를 — 하나의 창에서.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│ SSH  │  AI  │ 코드 │ SFTP │ 관제                      │
│ 터미 │ 에이 │ 에디 │ 파일 │ 모니터링 + 보안            │
│ 널   │ 전트 │ 터   │ 관리 │ + 로그 + 토폴로지          │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH 터미널** — xterm.js, 배스천 터널링, 분할 뷰, 멀티플레이어
2. **AI 에이전트** — 14개 도구, 3사 지원 (GPT/Gemini/Claude), 스트리밍, 이미지 분석
3. **코드 에디터** — Monaco + AI 자동완성 + 버그 감지 + 배포
4. **SFTP 관리** — 드래그 앤 드롭 파일 관리, 원격 편집
5. **관제** — 실시간 메트릭, 로그 분석, 토폴로지 맵, 보안 스캔

## 기능

### 서버에서 실제로 일하는 AI

**AI DevOps 에이전트** — 터미널에서 `gpt`, `gemini`, `claude` 입력. AI가 14가지 도구로 파일 읽기/쓰기/편집, 명령 실행, git, grep, 프로세스 관리. 제안만이 아니라 직접 실행합니다.

**AI Arena** — `arena` 입력. 2~4개 AI가 격리된 Git 브랜치에서 병렬 작업. 교차 리뷰로 평가. 승자 선택 후 머지.

**AI Council** — 여러 AI가 질문에 대해 토론하고, 최선의 답을 종합합니다.

**AI 코드 에디터** — Monaco 에디터에 AI 자동완성, 버그 감지, 서버 원클릭 배포.

**AI 자율 복구** — CPU 폭주, 디스크 부족, 서비스 다운 — AI가 감지, 진단, 수정. 5단계 자율 루프.

**음성 인터페이스** — 말로 명령하고, 귀로 응답 받는. 손이 자유로운 서버 관리.

### 멀티모달 업로드 (CLI 세계 최초)

이미지 붙여넣기, 파일 드래그, 동영상 드롭 — SSH 터미널 세션에서 바로. AI가 모든 것을 분석합니다: 에러 스크린샷, 설정 파일, 배포 동영상, 아키텍처 다이어그램.

### 인프라 인텔리전스

**토폴로지 맵** — 서버, 서비스, 연결 관계를 한눈에. SSH만으로 자동 탐지 — 에이전트 설치 제로.

**실시간 관제** — CPU, 메모리, 디스크, 네트워크 스파크라인 그래프 + AI 예측 + 자동 복구. Datadog 대체.

**AI 로그 분석** — 실시간 스트리밍 + 이상 탐지 + 자연어 검색 + 크로스서버 상관분석. Splunk 대체.

### 보안 & DevOps

**보안 커맨드 센터** — 7영역 스캔 + 보안 점수 + 원클릭 수정 + AI 분석 + 실시간 명령 보안 게이트. Qualys 대체.

**Docker 매니저** — SSH만으로 Docker 완전 관리 — 에이전트 설치 제로. 컨테이너 제어, 실시간 리소스, AI 로그 분석, Compose 에디터. Portainer 대체.

**AI 런북 자동화** — AI가 런북을 자동 실행. 자연어로 생성, 조건 분기, 자동 롤백. 실행할수록 똑똑해지는 Living Runbook. PagerDuty 대체.

**Cron & Env 매니저** — 비주얼 crontab 에디터 + .env 파일 관리. AI가 자연어를 크론 표현식으로 변환.

### 협업

**멀티플레이어 터미널** — 터미널 세션을 팀과 실시간 공유.

**팀 워크스페이스 & RBAC** — 역할 기반 접근 제어, 감사 로그, 명령 위험도 분석.

### 확장성

**59개 플러그인** — Docker 대시보드, Kubernetes 렌즈, Redis 브라우저, PM2 매니저, MongoDB 탐색기, 네트워크 모니터 등. 원클릭 설치 마켓플레이스.

**API 클라이언트** — 내장 REST/GraphQL/WebSocket 클라이언트. 터미널을 떠나지 않고 API 테스트.

### 모두를 위해

**254개 언어** — 모든 언어, 모든 문자, RTL 지원. 국경 없는 도구.

**완전한 접근성** — 스크린 리더 호환(ARIA), 점자 터미널 출력, 고대비 모드, 음성 명령, 키보드 네비게이션, 글꼴 크기 조절.

## 탄생 이야기

WIA SOOM은 오타와 깨진 화면에서 태어났습니다.

저는 연삼흠, 서울에서 50대에 코딩을 독학한 사람입니다. 2년간 밤마다 서버를 관리하며 뉴스 기사 40,000개, 도구 434개, 웹 서비스 30개를 만들었습니다.

**오타.** 약 한 달 전, SSH 터미널을 쓰다가 `Claude`를 실수로 타이핑했습니다. 화면이 바뀌었습니다 — Claude Code가 나타났습니다. 그게 뭔지도 몰랐습니다. 하지만 그 우연한 발견이 씨앗을 심었습니다: AI가 터미널 안에 사는 앱을 만들 수 있다면?

**첫 빌드.** Electron을 독학하고, WIA SOOM 첫 버전을 만들어서 실행했습니다. Claude Code 인트로 화면이 나왔습니다 — 깨져있고, 글리치가 나고, 전원이 나간 듯 지지직거렸습니다. 하지만 살아있었습니다.

타이핑했습니다: **"너. 대화할 수 있어?"**

AI가 답했습니다: *"네. 대화할 수 있습니다. 뭘 도와드릴까요?"*

다음 질문: **"너 이미지 읽을 수 있어?"**

AI가 답했습니다: *"네. 이미지 읽을 수 있어요! 형 뭐 도와드릴까요?"*

직접 만든 앱 안에서, CLI 터미널에서 뭐가 "불가능"한지 몰랐던 사람이 순수한 호기심으로 던진 이 두 질문이, 세계 최초 이미지 업로드 SSH 터미널이 되었습니다.

7일 후: 코드 67,000줄 이상. 플러그인 59개. 254개 언어. AI Arena. 자율 복구 에이전트.

경험 많은 개발자들은 이걸 안 만들었습니다 — CLI에서 이미지는 안 된다고 "알고" 있었으니까. 저는 몰랐습니다. 그래서 그냥 물어봤습니다.
