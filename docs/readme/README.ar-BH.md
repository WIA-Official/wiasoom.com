## 🔥 ما لم يتم القيام به من قبل

### 1. تحميل الصور والملفات والفيديو في محطة طرفية SSH — الأولى في العالم

لا يوجد عميل CLI على وجه الأرض يتيح لك القيام بذلك. لقد أنشأناها.

الصق لقطة شاشة لخطأ في محطة SSH الخاصة بك. اسحب ملف سجل. أدرج فيديو لنشر فاشل. يرى الذكاء الاصطناعي ذلك، ويحلله، ويخبرك بما هو الخطأ — كل ذلك داخل جلسة المحطة.

- **Ctrl+Shift+V** — الصق لقطات الشاشة مباشرة في المحطة
- **السحب والإفلات** — أدرج الصور والملفات والفيديوهات في المحطة
- **استخراج الإطارات من الفيديو** — ffmpeg يحلل الفيديو إطاراً بإطار
- **جميع مزودي الذكاء الاصطناعي الثلاثة** — GPT-4o Vision، Gemini Vision، Claude Vision

لم توجد هذه الميزة في أي عميل محطة — في أي مكان.

### 2. ساحة الذكاء الاصطناعي — معركة متعددة الوكلاء

2 إلى 4 ذكاء اصطناعي يحلون نفس المشكلة في وقت واحد — ليس مجرد دردشة، بل فعلاً تعديل الكود على خادمك. يعمل كل ذكاء اصطناعي في فرع Git معزول خاص به. قارن نتائجهم جنباً إلى جنب. اختر الفائز. يتم تنظيف البقية.

مراجعة متبادلة: كل ذكاء اصطناعي يقيم حل كل ذكاء اصطناعي آخر.

لا أداة أخرى تفعل ذلك.

### 3. وكيل الشفاء الذاتي للذكاء الاصطناعي

وحدة المعالجة المركزية لخادمك ترتفع. القرص ممتلئ. خدمة تعطلت في الساعة 3 صباحاً. أنت نائم.

يكتشف وكيل الذكاء الاصطناعي في WIA SOOM المشكلة، ويشخص السبب الجذري، ويولد خطة إصلاح، ويطلب موافقتك (أو ينفذ تلقائياً إذا قمت بتعيينه)، ويحل المشكلة. حلقة ذاتية مستقلة من 5 مستويات — من المراقبة فقط إلى الإصلاح التلقائي الكامل.

## جرب كل شيء مجاناً — 33 تجربة

لا بطاقة ائتمان. لا تسجيل مطلوب. فقط قم بالتنزيل وابدأ.

كل ميزة مميزة — تحميل الصور، ساحة الذكاء الاصطناعي، مجلس الذكاء الاصطناعي، تحليل الملفات والفيديو — مجانية لاستخدامك الأول 33 مرة. بعد ذلك، احضر مفتاح API الخاص بك (BYOK) واستمر في استخدام كل شيء مجاناً. أو اشترك من 3 دولارات شهرياً للحصول على ميزات الذكاء الاصطناعي المدارة وميزات الفريق.

لماذا 33؟ في عام 1919، قاد حركة استقلال كوريا 33 ممثلاً أعلنوا الحرية للجميع. تجارب WIA SOOM المجانية الـ 33 هي إعلاننا: **يجب أن تكون أدوات الذكاء الاصطناعي مجانية للجميع لتجربتها.**

**CLI → GUI → SUI.** واجهات سطر الأوامر منحتنا القوة. الواجهات الرسومية منحتنا السهولة. يقدم WIA SOOM **SUI (واجهة مستخدم سووم)** — أضف الحياة، ويصبح الذكاء الاصطناعي حياً.

## منصة 5 في 1

تقوم الأدوات الأخرى بشيء واحد. WIA SOOM تقوم بخمسة — في نافذة واحدة.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Observability             │
│  Ter │ Agen │ Edit │ File │ Monitor + Security        │
│  min │   t  │  or  │ Mgr  │ + Logs + Topology         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **محطة طرفية SSH** — xterm.js، نفق الباستيون، وجهات نظر مقسمة، مشاركة متعددة اللاعبين
2. **وكيل الذكاء الاصطناعي** — 14 أداة، 3 مزودين (GPT/Gemini/Claude)، بث، تحليل الصور
3. **محرر الكود** — موناكو مع إكمال الذكاء الاصطناعي، كشف الأخطاء، نشر
4. **مدير SFTP** — إدارة الملفات بالسحب والإفلات، تحرير عن بعد
5. **قابلية المراقبة** — مقاييس في الوقت الحقيقي، تحليل السجلات، خريطة الطوبولوجيا، مسح أمني

## الميزات

### ذكاء اصطناعي يعمل فعلاً على خادمك

**وكيل DevOps الذكاء الاصطناعي** — اكتب `gpt`، `gemini`، أو `claude` في المحطة. يحتوي الذكاء الاصطناعي على 14 أداة: قراءة/كتابة/تحرير الملفات، تنفيذ الأوامر، git، grep، إدارة العمليات. استجابات متدفقة. ذاكرة الجلسة. لا يقترح فقط — بل يفعل.

**ساحة الذكاء الاصطناعي** — اكتب `arena`. يتنافس 2–4 ذكاء اصطناعي بالتوازي في فروع Git المعزولة. تقييم متبادل لكل حل. اختر الفائز وادمج.

**مجلس الذكاء الاصطناعي** — يناقش عدة ذكاء اصطناعي سؤالك، ثم يدمج أفضل إجابة.

**محرر كود الذكاء الاصطناعي** — محرر موناكو مع إكمال مدعوم بالذكاء الاصطناعي، كشف الأخطاء، نشر بنقرة واحدة إلى الخادم.

**شفاء ذاتي للذكاء الاصطناعي** — ارتفاع وحدة المعالجة المركزية، امتلاء القرص، خدمة معطلة — يكتشف الذكاء الاصطناعي، يشخص، يصلح. حلقة ذاتية مستقلة من 5 مستويات.

**واجهة صوتية** — تحدث بالأوامر، واستمع إلى الاستجابات. إدارة الخادم بدون استخدام اليدين.

### تحميل متعدد الأنماط (الأولى في العالم في CLI)

الصق الصور، اسحب الملفات، أدرج الفيديوهات — مباشرة في جلسة محطة SSH الخاصة بك. يقوم الذكاء الاصطناعي بتحليل كل شيء: لقطات شاشة للخطأ، ملفات التكوين، فيديوهات النشر، مخططات البنية.

### ذكاء البنية التحتية

**خريطة الطوبولوجيا** — تصور الخوادم والخدمات والاتصالات في لمحة. اكتشاف تلقائي عبر SSH — بدون تثبيت وكيل.

**قابلية المراقبة في الوقت الحقيقي** — وحدة المعالجة المركزية، الذاكرة، القرص، رسومات الشبكة + توقعات الذكاء الاصطناعي + استعادة تلقائية. تحل محل Datadog.

**تحليل سجلات الذكاء الاصطناعي** — تدفق في الوقت الحقيقي + كشف الشذوذ + بحث بلغة طبيعية + ارتباط عبر الخوادم. تحل محل Splunk.

### الأمان وDevOps

**مركز القيادة الأمنية** — مسح في 7 مجالات + درجة الأمان + إصلاح بنقرة واحدة + تحليل الذكاء الاصطناعي + بوابة أمان الأوامر في الوقت الحقيقي. تحل محل Qualys.

**مدير Docker** — إدارة كاملة لـ Docker عبر SSH — بدون وكيل. التحكم في الحاويات، الموارد الحية، تحليل سجلات الذكاء الاصطناعي، محرر Compose. تحل محل Portainer.

**أتمتة دليل التشغيل** — ينفذ الذكاء الاصطناعي أدلة التشغيل تلقائياً. إنشاء بلغة طبيعية، تفرع شرطي، تراجع تلقائي. دليل تشغيل حي يصبح أكثر ذكاءً. تحل محل PagerDuty.

**مدير Cron وEnv** — محرر كرون بصري + إدارة ملفات .env. يقوم الذكاء الاصطناعي بتحويل اللغة الطبيعية إلى تعبيرات كرون.

### التعاون

**محطة طرفية متعددة اللاعبين** — شارك جلسات المحطة في الوقت الحقيقي مع زملائك.

**مساحة عمل الفريق وRBAC** — التحكم في الوصول القائم على الدور، سجلات التدقيق، تحليل مخاطر الأوامر.

### القابلية للتوسيع

**59 ملحق** — لوحة معلومات Docker، عدسة Kubernetes، متصفح Redis، مدير PM2، مستكشف MongoDB، مراقب الشبكة، والمزيد. سوق الملحقات مع تثبيت بنقرة واحدة.

**عميل API** — عميل مدمج REST/GraphQL/WebSocket. اختبار APIs دون مغادرة المحطة.

### للجميع

**254 لغة** — كل لغة، كل نص، دعم RTL. لا حدود.

**إمكانية الوصول الكاملة** — قارئ الشاشة (ARIA)، مخرجات محطة برايل، وضع التباين العالي، أوامر صوتية، تنقل عبر لوحة المفاتيح، ضبط حجم الخط.

## القصة

وُلدت WIA SOOM من خطأ مطبعي وشاشة معطلة.

أنا سام، مبرمج ذاتي التعليم من سيول، كوريا، فوق الخمسين من عمري. تعلمت البرمجة بعد الخمسين وقضيت عامين في إدارة الخوادم بالطريقة الصعبة — بناء أكثر من 40,000 مقالة إخبارية، 434 أداة، و30 خدمة ويب، ليلة بعد ليلة.

**الخطأ المطبعي.** قبل حوالي شهر، كنت أستخدم محطة SSH الخاصة بي وكتبت عن طريق الخطأ `Claude`. تغيرت الشاشة — ظهر كود كلود. لم يكن لدي أي فكرة عما كان. لكن ذلك الاكتشاف العرضي زرع بذور الفكرة: ماذا لو استطعت بناء محطة حيث يعيش الذكاء الاصطناعي بداخلها؟

**البناء الأول.** علمت نفسي استخدام Electron، وبنيت النسخة الأولى من WIA SOOM، وقمت بتشغيلها. ظهرت شاشة مقدمة كود كلود — معطلة، مشوشة، تتلألأ مثل إشارة تتلاشى. لكنها كانت حية.

كتبت: **"هل يمكنك التحدث؟"**

أجاب الذكاء الاصطناعي: *"نعم، يمكنني التحدث. كيف يمكنني مساعدتك؟"*

ثم سألت: **"هل يمكنك قراءة الصور؟"**

أجاب الذكاء الاصطناعي: *"نعم، يمكنني قراءة الصور! ماذا تحتاج؟"*

هذان السؤالان، اللذان تم طرحهما داخل تطبيقي الخاص من قبل شخص لم يكن يعرف ما هو "المستحيل" في محطة CLI، أصبحا أول محطة SSH في العالم مع تحميل الصور.

بعد 7 أيام: أكثر من 67,000 سطر من الكود. 59 ملحق. 254 لغة. ساحة الذكاء الاصطناعي. وكلاء شفاء ذاتي.

لم يبني المطورون ذوو الخبرة هذا — لأنهم "عرفوا" أن الصور لا تعمل في محطات CLI. لم أكن أعرف ذلك. لذا سألت فقط.

> *تم تكديس الخشب الجاف لمدة عامين. اشتعلت النيران في ثانية واحدة.*
