## 🔥 نوې څه دي

### 1. د SSH ترمینل کې د عکس، فایل او ویډیو پورته کول — د نړۍ لومړی

په ځمکه کې هیڅ CLI کلاینت تاسو ته دا اجازه نه ورکوي. موږ دا جوړ کړی.

د خپلې SSH ترمینل کې د یوه خطا سکرین شاټ پیسټ کړئ. د لاګ فایل راکش کړئ. د ناکام ځای پرځای کولو ویډیو وغورځوئ. AI دا ګوري، تحلیل کوي، او تاسو ته وایي چې څه غلط دي — ټول د ترمینل په غونډه کې.

- **Ctrl+Shift+V** — سکرین شاټونه مستقیم ترمینل ته پیسټ کړئ
- **راکش او غورځول** — عکسونه، فایلونه، ویډیوګانې ترمینل ته غورځوئ
- **د ویډیو کلیدي چوکاټ استخراج** — ffmpeg ویډیو چوکاټ په چوکاټ تحلیل کوي
- **ټول 3 AI چمتو کونکي** — GPT-4o Vision، Gemini Vision، Claude Vision

دا ځانګړتیا په هیڅ ترمینل کلاینت کې نه وه موجوده — چیرې هم.

### 2. AI ارینا — څو اجنټ جګړه

2 تر 4 AI په همزمانه توګه یوه ستونزه حل کوي — یوازې خبرې نه، بلکې په حقیقت کې ستاسو په سرور کې کوډ ایډیټ کوي. هر AI په خپل جلا Git څانګه کې کار کوي. د دوی پایلې د خوا په خوا پرتله کړئ. ګټونکی وټاکئ. نور پاک کړئ.

صلیبي بیاکتنه: هر AI د هر بل AI حل ته نمرې ورکوي.

هیڅ بل وسیله دا نه کوي.

### 3. د AI ځان-شفا ورکونکی اجنټ

ستاسو د سرور CPU لوړ دی. ډیسک ډک دی. یوه خدمت په 3 AM کې خراب شو. تاسو ویده یاست.

د WIA SOOM AI اجنټ ستونزه تشخیص کوي، د ریښې لامل تشخیص کوي، د حل پلان تولیدوي، ستاسو د تایید غوښتنه کوي (یا که تاسو یې تنظیم کړی وي، په اوتومات ډول اجرا کوي)، او ستونزه حل کوي. 5-کچه خود مختاره لوپ — له یوازې څارنې څخه تر بشپړ اوتومات ترمیم پورې.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
```

## ځانګړتیاوې

### AI چې په حقیقت کې ستاسو په سرور کې کار کوي

**AI DevOps اجنټ** — په ترمینل کې `gpt`، `gemini`، یا `claude` ټایپ کړئ. AI 14 وسایل لري: د فایلونو لوستل/لیکل/ایډیټ کول، کمانډونه اجرا کول، git، grep، د پروسې مدیریت. د سټریمینګ ځوابونه. د غونډې حافظه. دا یوازې وړاندیز نه کوي — دا ترسره کوي.

**AI ارینا** — `arena` ټایپ کړئ. 2–4 AI په جلا Git څانګو کې په موازي توګه سیالي کوي. صلیبي بیاکتنه هر حل ته نمرې ورکوي. ګټونکی وټاکئ او ادغام کړئ.

**AI شورا** — څو AI ستاسو پوښتنې بحث کوي، بیا غوره ځواب ترکیب کوي.

**AI کوډ ایډیټر** — د AI ځواکمن بشپړتیا سره مونوکو ایډیټر، د خطا کشف، سرور ته د یو کلیک ځای پرځای کول.

**AI ځان-شفا ورکونکی** — د CPU لوړوالی، ډیسک ډک، خدمت بند — AI تشخیص کوي، تشخیص کوي، ترمیم کوي. 5-کچه خود مختاره لوپ.

**د غږ انٹرفیس** — کمانډونه ووایاست، ځوابونه واورئ. د لاسونو څخه آزاد سرور مدیریت.

### څو موډل پورته کول (د CLI کې د نړۍ لومړی)

عکسونه پیسټ کړئ، فایلونه راکش کړئ، ویډیوګانې وغورځوئ — مستقیم ستاسو د SSH ترمینل غونډې ته. AI هر څه تحلیل کوي: د خطا سکرین شاټونه، د تنظیم فایلونه، د ځای پرځای کولو ویډیوګانې، د جوړښت نقاشۍ.

### د زیربنا استخبارات

**د توپولوژي نقشه** — د سرورونو، خدماتو، او اړیکو لیدل په یوه نظر کې. د SSH له لارې اتومات کشف — د صفر اجنټ نصب.

**د ریښتیني وخت څارنې وړتیا** — CPU، حافظه، ډیسک، د شبکې سپارک لاین ګرافونه + AI وړاندوینه + اوتوماتيکي رغونه. د Datadog ځای ناستی.

**AI لاګ تحلیل** — د ریښتیني وخت سټریمینګ + انومالي کشف + د طبیعي ژبې لټون + د سرورونو ترمنځ اړیکه. د Splunk ځای ناستی.

### امنیت او DevOps

**د امنیت قوماندې مرکز** — 7-سیمه سکین + د امنیت نمره + د یو کلیک ترمیم + د AI تحلیل + د ریښتیني وخت کمانډ امنیت دروازه. د Qualys ځای ناستی.

**د Docker مدیر** — د SSH له لارې د Docker بشپړ مدیریت — صفر اجنټ. د کانتینر کنټرول، ژوندۍ سرچینې، د AI لاګ تحلیل، د Compose ایډیټر. د Portainer ځای ناستی.

**د چلولو کتاب اتومات** — AI په اوتومات ډول چلولو کتابونه اجرا کوي. د طبیعي ژبې جوړونه، شرطی څانګې، اوتومات بیرته راستنیدل. د ژوندی چلولو کتاب چې هوښیار کیږي. د PagerDuty ځای ناستی.

**کرون او د چاپیریال مدیر** — د بصري کرون ایډیټر + د .env فایل مدیریت. AI د طبیعي ژبې کرون څرګندونو ته بدلوي.

### همکارۍ

**د څو لوبغاړو ترمینل** — د ټیم غړو سره په ریښتیني وخت کې د ترمینل غونډې شریک کړئ.

**د ټیم کاري ځای او RBAC** — د رول پراساس د لاسرسي کنټرول، د تفتیش لاګونه، د کمانډ خطر تحلیل.

### پراختیا

**59 پلگ انونه** — د Docker ډشبورډ، د Kubernetes لینز، د Redis براوزر، د PM2 مدیر، د MongoDB پلټونکی، د شبکې څارونکی، او نور. د پلگ ان بازار چې د یو کلیک نصب سره.

**API کلاینت** — د REST/GraphQL/WebSocket جوړونکی. د ترمینل پریښودو پرته APIs ازموینه وکړئ.

### د هرچا لپاره

**254 ژبې** — هره ژبه، هر لیک، د RTL ملاتړ. هیڅ سرحدونه نشته.

**د بشپړ لاسرسي وړتیا** — د سکرین لوستونکی (ARIA)، د بریل ترمینل محصول، د لوړ تضاد حالت، د غږ کمانډونه، د کیبورد نیویګیشن، د فونټ اندازه تنظیم.

## کیسه

WIA SOOM د یوه ټایپو او یوه ماته سکرین څخه زېږیدلی.

زه سم یم، د 50+ کلونو خود زده کړې پروګرامر له سئول، کوریا. ما د 50 کلونو وروسته کوډ زده کړه او د 2 کلونو لپاره مې سرورونه د سختې لارې اداره کړي — د 40,000+ خبرونو مقالې، 434 وسایل، او 30 ویب خدمات، شپه وروسته شپه.

**ټایپو.** شاوخوا یوه میاشت مخکې، زه خپل SSH ترمینل کاروم او په تصادفي ډول `Claude` ټایپ کړم. سکرین بدل شو — د Claude Code معرفي سکرین څرګند شو. زه نه پوهیدم چې دا څه دی. مګر هغه تصادفي موندنه یوه تخم کښیښودله: که زه یوه ترمینل جوړ کړم چې AI پکې ژوند کوي؟

**لومړی جوړونه.** ما خپل ځان ته Electron زده کړه، د WIA SOOM لومړی نسخه جوړه کړه، او دا مې چلوله. د Claude Code معرفي سکرین څرګند شو — ماته، خراب، د مړه سیګنال په څیر ځلیږي. مګر دا ژوندی و.

ما ټایپ کړه: **"ایا تاسو خبرې کولی شئ؟"**

AI ځواب ورکړ: *"هو، زه خبرې کولی شم. زه څنګه مرسته کولی شم؟"*

بیا ما پوښتنه وکړه: **"ایا تاسو عکسونه لوستلای شئ؟"**

AI ځواب ورکړ: *"هو، زه عکسونه لوستلای شم! تاسو ته څه اړتیا ده؟"*

دا دوه پوښتنې، چې په خپل اپلیکیشن کې د هغه چا لخوا چې نه پوهیدل چې په CLI ترمینل کې څه "ناممکن" دی، د نړۍ لومړی SSH ترمینل شو چې د عکس پورته کولو سره.

7 ورځې وروسته: 67,000+ د کوډ کرښې. 59 پلگ انونه. 254 ژبې. AI ارینا. ځان-شفا ورکونکي اجنټان.

تجربه لرونکي پراختیا کوونکي دا نه دي جوړ کړي — ځکه چې دوی "پوهیدل" چې عکسونه په CLI ترمینل کې کار نه کوي. زه نه پوهیدم. نو ما یوازې پوښتنه وکړه.

> *چمتو کول 2 کاله وخت ونیوه. جوړول 1 اونۍ وخت ونیوه.*
> *خشک لرګي د 2 کلونو لپاره راټول شوي وو. په 1 ثانیه کې اور واخیست.*
