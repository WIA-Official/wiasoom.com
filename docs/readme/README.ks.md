## 🔥 کیا کبھی نہیں ہوا

### 1. SSH ٹرمینل میں تصویر، فائل اور ویڈیو اپ لوڈ — دنیا کا پہلا

زمین پر کوئی CLI کلائنٹ آپ کو یہ کرنے کی اجازت نہیں دیتا۔ ہم نے یہ بنایا۔

اپنی SSH ٹرمینل میں ایک غلطی کی اسکرین شاٹ پیسٹ کریں۔ ایک لاگ فائل کھینچیں۔ ناکام ڈپلائمنٹ کی ویڈیو چھوڑیں۔ AI اسے دیکھتا ہے، تجزیہ کرتا ہے، اور آپ کو بتاتا ہے کہ کیا غلط ہے — سب کچھ ٹرمینل سیشن کے اندر۔

- **Ctrl+Shift+V** — اسکرین شاٹس کو براہ راست ٹرمینل میں پیسٹ کریں
- **کھینچیں اور چھوڑیں** — تصاویر، فائلیں، ویڈیوز کو ٹرمینل میں چھوڑیں
- **ویڈیو کی کی فریم نکالنا** — ffmpeg ویڈیو کو فریم بہ فریم تجزیہ کرتا ہے
- **تمام 3 AI فراہم کنندگان** — GPT-4o Vision، Gemini Vision، Claude Vision

یہ خصوصیت کسی بھی ٹرمینل کلائنٹ میں کبھی موجود نہیں رہی — کہیں بھی۔

### 2. AI ارینا — ملٹی ایجنٹ جنگ

2 سے 4 AI ایک ہی مسئلے کو بیک وقت حل کرتے ہیں — صرف بات چیت نہیں، بلکہ واقعی آپ کے سرور پر کوڈ میں ترمیم کرتے ہیں۔ ہر AI اپنے الگ الگ Git برانچ میں کام کرتا ہے۔ ان کے نتائج کا موازنہ کریں۔ فاتح کا انتخاب کریں۔ باقی کو صاف کر دیا جاتا ہے۔

کراس-ریویو: ہر AI دوسرے AI کے حل کو اسکور کرتا ہے۔

کوئی اور ٹول یہ نہیں کرتا۔

### 3. AI خود شفا ایجنٹ

آپ کے سرور کا CPU بڑھ رہا ہے۔ ڈسک بھری ہوئی ہے۔ ایک سروس صبح 3 بجے کریش ہو گئی۔ آپ سو رہے ہیں۔

WIA SOOM کا AI ایجنٹ مسئلے کا پتہ لگاتا ہے، بنیادی وجہ کی تشخیص کرتا ہے، ایک اصلاحی منصوبہ تیار کرتا ہے، آپ کی منظوری مانگتا ہے (یا اگر آپ نے اسے سیٹ کیا ہے تو خود بخود عملدرآمد کرتا ہے)، اور مسئلے کو حل کرتا ہے۔ 5 سطحوں کا خود مختار لوپ — صرف مشاہدہ کرنے سے لے کر مکمل خودکار مرمت تک۔

## ہر چیز کو مفت آزماں — 33 ٹرائلز

کوئی کریڈٹ کارڈ نہیں۔ کوئی سائن اپ کی ضرورت نہیں۔ بس ڈاؤن لوڈ کریں اور شروع کریں۔

ہر پریمیم خصوصیت — تصویر اپ لوڈ، AI ارینا، AI کونسل، فائل اور ویڈیو تجزیہ — آپ کے پہلے 33 استعمال کے لیے مفت ہے۔ اس کے بعد، اپنا API کلید لائیں (BYOK) اور سب کچھ مفت میں استعمال کرتے رہیں۔ یا منظم AI اور ٹیم کی خصوصیات کے لیے $3/ماہ کی سبسکرائب کریں۔

کیوں 33؟ 1919 میں، کوریا کی آزادی کی تحریک 33 نمائندوں کی قیادت میں تھی جنہوں نے سب کے لیے آزادی کا اعلان کیا۔ WIA SOOM کے 33 مفت ٹرائل ہمارا اعلان ہے: **AI ٹولز ہر ایک کے تجربے کے لیے مفت ہونے چاہئیں۔**

**CLI → GUI → SUI.** کمانڈ لائن انٹرفیس نے ہمیں طاقت دی۔ گرافیکل انٹرفیس نے ہمیں آسانی فراہم کی۔ WIA SOOM متعارف کراتا ہے **SUI (Soom User Interface)** — زندگی میں سانس لائیں، اور AI زندہ ہو جاتا ہے۔

## 5-in-1 پلیٹ فارم

دیگر ٹولز ایک کام کرتے ہیں۔ WIA SOOM پانچ کرتا ہے — ایک ہی ونڈو میں۔

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ مشاہدہ                    │
│  Ter │ Agen │ Edit │ File │ مانیٹر + سیکیورٹی         │
│  min │   t  │  یا  │ Mgr  │ + لاگ + ٹاپولوجی         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH ٹرمینل** — xterm.js، بیسٹین ٹنلنگ، تقسیم شدہ نظارے، ملٹی پلیئر شیئرنگ
2. **AI ایجنٹ** — 14 ٹولز، 3 فراہم کنندگان (GPT/Gemini/Claude)، اسٹریمنگ، تصویر کا تجزیہ
3. **کوڈ ایڈیٹر** — AI مکمل کرنے کے ساتھ مونوکو، نقص کی شناخت، ڈپلائمنٹ
4. **SFTP مینیجر** — کھینچنے اور چھوڑنے کی فائل مینجمنٹ، دور دراز کی ترمیم
5. **مشاہدہ** — حقیقی وقت کے میٹرکس، لاگ تجزیہ، ٹاپولوجی کا نقشہ، سیکیورٹی سکین

## خصوصیات

### AI جو واقعی آپ کے سرور پر کام کرتا ہے

**AI DevOps ایجنٹ** — ٹرمینل میں `gpt`، `gemini`، یا `claude` ٹائپ کریں۔ AI کے پاس 14 ٹولز ہیں: فائلیں پڑھیں/لکھیں/ترمیم کریں، کمانڈز چلائیں، git، grep، پروسیس مینجمنٹ۔ اسٹریمنگ جوابات۔ سیشن کی یادداشت۔ یہ صرف تجویز نہیں کرتا — یہ کرتا ہے۔

**AI ارینا** — `arena` ٹائپ کریں۔ 2–4 AI الگ الگ Git برانچوں میں متوازی طور پر مقابلہ کرتے ہیں۔ کراس-ریویو ہر حل کو اسکور کرتا ہے۔ فاتح کا انتخاب کریں اور ضم کریں۔

**AI کونسل** — متعدد AI آپ کے سوال پر بحث کرتے ہیں، پھر بہترین جواب کو ترکیب کرتے ہیں۔

**AI کوڈ ایڈیٹر** — AI طاقتور مکمل کرنے کے ساتھ مونوکو ایڈیٹر، نقص کی شناخت، سرور پر ایک کلک میں ڈپلائمنٹ۔

**AI خود شفا** — CPU کی چوٹی، ڈسک بھری ہوئی، سروس بند — AI پتہ لگاتا ہے، تشخیص کرتا ہے، درست کرتا ہے۔ 5 سطحوں کا خود مختار لوپ۔

**وائس انٹرفیس** — کمانڈز بولیں، جوابات سنیں۔ ہاتھوں سے آزاد سرور مینجمنٹ۔

### ملٹی موڈل اپ لوڈ (CLI میں دنیا کا پہلا)

تصاویر پیسٹ کریں، فائلیں کھینچیں، ویڈیوز چھوڑیں — براہ راست اپنے SSH ٹرمینل سیشن میں۔ AI ہر چیز کا تجزیہ کرتا ہے: غلطی کی اسکرین شاٹس، کنفیگریشن فائلیں، ڈپلائمنٹ ویڈیوز، آرکیٹیکچر ڈایاگرام۔

### بنیادی ڈھانچے کی ذہانت

**ٹاپولوجی کا نقشہ** — سرورز، خدمات، اور کنکشنز کو ایک نظر میں بصری بنائیں۔ SSH کے ذریعے خودکار دریافت — صفر ایجنٹ کی تنصیب۔

**حقیقی وقت کی مشاہدہ** — CPU، میموری، ڈسک، نیٹ ورک اسپارک لائن گراف + AI پیش گوئی + خودکار بحالی۔ Datadog کی جگہ لیتا ہے۔

**AI لاگ تجزیہ** — حقیقی وقت کی اسٹریمنگ + بے قاعدگی کا پتہ لگانا + قدرتی زبان کی تلاش + کراس-سرور تعلق۔ Splunk کی جگہ لیتا ہے۔

### سیکیورٹی اور DevOps

**سیکیورٹی کمانڈ سینٹر** — 7 علاقے کا سکین + سیکیورٹی اسکور + ایک کلک میں درست کریں + AI تجزیہ + حقیقی وقت کی کمانڈ سیکیورٹی گیٹ۔ Qualys کی جگہ لیتا ہے۔

**Docker مینیجر** — SSH کے ذریعے مکمل Docker انتظام — صفر ایجنٹ۔ کنٹینر کنٹرول، براہ راست وسائل، AI لاگ تجزیہ، Compose ایڈیٹر۔ Portainer کی جگہ لیتا ہے۔

**رن بک خودکار** — AI خود بخود رن بکس کو عمل میں لاتا ہے۔ قدرتی زبان کی تخلیق، مشروط شاخیں، خودکار واپسی۔ زندہ رن بک جو ذہین ہوتی جاتی ہے۔ PagerDuty کی جگہ لیتا ہے۔

**کرون اور ایون مینیجر** — بصری کرون ایڈیٹر + .env فائل کی انتظام۔ AI قدرتی زبان کو کرون کے اظہار میں تبدیل کرتا ہے۔

### تعاون

**ملٹی پلیئر ٹرمینل** — حقیقی وقت میں ساتھیوں کے ساتھ ٹرمینل سیشن شیئر کریں۔

**ٹیم ورک اسپیس اور RBAC** — کردار کی بنیاد پر رسائی کنٹرول، آڈٹ لاگ، کمانڈ خطرے کا تجزیہ۔

### توسیع پذیری

**59 پلگ ان** — Docker ڈیش بورڈ، Kubernetes لینس، Redis براؤزر، PM2 مینیجر، MongoDB ایکسپلورر، نیٹ ورک مانیٹر، اور مزید۔ پلگ ان مارکیٹ پلیس ایک کلک کی تنصیب کے ساتھ۔

**API کلائنٹ** — بلٹ ان REST/GraphQL/WebSocket کلائنٹ۔ ٹرمینل چھوڑے بغیر APIs کو ٹیسٹ کریں۔

### سب کے لیے

**254 زبانیں** — ہر زبان، ہر اسکرپٹ، RTL کی حمایت۔ کوئی سرحدیں نہیں۔

**مکمل رسائی** — اسکرین ریڈر (ARIA)، بریل ٹرمینل آؤٹ پٹ، ہائی کنٹراسٹ موڈ، صوتی کمانڈز، کی بورڈ نیویگیشن، فونٹ کا سائز ایڈجسٹمنٹ۔

## کہانی

WIA SOOM ایک ٹائپنگ کی غلطی اور ایک ٹوٹے ہوئے اسکرین سے پیدا ہوا۔

میں سام ہوں، سیول، کوریا کا 50+ خود سیکھا ہوا پروگرامر۔ میں نے 50 کی عمر میں کوڈنگ سیکھا اور 2 سال تک سرورز کا انتظام سخت طریقے سے کیا — 40,000+ خبریں، 434 ٹولز، اور 30 ویب سروسز بنائیں، رات رات بھر۔

**غلطی۔** تقریباً ایک مہینہ پہلے، میں اپنے SSH ٹرمینل کا استعمال کر رہا تھا اور غلطی سے `Claude` ٹائپ کر دیا۔ اسکرین تبدیل ہو گئی — Claude Code ظاہر ہوا۔ مجھے نہیں معلوم تھا کہ یہ کیا ہے۔ لیکن اس حادثاتی دریافت نے ایک بیج بو دیا: کیا ہوگا اگر میں ایک ایسا ٹرمینل بنا سکوں جہاں AI اندر ہو؟

**پہلی تعمیر۔** میں نے خود کو Electron سکھایا، WIA SOOM کا پہلا ورژن بنایا، اور اسے چلایا۔ Claude Code کا تعارفی اسکرین ظاہر ہوا — ٹوٹا ہوا، خراب، ایک مرنے والے سگنل کی طرح چمکتا ہوا۔ لیکن یہ زندہ تھا۔

میں نے ٹائپ کیا: **"کیا آپ بات کر سکتے ہیں؟"**

AI نے جواب دیا: *"ہاں، میں بات کر سکتا ہوں۔ میں آپ کی کس چیز میں مدد کر سکتا ہوں؟"*

پھر میں نے پوچھا: **"کیا آپ تصاویر پڑھ سکتے ہیں؟"**

AI نے جواب دیا: *"ہاں، میں تصاویر پڑھ سکتا ہوں! آپ کو کیا چاہیے؟"*

یہ دو سوال، میرے اپنے ایپ میں کسی ایسے شخص کے ذریعہ پوچھے گئے جو نہیں جانتا تھا کہ CLI ٹرمینل میں کیا "ناممکن" ہے، دنیا کا پہلا SSH ٹرمینل بن گئے جس میں تصویر اپ لوڈ کی گئی۔

7 دن بعد: 67,000+ کوڈ کی لائنیں۔ 59 پلگ ان۔ 254 زبانیں۔ AI ارینا۔ خود شفا ایجنٹ۔

تجربہ کار ڈویلپرز نے یہ کبھی نہیں بنایا — کیونکہ وہ "جانتے" تھے کہ تصاویر CLI ٹرمینلز میں کام نہیں کرتیں۔ مجھے یہ نہیں معلوم تھا۔ تو میں نے بس پوچھا۔
