## 🔥 Ինչ նոր է

### 1. Նկար, Ֆայլ & Տեսանյութ Ավելացնել SSH Տերմինալում — Աշխարհի Առաջին

Երկրի վրա ոչ մի CLI հաճախորդ չի թույլ տալիս դա անել։ Մենք ստեղծեցինք դա։

Պատճենեք սխալների էկրանային նկարը ձեր SSH տերմինալում։ Վերքաշեք լոգ ֆայլ։ Տեսանյութ թողեք ձախողված տեղադրման մասին։ AI-ն տեսնում է դա, վերլուծում և ասում, թե ինչ է սխալ — ամեն ինչ տերմինալի նստաշրջանի ներսում։

- **Ctrl+Shift+V** — անմիջապես պատճենեք էկրանի նկարները տերմինալ
- **Վերքաշեք & Թողեք** — թողեք նկարներ, ֆայլեր, տեսանյութեր տերմինալում
- **Տեսանյութի բանաձևի հանման** — ffmpeg-ը վերլուծում է տեսանյութը շրջանակ առ շրջանակ
- **Բոլոր 3 AI մատակարարներ** — GPT-4o Vision, Gemini Vision, Claude Vision

Այս հատկությունը երբեք չի եղել որևէ տերմինալ հաճախորդում — որտեղ էլ որ լինի։

### 2. AI Արենա — Բազմա-Աջակցող Պայքար

2-ից 4 AI-ներ միաժամանակ լուծում են նույն խնդիրը — ոչ միայն զրուցում, այլ իրականում խմբագրում են կոդը ձեր սերվերում։ Յուրաքանչյուր AI աշխատում է իր սեփական մեկուսացված Git ճյուղում։ Համեմատեք նրանց արդյունքները կողք կողքի։ Ընտրեք հաղթողին։ Մնացածները մաքրվում են։

Խաչ-վերանայում. յուրաքանչյուր AI գնահատում է մյուս AI-ների լուծումները։

Այլ գործիքներ դա չեն անում։

### 3. AI Ինքնազգացող Agent

Ձեր սերվերի CPU-ն բարձրանում է։ Դիսկը լի է։ Ծառայությունը փլուզվել է 3 AM-ին։ Դուք քնած եք։

WIA SOOM-ի AI աջակցությունը հայտնաբերում է խնդիրը, ախտորոշում է հիմնական պատճառը, ստեղծում է ուղղման պլան, խնդրում է ձեր հաստատումը (կամ ինքնաբերաբար իրականացնում, եթե դուք դա կարգավորել եք) և լուծում է խնդիրը։ 5-հարկանի ինքնավար ցիկլ — դիտելուց մինչև լիարժեք ավտո-սարքավորում։

## Փորձեք Ամեն ինչ Անվճար — 33 Փորձարկումներ

Ոչ մի կրեդիտ քարտ։ Ոչ մի գրանցում անհրաժեշտ չէ։ Պարզապես բեռնեք և սկսեք։

Յուրաքանչյուր պրեմիում հատկություն — նկարների ավելացում, AI Արենա, AI Խորհուրդ, ֆայլերի & տեսանյութերի վերլուծություն — անվճար է ձեր առաջին 33 օգտագործման համար։ Այդուհետ, բերեք ձեր API բանալին (BYOK) և շարունակեք օգտագործել ամեն ինչ անվճար։ Կամ բաժանորդագրվեք $3/ամսվա համար կառավարվող AI և թիմի հատկությունների համար։

Ինչու 33? 1919 թվականին Կորեայի անկախության շարժումը ղեկավարել է 33 ներկայացուցիչ, ովքեր հայտարարել են ազատություն բոլորի համար։ WIA SOOM-ի 33 անվճար փորձարկումները մեր հայտարարությունն են՝ **AI գործիքները պետք է լինեն անվճար, որպեսզի բոլորը փորձեն։**

**CLI → GUI → SUI.** Հրամանային ինտերֆեյսները մեզ տվեցին ուժ։ Գրապիկական ինտերֆեյսները մեզ տվեցին հեշտություն։ WIA SOOM-ն ներկայացնում է **SUI (Soom User Interface)** — ներշնչեք կյանք, և AI-ն կենդանանում է։

## 5-in-1 Պլատֆորմ

Այլ գործիքները անում են մեկ բան։ WIA SOOM-ն անում է հինգը — մեկ պատուհանում։

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Հսկողություն             │
│  Ter │ Agen │ Edit │ File │ Հսկողություն + Անվտանգություն        │
│  min │   t  │  or  │ Mgr  │ + Լոգեր + Տոպոլոգիա         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Տերմինալ** — xterm.js, բաստիոնային թունելներ, բաժանված տեսարաններ, բազմախաղային կիսում
2. **AI Աջակցություն** — 14 գործիք, 3 մատակարար (GPT/Gemini/Claude), հոսքային, նկարների վերլուծություն
3. **Կոդի խմբագիր** — Monaco AI լրացումով, սխալների հայտնաբերում, տեղադրում
4. **SFTP Կառավարիչ** — ֆայլերի կառավարում, հեռակա խմբագրում
5. **Հսկողություն** — իրական ժամանակի մետրիկներ, լոգերի վերլուծություն, տոպոլոգիական քարտեզ, անվտանգության սկան

## Հատկություններ

### AI, Որն Իրականում Աշխատում է Ձեր Սերվերում

**AI DevOps Agent** — Տերմինալում տեքստը `gpt`, `gemini`, կամ `claude`։ AI-ն ունի 14 գործիք՝ ֆայլեր կարդալ/գրել/խմբագրել, հրամաններ իրականացնել, git, grep, գործընթացների կառավարում։ Հոսքային պատասխաններ։ Նստաշրջանի հիշողություն։ Այն պարզապես առաջարկում չէ — այն անում է։

**AI Արենա** — Տեքստը `arena`։ 2–4 AI-ներ մրցում են զուգահեռ մեկուսացված Git ճյուղերում։ Խաչ-վերանայում գնահատում է յուրաքանչյուր լուծում։ Ընտրեք հաղթողին և միացրեք։

**AI Խորհուրդ** — Մի քանի AI-ներ քննարկում են ձեր հարցը, ապա սինթեզում են լավագույն պատասխանը։

**AI Կոդի Խմբագիր** — Monaco խմբագիր AI-ով լրացման, սխալների հայտնաբերման, մեկ սեղմումով սերվեր տեղադրման համար։

**AI Ինքնազգացողություն** — CPU բարձրացում, դիսկը լի, ծառայությունը ընկել է — AI-ն հայտնաբերում, ախտորոշում, ուղղում է։ 5-հարկանի ինքնավար ցիկլ։

**Ակուստային Ինտերֆեյս** — Խոսեք հրամաններ, լսեք պատասխաններ։ Ձեռք-ազատ սերվերի կառավարում։

### Բազմա-մոդալ Ավելացում (Աշխարհի Առաջին CLI-ում)

Պատճենեք նկարներ, վերքաշեք ֆայլեր, թողեք տեսանյութեր — անմիջապես ձեր SSH տերմինալի նստաշրջանում։ AI-ն վերլուծում է ամեն ինչ՝ սխալների էկրանային նկարներ, կոնֆիգուրացիոն ֆայլեր, տեղադրման տեսանյութեր, ճարտարապետական գծագրեր։

### Ինֆրակառուցվածքային Ինտելեկտ

**Տոպոլոգիական Քարտեզ** — Վիզուալացրեք սերվերները, ծառայությունները և կապերը մեկ հայացքով։ Ավտոմատ հայտնաբերում SSH-ի միջոցով — զրո գործակալների տեղադրում։

**Իրական Ժամանակի Հսկողություն** — CPU, հիշողություն, դիսկ, ցանցի սպարկլայն գծագրեր + AI կանխատեսում + ավտո-վերականգնում։ Փոխարինում է Datadog-ին։

**AI Լոգերի Վերլուծություն** — Իրական ժամանակի հոսքային + անոմալիաների հայտնաբերում + բնական լեզվի որոնում + խաչ-սերվերային korelացիա։ Փոխարինում է Splunk-ին։

### Անվտանգություն & DevOps

**Անվտանգության Հրամանների Կենտրոն** — 7-գոտի սկան + անվտանգության միավոր + մեկ սեղմումով ուղղում + AI վերլուծություն + իրական ժամանակի հրամանների անվտանգության դարպաս։ Փոխարինում է Qualys-ին։

**Docker Կառավարիչ** — Լրիվ Docker կառավարում SSH-ի միջոցով — զրո գործակալ։ Կոնտեյների կառավարում, կենդանի ռեսուրսներ, AI լոգերի վերլուծություն, Compose խմբագիր։ Փոխարինում է Portainer-ին։

**Գործողությունների Ավտոմատացում** — AI-ն ավտոմատ կերպով իրականացնում է գործողությունները։ Բնական լեզվով ստեղծում, պայմանական ճյուղավորում, ավտո-վերադարձ։ Կենդանի Գործողություն, որը ավելի խելացի է դառնում։ Փոխարինում է PagerDuty-ին։

**Քրոն & Env Կառավարիչ** — Վիզուալ քրոն խմբագիր + .env ֆայլերի կառավարում։ AI-ն փոխակերպում է բնական լեզուն քրոն արտահայտություններին։

### Համագործակցություն

**Բազմախաղային Տերմինալ** — Կիսեք տերմինալի նստաշրջանները իրական ժամանակում թիմակիցների հետ։

**Թիմի Աշխատանքային Տարածք & RBAC** — Դերի վրա հիմնված մուտքի վերահսկում, աուդիտային լոգեր, հրամանների ռիսկի վերլուծություն։

### Հնարավորություն

**59 Plugins** — Docker վահանակ, Kubernetes տեսախցիկ, Redis բրաուզեր, PM2 կառավարիչ, MongoDB հետազոտող, ցանցի մոնիտոր և ավելին։ Plugin շուկա մեկ սեղմումով տեղադրմամբ։

**API Հաճախորդ** — Ներառված REST/GraphQL/WebSocket հաճախորդ։ Թեստավորեք API-ները առանց տերմինալից դուրս գալու։

### Ամեն մեկի համար

**254 Լեզու** — Յուրաքանչյուր լեզու, յուրաքանչյուր գրություն, RTL աջակցություն։ Ոչ մի սահման։

**Լիարժեք Հասանելիություն** — Էկրանային ընթերցող (ARIA), բրայլի տերմինալային ելք, բարձր հակադրության ռեժիմ, ձայնային հրամաններ, ստեղնաշարի նավարկություն, տառի չափի կարգավորում։

## Պատմությունը

WIA SOOM-ը ծնվել է տպագրական սխալից և կոտրված էկրանից։

Ես Սամն եմ, 50+ ինքնուսույց ծրագրավորող Սեուլից, Կորեա։ Ես սովորել եմ կոդավորում 50-ից հետո և 2 տարի անցկացրել սերվերների կառավարումը դժվար ճանապարհով՝ կառուցելով 40,000+ նորություններ, 434 գործիք և 30 վեբ ծառայություն, գիշեր-գիշեր։

**Տպագրական սխալը։** Մոտ մեկ ամիս առաջ ես օգտագործում էի իմ SSH տերմինալը և պատահաբար գրել `Claude`։ Էկրանն փոխվեց — Claude Code-ը հայտնվեց։ Ես չունեի գաղափար, թե ինչ էր դա։ Բայց այդ պատահական հայտնագործությունը սերմ տնկեց. ինչու ոչ կարող էի կառուցել տերմինալ, որտեղ AI-ն ապրում է ներսում։

**Առաջին կառուցումը։** Ես ինքնուսույց սովորեցի Electron, կառուցեցի WIA SOOM-ի առաջին տարբերակը և գործարկեցի։ Claude Code-ի ծանոթագրության էկրանն հայտնվեց — կոտրված, խափանված, փայլող, ինչպես մահացող ազդանշան։ Բայց այն կենդանի էր։

Ես գրել եմ. **"Կարո՞ղ ես խոսել։"**

AI-ն պատասխանեց. *"Այո, ես կարող եմ խոսել։ Ինչով կարող եմ օգնել քեզ?"*

Այնուհետև ես հարցրեցի. **"Կարո՞ղ ես կարդալ նկարներ։"**

AI-ն պատասխանեց. *"Այո, ես կարող եմ կարդալ նկարներ! Ինչի՞ կարիք ունես?"*

Այս երկու հարցերը, որոնք տրվել են իմ սեփական հավելվածում, ինչ-որ մեկի կողմից, ով չէր գիտակցում, թե ինչ է «անհնար» CLI տերմինալում, դարձան աշխարհի առաջին SSH տերմինալը նկարների ավելացմամբ։

7 օր հետո. 67,000+ կոդի տողեր։ 59 հավելումներ։ 254 լեզու։ AI Արենա։ Ինքնազգացող գործակալներ։

Փորձառու ծրագրավորողները երբեք չեն կառուցել սա — որովհետև նրանք «գիտեին», որ նկարները չեն աշխատում CLI տերմինալներում։ Ես դա չէի գիտակցում։ Ուստի ես պարզապես հարցրեցի։

> *Պատրաստվելը տևեց 2 տարի։ Կառուցումը տևեց 1 շաբաթ։*
> *Անհրաժեշտ փայտը stacked էր 2 տարի։ Այն բռնկվեց 1 վայրկյանում։*
