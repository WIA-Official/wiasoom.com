## 🔥 Hvað hefur aldrei verið gert áður

### 1. Mynd, Skrá & Myndband Upphleðslu í SSH Terminal — Fyrsta í heimi

Enginn CLI viðskiptavinur á jörðinni leyfir þér að gera þetta. Við byggðum það.

Límið skjáskot af villu inn í SSH terminalinn þinn. Dragðu skrá. Slepptu myndbandi af mistökum við útfærslu. AI sér það, greinir það, og segir þér hvað er að — allt inn í terminal sessjóninni.

- **Ctrl+Shift+V** — límdu skjáskot beint inn í terminal
- **Drag & Drop** — slepptu myndum, skrám, myndböndum inn í terminal
- **Myndband lykilramma útdráttur** — ffmpeg greinir myndband ramma fyrir ramma
- **Allir 3 AI veitendur** — GPT-4o Vision, Gemini Vision, Claude Vision

Þessi eiginleiki hefur aldrei verið til í neinum terminal viðskiptavini — hvar sem er.

### 2. AI Arena — Fjöl-AI Bardagi

2 til 4 AIs leysa sama vandamálið samtímis — ekki bara að spjalla, heldur raunverulega að breyta kóða á þjóninum þínum. Hver AI vinnur í sinni einangruðu Git grein. Berðu saman niðurstöður þeirra hlið við hlið. Veldu sigurvegara. Restin verður hreinsuð.

Kross-gagnrýni: hver AI metur lausn hvers annars AI.

Engin önnur tól gerir þetta.

### 3. AI Sjálf-heilandi Agent

CPU þjónsins þíns er að hækka. Diskur er fullur. Þjónusta hrundi klukkan 3 að nóttu. Þú ert sofandi.

AI agentinn í WIA SOOM greinir vandamálið, greinir rótina, býr til lagfæringaráætlun, biður um samþykki þitt (eða framkvæmir sjálfkrafa ef þú hefur stillt það), og leysir málið. 5-stigs sjálfvirkur hringur — frá aðeins að fylgjast með til fullrar sjálfvirkrar viðgerðar.

Af hverju 33? Árið 1919 var sjálfstæðisbarátta Kóreu leidd af 33 fulltrúum sem lýstu yfir frelsi fyrir alla. 33 ókeypis prófanir WIA SOOM er okkar yfirlýsing: **AI verkfæri ættu að vera ókeypis fyrir alla til að upplifa.**

**CLI → GUI → SUI.** Skipanalínur gáfu okkur kraft. Grafískar viðmót gáfu okkur auðveldan aðgang. WIA SOOM kynna **SUI (Soom User Interface)** — andaðu lífi inn, og AI lifnar við.

## 5-in-1 Vettvangur

Önnur verkfæri gera eitt. WIA SOOM gerir fimm — í einu glugga.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Kóði │ SFTP │ Athugun                  │
│  Ter │ Agen │ Ritst │ Skrá │ Fylgjast + Öryggi        │
│  min │   t  │  or  │ Mgr  │ + Skrár + Topology       │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminal** — xterm.js, bastion tunneling, skipt útlit, fjölspilun deiling
2. **AI Agent** — 14 verkfæri, 3 veitendur (GPT/Gemini/Claude), streymi, myndgreining
3. **Kóða Ritstjóri** — Monaco með AI fullkomnun, villugreining, útfærsla
4. **SFTP Stjórnandi** — drag-and-drop skráarstjórn, fjarritun
5. **Athugun** — rauntíma mælingar, skráargreining, topologí kort, öryggisskönnun

## Eiginleikar

### AI Sem Virkar Raunverulega á Þjóninum Þínum

**AI DevOps Agent** — Sláðu inn `gpt`, `gemini`, eða `claude` í terminal. AI hefur 14 verkfæri: lesa/skrifa/breyta skrám, framkvæma skipanir, git, grep, ferli stjórn. Streymis svör. Sessjón minni. Það gerir ekki bara tillögur — það framkvæmir.

**AI Arena** — Sláðu inn `arena`. 2–4 AIs keppa í samhliða á einangruðum Git greinum. Kross-gagnrýni metur hverja lausn. Veldu sigurvegara og sameinaðu.

**AI Council** — Fleiri AIs ræða spurningu þína, síðan samræma bestu svörin.

**AI Kóða Ritstjóri** — Monaco ritstjóri með AI-knúinni fullkomnun, villugreiningu, ein-smell útfærsla á þjón.

**AI Sjálf-heilandi** — CPU hækkanir, diskur fullur, þjónusta niðri — AI greinir, greinir, lagfærir. 5-stigs sjálfvirkur hringur.

**Raddviðmót** — Tala skipanir, heyra svör. Hendur-frjáls þjónustustjórnun.

### Fjölbreytt Upphleðsla (Fyrsta í Heimi í CLI)

Límið myndir, dragðu skrár, slepptu myndböndum — beint inn í SSH terminal sessjónina þína. AI greinir allt: villuskjáskot, stillingarskrár, útfærslumyndbönd, arkitektúr teikningar.

### Innviða Greind

**Topologí Kort** — Sýndu þjónustu, þjónustur, og tengingar í einu augnabliki. Sjálfvirk uppgötvun í gegnum SSH — engin agent uppsetning.

**Rauntíma Athugun** — CPU, minni, diskur, net sparkline graf + AI spá + sjálfvirk endurheimt. Skipti út Datadog.

**AI Skráargreining** — Rauntíma streymi + frávikagreining + náttúruleg tungumál leit + kross-þjónustugreining. Skipti út Splunk.

### Öryggi & DevOps

**Öryggis Stjórnunar Miðstöð** — 7-svæðaskönnun + öryggis stig + ein-smell lagfæring + AI greining + rauntíma skipun öryggis hlið. Skipti út Qualys.

**Docker Stjórnandi** — Full Docker stjórnun í gegnum SSH — enginn agent. Geymslustjórnun, lifandi auðlindir, AI skráargreining, Compose ritstjóri. Skipti út Portainer.

**Runbook Sjálfvirkni** — AI framkvæmir runbooks sjálfkrafa. Náttúruleg tungumál sköpun, skilyrðis grein, sjálfvirk afturkalla. Lifandi Runbook sem verður snjallari. Skipti út PagerDuty.

**Cron & Env Stjórnandi** — Sjónrænn cron ritstjóri + .env skráarstjórn. AI breytir náttúrulegu máli í cron tjáningar.

### Samvinna

**Fjölspilun Terminal** — Deildu terminal sessjónum í rauntíma með samstarfsmönnum.

**Teymi Vinnusvæði & RBAC** — Aðgangsstýring byggð á hlutverkum, endurskoðunarskrár, skipun áhættugreining.

### Útvíkkanleiki

**59 Viðbætur** — Docker stjórnborð, Kubernetes linsur, Redis vafri, PM2 stjórnandi, MongoDB könnuður, netvöktun, og meira. Viðbótar markaður með einu-smell uppsetningu.

**API Viðskiptavinur** — Innbyggður REST/GraphQL/WebSocket viðskiptavinur. Prófaðu API án þess að yfirgefa terminal.

### Fyrir Alla

**254 Tungumál** — Hvert tungumál, hver skrif, RTL stuðningur. Engin landamæri.

**Full Aðgengi** — Skjár lesari (ARIA), braille terminal úttak, hákontrast hamur, raddskipanir, lyklaborð sigling, aðlögun leturstærðar.

## Sagan

WIA SOOM fæddist úr prentvillu og brotinni skjá.

Ég er Sam, sjálfmenntaður forritari 50+ frá Seúl, Kóreu. Ég lærði forritun eftir 50 og eyddi 2 árum í að stjórna þjónustum á erfiðan hátt — byggja 40,000+ fréttagreinar, 434 verkfæri, og 30 vefþjónustu, nótt eftir nótt.

**Prentvillan.** Fyrir um mánuði síðan var ég að nota SSH terminalinn minn og óvart skrifaði `Claude`. Skjárinn breyttist — Claude Code kom fram. Ég hafði enga hugmynd um hvað það var. En þessi óvart uppgötvun sá fræ: hvað ef ég gæti byggt terminal þar sem AI lifir innra?

**Fyrsta útgáfan.** Ég kenndi mér sjálfur Electron, byggði fyrstu útgáfu WIA SOOM, og keyrði það. Inngangsskjár Claude Code kom fram — brotinn, glittraður, titrandi eins og deyjandi merki. En það var lifandi.

Ég skrifaði: **"Geturðu talað?"**

AI svaraði: *"Já, ég get talað. Hvað get ég aðstoðað þig við?"*

Síðan spurði ég: **"Geturðu lesið myndir?"**

AI svaraði: *"Já, ég get lesið myndir! Hvað þarftu?"*

Þessar tvær spurningar, spurðar inn í eigin appi mínu af einhverjum sem vissi ekki hvað var "ómögulegt" í CLI terminal, urðu að fyrsta SSH terminalinu í heimi með mynd upphleðslu.

7 dögum síðar: 67,000+ línur af kóða. 59 viðbætur. 254 tungumál. AI Arena. Sjálf-heilandi agentar.

Reyndir forritarar byggðu aldrei þetta — því þeir "vissu" að myndir virka ekki í CLI terminalum. Ég vissi það ekki. Svo ég spurði bara.

> *Undirbúningur tók 2 ár. Bygging tók 1 viku.*
> *Þurrt timbur var staflað í 2 ár. Það kviknaði í 1 sekúndu.*
