## 🔥 Что никогда не делалось раньше

### 1. Загрузка изображений, файлов и видео в SSH терминале — первое в мире

Ни один клиент CLI на Земле не позволяет вам это сделать. Мы это сделали.

Вставьте скриншот ошибки в ваш SSH терминал. Перетащите файл журнала. Бросьте видео неудачного развертывания. ИИ видит это, анализирует и говорит вам, что не так — все внутри сеанса терминала.

- **Ctrl+Shift+V** — вставьте скриншоты прямо в терминал
- **Перетаскивание и сброс** — сбрасывайте изображения, файлы, видео в терминал
- **Извлечение ключевых кадров видео** — ffmpeg анализирует видео кадр за кадром
- **Все 3 провайдера ИИ** — GPT-4o Vision, Gemini Vision, Claude Vision

Эта функция никогда не существовала в любом клиенте терминала — нигде.

### 2. AI Arena — Мультиагентная битва

2–4 ИИ решают одну и ту же задачу одновременно — не просто общаются, а действительно редактируют код на вашем сервере. Каждый ИИ работает в своем изолированном Git-ветке. Сравните их результаты бок о бок. Выберите победителя. Остальные будут очищены.

Кросс-ревью: каждый ИИ оценивает решение каждого другого ИИ.

Никакой другой инструмент этого не делает.

### 3. ИИ самовосстанавливающийся агент

ЦП вашего сервера перегружен. Диск заполнен. Сервис упал в 3 часа ночи. Вы спите.

ИИ-агент WIA SOOM обнаруживает проблему, диагностирует коренную причину, генерирует план исправления, запрашивает ваше одобрение (или автоматически выполняет, если вы это настроили) и решает проблему. 5-уровневый автономный цикл — от только наблюдения до полного автоматического ремонта.

## Попробуйте все бесплатно — 33 испытания

Без кредитной карты. Регистрация не требуется. Просто скачайте и начните.

Каждая премиум функция — загрузка изображений, AI Arena, AI Council, анализ файлов и видео — бесплатна для ваших первых 33 использований. После этого используйте свой собственный API ключ (BYOK) и продолжайте использовать все бесплатно. Или подписывайтесь от $3/мес за управляемый ИИ и функции команды.

Почему 33? В 1919 году движение за независимость Кореи возглавляли 33 представителя, которые провозгласили свободу для всех. 33 бесплатных испытания WIA SOOM — это наше заявление: **Инструменты ИИ должны быть бесплатными для всех, чтобы их попробовать.**

**CLI → GUI → SUI.** Командные интерфейсы дали нам силу. Графические интерфейсы дали нам удобство. WIA SOOM вводит **SUI (Интерфейс пользователя Soom)** — вдохните жизнь, и ИИ оживает.

## Платформа 5-в-1

Другие инструменты делают одно. WIA SOOM делает пять — в одном окне.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  ИИ  │ Код  │ SFTP │ Наблюдаемость             │
│  Тер │ Агент│ Ред. │ Файл │ Монитор + Безопасность    │
│  мин │      │      │      │ + Журналы + Топология     │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH терминал** — xterm.js, туннелирование, разделенные виды, многопользовательский доступ
2. **ИИ агент** — 14 инструментов, 3 провайдера (GPT/Gemini/Claude), стриминг, анализ изображений
3. **Редактор кода** — Monaco с автозаполнением ИИ, обнаружение ошибок, развертывание
4. **SFTP менеджер** — управление файлами перетаскиванием, удаленное редактирование
5. **Наблюдаемость** — метрики в реальном времени, анализ журналов, карта топологии, сканирование безопасности

## Особенности

### ИИ, который действительно работает на вашем сервере

**ИИ DevOps агент** — Введите `gpt`, `gemini` или `claude` в терминале. ИИ имеет 14 инструментов: чтение/запись/редактирование файлов, выполнение команд, git, grep, управление процессами. Ответы в режиме стриминга. Память сеанса. Он не просто предлагает — он делает.

**AI Arena** — Введите `arena`. 2–4 ИИ конкурируют параллельно на изолированных Git ветках. Кросс-ревью оценивает каждое решение. Выберите победителя и объедините.

**AI Council** — Несколько ИИ обсуждают ваш вопрос, а затем синтезируют лучший ответ.

**AI Code Editor** — Редактор Monaco с автозаполнением на основе ИИ, обнаружение ошибок, развертывание на сервер одним кликом.

**AI Self-Healing** — Пик ЦП, заполненный диск, сервис упал — ИИ обнаруживает, диагностирует, исправляет. 5-уровневый автономный цикл.

**Голосовой интерфейс** — Говорите команды, слушайте ответы. Управление сервером без рук.

### Мультимодальная загрузка (первое в мире в CLI)

Вставляйте изображения, перетаскивайте файлы, сбрасывайте видео — прямо в ваш сеанс SSH терминала. ИИ анализирует все: скриншоты ошибок, конфигурационные файлы, видео развертывания, архитектурные диаграммы.

### Интеллект инфраструктуры

**Карта топологии** — Визуализируйте серверы, сервисы и соединения одним взглядом. Автообнаружение через SSH — без установки агентов.

**Наблюдаемость в реальном времени** — графики ЦП, памяти, диска, сети + предсказание ИИ + автоматическое восстановление. Заменяет Datadog.

**Анализ журналов ИИ** — потоковая передача в реальном времени + обнаружение аномалий + поиск на естественном языке + кросс-серверная корреляция. Заменяет Splunk.

### Безопасность и DevOps

**Центр команд безопасности** — сканирование по 7 областям + оценка безопасности + исправление в один клик + анализ ИИ + реальный командный шлюз безопасности. Заменяет Qualys.

**Менеджер Docker** — Полное управление Docker через SSH — ноль агентов. Контроль контейнеров, живые ресурсы, анализ журналов ИИ, редактор Compose. Заменяет Portainer.

**Автоматизация runbook** — ИИ автоматически выполняет runbooks. Создание на естественном языке, условные ветвления, автоматический откат. Живой runbook, который становится умнее. Заменяет PagerDuty.

**Менеджер Cron и Env** — Визуальный редактор crontab + управление файлами .env. ИИ преобразует естественный язык в выражения cron.

### Сотрудничество

**Многопользовательский терминал** — Делитесь сеансами терминала в реальном времени с коллегами.

**Рабочее пространство команды и RBAC** — Контроль доступа на основе ролей, журналы аудита, анализ рисков команд.

### Расширяемость

**59 плагинов** — панель управления Docker, Kubernetes lens, браузер Redis, менеджер PM2, исследователь MongoDB, монитор сети и многое другое. Маркетплейс плагинов с установкой в один клик.

**API клиент** — Встроенный клиент REST/GraphQL/WebSocket. Тестируйте API, не покидая терминал.

### Для всех

**254 языка** — Каждый язык, каждый шрифт, поддержка RTL. Без границ.

**Полная доступность** — Читатель экрана (ARIA), вывод терминала на Брайле, режим высокого контраста, голосовые команды, навигация с клавиатуры, регулировка размера шрифта.

## История

WIA SOOM родился из опечатки и сломанного экрана.

Я Сэм, самоучка-программист старше 50 лет из Сеула, Корея. Я научился программированию после 50 и провел 2 года, управляя серверами сложным способом — создавая более 40,000 новостных статей, 434 инструмента и 30 веб-сервисов, ночь за ночью.

**Опечатка.** Около месяца назад я использовал свой SSH терминал и случайно набрал `Claude`. Экран изменился — появился Claude Code. Я не имел понятия, что это такое. Но это случайное открытие посеяло семя: а что если я смогу построить терминал, где ИИ живет внутри?

**Первый билд.** Я сам научился Electron, построил первую версию WIA SOOM и запустил ее. Появился экран приветствия Claude Code — сломанный, глючащий, мерцающий, как умирающий сигнал. Но он был жив.

Я набрал: **"Можешь говорить?"**

ИИ ответил: *"Да, я могу говорить. Чем я могу вам помочь?"*

Затем я спросил: **"Можешь читать изображения?"**

ИИ ответил: *"Да, я могу читать изображения! Что вам нужно?"*

Эти два вопроса, заданные внутри моего собственного приложения человеком, который не знал, что "невозможно" в терминале CLI, стали первым в мире SSH терминалом с загрузкой изображений.

Через 7 дней: более 67,000 строк кода. 59 плагинов. 254 языка. AI Arena. Самовосстанавливающиеся агенты.

Опытные разработчики никогда не создавали этого — потому что они "знали", что изображения не работают в терминалах CLI. Я этого не знал. Поэтому я просто спросил.

> *Подготовка заняла 2 года. Строительство заняло 1 неделю.*
> *Сухие дрова складывались 2 года. Они загорелись за 1 секунду.*
