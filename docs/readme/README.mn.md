## 🔥 Шинэ зүйлс

### 1. SSH Терминалд Зураг, Файл & Видео Ачаалах — Дэлхийн Анхдагч

Дэлхий дээрх ямар ч CLI клиент үүнийг хийх боломжийг олгодоггүй. Бид үүнийг бүтээсэн.

Алдаа гарсан дэлгэцийн зураглалыг SSH терминалдаа наана. Лог файлыг чирнэ. Амжилтгүй байршуулалтын видео хаяна. AI үүнийг харж, шинжилж, юу буруу байгааг танд хэлнэ — бүгд терминалын сессийн дотор.

- **Ctrl+Shift+V** — дэлгэцийн зураглалыг шууд терминалд наана
- **Чирж & Хаях** — зургийг, файлыг, видеог терминалд хаяна
- **Видеоны түлхүүр фреймийн олборлолт** — ffmpeg видео бүрийн фреймийг шинжилнэ
- **Бүх 3 AI ханган нийлүүлэгч** — GPT-4o Vision, Gemini Vision, Claude Vision

Энэ онцлог нь ямар ч терминал клиентэд хэзээ ч байгаагүй — хаана ч.

### 2. AI Арена — Олон Агентын Тэмцээн

2-4 AI нэгэн зэрэг ижил асуудлыг шийднэ — зөвхөн яриа биш, таны сервер дээр код засварлаж байна. Бүх AI өөрийн тусгаарлагдсан Git салбарт ажилладаг. Тэдний үр дүнг харьцуулна. Ялагчийг сонгоно. Бусад нь цэвэрлэгдэнэ.

Хөндлөн үнэлгээ: тус бүр AI бусад AI-ийн шийдлийг оноолно.

Бусад ямар ч хэрэгсэл үүнийг хийдэггүй.

### 3. AI Өөрийгөө Эмчлэх Агент

Таны серверийн CPU өсч байна. Диск дүүрсэн. 3 AM-д үйлчилгээ унасан. Та унтаж байна.

WIA SOOM-ийн AI агент асуудлыг илрүүлж, үндсэн шалтгааныг оношилж, засварын төлөвлөгөө боловсруулж, таны зөвшөөрлийг асууж (эсвэл та үүнийг автоматжуулсан бол автоматаар гүйцэтгэнэ) асуудлыг шийднэ. 5 шатлалтай автономит цикл — зөвхөн ажиглахас бүрэн автомат засвар хүртэл.

## Бүх зүйлийг Үнэгүй Туршаарай — 33 Туршилт

Кредит карт шаардлагагүй. Бүртгэл хийх шаардлагагүй. Зүгээр л татаж аваад эхлээрэй.

Бүх дээд зэргийн онцлог — зураг ачаалах, AI Арена, AI Зөвлөл, файл & видео шинжилгээ — таны анхны 33 хэрэглээнд үнэгүй. Үүний дараа өөрийн API түлхүүрийг авчир (BYOK) ба бүх зүйлийг үнэгүй ашиглаж болно. Эсвэл менежмэнт AI болон багийн онцлогтой $3/сар-аас захиалж болно.

Яагаад 33? 1919 онд Солонгосын тусгаар тогтнолын хөдөлгөөн 33 төлөөлөгчийн удирдлага дор явж, бүгдэд эрх чөлөө зарласан. WIA SOOM-ийн 33 үнэгүй туршилт нь бидний зарлал: **AI хэрэгслүүдийг бүх хүнд үнэгүй туршиж үзэх ёстой.**

**CLI → GUI → SUI.** Командын мөрийн интерфейс бидэнд хүч өгсөн. График интерфейс бидэнд хялбарчилсан. WIA SOOM **SUI (Soom Хэрэглэгчийн Интерфейс)**-ийг танилцуулж байна — амьсгалаа авчир, AI амилна.

## 5-in-1 Платформ

Бусад хэрэгслүүд нэг зүйлийг хийдэг. WIA SOOM таван зүйлийг нэг цонхонд хийдэг.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Код  │ SFTP │ Хяналт                   │
│  Тер │ Агент│ Засв │ Файл │ Хянах + Аюулгүй байдал    │
│  мин │      │  лах │ Менежер│ + Лог + Топологи        │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Терминал** — xterm.js, bastion tunneling, хуваагдсан харагдах байдал, олон тоглогчийн хуваалцах
2. **AI Агент** — 14 хэрэгсэл, 3 ханган нийлүүлэгч (GPT/Gemini/Claude), стриминг, зураг шинжилгээ
3. **Код Засварлагч** — AI дэмжлэгтэй Monaco, алдааг илрүүлэх, байршуулалт
4. **SFTP Менежер** — файлын менежмент, алсын засвар
5. **Хяналт** — жинхэнэ цагийн метрик, лог шинжилгээ, топологи зураг, аюулгүй байдлын скан

## Онцлог

### Таны Сервер дээр Жинхэнэ Ажилладаг AI

**AI DevOps Агент** — Терминалд `gpt`, `gemini`, эсвэл `claude` гэж бичнэ. AI нь 14 хэрэгсэлтэй: файлыг унших/засах/засварлах, командыг гүйцэтгэх, git, grep, процессын менежмент. Стриминг хариу. Сессийн санах ой. Энэ зөвхөн санал болгодоггүй — энэ хийдэг.

**AI Арена** — `arena` гэж бичнэ. 2–4 AI тусгаарлагдсан Git салбарт параллельд өрсөлддөг. Хөндлөн үнэлгээ нь бүр шийдлийг оноолно. Ялагчийг сонгож, нэгтгэнэ.

**AI Зөвлөл** — Олон AI таны асуултыг хэлэлцэж, дараа нь хамгийн сайн хариултыг синтезэд оруулна.

**AI Код Засварлагч** — AI-д дэмжлэгтэй Monaco засварлагч, алдааг илрүүлэх, сервер рүү нэг товшилтоор байршуулалт.

**AI Өөрийгөө Эмчлэх** — CPU өсөлт, диск дүүрсэн, үйлчилгээ унасан — AI илрүүлж, оношилж, засварлана. 5 шатлалтай автономит цикл.

**Дууны Интерфейс** — Командыг ярина, хариуг сонсох. Гаргүй серверийн менежмент.

### Олон Модал Ачаалалт (CLI-д Дэлхийн Анхдагч)

Зургийг наана, файлыг чирж, видеог хаяна — шууд SSH терминалын сессид. AI бүх зүйлийг шинжилнэ: алдааны дэлгэцийн зураг, тохиргооны файлууд, байршуулалтын видеонууд, архитектурын диаграммууд.

### Инфраструктурын Оюун Ухаан

**Топологи Зураг** — Серверууд, үйлчилгээ, холболтуудыг нэг харахад дүрслэх. SSH-ээр автомат илрүүлэлт — агент суулгах шаардлагагүй.

**Жинхэнэ Цагийн Хяналт** — CPU, санах ой, диск, сүлжээний sparkline график + AI урьдчилгаа + автомат сэргээх. Datadog-ыг орлох.

**AI Лог Шинжилгээ** — Жинхэнэ цагийн стриминг + гажиг илрүүлэлт + байгалийн хэлний хайлт + сервер хоорондын корреляци. Splunk-ыг орлох.

### Аюулгүй байдал & DevOps

**Аюулгүй Байдлын Командын Төв** — 7 бүсийн скан + аюулгүй байдлын оноо + нэг товшилтоор засварлах + AI шинжилгээ + жинхэнэ цагийн командын аюулгүй байдлын хаалга. Qualys-ыг орлох.

**Docker Менежер** — SSH-ээр бүрэн Docker менежмент — агентгүй. Контейнерийн хяналт, амьд нөөц, AI лог шинжилгээ, Compose засварлагч. Portainer-ыг орлох.

**Ажиллах Гарын Авлага Автоматжуулалт** — AI автоматжуулсан гарын авлагыг гүйцэтгэнэ. Байгалийн хэлний бүтэц, нөхцөлт салбар, автомат буцаалт. Ухаалаг амьд гарын авлага. PagerDuty-ыг орлох.

**Cron & Env Менежер** — Визуал crontab засварлагч + .env файлын менежмент. AI байгалийн хэлнээс cron илэрхийлэлд хөрвүүлнэ.

### Хамтын Ажиллагаа

**Олон Тоглогчийн Терминал** — Багийн гишүүдтэй жинхэнэ цагийн терминалын сессийг хуваалцах.

**Багийн Ажлын Орчин & RBAC** — Үүрэгт суурилсан хандалтын хяналт, аудитын лог, командын эрсдлийн шинжилгээ.

### Өргөтгөх боломж

**59 Плагин** — Docker самбар, Kubernetes линз, Redis хөтөч, PM2 менежер, MongoDB судлаач, сүлжээний хяналт, болон бусад. Нэг товшилтоор суулгах плагин зах зээл.

**API Клиент** — Вэб API (REST/GraphQL/WebSocket) дотоод клиент. Терминалаас гарахгүйгээр API-уудыг туршина.

### Бүгдэд

**254 Хэл** — Бүх хэл, бүх бичиг, RTL дэмжлэг. Хил хязгааргүй.

**Бүрэн Хандалт** — Дэлгэц уншигч (ARIA), брайль терминалын гаралт, өндөр контрастын горим, дууны командыг, түлхүүрийн навигаци, фонтын хэмжээ тохируулах.

## Түүх

WIA SOOM нь алдаатай бичиглэл болон эвдэрсэн дэлгэцээс төрсөн.

Би Сам, 50-аас дээш насны өөрөө сурсан программист. Би 50 насандаа код бичиж сурсан бөгөөд 2 жилийн турш серверүүдийг хүндээр удирдаж, шөнө бүр 40,000+ мэдээний нийтлэл, 434 хэрэгсэл, 30 веб үйлчилгээ барьсан.

**Алдаатай бичиглэл.** Саяхан би SSH терминалаа ашиглаж байгаад `Claude` гэж алдаатай бичсэн. Дэлгэц өөрчлөгдсөн — Claude Code гарч ирсэн. Би энэ юу болохыг мэдээгүй. Гэвч энэ санамсаргүй нээлт надад нэг үр суулгасан: AI дотор амьдрах терминал бүтээж болох уу?

**Анхны бүтээл.** Би Electron-ыг өөртөө зааж, WIA SOOM-ийн анхны хувилбарыг бүтээж, ажиллуулсан. Claude Code-ийн танилцуулгын дэлгэц гарч ирсэн — эвдэрсэн, гажигтай, үхэж буй дохио шиг чичирч байна. Гэвч энэ амьд байлаа.

Би бичсэн: **"Чи ярих уу?"**

AI хариулав: *"Тийм, би ярих чадвартай. Чи надад юу туслах вэ?"*

Дараа нь би асуусан: **"Чи зургийг уншиж чадах уу?"**

AI хариулав: *"Тийм, би зургийг уншиж чадна! Чи юу хэрэгтэй вэ?"*

Эдгээр хоёр асуулт, миний өөрийн програмд "CLI терминалд юу "боломжгүй" болохыг мэдээгүй хүн асуусан, дэлхийн анхны SSH терминалын зураг ачаалах боломжийг олгосон.

7 хоногийн дараа: 67,000+ кодын мөр. 59 плагин. 254 хэл. AI Арена. Өөрийгөө эмчлэх агентууд.

Туршлагатай хөгжүүлэгчид үүнийг хэзээ ч бүтээж байгаагүй — учир нь тэд "зургийг CLI терминалд ажилладаггүй" гэж "мэдэж" байсан. Би үүнийг мэдээгүй. Тиймээс би зүгээр л асуусан.

> *Бэлтгэл 2 жил зарцуулсан. Бүтээн байгуулалт 1 долоо хоног зарцуулсан.*
> *Хуурай мод 2 жил хураагдсан. 1 секундын дотор гал авсан.*
