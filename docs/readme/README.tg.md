## 🔥 Чӣ нав аст

### 1. Бор кардани тасвир, файл ва видео дар SSH Terminal — аввалин дар ҷаҳон

Ҳеҷ клиенти CLI дар Замин ба шумо имкон намедиҳад, ки ин корро кунед. Мо онро сохтем.

Скриншоти хатоеро дар SSH терминали худ часпонед. Файли логро кашед. Видеои нокомии интишорро гузоред. AI онро мебинад, таҳлил мекунад ва ба шумо мегӯяд, ки чӣ хато аст — ҳама дар дохили сессияи терминал.

- **Ctrl+Shift+V** — скриншотҳоро мустақиман ба терминал часпонед
- **Drag & Drop** — тасвирҳо, файлҳо, видеоҳоро ба терминал гузоред
- **Ихтилофи видеокадр** — ffmpeg видеоро кадр ба кадр таҳлил мекунад
- **Ҳамаи 3 провайдери AI** — GPT-4o Vision, Gemini Vision, Claude Vision

Ин хусусият дар ҳеҷ клиенти терминал вуҷуд надошт — дар куҷо.

### 2. AI Arena — Ҷанги Мулти-агент

2 то 4 AI мушкилоти якхелаеро ҳамзамон ҳал мекунанд — на танҳо гуфтугӯ, балки воқеан кодро дар сервери шумо таҳрир мекунанд. Ҳар AI дар шохаи Git-и алоҳидаи худ кор мекунад. Натиҷаҳои онҳоро паҳлӯ ба паҳлӯ муқоиса кунед. Ғолибро интихоб кунед. Боқимонда тоза карда мешаванд.

Баррасии мутақобила: ҳар AI ҳар як ҳалли AI-ро баҳо медиҳад.

Ҳеҷ асбоби дигар ин корро намекунад.

### 3. AI Agent-и худ-табобаткунанда

CPU-и сервери шумо баланд мешавад. Диск пур аст. Хидмат дар соати 3-и субҳ фурӯ меравад. Шумо хобед.

Agent-и AI-и WIA SOOM мушкилотро шеносо мекунад, сабаби аслиро ташхис мекунад, нақшаи ислоҳотро таҳия мекунад, барои тасдиқи шумо (ё автоматикӣ иҷро мекунад, агар шумо онро танзим карда бошед) мепурсад ва мушкилотро ҳал мекунад. 5-сатҳи давраии мустақил — аз танҳо назорат то пурра таъмир.

## Ҳама чизро ройгон санҷед — 33 озмоиш

Ҳеҷ корти кредитӣ. Ҳеҷ сабти ном лозим нест. Танҳо бор кунед ва оғоз кунед.

Ҳар як хусусияти премиум — бор кардани тасвир, AI Arena, AI Council, таҳлили файл ва видео — барои 33 истифодаи аввал ройгон аст. Пас аз он, калиди API-и худро биёред (BYOK) ва ҳама чизро барои ройгон идома диҳед. Ё аз $3/мо барои хусусиятҳои AI ва дастаи идорашаванда обуна шавед.

Чаро 33? Дар соли 1919, ҳаракати истиқлолияти Корея бо 33 намояндае, ки озодии ҳама чизро эълон карданд, роҳбарӣ мекард. 33 озмоиши ройгони WIA SOOM эълони мо аст: **Асбобҳои AI бояд барои ҳама ройгон бошанд.**

**CLI → GUI → SUI.** Интерфейсҳои командӣ ба мо қудрат доданд. Интерфейсҳои графикӣ ба мо осонӣ доданд. WIA SOOM **SUI (Soom User Interface)** -ро муаррифӣ мекунад — ҳаётро нафас гиред, ва AI зинда мешавад.

## Платформаи 5-in-1

Асбобҳои дигар як чизро мекунанд. WIA SOOM панҷ чизро мекунад — дар як тиреза.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Код  │ SFTP │ Нозирӣ                  │
│  Ter │ Agen │ Edit │ File │ Монитор + Амният        │
│  min │   t  │  or  │ Mgr  │ + Логҳо + Топология     │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminal** — xterm.js, туннелсозии бастион, намоишҳои тақсимшуда, мубодилаи мултиплеер
2. **AI Agent** — 14 асбоб, 3 провайдер (GPT/Gemini/Claude), стриминг, таҳлили тасвир
3. **Code Editor** — Monaco бо AI пуркунанда, шеносоии хато, интишор
4. **SFTP Manager** — идоракунии файлҳои кашидан ва гузоштан, таҳрири дурдаст
5. **Observability** — метрикаи вақти воқеӣ, таҳлили лог, харитаи топология, скани амният

## Хусусиятҳо

### AI, ки воқеан дар сервери шумо кор мекунад

**AI DevOps Agent** — Дар терминал `gpt`, `gemini`, ё `claude` нависед. AI 14 асбоб дорад: хондан/навиштан/таҳрир кардани файлҳо, иҷрои фармонҳо, git, grep, идоракунии раванд. Посухҳои стриминг. Хатирҳои сессия. Он танҳо пешниҳод намекунад — он иҷро мекунад.

**AI Arena** — `arena` нависед. 2–4 AI дар шохаҳои Git-и алоҳида рақобат мекунанд. Баррасии мутақобила ҳар ҳалли AI-ро баҳо медиҳад. Ғолибро интихоб кунед ва муттаҳид кунед.

**AI Council** — Мулти AI саволи шуморо муҳокима мекунанд, сипас беҳтарин ҷавобро синтез мекунанд.

**AI Code Editor** — Редактори Monaco бо пуркунандаи AI, шеносоии хато, интишори як-клик ба сервер.

**AI Self-Healing** — баланд шудани CPU, пур шудани диск, фурӯ рафтани хидмат — AI шеносо мекунад, ташхис мекунад, ислоҳ мекунад. 5-сатҳи давраии мустақил.

**Voice Interface** — Фармонҳоро гӯед, посухҳоро бишнавед. Идоракунии сервери бидуни даст.

### Боркунии мултимодалӣ (Аввалин дар CLI)

Тасвирҳоро часпонед, файлҳоро кашед, видеоҳоро гузоред — мустақиман ба сессияи SSH терминали шумо. AI ҳама чизро таҳлил мекунад: скриншотҳои хато, файлҳои конфиг, видеои интишор, диаграммаҳои архитектура.

### Иқтидори инфрасохтор

**Topology Map** — Серверҳо, хидматҳо ва пайвандҳоро дар як нигоҳ визуализатсия кунед. Кашфи автоматӣ тавассути SSH — насби агент нест.

**Нозирии вақти воқеӣ** — CPU, хотира, диск, графикҳои sparkline шабака + пешгӯии AI + барқарорсозии автоматикӣ. Datadog-ро иваз мекунад.

**AI Log Analysis** — Стриминги вақти воқеӣ + шеносоии аномалия + ҷустуҷӯи забони табиӣ + мураттабкунии байни серверҳо. Splunk-ро иваз мекунад.

### Амният ва DevOps

**Маркази фармондеҳӣ** — Сканерии 7-минтақа + баҳоҳои амният + ислоҳи як-клик + таҳлили AI + дарвози амнияти фармонҳои вақти воқеӣ. Qualys-ро иваз мекунад.

**Docker Manager** — Идоракунии пурраи Docker тавассути SSH — агент нест. Назорати контейнер, захираҳои зинда, таҳлили логҳои AI, редактори Compose. Portainer-ро иваз мекунад.

**Автоматизатсияи китобчаи корӣ** — AI китобчаҳои кориро автоматикӣ иҷро мекунад. Эҷоди забони табиӣ, шохаҳои шартӣ, баргардонидани автоматикӣ. Китобчаи кории зинда, ки худаш хирадманд мешавад. PagerDuty-ро иваз мекунад.

**Cron & Env Manager** — Визуалии редактори crontab + идоракунии файли .env. AI забони табииро ба изҳороти cron табдил медиҳад.

### Ҳамкорӣ

**Multiplayer Terminal** — Сессияҳои терминалро бо ҳамкорон дар вақти воқеӣ мубодила кунед.

**Фазои кории даста ва RBAC** — Назорати дастрасии асоси нақш, логҳои аудити, таҳлили хатарҳои фармон.

### Воситаҳои васеъшавӣ

**59 Plugins** — Дашборди Docker, линзаи Kubernetes, браузери Redis, менеджери PM2, муҳандисии MongoDB, мониторинги шабака ва бештар. Бозори плагинҳо бо насби як-клик.

**API Client** — Мизоҷи REST/GraphQL/WebSocket-и сохташударо. API-ҳоро бе тарк кардани терминал санҷед.

### Барои ҳама

**254 Забон** — Ҳар забон, ҳар скрипт, дастгирии RTL. Ҳеҷ марз нест.

**Дастрасии пурра** — Хонандаи экран (ARIA), натиҷаи терминали Брайл, режимҳои контрасти баланд, фармонҳои овозӣ, навигацияи клавиатура, танзими андозаи шрифт.

## Ҳикоя

WIA SOOM аз як хатогӣ ва як экран шикаста таваллуд шуд.

Ман Сам, барномасози 50+ сола, ки дар Сеул, Корея таълим гирифтаам. Ман пас аз 50-солагӣ барномасозиро омӯхтам ва 2 солро барои идоракунии серверҳо бо роҳи душвор сарф кардам — сохтани 40,000+ мақолаи хабарӣ, 434 асбоб ва 30 хидмати веб, шаби пас аз шаб.

**Хатогӣ.** Тақрибан як моҳ пеш, ман терминали SSH-и худро истифода мебурдам ва хато навиштам `Claude`. Экран иваз шуд — Кодекси Claude пайдо шуд. Ман намедонистам, ки ин чӣ аст. Аммо ин кашфи хато як тухм шеносо кард: чӣ мешавад, агар ман терминал созам, ки AI дар дохили он зиндагӣ кунад?

**Сохтани аввалин.** Ман худро Electron омӯзондам, аввалин версияи WIA SOOM-ро сохтам ва онро иҷро кардам. Саҳнаи муаррифии Кодекси Claude пайдо шуд — шикаста, хато, мижакаи сигнале, ки мемирад. Аммо он зинда буд.

Ман навиштам: **"Шумо гап зада метавонед?"**

AI посух дод: *"Ҳа, ман гап зада метавонам. Чӣ кӯмак кунам?"*

Сипас ман пурсидем: **"Шумо тасвирҳоро хонда метавонед?"**

AI посух дод: *"Ҳа, ман тасвирҳоро хонда метавонам! Шумо чӣ лозим доред?"*

Ин ду савол, ки дар дохили барномаи худ аз ҷониби касе, ки намедонист, ки "нобуд" дар терминали CLI чист, зада шуданд, аввалин терминали SSH бо бор кардани тасвир дар ҷаҳон гардид.

7 рӯз пас: 67,000+ хатти код. 59 плагин. 254 забон. AI Arena. Агентҳои худ-табобаткунанда.

Барномасозони таҷрибадор инро сохта наметавонистанд — зеро онҳо "медонистанд", ки тасвирҳо дар терминалҳои CLI кор намекунанд. Ман намедонистам. Пас ман танҳо пурсидем.

> *Тайёрӣ 2 сол гирифт. Сохтани 1 ҳафта.*
> *Дарахти хушки 2 сол ҷамъ шуд. Он дар 1 сония оташ гирифт.*
