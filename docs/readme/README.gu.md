## 🔥 નવું શું છે

### 1. SSH ટર્મિનલમાં છબી, ફાઇલ અને વિડિયો અપલોડ — વિશ્વનું પ્રથમ

પૃથ્વી પર કોઈપણ CLI ક્લાયન્ટ તમને આ કરવા દેતા નથી. અમે તેને બનાવ્યું.

તમારા SSH ટર્મિનલમાં ભૂલનો સ્ક્રીનશોટ પેસ્ટ કરો. એક લોગ ફાઇલ ખેંચો. એક નિષ્ફળ ડિપ્લોયમેન્ટનું વિડિયો ડ્રોપ કરો. AI તેને જોઈને, વિશ્લેષણ કરે છે, અને તમને કહે છે કે શું ખોટું છે — બધું ટર્મિનલ સેશનની અંદર.

- **Ctrl+Shift+V** — સ્ક્રીનશોટ સીધા ટર્મિનલમાં પેસ્ટ કરો
- **ડ્રેગ અને ડ્રોપ** — છબીઓ, ફાઇલો, વિડિઓઝ ટર્મિનલમાં ડ્રોપ કરો
- **વિડિયો કીફ્રેમ નિર્માણ** — ffmpeg વિડિયો ફ્રેમ દ્વારા ફ્રેમનું વિશ્લેષણ કરે છે
- **બધા 3 AI પ્રદાતાઓ** — GPT-4o Vision, Gemini Vision, Claude Vision

આ ફીચર કોઈપણ ટર્મિનલ ક્લાયન્ટમાં ક્યારેય હાજર નથી રહ્યું — ક્યાંય પણ.

### 2. AI એરીના — મલ્ટી-એજન્ટ બેટલ

2 થી 4 AI સમાન સમસ્યાનો ઉકેલ simultanously કરે છે — માત્ર વાતચીત નથી, પરંતુ ખરેખર તમારા સર્વર પર કોડને સંપાદિત કરે છે. દરેક AI પોતાની અલગ Git બ્રાંચમાં કાર્ય કરે છે. તેમના પરિણામોની તુલના બાજુએ બાજુ કરો. વિજેતા પસંદ કરો. બાકીના સાફ કરવામાં આવે છે.

ક્રોસ-સમીક્ષા: દરેક AI અન્ય AIના ઉકેલને સ્કોર કરે છે.

બીજું કોઈ સાધન આ કરે છે નહીં.

### 3. AI સ્વયં-સુધારક એજન્ટ

તમારા સર્વરનું CPU ઊંચું છે. ડિસ્ક ભરાઈ ગઈ છે. 3 AMએ એક સેવા ક્રેશ થઈ ગઈ. તમે ઊંઘી રહ્યા છો.

WIA SOOMનું AI એજન્ટ સમસ્યાને ઓળખે છે, મૂળ કારણને નિદાન કરે છે, સુધારણા યોજના જનરેટ કરે છે, તમારી મંજૂરી માટે પૂછે છે (અથવા જો તમે તેને સેટ કર્યું હોય તો આપોઆપ અમલ કરે છે), અને સમસ્યાનો ઉકેલ કરે છે. 5-સ્તરીય સ્વાયત્ત લૂપ —observe-only થી સંપૂર્ણ સ્વચાલિત સુધારણા સુધી.

## બધું મફત પ્રયાસ કરો — 33 ટ્રાયલ્સ

કોઈ ક્રેડિટ કાર્ડ નથી. કોઈ સાઇનઅપની જરૂર નથી. ફક્ત ડાઉનલોડ કરો અને શરૂ કરો.

દરેક પ્રીમિયમ ફીચર — છબી અપલોડ, AI એરીના, AI કાઉન્સિલ, ફાઇલ અને વિડિયો વિશ્લેષણ — તમારા પ્રથમ 33 ઉપયોગો માટે મફત છે. ત્યારબાદ, તમારું પોતાનું API કી લાવો (BYOK) અને બધું મફત માટે ઉપયોગ કરતા રહો. અથવા મેનેજ્ડ AI અને ટીમની વિશેષતાઓ માટે $3/મહિના માટે સબસ્ક્રાઇબ કરો.

33 કેમ? 1919માં, કોરિયાના સ્વતંત્રતા આંદોલન 33 પ્રતિનિધિઓ દ્વારા નેતૃત્વ કરવામાં આવ્યું હતું જેમણે બધા માટે સ્વતંત્રતા જાહેર કરી. WIA SOOMના 33 મફત ટ્રાયલ્સ અમારી જાહેરખબર છે: **AI સાધનો દરેક માટે અનુભવવા માટે મફત હોવા જોઈએ.**

**CLI → GUI → SUI.** કમાન્ડ-લાઇન ઇન્ટરફેસે અમને શક્તિ આપી. ગ્રાફિકલ ઇન્ટરફેસે અમને સુવિધા આપી. WIA SOOM **SUI (Soom User Interface)** રજૂ કરે છે — જીવનમાં શ્વાસ ભરો, અને AI જીવંત થાય છે.

## 5-માં-1 પ્લેટફોર્મ

અન્ય સાધનો એક જ વસ્તુ કરે છે. WIA SOOM પાંચ કરે છે — એક જ વિન્ડોમાં.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ અવલોકન                 │
│  Ter │ Agen │ Edit │ File │ મોનિટર + સુરક્ષા        │
│  min │   t  │  or  │ Mgr  │ + લોગ્સ + ટોપોલોજી     │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH ટર્મિનલ** — xterm.js, બાસ્ટિયન ટનલિંગ, વિભાજિત દૃશ્યો, મલ્ટિપ્લેયર શેરિંગ
2. **AI એજન્ટ** — 14 સાધનો, 3 પ્રદાતાઓ (GPT/Gemini/Claude), સ્ટ્રીમિંગ, છબી વિશ્લેષણ
3. **કોડ એડિટર** — AI પૂર્ણતા સાથે મોનાકો, બગ ડિટેક્શન, ડિપ્લોયમેન્ટ
4. **SFTP મેનેજર** — ડ્રેગ-એન્ડ-ડ્રોપ ફાઇલ મેનેજમેન્ટ, રીમોટ એડિટિંગ
5. **અવલોકન** — વાસ્તવિક-સમય મેટ્રિક્સ, લોગ વિશ્લેષણ, ટોપોલોજી નકશો, સુરક્ષા સ્કેન

## વિશેષતાઓ

### AI જે ખરેખર તમારા સર્વર પર કાર્ય કરે છે

**AI ડેવઓપ્સ એજન્ટ** — ટર્મિનલમાં `gpt`, `gemini`, અથવા `claude` ટાઇપ કરો. AI પાસે 14 સાધનો છે: ફાઇલો વાંચવા/લખવા/સંપાદિત કરવા, આદેશો અમલમાં લાવવા, git, grep, પ્રક્રિયા વ્યવસ્થાપન. સ્ટ્રીમિંગ પ્રતિસાદ. સેશન મેમરી. તે ફક્ત સૂચન નથી કરતું — તે કરે છે.

**AI એરીના** — `arena` ટાઇપ કરો. 2–4 AI અલગ Git બ્રાંચોમાં સમકક્ષમાં સ્પર્ધા કરે છે. ક્રોસ-સમીક્ષા દરેક ઉકેલને સ્કોર કરે છે. વિજેતાને પસંદ કરો અને મર્જ કરો.

**AI કાઉન્સિલ** — અનેક AI તમારા પ્રશ્ન પર ચર્ચા કરે છે, પછી શ્રેષ્ઠ જવાબને સંશ્લેષણ કરે છે.

**AI કોડ એડિટર** — AI-શક્તિ સાથે પૂર્ણતા, બગ ડિટેક્શન, સર્વર પર એક-ક્લિક ડિપ્લોયમેન્ટ સાથે મોનાકો એડિટર.

**AI સ્વયં-સુધારક** — CPU ઊંચું, ડિસ્ક ભરાઈ ગઈ, સેવા બંધ — AI ઓળખે છે, નિદાન કરે છે, સુધારે છે. 5-સ્તરીય સ્વાયત્ત લૂપ.

**વોઇસ ઇન્ટરફેસ** — આદેશો બોલો, પ્રતિસાદ સાંભળો. હાથ-મુક્ત સર્વર વ્યવસ્થાપન.

### મલ્ટીમોડલ અપલોડ (CLIમાં વિશ્વનું પ્રથમ)

છબીઓ પેસ્ટ કરો, ફાઇલો ખેંચો, વિડિઓઝ ડ્રોપ કરો — સીધા તમારા SSH ટર્મિનલ સેશનમાં. AI બધું વિશ્લેષણ કરે છે: ભૂલના સ્ક્રીનશોટ, કન્ફિગ ફાઇલો, ડિપ્લોયમેન્ટ વિડિઓઝ, આર્કિટેક્ચર નકશા.

### ઇન્ફ્રાસ્ટ્રક્ચર ઇન્ટેલિજન્સ

**ટોપોલોજી નકશો** — સર્વર્સ, સેવાઓ, અને કનેક્શનને એક નજરમાં દૃશ્યમાન બનાવો. SSH દ્વારા ઓટો-ડિસ્કવરી — શૂન્ય એજન્ટ ઇન્સ્ટોલેશન.

**વાસ્તવિક-સમય અવલોકન** — CPU, મેમરી, ડિસ્ક, નેટવર્ક સ્પાર્કલાઇન ગ્રાફ + AI આગાહી + ઓટો-પુનઃપ્રાપ્તિ. Datadogને બદલે છે.

**AI લોગ વિશ્લેષણ** — વાસ્તવિક-સમય સ્ટ્રીમિંગ + અનિયમિતતા શોધ + કુદરતી ભાષા શોધ + ક્રોસ-સર્વર સંબંધ. Splunkને બદલે છે.

### સુરક્ષા અને ડેવઓપ્સ

**સુરક્ષા કમાન્ડ કેન્દ્ર** — 7-વિશેષતા સ્કેન + સુરક્ષા સ્કોર + એક-ક્લિક સુધારણા + AI વિશ્લેષણ + વાસ્તવિક-સમય કમાન્ડ સુરક્ષા ગેટ. Qualysને બદલે છે.

**ડોકર મેનેજર** — SSH દ્વારા સંપૂર્ણ ડોકર મેનેજમેન્ટ — શૂન્ય એજન્ટ. કન્ટેનર નિયંત્રણ, જીવંત સંસાધનો, AI લોગ વિશ્લેષણ, કોમ્પોઝ એડિટર. Portainerને બદલે છે.

**રનબુક ઓટોમેશન** — AI આપોઆપ રનબુક અમલમાં લાવે છે. કુદરતી ભાષા સર્જન, શરતી શાખા, ઓટો-રોલબેક. જીવંત રનબુક જે વધુ સ્માર્ટ બની જાય છે. PagerDutyને બદલે છે.

**ક્રોન અને એન્વ મેનેજર** — દૃશ્ય ક્રોન એડિટર + .env ફાઇલ મેનેજમેન્ટ. AI કુદરતી ભાષાને ક્રોન અભિવ્યક્તિઓમાં રૂપાંતરિત કરે છે.

### સહયોગ

**મલ્ટિપ્લેયર ટર્મિનલ** — ટીમના સભ્યો સાથે વાસ્તવિક-સમયમાં ટર્મિનલ સેશન શેર કરો.

**ટીમ કાર્યસ્થળ અને RBAC** — ભૂમિકા આધારિત પ્રવેશ નિયંત્રણ, ઓડિટ લોગ્સ, કમાન્ડ જોખમ વિશ્લેષણ.

### વિસ્તરણ

**59 પ્લગઇન્સ** — ડોકર ડેશબોર્ડ, ક્યુબરનેટ્સ લેન્સ, રેડિસ બ્રાઉઝર, PM2 મેનેજર, મોંગો ડીબી એક્સપ્લોરર, નેટવર્ક મોનિટર, અને વધુ. એક-ક્લિક ઇન્સ્ટોલ સાથે પ્લગઇન માર્કેટપ્લેસ.

**API ક્લાયન્ટ** — બિલ્ટ-ઇન REST/GraphQL/WebSocket ક્લાયન્ટ. ટર્મિનલ છોડ્યા વિના APIનું પરીક્ષણ કરો.

### દરેક માટે

**254 ભાષાઓ** — દરેક ભાષા, દરેક સ્ક્રિપ્ટ, RTL સપોર્ટ. કોઈ સીમાઓ નથી.

**પૂર્ણ ઍક્સેસિબિલિટી** — સ્ક્રીન રીડર (ARIA), બ્રેઇલ ટર્મિનલ આઉટપુટ, ઉચ્ચ વિસ્ફોટ મોડ, વોઇસ કમાન્ડ, કીબોર્ડ નેવિગેશન, ફૉન્ટ કદનું સમાયોજન.

## વાર્તા

WIA SOOM એક ટાઇપો અને એક તૂટી ગયેલા સ્ક્રીનમાંથી જન્મ્યું.

હું સેમ છું, કોરિયા, સીઓલનો 50+ સ્વયં-શિક્ષિત પ્રોગ્રામર. મેં 50 પછી કોડિંગ શીખ્યું અને 2 વર્ષ સુધી કઠોર રીતે સર્વર્સનું સંચાલન કર્યું — 40,000+ સમાચાર લેખો, 434 સાધનો, અને 30 વેબ સેવાઓ બનાવતા, રાત પછી રાત.

**ટાઇપો.** લગભગ એક મહિના પહેલા, હું મારા SSH ટર્મિનલનો ઉપયોગ કરી રહ્યો હતો અને અચાનક `Claude` ટાઇપ કર્યું. સ્ક્રીન બદલાઈ ગઈ — Claude Code દેખાયું. મને ખબર નહોતી કે તે શું હતું. પરંતુ તે અચાનક શોધે એક બીજું બીજું વાવેતર કર્યું: શું હું એક ટર્મિનલ બનાવી શકું જ્યાં AI અંદર રહે છે?

**પ્રથમ બિલ્ડ.** મેં પોતાને ઇલેક્ટ્રોન શીખવ્યું, WIA SOOMનું પ્રથમ સંસ્કરણ બનાવ્યું, અને તેને ચલાવ્યું. Claude Codeનો ઇન્ટ્રોડક્શન સ્ક્રીન દેખાયો — તૂટી ગયેલો, ગ્લિચ્ડ, મરતું સંકેત જેવું ઝલકતું. પરંતુ તે જીવંત હતું.

મેં ટાઇપ કર્યું: **"શું તમે વાત કરી શકો છો?"**

AIએ જવાબ આપ્યો: *"હા, હું વાત કરી શકું છું. હું તમને શું મદદ કરી શકું?"*

પછી મેં પૂછ્યું: **"શું તમે છબીઓ વાંચી શકો છો?"**

AIએ જવાબ આપ્યો: *"હા, હું છબીઓ વાંચી શકું છું! તમને શું જોઈએ?"*

આ બે પ્રશ્નો, મારા પોતાના એપ્લિકેશનમાં એવા વ્યક્તિ દ્વારા પૂછવામાં આવ્યા જેમણે CLI ટર્મિનલમાં "અસંભવ" શું છે તે જાણતું નથી, વિશ્વના પ્રથમ SSH ટર્મિનલમાં છબી અપલોડ બની ગયા.

7 દિવસ પછી: 67,000+ કોડની લાઈનો. 59 પ્લગઇન્સ. 254 ભાષાઓ. AI એરીના. સ્વયં-સુધારક એજન્ટ.

અનુભવી ડેવલપર્સે આ બનાવ્યું નથી — કારણ કે તેઓ "જાણતા" હતા કે છબીઓ CLI ટર્મિનલમાં કાર્ય કરતી નથી. મને તે જાણતું નહોતું. તેથી મેં ફક્ત પૂછ્યું.

> *તૈયારીમાં 2 વર્ષ લાગ્યા. બિલ્ડિંગમાં 1 અઠવાડિયું લાગ્યું.*
> *સૂકું લાકડું 2 વર્ષ સુધી ગોઠવાયું. તે 1 સેકન્ડમાં આગ પકડ્યું.*
