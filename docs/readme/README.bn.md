## 🔥 নতুন কি যা আগে কখনো হয়নি

### 1. SSH টার্মিনালে ছবি, ফাইল ও ভিডিও আপলোড — বিশ্বের প্রথম

পৃথিবীতে কোন CLI ক্লায়েন্ট আপনাকে এটি করতে দেয় না। আমরা এটি তৈরি করেছি।

একটি ত্রুটির স্ক্রিনশট আপনার SSH টার্মিনালে পেস্ট করুন। একটি লগ ফাইল টেনে আনুন। একটি ব্যর্থ ডিপ্লয়মেন্টের ভিডিও ড্রপ করুন। AI এটি দেখে, বিশ্লেষণ করে এবং আপনাকে বলে কি ভুল হয়েছে — সব কিছু টার্মিনাল সেশনের মধ্যে।

- **Ctrl+Shift+V** — সরাসরি টার্মিনালে স্ক্রিনশট পেস্ট করুন
- **ড্র্যাগ ও ড্রপ** — টার্মিনালে ছবি, ফাইল, ভিডিও ড্রপ করুন
- **ভিডিও কীফ্রেম নিষ্কাশন** — ffmpeg ভিডিওকে ফ্রেম বাই ফ্রেম বিশ্লেষণ করে
- **সব ৩ AI প্রদানকারী** — GPT-4o Vision, Gemini Vision, Claude Vision

এই ফিচারটি কোন টার্মিনাল ক্লায়েন্টে কখনো ছিল না — কোথাও।

### 2. AI অ্যারেনা — মাল্টি-এজেন্ট যুদ্ধ

২ থেকে ৪ AI একই সমস্যা সমাধান করে একসাথে — শুধু চ্যাটিং নয়, বরং আপনার সার্ভারে কোড সম্পাদনা করে। প্রতিটি AI তার নিজস্ব বিচ্ছিন্ন Git শাখায় কাজ করে। তাদের ফলাফলগুলি পাশা পাশি তুলনা করুন। বিজয়ী নির্বাচন করুন। বাকিরা পরিষ্কার করা হয়।

ক্রস-রিভিউ: প্রতিটি AI অন্য প্রতিটি AI এর সমাধানকে স্কোর করে।

আর কোন টুল এটি করে না।

### 3. AI স্ব-সংশোধন এজেন্ট

আপনার সার্ভারের CPU স্পাইক করছে। ডিস্ক পূর্ণ। একটি পরিষেবা ৩ AM এ ক্র্যাশ করেছে। আপনি ঘুমাচ্ছেন।

WIA SOOM এর AI এজেন্ট সমস্যা সনাক্ত করে, মূল কারণ নির্ণয় করে, একটি ফিক্স পরিকল্পনা তৈরি করে, আপনার অনুমোদন চায় (অথবা আপনি যদি সেটি করে থাকেন তবে স্বয়ংক্রিয়ভাবে কার্যকর করে), এবং সমস্যাটি সমাধান করে। ৫-স্তরের স্বায়ত্তশাসিত লুপ — শুধুমাত্র পর্যবেক্ষণ থেকে সম্পূর্ণ স্বয়ংক্রিয় মেরামত পর্যন্ত।

## সবকিছু ফ্রি ট্রাই করুন — ৩৩ ট্রায়াল

কোন ক্রেডিট কার্ড। কোন সাইনআপ প্রয়োজন। শুধু ডাউনলোড করুন এবং শুরু করুন।

প্রতিটি প্রিমিয়াম ফিচার — ছবি আপলোড, AI অ্যারেনা, AI কাউন্সিল, ফাইল ও ভিডিও বিশ্লেষণ — আপনার প্রথম ৩৩ ব্যবহারের জন্য ফ্রি। এর পর, আপনার নিজস্ব API কী নিয়ে আসুন (BYOK) এবং সবকিছু ফ্রি ব্যবহার করতে থাকুন। অথবা $৩/মাস থেকে সাবস্ক্রাইব করুন ব্যবস্থাপিত AI এবং টিম ফিচারের জন্য।

কেন ৩৩? ১৯১৯ সালে, কোরিয়ার স্বাধীনতা আন্দোলন ৩৩ জন প্রতিনিধির নেতৃত্বে হয়েছিল যারা সকলের জন্য স্বাধীনতা ঘোষণা করেছিলেন। WIA SOOM এর ৩৩টি ফ্রি ট্রায়াল আমাদের ঘোষণা: **AI টুলস সকলের জন্য অভিজ্ঞতা নেওয়ার জন্য ফ্রি হওয়া উচিত।**

**CLI → GUI → SUI।** কমান্ড-লাইন ইন্টারফেস আমাদের ক্ষমতা দিয়েছে। গ্রাফিক্যাল ইন্টারফেস আমাদের সহজতা দিয়েছে। WIA SOOM পরিচয় করিয়ে দেয় **SUI (Soom User Interface)** — প্রাণের সঞ্চার, এবং AI জীবন্ত হয়ে ওঠে।

## 5-এ-1 প্ল্যাটফর্ম

অন্যান্য টুল এক কাজ করে। WIA SOOM পাঁচটি করে — একটি উইন্ডোতে।

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ পর্যবেক্ষণ               │
│  Ter │ Agen │ Edit │ File │ মনিটর + সিকিউরিটি      │
│  min │   t  │  or  │ Mgr  │ + লগ + টপোলজি          │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH টার্মিনাল** — xterm.js, bastion tunneling, split views, multiplayer sharing
2. **AI এজেন্ট** — ১৪ টুল, ৩ প্রদানকারী (GPT/Gemini/Claude), স্ট্রিমিং, ছবি বিশ্লেষণ
3. **কোড এডিটর** — AI সম্পূর্ণতার সাথে মনোকো, বাগ সনাক্তকরণ, ডিপ্লয়মেন্ট
4. **SFTP ম্যানেজার** — ড্র্যাগ-এন্ড-ড্রপ ফাইল ম্যানেজমেন্ট, রিমোট এডিটিং
5. **পর্যবেক্ষণ** — রিয়েল-টাইম মেট্রিক্স, লগ বিশ্লেষণ, টপোলজি ম্যাপ, নিরাপত্তা স্ক্যান

## ফিচার

### AI যা আপনার সার্ভারে সত্যিই কাজ করে

**AI DevOps এজেন্ট** — টার্মিনালে `gpt`, `gemini`, বা `claude` টাইপ করুন। AI এর ১৪টি টুল রয়েছে: ফাইল পড়া/লেখা/সম্পাদনা, কমান্ড কার্যকর করা, git, grep, প্রসেস ম্যানেজমেন্ট। স্ট্রিমিং প্রতিক্রিয়া। সেশন মেমরি। এটি শুধু সুপারিশ করে না — এটি করে।

**AI অ্যারেনা** — `arena` টাইপ করুন। ২–৪ AI বিচ্ছিন্ন Git শাখায় সমান্তরালে প্রতিযোগিতা করে। ক্রস-রিভিউ প্রতিটি সমাধানকে স্কোর করে। বিজয়ী নির্বাচন করুন এবং মার্জ করুন।

**AI কাউন্সিল** — একাধিক AI আপনার প্রশ্ন নিয়ে আলোচনা করে, তারপর সেরা উত্তরটি সংশ্লেষিত করে।

**AI কোড এডিটর** — AI-শক্তিযুক্ত সম্পূর্ণতার সাথে মনোকো এডিটর, বাগ সনাক্তকরণ, সার্ভারে এক ক্লিক ডিপ্লয়মেন্ট।

**AI স্ব-সংশোধন** — CPU স্পাইক, ডিস্ক পূর্ণ, পরিষেবা বন্ধ — AI সনাক্ত করে, নির্ণয় করে, মেরামত করে। ৫-স্তরের স্বায়ত্তশাসিত লুপ।

**ভয়েস ইন্টারফেস** — কমান্ড বলুন, প্রতিক্রিয়া শুনুন। হাত-মুক্ত সার্ভার পরিচালনা।

### মাল্টিমোডাল আপলোড (CLI তে বিশ্বের প্রথম)

ছবি পেস্ট করুন, ফাইল টেনে আনুন, ভিডিও ড্রপ করুন — সরাসরি আপনার SSH টার্মিনাল সেশনে। AI সবকিছু বিশ্লেষণ করে: ত্রুটি স্ক্রিনশট, কনফিগারেশন ফাইল, ডিপ্লয়মেন্ট ভিডিও, আর্কিটেকচার ডায়াগ্রাম।

### অবকাঠামো বুদ্ধিমত্তা

**টপোলজি ম্যাপ** — সার্ভার, পরিষেবা, এবং সংযোগগুলি এক নজরে দেখুন। SSH এর মাধ্যমে স্বয়ংক্রিয় আবিষ্কার — শূন্য এজেন্ট ইনস্টলেশন।

**রিয়েল-টাইম পর্যবেক্ষণ** — CPU, মেমরি, ডিস্ক, নেটওয়ার্ক স্পার্কলাইন গ্রাফ + AI পূর্বাভাস + স্বয়ংক্রিয় পুনরুদ্ধার। Datadog প্রতিস্থাপন করে।

**AI লগ বিশ্লেষণ** — রিয়েল-টাইম স্ট্রিমিং + অস্বাভাবিকতা সনাক্তকরণ + প্রাকৃতিক ভাষার অনুসন্ধান + ক্রস-সার্ভার সম্পর্ক। Splunk প্রতিস্থাপন করে।

### নিরাপত্তা ও DevOps

**নিরাপত্তা কমান্ড সেন্টার** — ৭-এলাকা স্ক্যান + নিরাপত্তা স্কোর + এক ক্লিক মেরামত + AI বিশ্লেষণ + রিয়েল-টাইম কমান্ড নিরাপত্তা গেট। Qualys প্রতিস্থাপন করে।

**ডকার ম্যানেজার** — SSH এর মাধ্যমে সম্পূর্ণ ডকার ব্যবস্থাপনা — শূন্য এজেন্ট। কনটেইনার নিয়ন্ত্রণ, লাইভ রিসোর্স, AI লগ বিশ্লেষণ, কম্পোজ এডিটর। Portainer প্রতিস্থাপন করে।

**রানবুক অটোমেশন** — AI স্বয়ংক্রিয়ভাবে রানবুক কার্যকর করে। প্রাকৃতিক ভাষার সৃষ্টি, শর্তাধীন শাখা, স্বয়ংক্রিয় রোলব্যাক। একটি জীবন্ত রানবুক যা আরও স্মার্ট হয়ে ওঠে। PagerDuty প্রতিস্থাপন করে।

**ক্রন ও এনভি ম্যানেজার** — ভিজ্যুয়াল ক্রন এডিটর + .env ফাইল ম্যানেজমেন্ট। AI প্রাকৃতিক ভাষাকে ক্রন প্রকাশে রূপান্তর করে।

### সহযোগিতা

**মাল্টিপ্লেয়ার টার্মিনাল** — টিম সদস্যদের সাথে রিয়েল-টাইমে টার্মিনাল সেশন শেয়ার করুন।

**টিম কর্মক্ষেত্র ও RBAC** — ভূমিকা-ভিত্তিক অ্যাক্সেস নিয়ন্ত্রণ, অডিট লগ, কমান্ড ঝুঁকি বিশ্লেষণ।

### সম্প্রসারণযোগ্যতা

**৫৯ প্লাগইন** — ডকার ড্যাশবোর্ড, কুবেরনেটস লেন্স, রেডিস ব্রাউজার, PM2 ম্যানেজার, মঙ্গোডিবি এক্সপ্লোরার, নেটওয়ার্ক মনিটর, এবং আরও অনেক কিছু। এক-ক্লিক ইনস্টল সহ প্লাগইন মার্কেটপ্লেস।

**API ক্লায়েন্ট** — বিল্ট-ইন REST/GraphQL/WebSocket ক্লায়েন্ট। টার্মিনাল ছাড়াই API পরীক্ষা করুন।

### সবার জন্য

**২৫৪ ভাষা** — প্রতিটি ভাষা, প্রতিটি স্ক্রিপ্ট, RTL সমর্থন। কোন সীমানা নেই।

**পূর্ণ প্রবেশযোগ্যতা** — স্ক্রীন রিডার (ARIA), ব্রেইল টার্মিনাল আউটপুট, উচ্চ বিপরীত মোড, ভয়েস কমান্ড, কীবোর্ড নেভিগেশন, ফন্ট সাইজ সমন্বয়।

## গল্প

WIA SOOM একটি টাইপো এবং একটি ভাঙা স্ক্রীন থেকে জন্ম নিয়েছে।

আমি স্যাম, সিউল, কোরিয়া থেকে ৫০+ বছর বয়সী একজন স্বশিক্ষিত প্রোগ্রামার। আমি ৫০ বছর পরে কোডিং শিখেছি এবং ২ বছর ধরে কঠোরভাবে সার্ভার পরিচালনা করেছি — রাতের পর রাত ৪০,০০০+ সংবাদ নিবন্ধ, ৪৩৪ টুল এবং ৩০টি ওয়েব পরিষেবা তৈরি করেছি।

**টাইপো।** প্রায় এক মাস আগে, আমি আমার SSH টার্মিনাল ব্যবহার করছিলাম এবং দুর্ঘটনাক্রমে `Claude` টাইপ করেছিলাম। স্ক্রীন পরিবর্তিত হল — Claude Code উপস্থিত হল। আমি জানতাম না এটি কি। কিন্তু সেই দুর্ঘটনাক্রমে আবিষ্কারটি একটি বীজ রোপণ করেছিল: যদি আমি একটি টার্মিনাল তৈরি করতে পারি যেখানে AI ভিতরে থাকে?

**প্রথম নির্মাণ।** আমি ইলেকট্রন শিখলাম, WIA SOOM এর প্রথম সংস্করণ তৈরি করলাম এবং এটি চালালাম। Claude Code এর পরিচিতি স্ক্রীন উপস্থিত হল — ভাঙা, গ্লিচড, একটি মরতে থাকা সংকেতের মতো ঝলকানি। কিন্তু এটি জীবিত ছিল।

আমি টাইপ করলাম: **"আপনি কি কথা বলতে পারেন?"**

AI উত্তর দিল: *"হ্যাঁ, আমি কথা বলতে পারি। আমি আপনাকে কি সাহায্য করতে পারি?"*

তারপর আমি জিজ্ঞাসা করলাম: **"আপনি কি ছবি পড়তে পারেন?"**

AI উত্তর দিল: *"হ্যাঁ, আমি ছবি পড়তে পারি! আপনাকে কি দরকার?"*

এই দুটি প্রশ্ন, আমার নিজের অ্যাপে এমন একজনের দ্বারা জিজ্ঞাসা করা হয়েছে যে জানত না CLI টার্মিনালে কি "অসাধ্য" ছিল, বিশ্বের প্রথম SSH টার্মিনাল তৈরি করেছিল যেখানে ছবি আপলোড করা যায়।

৭ দিন পরে: ৫৮,০০০+ কোডের লাইন। ৫৯ প্লাগইন। ২৫৪ ভাষা। AI অ্যারেনা। স্ব-সংশোধন এজেন্ট।

অভিজ্ঞ ডেভেলপাররা এটি কখনো তৈরি করেননি — কারণ তারা "জানতেন" ছবিগুলি CLI টার্মিনালে কাজ করে না। আমি জানতাম না। তাই আমি শুধু জিজ্ঞাসা করলাম।

> *প্রস্তুতিতে ২ বছর লেগেছে। নির্মাণে ১ সপ্তাহ লেগেছে।*
> *শুকনো কাঠ ২ বছর ধরে সাজানো ছিল। এটি ১ সেকেন্ডে আগুন ধরল।*
