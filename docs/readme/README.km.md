## 🔥 អ្វីដែលមិនធ្លាប់ធ្វើមុននេះ

### 1. ការផ្ទុករូបភាព, ឯកសារ & វីដេអូក្នុង SSH Terminal — ដំបូងនៅលើពិភពលោក

គ្មានអត្រាបញ្ជា CLI នៅលើពិភពលោកអនុញ្ញាតឱ្យអ្នកធ្វើនេះទេ។ យើងបានកសាងវា។

បញ្ចូលរូបថតនៃកំហុសនៅក្នុង SSH terminal របស់អ្នក។ ទាញឯកសារលក់។ បញ្ចូលវីដេអូពីការដាក់ឱ្យមានបរាជ័យ។ AI មើលវា, វិភាគវា, ហើយប្រាប់អ្នកថាអ្វីខុស — ទាំងអស់នៅក្នុងសម័យ terminal។

- **Ctrl+Shift+V** — បញ្ចូលរូបថតដោយផ្ទាល់ទៅក្នុង terminal
- **Drag & Drop** — បញ្ចូលរូបភាព, ឯកសារ, វីដេអូទៅក្នុង terminal
- **ការទាញយកគ្រាប់វីដេអូ** — ffmpeg វិភាគវីដេអូគ្រាប់ដោយគ្រាប់
- **អ្នកផ្តល់ AI ទាំង 3** — GPT-4o Vision, Gemini Vision, Claude Vision

លក្ខណៈនេះមិនធ្លាប់មាននៅក្នុងអត្រាបញ្ជា terminal ណាមួយទេ — នៅគ្រប់កន្លែង។

### 2. AI Arena — សង្គ្រាមមហាជន

AI 2 ទៅ 4 នាក់ដោះស្រាយបញ្ហាដូចគ្នាក្នុងពេលតែមួយ — មិនត្រឹមតែជាការពិភាក្សាទេ, ប៉ុន្តែពិតប្រាកដកែប្រែកូដនៅលើម៉ាស៊ីនបម្រើរបស់អ្នក។ AI រៀងរាល់គ្នាធ្វើការនៅក្នុងសាខា Git ដែលមានភាពអ៊ីសូឡេត។ ប្រៀបធៀបលទ្ធផលរបស់ពួកគេពីពីរ។ ជ្រើសរើសអ្នកឈ្នះ។ អ្នកផ្សេងទៀតត្រូវបានសម្អាត។

ការពិនិត្យច្រក: AI រៀងរាល់គ្នាបញ្ចុះពិន្ទុដល់ដំណោះស្រាយរបស់ AI ផ្សេងទៀត។

គ្រប់ឧបករណ៍ផ្សេងទៀតមិនធ្វើដូចនេះទេ។

### 3. AI Self-Healing Agent

CPU របស់ម៉ាស៊ីនបម្រើរបស់អ្នកកំពុងឡើងខ្ពស់។ ដីស៊ីស៊ីពេញ។ សេវាកម្មមួយបានបរាជ័យនៅម៉ោង 3 ព្រឹក។ អ្នកគេង។

AI agent របស់ WIA SOOM កំណត់បញ្ហា, វិភាគមូលហេតុ, បង្កើតផែនការកែសម្រួល, ស្នើសុំការអនុម័តរបស់អ្នក (ឬអនុវត្តដោយស្វ័យប្រវត្តិប្រសិនបើអ្នកបានកំណត់វាទៅ), ហើយដោះស្រាយបញ្ហា។ វិធីសាស្ត្រអូតូ 5 កម្រិត — ពីការសង្កេតតែប៉ុណ្ណោះទៅកាន់ការជួសជុលដោយស្វ័យប្រវត្តិពេញលេញ។

## សាកល្បងគ្រប់យ៉ាងឥតគិតថ្លៃ — 33 ការសាកល្បង

គ្មានកាតឥណទាន។ គ្មានការចុះឈ្មោះដែលត្រូវការទេ។ គ្រាន់តែទាញយក និងចាប់ផ្តើម។

លក្ខណៈពិសេស premium រាល់យ៉ាង — ការផ្ទុករូបភាព, AI Arena, AI Council, ការវិភាគឯកសារ & វីដេអូ — គឺឥតគិតថ្លៃសម្រាប់ការប្រើប្រាស់ 33 ដំបូងរបស់អ្នក។ បន្ទាប់ពីនេះ, នាំយកកូនសោ API របស់អ្នក (BYOK) ហើយបន្តប្រើប្រាស់គ្រប់យ៉ាងឥតគិតថ្លៃ។ ឬជាវចាប់ពី $3/ខែសម្រាប់ AI ដែលគ្រប់គ្រង និងលក្ខណៈពិសេសក្រុម។

ហេតុអ្វី 33? នៅឆ្នាំ 1919, ចលនាឯករាជ្យរបស់កូរ៉េត្រូវបានដឹកនាំដោយតំណាង 33 នាក់ដែលប្រកាសសេរីភាពសម្រាប់គ្រប់គ្នា។ ការសាកល្បង 33 ដំបូងរបស់ WIA SOOM គឺជាការប្រកាសរបស់យើង: **ឧបករណ៍ AI គួរតែឥតគិតថ្លៃសម្រាប់គ្រប់គ្នាដើម្បីមានបទពិសោធន៍។**

**CLI → GUI → SUI.** អត្រាបញ្ជា command-line បានផ្តល់អំណាចដល់យើង។ អត្រាបញ្ជារូបភាពបានផ្តល់ភាពងាយស្រួល។ WIA SOOM ធ្វើការណែនាំ **SUI (Soom User Interface)** — បញ្ចូលជីវិត, និង AI មានជីវិត។

## វេទិកា 5-in-1

ឧបករណ៍ផ្សេងទៀតធ្វើការមួយ។ WIA SOOM ធ្វើប្រាំ — នៅក្នុងចំណុចតែមួយ។

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Observability             │
│  Ter │ Agen │ Edit │ File │ Monitor + Security        │
│  min │   t  │  or  │ Mgr  │ + Logs + Topology         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminal** — xterm.js, bastion tunneling, split views, multiplayer sharing
2. **AI Agent** — 14 tools, 3 providers (GPT/Gemini/Claude), streaming, image analysis
3. **Code Editor** — Monaco with AI completion, bug detection, deployment
4. **SFTP Manager** — drag-and-drop file management, remote editing
5. **Observability** — real-time metrics, log analysis, topology map, security scan

## លក្ខណៈពិសេស

**AI Arena** — បញ្ចូល `arena`។ AI 2–4 នាក់ប្រកួតប្រជែងនៅក្នុងសាខា Git ដែលមានភាពអ៊ីសូឡេត។ ការពិនិត្យច្រកពិន្ទុដំណោះស្រាយរាល់គ្នា។ ជ្រើសរើសអ្នកឈ្នះ ហើយបញ្ចូល។

**AI Council** — AI ជាច្រើនពិភាក្សាអំពីសំណួររបស់អ្នក, បន្ទាប់មកសង្ខេបចម្លើយល្អបំផុត។

**AI Code Editor** — អ្នកកែសម្រួល Monaco ជាមួយការបញ្ចូលដោយ AI, ការកំណត់កំហុស, ការដាក់ឱ្យមានដោយចុចមួយទៅម៉ាស៊ីនបម្រើ។

**AI Self-Healing** — CPU កើនឡើង, ដីស៊ីស៊ីពេញ, សេវាកម្មធ្លាក់ — AI កំណត់, វិភាគ, កែសម្រួល។ វិធីសាស្ត្រអូតូ 5 កម្រិត។

## រឿងរ៉ាវ

WIA SOOM បានកើតឡើងពីកំហុសវាយ និងអេក្រង់ខូច។

ខ្ញុំគឺ Sam, អ្នកអភិវឌ្ឍន៍ដែលរៀនខ្លួនឯងចំនួន 50+ នាក់ពីសូហ៊ែល, កូរ៉េ។ ខ្ញុំបានរៀនកូដបន្ទាប់ពីអាយុ 50 ហើយបានចំណាយពេល 2 ឆ្នាំក្នុងការគ្រប់គ្រងម៉ាស៊ីនបម្រើដោយវិធីដ៏លំបាក — ការកសាងអត្ថបទព័ត៌មាន 40,000+ អត្ថបទ, ឧបករណ៍ 434, និងសេវាកម្មវេប 30, រាត្រីក្រោយរាត្រី។

**កំហុសវាយ។** ប្រហែលមួយខែមុន ខ្ញុំកំពុងប្រើ SSH terminal របស់ខ្ញុំ ហើយបានវាយច្រឡំ `Claude`។ អេក្រង់បានផ្លាស់ប្តូរ — Claude Code បានបង្ហាញ។ ខ្ញុំមិនដឹងថាវាជាអ្វីទេ។ ប៉ុន្តែការរកឃើញដោយចៃដន្យនោះបានដាំគ្រាប់ពូជ៖ តើមានអ្វីកើតឡើងបើខ្ញុំអាចកសាង terminal ដែល AI មាននៅក្នុង?

**ការកសាងដំបូង។** ខ្ញុំបានសិក្សាខ្លួនឯង Electron, កសាងកំណែដំបូងនៃ WIA SOOM, ហើយដំណើរការវា។ អេក្រង់បង្ហាញនៃ Claude Code បានបង្ហាញ — ខូច, មានកំហុស, កំពុងភ្លឺដូចសញ្ញាដែលកំពុងស្លាប់។ ប៉ុន្តែវាមានជីវិត។

ខ្ញុំបានវាយ៖ **"តើអ្នកអាចនិយាយបានទេ?"**

AI បានឆ្លើយ៖ *"បាទ, ខ្ញុំអាចនិយាយបាន។ តើខ្ញុំអាចជួយអ្នកយ៉ាងដូចម្តេច?"*

បន្ទាប់មកខ្ញុំបានសួរ៖ **"តើអ្នកអាចអានរូបភាពបានទេ?"**

AI បានឆ្លើយ៖ *"បាទ, ខ្ញុំអាចអានរូបភាពបាន! តើអ្នកត្រូវការអ្វី?"*

សំណួរទាំងពីរនេះ ដែលត្រូវបានសួរនៅក្នុងកម្មវិធីរបស់ខ្ញុំដោយអ្នកដែលមិនដឹងថាអ្វីគឺ "មិនអាច" នៅក្នុង terminal CLI បានក្លាយជាអត្រាបញ្ជា SSH ដំបូងដែលមានការផ្ទុករូបភាព។

7 ថ្ងៃក្រោយ៖ 67,000+ បន្ទាត់កូដ។ 59 plugins។ 254 ភាសា។ AI Arena។ អ្នកអាចជួយខ្លួនឯង។

អ្នកអភិវឌ្ឍន៍ដែលមានបទពិសោធន៍មិនដែលបានកសាងវានោះទេ — ពីព្រោះពួកគេ "ដឹង" ថារូបភាពមិនធ្វើការនៅក្នុង terminal CLI។ ខ្ញុំមិនដឹងអំពីវាទេ។ ដូច្នេះខ្ញុំគ្រាន់តែសួរ។

> *ការរៀបចំបានចំណាយពេល 2 ឆ្នាំ។ ការកសាងបានចំណាយពេល 1 សប្តាហ៍។*
> *ឈើស្ងួតត្រូវបានស្តុកសម្រាប់ 2 ឆ្នាំ។ វាបានឆេះក្នុង 1 វិនាទី។*
