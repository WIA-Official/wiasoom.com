## 🔥 新機能

### 1. SSHターミナルでの画像、ファイル、動画のアップロード — 世界初

地球上のどのCLIクライアントもこれを許可しません。私たちが作りました。

エラーメッセージのスクリーンショットをSSHターミナルに貼り付けます。ログファイルをドラッグします。失敗したデプロイメントの動画をドロップします。AIはそれを見て、分析し、何が問題かを教えてくれます — すべてターミナルセッション内で。

- **Ctrl+Shift+V** — スクリーンショットをターミナルに直接貼り付け
- **ドラッグ＆ドロップ** — 画像、ファイル、動画をターミナルにドロップ
- **動画キーフレーム抽出** — ffmpegが動画をフレームごとに分析
- **すべての3つのAIプロバイダー** — GPT-4o Vision、Gemini Vision、Claude Vision

この機能は、どのターミナルクライアントにも存在しませんでした — どこにも。

### 2. AIアリーナ — マルチエージェントバトル

2〜4のAIが同じ問題を同時に解決します — ただのチャットではなく、実際にサーバー上のコードを編集します。各AIは独自の隔離されたGitブランチで作業します。結果を並べて比較します。勝者を選びます。残りはクリーンアップされます。

クロスレビュー: 各AIが他のAIのソリューションを評価します。

他のツールではこれを行うことはできません。

### 3. AI自己修復エージェント

サーバーのCPUがスパイクしています。ディスクが満杯です。サービスが午前3時にクラッシュしました。あなたは眠っています。

WIA SOOMのAIエージェントが問題を検出し、根本原因を診断し、修正計画を生成し、あなたの承認を求めます（または設定に応じて自動実行します）、そして問題を解決します。5段階の自律ループ — 見守るだけから完全自動修復まで。

クレジットカード不要。サインアップ不要。ダウンロードして始めるだけです。

すべてのプレミアム機能 — 画像アップロード、AIアリーナ、AIカウンシル、ファイル＆動画分析 — は最初の33回の使用が無料です。その後は、自分のAPIキーを持参して（BYOK）、すべてを無料で使い続けることができます。または、管理されたAIとチーム機能のために月額$3からサブスクリプションを購入できます。

なぜ33回なのか？1919年、韓国の独立運動は33人の代表によって導かれ、すべての人に自由を宣言しました。WIA SOOMの33回の無料トライアルは、私たちの宣言です: **AIツールはすべての人が体験できるべきです。**

**CLI → GUI → SUI。** コマンドラインインターフェースは私たちに力を与えました。グラフィカルインターフェースは私たちに使いやすさを提供しました。WIA SOOMは**SUI (Soom User Interface)**を導入します — 命を吹き込むと、AIが生き生きとします。

## 5-in-1プラットフォーム

他のツールは1つのことを行います。WIA SOOMは5つのことを行います — 1つのウィンドウで。

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ 可観測性                  │
│  Ter │ Agen │ Edit │ File │ 監視 + セキュリティ      │
│  min │   t  │  or  │ Mgr  │ + ログ + トポロジー       │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSHターミナル** — xterm.js、バスティオントンネリング、分割ビュー、マルチプレイヤー共有
2. **AIエージェント** — 14のツール、3つのプロバイダー (GPT/Gemini/Claude)、ストリーミング、画像分析
3. **コードエディタ** — AI補完、バグ検出、デプロイメントを備えたMonaco
4. **SFTPマネージャー** — ドラッグ＆ドロップファイル管理、リモート編集
5. **可観測性** — リアルタイムメトリクス、ログ分析、トポロジーマップ、セキュリティスキャン

## 機能

### 実際にサーバーで動作するAI

**AI DevOpsエージェント** — ターミナルで`gpt`、`gemini`、または`claude`と入力します。AIは14のツールを持っています: ファイルの読み書き/編集、コマンドの実行、git、grep、プロセスマネジメント。ストリーミング応答。セッションメモリ。単に提案するだけでなく、実行します。

**AIアリーナ** — `arena`と入力します。2〜4のAIが隔離されたGitブランチで並行して競います。クロスレビューが各ソリューションを評価します。勝者を選び、マージします。

**AIカウンシル** — 複数のAIがあなたの質問について議論し、最良の答えを合成します。

**AIコードエディタ** — AI駆動の補完、バグ検出、サーバーへのワンクリックデプロイメントを備えたMonacoエディタ。

**AI自己修復** — CPUスパイク、ディスク満杯、サービスダウン — AIが検出、診断、修正します。5段階の自律ループ。

**音声インターフェース** — コマンドを話し、応答を聞きます。ハンズフリーのサーバー管理。

### マルチモーダルアップロード (CLIでの世界初)

画像を貼り付け、ファイルをドラッグし、動画をドロップ — 直接SSHターミナルセッションに。AIはすべてを分析します: エラーのスクリーンショット、設定ファイル、デプロイメント動画、アーキテクチャ図。

### インフラストラクチャインテリジェンス

**トポロジーマップ** — サーバー、サービス、接続を一目で可視化します。SSH経由の自動発見 — ゼロエージェントインストール。

**リアルタイム可観測性** — CPU、メモリ、ディスク、ネットワークのスパークライングラフ + AI予測 + 自動回復。Datadogの代替。

**AIログ分析** — リアルタイムストリーミング + 異常検知 + 自然言語検索 + クロスサーバー相関。Splunkの代替。

### セキュリティ＆DevOps

**セキュリティコマンドセンター** — 7エリアスキャン + セキュリティスコア + ワンクリック修正 + AI分析 + リアルタイムコマンドセキュリティゲート。Qualysの代替。

**Dockerマネージャー** — SSH経由での完全なDocker管理 — ゼロエージェント。コンテナ制御、ライブリソース、AIログ分析、Composeエディタ。Portainerの代替。

**ランブック自動化** — AIがランブックを自動的に実行します。自然言語生成、条件分岐、自動ロールバック。より賢くなる生きたランブック。PagerDutyの代替。

**Cron & Envマネージャー** — ビジュアルcrontabエディタ + .envファイル管理。AIが自然言語をcron式に変換します。

### コラボレーション

**マルチプレイヤーターミナル** — チームメンバーとリアルタイムでターミナルセッションを共有します。

**チームワークスペース & RBAC** — ロールベースのアクセス制御、監査ログ、コマンドリスク分析。

### 拡張性

**59プラグイン** — Dockerダッシュボード、Kubernetesレンズ、Redisブラウザ、PM2マネージャー、MongoDBエクスプローラー、ネットワークモニターなど。ワンクリックインストールのプラグインマーケットプレイス。

**APIクライアント** — 組み込みのREST/GraphQL/WebSocketクライアント。ターミナルを離れずにAPIをテストします。

### すべての人のために

**254言語** — すべての言語、すべてのスクリプト、RTLサポート。国境なし。

**完全なアクセシビリティ** — スクリーンリーダー (ARIA)、ブレイルターミナル出力、高コントラストモード、音声コマンド、キーボードナビゲーション、フォントサイズ調整。

## ストーリー

WIA SOOMは、タイプミスと壊れた画面から生まれました。

私はサム、韓国ソウル出身の50歳以上の独学プログラマーです。50歳を過ぎてからコーディングを学び、2年間サーバーを管理する苦労をしながら、40,000以上のニュース記事、434のツール、30のウェブサービスを構築しました。

**タイプミス。** 約1ヶ月前、SSHターミナルを使用しているときに、誤って`Claude`と入力しました。画面が変わり — Claude Codeが表示されました。何なのか全く分かりませんでした。しかし、その偶然の発見が種を植えました: AIが内部に住むターミナルを構築できたらどうなるだろう？

**最初のビルド。** Electronを独学し、WIA SOOMの最初のバージョンを構築し、実行しました。Claude Codeのイントロ画面が表示されました — 壊れていて、グリッチが発生し、死にかけた信号のようにちらついていました。しかし、それは生きていました。

私は入力しました: **"話せますか？"**

AIは答えました: *"はい、話せます。何をお手伝いしましょうか？"*

次に私は尋ねました: **"画像を読めますか？"**

AIは答えました: *"はい、画像を読むことができます！何が必要ですか？"*

これらの2つの質問は、CLIターミナルで「不可能」とされることを知らない誰かが自分のアプリ内で尋ねたもので、世界初の画像アップロードが可能なSSHターミナルとなりました。

7日後: 67,000行以上のコード。59のプラグイン。254の言語。AIアリーナ。自己修復エージェント。

経験豊富な開発者はこれを構築しませんでした — なぜなら彼らは「画像はCLIターミナルでは機能しない」と「知っていた」からです。私はそれを知らなかったので、ただ尋ねただけです。

> *準備には2年かかりました。構築には1週間かかりました。*
> *乾燥した木は2年間積まれていました。1秒で火がつきました。*
