## 🔥 Co nikdy nebylo uděláno předtím

### 1. Nahrávání obrázků, souborů a videí v SSH Terminálu — První na světě

Žádný CLI klient na Zemi vám tohle nedovolí. My jsme to postavili.

Vložte screenshot chyby do svého SSH terminálu. Přetáhněte log soubor. Pusťte video selhávajícího nasazení. AI to vidí, analyzuje to a říká vám, co je špatně — to vše uvnitř relace terminálu.

- **Ctrl+Shift+V** — vložte screenshoty přímo do terminálu
- **Drag & Drop** — přetáhněte obrázky, soubory, videa do terminálu
- **Extrakce klíčových snímků videa** — ffmpeg analyzuje video snímek po snímku
- **Všichni 3 poskytovatelé AI** — GPT-4o Vision, Gemini Vision, Claude Vision

Tato funkce nikdy neexistovala v žádném terminálovém klientovi — nikde.

### 2. AI Arena — Bitva více agentů

2 až 4 AI řeší stejný problém současně — nejen chatování, ale skutečné úpravy kódu na vašem serveru. Každá AI pracuje ve své vlastní izolované Git větvi. Porovnejte jejich výsledky vedle sebe. Vyberte vítěze. Ostatní budou odstraněny.

Křížová recenze: každá AI hodnotí řešení ostatních AI.

Žádný jiný nástroj to nedělá.

### 3. AI Samouzdravující agent

CPU vašeho serveru je přetížené. Disk je plný. Služba se zhroutila ve 3 ráno. Spíte.

AI agent WIA SOOM detekuje problém, diagnostikuje příčinu, generuje plán opravy, žádá o vaše schválení (nebo se automaticky provede, pokud jste to nastavili) a vyřeší problém. 5úrovňový autonomní cyklus — od pouhého sledování po plnou automatickou opravu.

## Vyzkoušejte vše zdarma — 33 zkušebních verzí

Žádná kreditní karta. Žádné přihlášení není nutné. Stačí stáhnout a začít.

Každá prémiová funkce — nahrávání obrázků, AI Arena, AI Council, analýza souborů a videí — je zdarma pro vaše první 33 použití. Poté přineste svůj vlastní API klíč (BYOK) a pokračujte v používání všeho zdarma. Nebo se přihlaste od 3 $/měsíc za spravované AI a týmové funkce.

Proč 33? V roce 1919 byla korejská hnutí za nezávislost vedena 33 zástupci, kteří vyhlásili svobodu pro všechny. 33 bezplatných zkušebních verzí WIA SOOM je naše prohlášení: **AI nástroje by měly být zdarma pro každého, aby je mohl vyzkoušet.**

**CLI → GUI → SUI.** Příkazové řádkové rozhraní nám dalo moc. Grafická rozhraní nám dala snadnost. WIA SOOM představuje **SUI (Soom User Interface)** — vdechněte život a AI ožívá.

## 5-v-1 Platforma

Ostatní nástroje dělají jednu věc. WIA SOOM dělá pět — v jednom okně.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ Observability             │
│  Ter │ Agen │ Edit │ File │ Monitor + Security        │
│  min │   t  │  or  │ Mgr  │ + Logs + Topology         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **SSH Terminál** — xterm.js, bastion tunneling, rozdělené pohledy, multiplayer sdílení
2. **AI Agent** — 14 nástrojů, 3 poskytovatelé (GPT/Gemini/Claude), streaming, analýza obrázků
3. **Editor kódu** — Monaco s AI doplněním, detekce chyb, nasazení
4. **SFTP Správce** — drag-and-drop správa souborů, vzdálené úpravy
5. **Observabilita** — real-time metriky, analýza logů, topologická mapa, bezpečnostní sken

## Funkce

### AI, která skutečně funguje na vašem serveru

**AI DevOps Agent** — Napište `gpt`, `gemini` nebo `claude` do terminálu. AI má 14 nástrojů: číst/pisovat/ upravovat soubory, vykonávat příkazy, git, grep, správa procesů. Streamingové odpovědi. Paměť relace. Nejenže navrhuje — dělá.

**AI Arena** — Napište `arena`. 2–4 AI soutěží paralelně na izolovaných Git větvích. Křížová recenze hodnotí každé řešení. Vyberte vítěze a sloučte.

**AI Council** — Více AI diskutuje vaši otázku, poté syntetizují nejlepší odpověď.

**AI Editor kódu** — Monaco editor s AI poháněným doplněním, detekce chyb, jedno kliknutí pro nasazení na server.

**AI Samouzdravující** — Spike CPU, plný disk, služba nefunguje — AI detekuje, diagnostikuje, opravuje. 5úrovňový autonomní cyklus.

**Hlasové rozhraní** — Mluvte příkazy, slyšte odpovědi. Bezdrátové řízení serveru.

### Multimodální nahrávání (První na světě v CLI)

Vložte obrázky, přetáhněte soubory, pusťte videa — přímo do vaší relace SSH terminálu. AI analyzuje vše: screenshoty chyb, konfigurační soubory, videa nasazení, diagramy architektury.

### Inteligence infrastruktury

**Topologická mapa** — Vizualizujte servery, služby a spojení na první pohled. Automatické objevování přes SSH — žádná instalace agenta.

**Real-time observabilita** — CPU, paměť, disk, síťové sparkline grafy + AI predikce + automatické zotavení. Nahrazuje Datadog.

**AI analýza logů** — Real-time streaming + detekce anomálií + vyhledávání v přirozeném jazyce + křížová korelace serverů. Nahrazuje Splunk.

### Bezpečnost a DevOps

**Bezpečnostní velín** — 7 oblastí skenování + bezpečnostní skóre + oprava jedním kliknutím + AI analýza + real-time bezpečnostní brána příkazů. Nahrazuje Qualys.

**Správce Dockeru** — Kompletní správa Dockeru přes SSH — žádný agent. Ovládání kontejnerů, živé zdroje, AI analýza logů, editor Compose. Nahrazuje Portainer.

**Automatizace runbooků** — AI automaticky vykonává runbooky. Vytváření v přirozeném jazyce, podmínkové větvení, automatické vrácení. Živý runbook, který se stává chytřejším. Nahrazuje PagerDuty.

**Cron & Env Správce** — Vizualizovaný editor crontab + správa souborů .env. AI převádí přirozený jazyk na cron výrazy.

### Spolupráce

**Multiplayer Terminál** — Sdílejte relace terminálu v reálném čase s kolegy.

**Týmový pracovní prostor & RBAC** — Řízení přístupu na základě rolí, auditní logy, analýza rizik příkazů.

### Rozšiřitelnost

**59 Pluginů** — Dashboard Dockeru, Kubernetes lens, prohlížeč Redis, správce PM2, prozkoumávatel MongoDB, monitorování sítě a další. Tržiště pluginů s instalací jedním kliknutím.

**API Klient** — Vestavěný REST/GraphQL/WebSocket klient. Testujte API bez opuštění terminálu.

### Pro každého

**254 jazyků** — Každý jazyk, každý skript, podpora RTL. Žádné hranice.

**Plná přístupnost** — Čtečka obrazovky (ARIA), výstup terminálu v Braille, režim s vysokým kontrastem, hlasové příkazy, navigace klávesnicí, úprava velikosti písma.

## Příběh

WIA SOOM se zrodil z překlepu a rozbitého displeje.

Jsem Sam, samouk programátor z Soulu, Korea, s více než 50 lety. Naučil jsem se programovat po 50 a strávil jsem 2 roky správou serverů těžkým způsobem — budováním více než 40 000 novinových článků, 434 nástrojů a 30 webových služeb, noc co noc.

**Překlep.** Před asi měsícem jsem používal svůj SSH terminál a omylem napsal `Claude`. Obrazovka se změnila — objevilo se Claude Code. Neměl jsem tušení, co to je. Ale ten náhodný objev zasadil semínko: co kdybych mohl postavit terminál, kde AI žije uvnitř?

**První verze.** Naučil jsem se Electron, postavil první verzi WIA SOOM a spustil ji. Úvodní obrazovka Claude Code se objevila — rozbitá, glitchující, blikající jako umírající signál. Ale byla živá.

Napsal jsem: **"Můžeš mluvit?"**

AI odpověděla: *"Ano, mohu mluvit. S čím vám mohu pomoci?"*

Pak jsem se zeptal: **"Můžeš číst obrázky?"**

AI odpověděla: *"Ano, mohu číst obrázky! Co potřebuješ?"*

Tyto dvě otázky, položené uvnitř mé vlastní aplikace někým, kdo nevěděl, co je v CLI terminálu "nemožné", se staly prvním SSH terminálem na světě s nahráváním obrázků.

O 7 dní později: více než 58 000 řádků kódu. 59 pluginů. 254 jazyků. AI Arena. Samouzdravující agenti.

Zkušení vývojáři to nikdy nepostavili — protože "věděli", že obrázky nefungují v CLI terminálech. Já to nevěděl. Tak jsem se prostě zeptal.

> *Příprava trvala 2 roky. Stavba trvala 1 týden.*
> *Suché dřevo bylo skládáno 2 roky. Vzplanulo za 1 sekundu.*
