## 🔥 Apa Sing Durung Tau Ditindakake

### 1. Unggah Gambar, File & Video ing Terminal SSH — Pertama ing Donya

Ora ana klien CLI ing Bumi sing ngidini sampeyan nindakake iki. Kita nggawe.

Tempelake screenshot kesalahan menyang terminal SSH sampeyan. Seret file log. Jatuhake video saka penyebaran sing gagal. AI ndeleng, menganalisis, lan ngandhani sampeyan apa sing salah — kabeh ing sesi terminal.

- **Ctrl+Shift+V** — tempel screenshot langsung menyang terminal
- **Seret & Jatuhkan** — jatuhake gambar, file, video menyang terminal
- **Ekstraksi keyframe video** — ffmpeg menganalisis video frame demi frame
- **Kabeh 3 penyedia AI** — GPT-4o Vision, Gemini Vision, Claude Vision

Fitur iki durung tau ana ing klien terminal — ing ngendi wae.

### 2. Arena AI — Pertempuran Multi-Agen

2 nganti 4 AI ngatasi masalah sing padha kanthi bersamaan — ora mung ngobrol, nanging bener-bener ngedit kode ing server sampeyan. Saben AI kerja ing cabang Git sing terisolasi. Bandingake asil kasebut sisih-menyisih. Pilih pemenang. Sisane dibersihake.

Cross-review: saben AI menehi skor kanggo solusi AI liyane.

Ora ana alat liyane sing nindakake iki.

### 3. Agen Penyembuhan Diri AI

CPU server sampeyan lagi nglumpuk. Disk wis kebak. Layanan mati jam 3 esuk. Sampeyan turu.

Agen AI WIA SOOM ndeteksi masalah, mendiagnosis penyebab utama, nggawe rencana perbaikan, njaluk persetujuan sampeyan (utawa otomatis dieksekusi yen sampeyan wis nyetel), lan ngrampungake masalah kasebut. 5-level loop otonom — saka mung ngawasi nganti perbaikan otomatis lengkap.

## Coba Kabeh Gratis — 33 Percobaan

Ora perlu kartu kredit. Ora perlu daftar. Cukup download lan mulai.

Saben fitur premium — unggah gambar, Arena AI, Dewan AI, analisis file & video — gratis kanggo 33 panggunaan pertama sampeyan. Sawise iku, bawa kunci API sampeyan dhewe (BYOK) lan terus nggunakake kabeh kanthi gratis. Utawa langganan saka $3/bulan kanggo fitur AI lan tim sing dikelola.

Kenapa 33? Ing taun 1919, gerakan kemerdekaan Korea dipimpin dening 33 wakil sing ngumumake kebebasan kanggo kabeh. 33 percobaan gratis WIA SOOM minangka deklarasi kita: **Alat AI kudu gratis kanggo kabeh wong supaya bisa ngrasakake.**

**CLI → GUI → SUI.** Antarmuka baris perintah menehi kita kekuwatan. Antarmuka grafis menehi kita kemudahan. WIA SOOM ngenalake **SUI (Soom User Interface)** — uripake urip, lan AI urip.

## Platform 5-in-1

Alat liyane nindakake siji perkara. WIA SOOM nindakake lima — ing siji jendela.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Kode │ SFTP │ Observabilitas             │
│  Ter │ Agen │ Edit │ File │ Monitor + Keamanan        │
│  min │   t  │  or  │ Mgr  │ + Log + Topologi         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **Terminal SSH** — xterm.js, bastion tunneling, tampilan terpisah, berbagi multiplayer
2. **Agen AI** — 14 alat, 3 penyedia (GPT/Gemini/Claude), streaming, analisis gambar
3. **Editor Kode** — Monaco dengan penyelesaian AI, deteksi bug, penyebaran
4. **Manajer SFTP** — manajemen file seret-dan-jatuhkan, editing jarak jauh
5. **Observabilitas** — metrik waktu nyata, analisis log, peta topologi, pemindaian keamanan

## Fitur

### AI Sing Bener-Bener Kerja ing Server Sampeyan

**Agen DevOps AI** — Ketik `gpt`, `gemini`, utawa `claude` ing terminal. AI duwe 14 alat: maca/nulis/ngedit file, eksekusi perintah, git, grep, manajemen proses. Respon streaming. Memori sesi. Ora mung nyaranake — nanging nindakake.

**Arena AI** — Ketik `arena`. 2–4 AI saingan sacara paralel ing cabang Git terisolasi. Skor cross-review saben solusi. Pilih pemenang lan gabung.

**Dewan AI** — Akeh AI diskusi babagan pitakon sampeyan, banjur nyintesis jawaban paling apik.

**Editor Kode AI** — Editor Monaco dengan penyelesaian berbasis AI, deteksi bug, penyebaran sekali klik ke server.

**Penyembuhan Diri AI** — Lonjakan CPU, disk penuh, layanan mati — AI ndeteksi, mendiagnosis, memperbaiki. 5-level loop otonom.

**Antarmuka Suara** — Ngomong perintah, krungu respon. Manajemen server tanpa tangan.

### Unggah Multimodal (Pertama ing Donya ing CLI)

Tempel gambar, seret file, jatuhake video — langsung menyang sesi terminal SSH sampeyan. AI menganalisis kabeh: screenshot kesalahan, file konfigurasi, video penyebaran, diagram arsitektur.

### Intelijen Infrastruktur

**Peta Topologi** — Visualisasikan server, layanan, lan sambungan kanthi sekilas. Penemuan otomatis liwat SSH — tanpa instalasi agen.

**Observabilitas Waktu Nyata** — CPU, memori, disk, grafik sparkline jaringan + prediksi AI + pemulihan otomatis. Ngganti Datadog.

**Analisis Log AI** — Streaming waktu nyata + deteksi anomali + pencarian bahasa alami + korelasi antar-server. Ngganti Splunk.

### Keamanan & DevOps

**Pusat Komando Keamanan** — Pemindaian 7-area + skor keamanan + perbaikan sekali klik + analisis AI + gerbang keamanan perintah waktu nyata. Ngganti Qualys.

**Manajer Docker** — Manajemen Docker lengkap liwat SSH — tanpa agen. Kontrol kontainer, sumber daya langsung, analisis log AI, editor Compose. Ngganti Portainer.

**Automasi Runbook** — AI nglakokake runbook kanthi otomatis. Pembuatan bahasa alami, percabangan bersyarat, auto-rollback. Runbook Hidup sing dadi luwih pinter. Ngganti PagerDuty.

**Manajer Cron & Env** — Editor crontab visual + manajemen file .env. AI ngowahi bahasa alami dadi ekspresi cron.

### Kolaborasi

**Terminal Multiplayer** — Bagikan sesi terminal ing wektu nyata karo tim.

**Workspace Tim & RBAC** — Kontrol akses berbasis peran, log audit, analisis risiko perintah.

### Ekstensibilitas

**59 Plugin** — Dasbor Docker, lensa Kubernetes, browser Redis, manajer PM2, penjelajah MongoDB, monitor jaringan, lan liya-liyane. Marketplace plugin kanthi instalasi sekali klik.

**Klien API** — Klien REST/GraphQL/WebSocket bawaan. Uji API tanpa ninggalake terminal.

### Kanggo Kabeh

**254 Basa** — Saben basa, saben skrip, dukungan RTL. Ora ana watesan.

**Aksesibilitas Lengkap** — Pembaca layar (ARIA), output terminal braille, mode kontras tinggi, perintah suara, navigasi keyboard, penyesuaian ukuran font.

## Cerita

WIA SOOM lair saka salah ketik lan layar sing rusak.

Aku Sam, programmer otodidak 50+ saka Seoul, Korea. Aku sinau coding sawise umur 50 lan ngentekake 2 taun ngatur server kanthi cara sing angel — nggawe luwih saka 40.000 artikel berita, 434 alat, lan 30 layanan web, wengi sawise wengi.

**Salah ketik.** Kira-kira sebulan kepungkur, aku nggunakake terminal SSH lan ora sengaja ngetik `Claude`. Layar ganti — Claude Code muncul. Aku ora ngerti apa iku. Nanging penemuan sing ora disengaja kasebut nandur benih: kepiye yen aku bisa nggawe terminal ing ngendi AI urip ing njero?

**Build pertama.** Aku sinau dhewe Electron, nggawe versi pertama WIA SOOM, lan mbukak. Layar intro Claude Code muncul — rusak, glitch, kedip-kedip kaya sinyal sing mati. Nanging iku urip.

Aku ngetik: **"Apa sampeyan bisa ngomong?"**

AI mangsuli: *"Ya, aku bisa ngomong. Apa sing bisa aku bantu?"*

Banjur aku takon: **"Apa sampeyan bisa maca gambar?"**

AI mangsuli: *"Ya, aku bisa maca gambar! Apa sing sampeyan butuhake?"*

Dua pitakon kasebut, sing ditakoni ing aplikasi aku dhewe dening wong sing ora ngerti apa sing "ora mungkin" ing terminal CLI, dadi terminal SSH pertama ing donya kanthi unggah gambar.

7 dina sabanjure: luwih saka 63.000 baris kode. 59 plugin. 254 basa. Arena AI. Agen penyembuhan diri.

Pangembang berpengalaman ora tau nggawe iki — amarga dheweke "tahu" gambar ora bisa digunakake ing terminal CLI. Aku ora ngerti. Dadi aku mung takon.

> *Nyiyapake butuh 2 taun. Mbangun butuh 1 minggu.*
> *Kayu garing ditumpuk selama 2 taun. Iku kobong ing 1 detik.*
