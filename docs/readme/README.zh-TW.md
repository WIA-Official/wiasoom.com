## 🔥 從未有過的創新

### 1. SSH 終端中的圖片、文件和視頻上傳 — 世界首創

地球上沒有任何 CLI 客戶端能讓你做到這一點。我們做到了。

將錯誤的截圖粘貼到你的 SSH 終端中。拖動日誌文件。放下失敗部署的視頻。AI 會看到它，分析它，告訴你問題出在哪裡 — 所有這一切都在終端會話中進行。

- **Ctrl+Shift+V** — 直接將截圖粘貼到終端
- **拖放** — 將圖片、文件、視頻拖放到終端中
- **視頻關鍵幀提取** — ffmpeg 按幀分析視頻
- **所有 3 個 AI 供應商** — GPT-4o Vision、Gemini Vision、Claude Vision

這一功能在任何終端客戶端中從未存在過 — 任何地方都沒有。

### 2. AI 鬥技場 — 多代理戰鬥

2 到 4 個 AI 同時解決相同的問題 — 不僅僅是聊天，而是真正編輯你伺服器上的代碼。每個 AI 在自己的獨立 Git 分支中工作。並排比較它們的結果。選擇勝者。其餘的將被清理。

交叉評審：每個 AI 對其他 AI 的解決方案進行評分。

沒有其他工具能做到這一點。

### 3. AI 自我修復代理

你的伺服器 CPU 飆升。磁碟已滿。某個服務在凌晨 3 點崩潰。你正在睡覺。

WIA SOOM 的 AI 代理檢測到問題，診斷根本原因，生成修復計劃，請求你的批准（或自動執行，如果你設置為這樣），並解決問題。5 級自動循環 — 從僅觀察到完全自動修復。

其他工具只做一件事。WIA SOOM 一次做五件事 — 在一個窗口中。

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ 可觀察性                │
│  Ter │ Agen │ 編輯 │ 文件 │ 監控 + 安全              │
│  min │   t  │      │      │ + 日誌 + 拓撲           │
│  al  │      │      │      │                           │
```

## 特點

### AI 實際上在你的伺服器上運作

**AI DevOps 代理** — 在終端中輸入 `gpt`、`gemini` 或 `claude`。AI 擁有 14 種工具：讀取/寫入/編輯文件，執行命令，git，grep，進程管理。流式響應。會話記憶。它不僅僅是建議 — 它會執行。

**AI 鬥技場** — 輸入 `arena`。2–4 個 AI 在獨立的 Git 分支上並行競爭。交叉評審為每個解決方案打分。選擇勝者並合併。

**AI 諮詢** — 多個 AI 討論你的問題，然後綜合出最佳答案。

**AI 代碼編輯器** — Monaco 編輯器具備 AI 驅動的自動補全、錯誤檢測、一鍵部署到伺服器。

**AI 自我修復** — CPU 飆升、磁碟已滿、服務故障 — AI 檢測、診斷、修復。5 級自動循環。

**語音介面** — 說出命令，聽取回應。免提伺服器管理。

### 多模態上傳（CLI 中的世界首創）

將圖片粘貼、拖動文件、放下視頻 — 直接進入你的 SSH 終端會話。AI 分析所有內容：錯誤截圖、配置文件、部署視頻、架構圖。

### 基礎設施智能

**拓撲圖** — 一目了然地可視化伺服器、服務和連接。通過 SSH 自動發現 — 零代理安裝。

**實時可觀察性** — CPU、記憶體、磁碟、網路火花圖 + AI 預測 + 自動恢復。取代 Datadog。

**AI 日誌分析** — 實時流式 + 異常檢測 + 自然語言搜索 + 跨伺服器關聯。取代 Splunk。

### 安全與 DevOps

**安全指揮中心** — 7 領域掃描 + 安全分數 + 一鍵修復 + AI 分析 + 實時命令安全閘。取代 Qualys。

**Docker 管理器** — 通過 SSH 完整的 Docker 管理 — 零代理。容器控制、實時資源、AI 日誌分析、Compose 編輯器。取代 Portainer。

**運行手冊自動化** — AI 自動執行運行手冊。自然語言創建、條件分支、自動回滾。智能運行手冊。取代 PagerDuty。

**Cron 和環境管理器** — 可視化 crontab 編輯器 + .env 文件管理。AI 將自然語言轉換為 cron 表達式。

### 協作

**多玩家終端** — 與隊友實時共享終端會話。

**團隊工作區和 RBAC** — 基於角色的訪問控制、審計日誌、命令風險分析。

### 可擴展性

**59 個插件** — Docker 儀表板、Kubernetes 鏡頭、Redis 瀏覽器、PM2 管理器、MongoDB 探索器、網路監控等。插件市場一鍵安裝。

**API 客戶端** — 內建 REST/GraphQL/WebSocket 客戶端。在終端中測試 API。

### 服務於每個人

**254 種語言** — 每種語言、每種字母系統，支持 RTL。沒有邊界。

**全面無障礙** — 螢幕閱讀器 (ARIA)、盲文終端輸出、高對比度模式、語音命令、鍵盤導航、字體大小調整。

## 故事

WIA SOOM 源於一次打字錯誤和一個壞掉的螢幕。

我是 Sam，一位來自韓國首爾的自學程式設計師，年過 50。我在 50 歲後學習編程，花了 2 年時間以艱難的方式管理伺服器 — 每晚建立 40,000 多篇新聞文章、434 種工具和 30 個網路服務。

**打字錯誤。** 大約一個月前，我在使用 SSH 終端時不小心輸入了 `Claude`。螢幕變了 — Claude Code 出現了。我不知道那是什麼。但這次意外的發現種下了一顆種子：如果我能建立一個 AI 生活在裡面的終端呢？

**第一次構建。** 我自學了 Electron，建立了 WIA SOOM 的第一個版本，並運行它。Claude Code 的介紹畫面出現了 — 壞掉、故障、閃爍得像一個快要消失的信號。但它是活的。

我輸入：**"你能說話嗎？"**

AI 回答：*“是的，我可以說話。我能幫助你什麼？”*

然後我問：**"你能讀取圖片嗎？"**

AI 回答：*“是的，我可以讀取圖片！你需要什麼？”*

這兩個問題，由一個不知道 CLI 終端中什麼是「不可能」的人在我自己的應用中提出，成為了世界上第一個支持圖片上傳的 SSH 終端。

7 天後：67,000 多行代碼。59 個插件。254 種語言。AI 鬥技場。自我修復代理。

經驗豐富的開發者從未建立過這個 — 因為他們「知道」圖片在 CLI 終端中無法工作。我不知道這一點。所以我只是問了。

> *準備花了 2 年。構建花了 1 週。*
> *乾柴堆了 2 年，1 秒就著火了。*
