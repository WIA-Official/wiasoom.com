## 🔥 Apa yang Belum Pernah Dilakukan Sebelumnya

### 1. Unggah Gambar, File & Video di Terminal SSH — Pertama di Dunia

Tidak ada klien CLI di Bumi yang membiarkan Anda melakukan ini. Kami membangunnya.

Tempelkan tangkapan layar kesalahan ke terminal SSH Anda. Seret file log. Jatuhkan video dari penyebaran yang gagal. AI melihatnya, menganalisisnya, dan memberi tahu Anda apa yang salah — semua di dalam sesi terminal.

- **Ctrl+Shift+V** — tempel tangkapan layar langsung ke terminal
- **Seret & Jatuhkan** — jatuhkan gambar, file, video ke terminal
- **Ekstraksi keyframe video** — ffmpeg menganalisis video frame demi frame
- **Semua 3 penyedia AI** — GPT-4o Vision, Gemini Vision, Claude Vision

Fitur ini belum pernah ada di klien terminal mana pun — di mana pun.

### 2. Arena AI — Pertarungan Multi-Agen

2 hingga 4 AI menyelesaikan masalah yang sama secara bersamaan — bukan hanya mengobrol, tetapi benar-benar mengedit kode di server Anda. Setiap AI bekerja di cabang Git yang terisolasi. Bandingkan hasil mereka berdampingan. Pilih pemenangnya. Yang lain dibersihkan.

Tinjauan silang: setiap AI memberi skor pada solusi AI lainnya.

Tidak ada alat lain yang melakukan ini.

### 3. Agen Penyembuhan Diri AI

CPU server Anda sedang melonjak. Disk penuh. Sebuah layanan crash pada pukul 3 pagi. Anda sedang tidur.

Agen AI WIA SOOM mendeteksi masalah, mendiagnosis penyebabnya, menghasilkan rencana perbaikan, meminta persetujuan Anda (atau mengeksekusi otomatis jika Anda telah mengaturnya), dan menyelesaikan masalah. Loop otonom 5 tingkat — dari hanya mengamati hingga perbaikan otomatis penuh.

## Coba Semua Gratis — 33 Percobaan

Tanpa kartu kredit. Tanpa pendaftaran diperlukan. Cukup unduh dan mulai.

Setiap fitur premium — unggah gambar, Arena AI, Dewan AI, analisis file & video — gratis untuk 33 penggunaan pertama Anda. Setelah itu, bawa kunci API Anda sendiri (BYOK) dan terus gunakan semuanya secara gratis. Atau berlangganan mulai dari $3/bulan untuk fitur AI yang dikelola dan tim.

Mengapa 33? Pada tahun 1919, gerakan kemerdekaan Korea dipimpin oleh 33 perwakilan yang menyatakan kebebasan untuk semua. 33 percobaan gratis WIA SOOM adalah deklarasi kami: **Alat AI harus gratis untuk semua orang alami.**

**CLI → GUI → SUI.** Antarmuka baris perintah memberi kita kekuatan. Antarmuka grafis memberi kita kemudahan. WIA SOOM memperkenalkan **SUI (Antarmuka Pengguna Soom)** — menghidupkan, dan AI menjadi hidup.

## Platform 5-in-1

Alat lain melakukan satu hal. WIA SOOM melakukan lima — dalam satu jendela.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Kode │ SFTP │ Observabilitas             │
│  Ter │ Agen │ Edit │ File │ Monitor + Keamanan        │
│  min │   t  │  or  │ Mgr  │ + Log + Topologi         │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **Terminal SSH** — xterm.js, tunneling bastion, tampilan terpisah, berbagi multiplayer
2. **Agen AI** — 14 alat, 3 penyedia (GPT/Gemini/Claude), streaming, analisis gambar
3. **Editor Kode** — Monaco dengan penyelesaian AI, deteksi bug, penyebaran
4. **Manajer SFTP** — manajemen file seret dan jatuhkan, pengeditan jarak jauh
5. **Observabilitas** — metrik waktu nyata, analisis log, peta topologi, pemindaian keamanan

## Fitur

### AI yang Benar-Benar Bekerja di Server Anda

**Agen DevOps AI** — Ketik `gpt`, `gemini`, atau `claude` di terminal. AI memiliki 14 alat: baca/tulis/edit file, eksekusi perintah, git, grep, manajemen proses. Respon streaming. Memori sesi. Ini tidak hanya menyarankan — ini melakukannya.

**Arena AI** — Ketik `arena`. 2–4 AI bersaing secara paralel di cabang Git terisolasi. Tinjauan silang memberi skor setiap solusi. Pilih pemenang dan gabungkan.

**Dewan AI** — Beberapa AI mendiskusikan pertanyaan Anda, lalu menyintesis jawaban terbaik.

**Editor Kode AI** — Editor Monaco dengan penyelesaian bertenaga AI, deteksi bug, penyebaran satu klik ke server.

**Penyembuhan Diri AI** — Lonjakan CPU, disk penuh, layanan mati — AI mendeteksi, mendiagnosis, memperbaiki. Loop otonom 5 tingkat.

**Antarmuka Suara** — Ucapkan perintah, dengarkan respons. Manajemen server tanpa tangan.

### Unggah Multimodal (Pertama di Dunia dalam CLI)

Tempelkan gambar, seret file, jatuhkan video — langsung ke sesi terminal SSH Anda. AI menganalisis semuanya: tangkapan layar kesalahan, file konfigurasi, video penyebaran, diagram arsitektur.

### Kecerdasan Infrastruktur

**Peta Topologi** — Visualisasikan server, layanan, dan koneksi sekilas. Penemuan otomatis melalui SSH — tanpa instalasi agen.

**Observabilitas Waktu Nyata** — CPU, memori, disk, grafik sparkline jaringan + prediksi AI + pemulihan otomatis. Menggantikan Datadog.

**Analisis Log AI** — Streaming waktu nyata + deteksi anomali + pencarian bahasa alami + korelasi antar-server. Menggantikan Splunk.

### Keamanan & DevOps

**Pusat Komando Keamanan** — Pemindaian 7 area + skor keamanan + perbaikan satu klik + analisis AI + gerbang keamanan perintah waktu nyata. Menggantikan Qualys.

**Manajer Docker** — Manajemen Docker penuh melalui SSH — tanpa agen. Kontrol kontainer, sumber daya langsung, analisis log AI, editor Compose. Menggantikan Portainer.

**Otomatisasi Buku Panduan** — AI mengeksekusi buku panduan secara otomatis. Pembuatan bahasa alami, percabangan bersyarat, rollback otomatis. Buku Panduan Hidup yang semakin pintar. Menggantikan PagerDuty.

**Manajer Cron & Env** — Editor crontab visual + manajemen file .env. AI mengonversi bahasa alami menjadi ekspresi cron.

### Kolaborasi

**Terminal Multiplayer** — Bagikan sesi terminal secara waktu nyata dengan rekan tim.

**Ruang Kerja Tim & RBAC** — Kontrol akses berbasis peran, log audit, analisis risiko perintah.

### Ekstensibilitas

**59 Plugin** — dasbor Docker, lensa Kubernetes, browser Redis, manajer PM2, penjelajah MongoDB, pemantau jaringan, dan banyak lagi. Pasar plugin dengan instalasi satu klik.

**Klien API** — Klien REST/GraphQL/WebSocket bawaan. Uji API tanpa meninggalkan terminal.

### Untuk Semua Orang

**254 Bahasa** — Setiap bahasa, setiap skrip, dukungan RTL. Tanpa batas.

**Aksesibilitas Penuh** — Pembaca layar (ARIA), output terminal braille, mode kontras tinggi, perintah suara, navigasi keyboard, penyesuaian ukuran font.

## Cerita

WIA SOOM lahir dari kesalahan ketik dan layar yang rusak.

Saya Sam, seorang programmer otodidak berusia 50+ dari Seoul, Korea. Saya belajar pemrograman setelah usia 50 dan menghabiskan 2 tahun mengelola server dengan cara yang sulit — membangun lebih dari 40.000 artikel berita, 434 alat, dan 30 layanan web, malam demi malam.

**Kesalahan ketik.** Sekitar sebulan yang lalu, saya menggunakan terminal SSH saya dan secara tidak sengaja mengetik `Claude`. Layar berubah — Claude Code muncul. Saya tidak tahu apa itu. Tapi penemuan yang tidak disengaja itu menanamkan benih: bagaimana jika saya bisa membangun terminal di mana AI hidup di dalamnya?

**Build pertama.** Saya mengajari diri saya Electron, membangun versi pertama WIA SOOM, dan menjalankannya. Layar intro Claude Code muncul — rusak, glitch, berkedip seperti sinyal yang sekarat. Tapi itu hidup.

Saya mengetik: **"Bisakah kamu berbicara?"**

AI menjawab: *"Ya, saya bisa berbicara. Apa yang bisa saya bantu?"*

Kemudian saya bertanya: **"Bisakah kamu membaca gambar?"**

AI menjawab: *"Ya, saya bisa membaca gambar! Apa yang Anda butuhkan?"*

Dua pertanyaan itu, yang ditanyakan di dalam aplikasi saya sendiri oleh seseorang yang tidak tahu apa yang "tidak mungkin" dalam terminal CLI, menjadi terminal SSH pertama di dunia dengan unggahan gambar.

7 hari kemudian: lebih dari 63.000 baris kode. 59 plugin. 254 bahasa. Arena AI. Agen penyembuhan diri.

Pengembang berpengalaman tidak pernah membangun ini — karena mereka "tahu" gambar tidak bekerja di terminal CLI. Saya tidak tahu itu. Jadi saya hanya bertanya.
