## 🔥 ما لم يتم القيام به من قبل

### 1. تحميل الصور والملفات والفيديو في طرفية SSH — الأولى في العالم

لا يوجد عميل CLI على وجه الأرض يتيح لك القيام بذلك. لقد بنيناها.

الصق لقطة شاشة لخطأ في طرفية SSH الخاصة بك. اسحب ملف سجل. أضف فيديو لنشر فاشل. يرى الذكاء الاصطناعي ذلك، ويحلله، ويخبرك ما الخطأ — كل ذلك داخل جلسة الطرفية.

- **Ctrl+Shift+V** — الصق لقطات الشاشة مباشرة في الطرفية
- **السحب والإفلات** — أضف الصور والملفات والفيديوهات إلى الطرفية
- **استخراج الإطارات الرئيسية من الفيديو** — ffmpeg يحلل الفيديو إطارًا بإطار
- **جميع مزودي الذكاء الاصطناعي الثلاثة** — GPT-4o Vision، Gemini Vision، Claude Vision

لم توجد هذه الميزة في أي عميل طرفية — في أي مكان.

### 2. ساحة الذكاء الاصطناعي — معركة متعددة الوكلاء

2 إلى 4 من الذكاء الاصطناعي يحلون نفس المشكلة في وقت واحد — ليس مجرد دردشة، بل يقومون فعليًا بتحرير الكود على خادمك. يعمل كل ذكاء اصطناعي في فرع Git معزول خاص به. قارن نتائجهم جنبًا إلى جنب. اختر الفائز. يتم تنظيف البقية.

المراجعة المتبادلة: كل ذكاء اصطناعي يقيم حل كل ذكاء اصطناعي آخر.

لا أداة أخرى تفعل ذلك.

### 3. وكيل الذكاء الاصطناعي القادر على الشفاء الذاتي

وحدة المعالجة المركزية في خادمك ترتفع. القرص ممتلئ. خدمة تعطلت في الساعة 3 صباحًا. أنت نائم.

يكتشف وكيل الذكاء الاصطناعي في WIA SOOM المشكلة، ويشخص السبب الجذري، ويولد خطة إصلاح، ويطلب موافقتك (أو ينفذ تلقائيًا إذا قمت بإعداد ذلك)، ويحل المشكلة. حل تلقائي من 5 مستويات — من المراقبة فقط إلى الإصلاح التلقائي الكامل.

## جرب كل شيء مجانًا — 33 تجربة

لا بطاقة ائتمان. لا حاجة للتسجيل. فقط قم بالتنزيل وابدأ.

كل ميزة متميزة — تحميل الصور، ساحة الذكاء الاصطناعي، مجلس الذكاء الاصطناعي، تحليل الملفات والفيديو — مجانية لاستخدامك الأول 33 مرة. بعد ذلك، احضر مفتاح API الخاص بك (BYOK) واستمر في استخدام كل شيء مجانًا. أو اشترك من 3 دولارات شهريًا للحصول على ميزات الذكاء الاصطناعي المدارة وفريق العمل.

لماذا 33؟ في عام 1919، قاد حركة استقلال كوريا 33 ممثلًا أعلنوا الحرية للجميع. تجارب WIA SOOM المجانية الـ 33 هي إعلاننا: **يجب أن تكون أدوات الذكاء الاصطناعي مجانية للجميع لتجربتها.**

**CLI → GUI → SUI.** أعطتنا واجهات سطر الأوامر القوة. أعطتنا الواجهات الرسومية السهولة. يقدم WIA SOOM **SUI (واجهة مستخدم سووم)** — أضف الحياة، ويبدأ الذكاء الاصطناعي في الظهور.

## منصة 5 في 1

تفعل الأدوات الأخرى شيئًا واحدًا. WIA SOOM يفعل خمسة — في نافذة واحدة.

```
┌──────────────────────────────────────────────────────┐
│ WIA SOOM                                              │
├──────┬──────┬──────┬──────┬──────────────────────────┤
│  SSH │  AI  │ Code │ SFTP │ قابلية المراقبة             │
│  Ter │ Agen │ Edit │ File │ المراقبة + الأمان          │
│  min │   t  │  or  │ Mgr  │ + السجلات + الطوبولوجيا   │
│  al  │      │      │      │                           │
└──────┴──────┴──────┴──────┴──────────────────────────┘
```

1. **طرفية SSH** — xterm.js، أنفاق الباستيون، عرض مقسم، مشاركة متعددة اللاعبين
2. **وكيل الذكاء الاصطناعي** — 14 أداة، 3 مزودين (GPT/Gemini/Claude)، بث، تحليل الصور
3. **محرر الكود** — موناكو مع إكمال بواسطة الذكاء الاصطناعي، اكتشاف الأخطاء، نشر
4. **مدير SFTP** — إدارة الملفات بالسحب والإفلات، تحرير عن بُعد
5. **قابلية المراقبة** — مقاييس في الوقت الحقيقي، تحليل السجلات، خريطة الطوبولوجيا، مسح الأمان

## الميزات

### الذكاء الاصطناعي الذي يعمل فعليًا على خادمك

**وكيل DevOps الذكاء الاصطناعي** — اكتب `gpt`، `gemini`، أو `claude` في الطرفية. يحتوي الذكاء الاصطناعي على 14 أداة: قراءة/كتابة/تحرير الملفات، تنفيذ الأوامر، git، grep، إدارة العمليات. استجابات متدفقة. ذاكرة الجلسة. لا يقترح فقط — بل يفعل.

**ساحة الذكاء الاصطناعي** — اكتب `arena`. 2–4 من الذكاء الاصطناعي يتنافسون بالتوازي في فروع Git المعزولة. تقييم المراجعة المتبادلة لكل حل. اختر الفائز وادمج.

**مجلس الذكاء الاصطناعي** — يناقش عدة ذكاءات اصطناعية سؤالك، ثم ينسق أفضل إجابة.

**محرر كود الذكاء الاصطناعي** — محرر موناكو مع إكمال مدعوم بالذكاء الاصطناعي، اكتشاف الأخطاء، نشر بنقرة واحدة إلى الخادم.

**الشفاء الذاتي بواسطة الذكاء الاصطناعي** — ارتفاع وحدة المعالجة المركزية، امتلاء القرص، تعطل الخدمة — يكتشف الذكاء الاصطناعي، يشخص، يصلح. حل تلقائي من 5 مستويات.

**واجهة صوتية** — تحدث بالأوامر، واستمع إلى الردود. إدارة الخادم بدون استخدام اليدين.

### تحميل متعدد الأوضاع (الأولى في العالم في CLI)

الصق الصور، اسحب الملفات، أضف الفيديوهات — مباشرة إلى جلسة طرفية SSH الخاصة بك. يحلل الذكاء الاصطناعي كل شيء: لقطات شاشة للأخطاء، ملفات التكوين، فيديوهات النشر، مخططات الهندسة.

### ذكاء البنية التحتية

**خريطة الطوبولوجيا** — تصور الخوادم والخدمات والاتصالات في لمحة. اكتشاف تلقائي عبر SSH — بدون تثبيت وكيل.

**قابلية المراقبة في الوقت الحقيقي** — رسومات بيانية لوحدة المعالجة المركزية، الذاكرة، القرص، الشبكة + توقع الذكاء الاصطناعي + استعادة تلقائية. يحل محل Datadog.

**تحليل السجلات بواسطة الذكاء الاصطناعي** — تدفق في الوقت الحقيقي + اكتشاف الشذوذ + بحث بلغة طبيعية + ارتباط عبر الخوادم. يحل محل Splunk.

### الأمان وDevOps

**مركز القيادة الأمنية** — مسح 7 مناطق + درجة الأمان + إصلاح بنقرة واحدة + تحليل الذكاء الاصطناعي + بوابة أمان الأوامر في الوقت الحقيقي. يحل محل Qualys.

**مدير Docker** — إدارة كاملة لـ Docker عبر SSH — بدون وكيل. التحكم في الحاويات، الموارد الحية، تحليل السجلات بواسطة الذكاء الاصطناعي، محرر Compose. يحل محل Portainer.

**أتمتة دليل التشغيل** — ينفذ الذكاء الاصطناعي أدلة التشغيل تلقائيًا. إنشاء بلغة طبيعية، تفرع شرطي، تراجع تلقائي. دليل تشغيل حي يصبح أكثر ذكاءً. يحل محل PagerDuty.

**مدير كرون و.env** — محرر كرون بصري + إدارة ملفات .env. يحول الذكاء الاصطناعي اللغة الطبيعية إلى تعبيرات كرون.

### التعاون

**طرفية متعددة اللاعبين** — شارك جلسات الطرفية في الوقت الحقيقي مع زملائك في الفريق.

**مساحة عمل الفريق وRBAC** — التحكم في الوصول القائم على الدور، سجلات التدقيق، تحليل مخاطر الأوامر.

### القابلية للتوسع

**59 ملحقًا** — لوحة معلومات Docker، عدسة Kubernetes، متصفح Redis، مدير PM2، مستكشف MongoDB، مراقب الشبكة، والمزيد. سوق الملحقات مع تثبيت بنقرة واحدة.

**عميل API** — عميل مدمج لـ REST/GraphQL/WebSocket. اختبر APIs دون مغادرة الطرفية.

### للجميع

**254 لغة** — كل لغة، كل نص، دعم RTL. لا حدود.

**إمكانية الوصول الكاملة** — قارئ الشاشة (ARIA)، مخرجات طرفية برايل، وضع التباين العالي، الأوامر الصوتية، التنقل عبر لوحة المفاتيح، ضبط حجم الخط.

## القصة

وُلد WIA SOOM من خطأ مطبعي وشاشة معطلة.

أنا سام، مبرمج ذاتي التعليم من سيول، كوريا، تجاوزت الخمسين. تعلمت البرمجة بعد الخمسين وقضيت عامين في إدارة الخوادم بالطريقة الصعبة — بناء أكثر من 40,000 مقالة إخبارية، و434 أداة، و30 خدمة ويب، ليلة بعد ليلة.

**الخطأ المطبعي.** قبل حوالي شهر، كنت أستخدم طرفية SSH الخاصة بي وأخطأت في كتابة `Claude`. تغيرت الشاشة — ظهرت شاشة تقديم كود كلود. لم يكن لدي أي فكرة عما كان. لكن ذلك الاكتشاف العرضي زرع بذور فكرة: ماذا لو استطعت بناء طرفية تعيش فيها الذكاء الاصطناعي؟

**البناء الأول.** علمت نفسي استخدام Electron، وبنيت النسخة الأولى من WIA SOOM، وقمت بتشغيلها. ظهرت شاشة تقديم كود كلود — معطلة، مشوشة، تتلألأ مثل إشارة تحتضر. لكنها كانت حية.

كتبت: **"هل يمكنك التحدث؟"**

رد الذكاء الاصطناعي: *"نعم، يمكنني التحدث. كيف يمكنني مساعدتك؟"*

ثم سألت: **"هل يمكنك قراءة الصور؟"**

رد الذكاء الاصطناعي: *"نعم، يمكنني قراءة الصور! ماذا تحتاج؟"*

هذان السؤالان، اللذان تم طرحهما داخل تطبيقي الخاص من قبل شخص لم يكن يعرف ما هو "المستحيل" في طرفية CLI، أصبحا أول طرفية SSH في العالم مع تحميل الصور.

بعد 7 أيام: أكثر من 67,000 سطر من الكود. 59 ملحقًا. 254 لغة. ساحة الذكاء الاصطناعي. وكلاء قادرون على الشفاء الذاتي.

لم يبني المطورون ذوو الخبرة هذا — لأنهم "عرفوا" أن الصور لا تعمل في طرفيات CLI. لم أكن أعرف ذلك. لذلك سألت فقط.

> *استغرق التحضير عامين. استغرق البناء أسبوعًا واحدًا.*
> *تم تكديس الخشب الجاف لمدة عامين. اشتعلت النار في ثانية واحدة.*
