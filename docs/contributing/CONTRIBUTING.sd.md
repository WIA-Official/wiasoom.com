## Conduct Code

اسان هر ڪنهن لاءِ هڪ خوش آمديد ۽ شموليت وارو تجربو مهيا ڪرڻ لاءِ پرعزم آهيون.

- **احترام ڪريو.** هر ڪنهن سان عزت سان پيش اچو.
- **تعميراتي ٿيو.** مددگار راءِ پيش ڪريو، تباهه ڪندڙ تنقيد نه.
- **شموليت وارو ٿيو.** اسان 254 ٻولين جي حمايت ڪندا آهيون ۽ ڌرتي جي هر ملڪ مان شموليت ڪندڙن کي خوش آمديد چئون ٿا.
- **هراساني نه ڪريو.** ڪنهن به قسم جي تفريق لاءِ صفر برداشت.

## 🌐 ترجمو شموليت (254 ٻوليون)

WIA SOOM **254 ٻولين** جي حمايت ڪري ٿو — امهاريڪ کان زولو تائين، بريل ۽ RTL ٻولين سميت.

### ترجمو ڪيئن ڪم ڪري ٿو

- بنيادي ٻولي فائل: `src/renderer/src/i18n/en.json`
- سڀ 254 ٻولي فائلون هڪ ئي ڊائريڪٽري ۾ آهن
- ترجمو `scripts/translate-patch.js` (GPT-4o-mini API) ذريعي ڪيو ويندو آهي

### ترجمن ۾ شموليت ڪيئن ڪجي

#### آپشن 1: هڪ خاص ترجمو درست ڪريو

1. ٻولي فائل ڳوليو: `src/renderer/src/i18n/{lang-code}.json`
2. غلط ترجمو درست ڪريو
3. تبديلي سان گڏ هڪ PR جمع ڪريو

#### آپشن 2: گم ٿيل ڪي شامل ڪريو
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### آپشن 3: مشين ترجمون جو جائزو وٺو

اسان جي 254 ٻولين مان ڪيترائي مشين پاران ترجمو ڪيا ويا. مقامي ڳالهائيندڙن جا جائزو انتهائي قيمتي آهن!

1. پنهنجي ٻولي فائل چونڊيو
2. ترجمون جو جائزو وٺو
3. ڪنهن به عجيب يا غلط ترجمون کي درست ڪريو
4. هڪ PR جمع ڪريو

### ٻولي جي ڪوڊ

اسان معياري ISO 639-1 ڪوڊ استعمال ڪندا آهي��ن (مثلاً، `ko`, `en`, `ja`, `ar`, `hi`) جتي ضروري هجي علائقائي متغيرات سان (مثلاً، `zh-CN`, `pt-BR`).
