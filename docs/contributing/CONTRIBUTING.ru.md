## Кодекс поведения

Мы стремимся предоставить приветливый и инклюзивный опыт для всех.

- **Будьте уважительными.** Относитесь ко всем с достоинством.
- **Будьте конструктивными.** Предлагайте полезные отзывы, а не разрушительную критику.
- **Будьте инклюзивными.** Мы поддерживаем 254 языка и приветствуем участников из каждой страны на Земле.
- **Без домогательств.** Нулевая терпимость к любой форме дискриминации.

## 🐛 Как сообщить об ошибках

1. Перейдите на [GitHub Issues](https://github.com/WIA-Official/wiasoom.com/issues)
2. Нажмите **"New Issue"**
3. Выберите шаблон **"Bug Report"**
4. Включите:
   - Версию WIA SOOM (Настройки → О программе)
   - ОС и версия (Windows/macOS/Linux)
   - Шаги для воспроизведения
   - Ожидаемое и фактическое поведение
   - Скриншоты или вывод терминала, если возможно

## 💡 Как предложить функции

1. Перейдите на [GitHub Issues](https://github.com/WIA-Official/wiasoom.com/issues)

4. Опишите:

   - Любые альтернативы, которые вы рассматривали

## 🔌 Как подать плагин

WIA SOOM имеет мощную систему плагинов — вы можете создать свой собственный плагин за 5 минут.

### Быстрый старт
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### Полное руководство

Прочитайте **[Руководство для разработчиков плагинов](docs/PLUGIN_DEVELOPER_GUIDE.md)** для:
- Полной справки по API
- Рабочих примеров
- Пошаговых учебников
- Лучших практик и правил безопасности

### Подайте ваш плагин

1. Сделайте форк [Plugin Store](https://wiasoom.com)
2. Добавьте ваш плагин в `plugins/{your-plugin-name}/`
3. Подайте запрос на изменение
4. После проверки ваш плагин появится в Магазине плагинов для всех ��ользователей!

5. Зафиксируйте с ясным сообщением:
   ```

   ```

### Конвенция сообщений коммитов

| Префикс | Используется для |
|---------|------------------|

| `refactor:` | Реструктуризация кода (без изменения поведения) |

## 🌐 Вклад в переводы (254 языка)

WIA SOOM поддерживает **254 языка** — от амхарского до зулу, включая шрифт Брайля и языки с RTL.

### Как работает перевод

- Файл базового языка: `src/renderer/src/i18n/en.json`
- Все 254 файла языков находятся в одной директории
- Перевод осуществляется с помощью `scripts/translate-patch.js` (GPT-4o-mini API)

### Как внести вклад в переводы

#### Вариант 1: Исправить конкретный перевод

1. Найдите файл языка: `src/renderer/src/i18n/{lang-code}.json`
2. Исправьте неверный перевод
3. Подайте PR с изменением

#### Вариант 2: Добавить отсутствующие ключи
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### Вариант 3: Проверить машинные переводы

Многие из наших 254 языков были переведены с помощью машинного перевода. Отзывы носит��лей языка невероятно ценны!

1. Выберите файл вашего языка
2. Проверьте переводы
3. Исправьте любые неуклюжие или неверные переводы
4. Подайте PR

### Коды языков

Мы используем стандартные коды ISO 639-1 (например, `ko`, `en`, `ja`, `ar`, `hi`) с региональными вариантами, где это необходимо (например, `zh-CN`, `pt-BR`).
