## நடவடிக்கை விதிமீறல்

எல்லோருக்கும் வரவேற்கும் மற்றும் உள்ளடக்கிய அனுபவத்தை வழங்குவதில் நாங்கள் உறுதியாக உள்ளோம்.

- **மரியாதையாக இருங்கள்.** அனைவரையும் மரியாதையுடன் நடத்துங்கள்.
- **உதவிகரமாக இருங்கள்.** அழிவான விமர்சனங்களை அல்ல, உதவிகரமான கருத்துக்களை வழங்குங்கள்.
- **உள்ளடக்கியதாக இருங்கள்.** நாங்கள் 254 மொழிகளை ஆதரிக்கிறோம் மற்றும் பூமியின் ஒவ்வொரு நாட்டிலிருந்தும் பங்களிப்பாளர்களை வரவேற்கிறோம்.
- **துன்புறுத்தல் இல்லை.** எந்தவொரு வகை வேறுபாட்டிற்கும் பூட்டு நிலை.

## 🌐 மொழிபெயர்ப்பு பங்களிப்புகள் (254 மொழிகள்)

WIA SOOM **254 மொழிகளை** ஆதரிக்கிறது — அம்ஹாரிக் முதல் சூலு வரை, ப்ரெயி��் மற்றும் RTL மொழிகளை உள்ளடக்கியது.

### மொழிபெயர்ப்பு எப்படி செயல்படுகிறது

- அடிப்படை மொழி கோப்பு: `src/renderer/src/i18n/en.json`
- அனைத்து 254 மொழி கோப்புகள் ஒரே அடைவில் உள்ளன
- மொழிபெயர்ப்பு `scripts/translate-patch.js` மூலம் செய்யப்படுகிறது (GPT-4o-mini API)

### மொழிபெயர்ப்புகளை எப்படி பங்களிக்க வேண்டும்

#### விருப்பம் 1: குறிப்பிட்ட மொழிபெயர்ப்பை சரிசெய்யவும்

1. மொழி கோப்பை கண்டுபிடிக்கவும்: `src/renderer/src/i18n/{lang-code}.json`
2. தவறான மொழிபெயர்ப்பை சரிசெய்யவும்
3. மாற்றத்துடன் ஒரு PR ஐ சமர்ப்பிக்கவும்

#### விருப்பம் 2: காணாமல் போன விசைகளைச் சேர்க்கவும்
§§§CHUNK_SEPARATOR§§§
#### விருப்பம் 3: இயந்திர மொழிபெயர்ப்புகளை மதிப்பீடு செய்யவும்

எங்கள் 254 மொழிகளில் பலவற்றை இயந்திரம் மொழிபெயர்த்துள்ளது. உள்ளூர் பேசுநர்களின் மதிப்பீடுகள் மிகவும் மதிப்புமிக்கவை!

1. உங்கள் மொழி கோப்பை தேர்ந்தெடுக்கவும்
2. மொழிபெயர்ப்புகளை மதிப்பீடு செய்யவும்
3. எந்தவொரு அசௌகரியமான அல்லது தவறான மொழிபெயர்ப்புகளைச் சரிசெய்யவும்
4. ஒரு PR ஐ சமர்ப்பிக்கவும்

### மொழி குறியீடுகள்

நாங்கள் தேவையான இடங்களில் பிராந்திய மாறுபாடுகளுடன் கூடிய நிலையான ISO 639-1 குறியீடுகளை (எ.கா., `ko`, `en`, `ja`, `ar`, `hi`) பயன்படுத்துகிறோம்.
