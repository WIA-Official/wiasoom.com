## קוד התנהגות

אנו מחויבים לספק חוויה מקבלת ומכילה לכל אחד.

- **היו מכבדים.** התייחסו לכולם בכבוד.
- **היו בונים.** הציעו משוב מועיל, לא ביקורת הרסנית.
- **היו כוללים.** אנו תומכים ב-254 שפות ומקבלים תרומות מכל מדינה על פני כדור הארץ.
- **אין הטרדות.** אפס סובלנות להפליה מכל סוג.

## 🔌 איך להגיש תוסף

ל-WIA SOOM יש מערכת תוספים חזקה — אתם יכולים לבנות את התוסף שלכם תוך 5 דקות.

### התחלה מהירה
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### מדריך מלא

קראו את **[מדריך מפתח התוספים](docs/PLUGIN_DEVELOPER_GUIDE.md)** עבור:
- הפניה מלאה ל-API
- דוגמאות עבודה
- מדריכים שלב-אחר-שלב
- שיטות עבודה מומלצות וכללי אבטחה

### הגישו את התוסף שלכם

1. עשו פורק ל-[Plugin Store](https://wiasoom.com)
2. הוסיפו את התוסף שלכם ל-`plugins/{your-plugin-name}/`
3. הגישו בקשת משיכה
4. לאחר סקירה, התוסף שלכם יופיע בחנות התוספים עבור כל המשתמשים!

## 🌐 תרומות תרגום (254 שפות)

WIA SOOM תומכת ב-**254 שפות** — מאמהרית עד זולו, כולל ברייל ושפות RTL.

### איך עובד התרגום

- קובץ שפה בסיסי: `src/renderer/src/i18n/en.json`
- כל 254 קובצי השפה נמצאים באותו תיקייה
- התרגום מתבצע באמצעות `scripts/translate-patch.js` (GPT-4o-mini API)

### איך לתרום תרגומים

#### אפשרות 1: לתקן תרגום ספציפי

1. מצאו את קובץ השפה: `src/renderer/src/i18n/{lang-code}.json`
2. תקנו את התרגום השגוי
3. ��גישו PR עם השינוי

#### אפשרות 2: להוסיף מפתחות חסרים
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### אפשרות 3: לסקור תרגומים ממכונה

רבים מהשפות שלנו תורגמו באמצעות מכונה. סקירות דוברי שפת אם הן יקרות ערך מאוד!

1. בחרו את קובץ השפה שלכם
2. סקרו את התרגומים
3. תקנו כל תרגום מוזר או שגוי
4. הגישו PR

### קודי שפות

אנו משתמשים בקודים הסטנדרטיים ISO 639-1 (למשל, `ko`, `en`, `ja`, `ar`, `hi`) עם וריאנטים אזוריים לפי הצורך (למשל, `zh-CN`, `pt-BR`).
