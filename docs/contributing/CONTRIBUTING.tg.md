## 🔌 Чӣ гуна плагин пешниҳод кунем

WIA SOOM системаи плагини қавӣ дорад — шумо метавонед дар 5 дақиқа плагини худро созед.

### Оғози зуд
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### Роҳнамои пурра

Роҳнамои **[Plugin Developer Guide](docs/PLUGIN_DEVELOPER_GUIDE.md)**-ро барои:
- Маъруфи API комил
- Мисолҳои корӣ
- Дастурҳои қадам ба қадам
- Тадбирҳои беҳтарин ва қоидаҳои амният

### Плагини худро пешниҳод кунед

1. [Plugin Store](https://wiasoom.com)-ро форк кунед
2. Плагини худро ба `plugins/{your-plugin-name}/` илова кунед
3. Pull Request пешниҳод кунед
4. Пас аз баррасӣ, плагини шумо барои ҳамаи корбарон дар Plugin Store пайдо мешавад!

## 🌐 Саҳмгузориҳои тарҷума (254 забон)

WIA SOOM **254 забон**-ро дастгирӣ мекунад — аз Амхарӣ то Зул, шомили Брайл ва забонҳои RTL.

### Чӣ гуна тарҷума кор мекунад

- Файли забони асосӣ: `src/renderer/src/i18n/en.json`
- Ҳама 254 файли забон дар як директория мебошанд
- Тарҷума тавассути `scripts/translate-patch.js` (GPT-4o-mini API) анҷом дода мешавад

### Чӣ гуна тарҷумаҳоро саҳм гузоред

#### Варианти 1: Тарҷумаи махсусро ислоҳ кунед

1. Файли забонро пайдо кунед: `src/renderer/src/i18n/{lang-code}.json`
2. Тарҷумаи нодурустр�� ислоҳ кунед
3. PR-ро бо тағйирот пешниҳод кунед

#### Варианти 2: Ключҳои гумшударо илова кунед
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### Варианти 3: Тарҷумаҳои мошинро баррасӣ кунед

Бисёре аз 254 забонҳои мо бо мошин тарҷума шудаанд. Баррасии гӯяндагони аслӣ хеле арзишманд аст!

1. Файли забони худро интихоб кунед
2. Тарҷумаҳоро баррасӣ кунед
3. Ҳар гуна тарҷумаҳои нодуруст ё нороҳатро ислоҳ кунед
4. PR-ро пешниҳод кунед

### Кодҳои Забон

Мо кодҳои стандартии ISO 639-1-ро истифода мебарем (масалан, `ko`, `en`, `ja`, `ar`, `hi`) бо вариантҳои минтақавӣ, агар лозим бошад (масалан, `zh-CN`, `pt-BR`).
