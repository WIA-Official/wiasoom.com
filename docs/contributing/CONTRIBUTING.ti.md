```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```

### ሙሉእ መምርሒ

ነቲ **[Plugin Developer Guide](docs/PLUGIN_DEVELOPER_GUIDE.md)** ንከምዚ ኣንብቦ:
- ሙሉእ ናይ API ማጣቐሲ
- ዝሰርሑ ኣብነታት
- ስጉምቲ-ብ-ስጉምቲ መምሃሪ
- ዝበለጹ ኣሰራርሓታትን ሕግታት ድሕንነትን

### ፕላግ-ኢንካ ኣቕርብ

2. ፕላግ-ኢንካ ናብ `plugins/{your-plugin-name}/` ወስኮ
3. Pull Request ኣቕርብ
4. ድሕሪ ምርመራ፣ ፕላግ-ኢንካ ኣብ Plugin Store ንኹሎም ተጠቀምቲ ይርአ!

3. ለውጥታትካ ግበር
4. ኣብ ውሽጢ ፈትን:


   ```

   ```
6. ፑሽ ግበርን ኣንጻር `main` PR ኽፈትን

### ስምምዕ መልእኽቲ ኮሚት

| ቅድመ-ጥብቆ | ንእንታይ ይጥቀመሉ |
|--------|---------|
| `feat:` | ሓድሽ ባህሪ |
| `fix:` | ምፍታሕ ጸገም |
| `docs:` | ሰነዳት ጥራይ |
| `refactor:` | ምስራዕ ኮድ (ለውጢ ባህሪ ዘይብሉ) |
| `i18n:` | ምዕባለ ትርጉም |
| `plugin:` | ለውጥታት ፕላግ-ኢን |

- [ ] ኮድ ብዘይ ጌጋ ይሰርሕ

## 🌐 ኣበርክቶ ትርጉም (254 ቋንቋታት)

WIA SOOM **254 ቋንቋታት** ይድግፍ — ካብ ኣምሓርኛ ክሳብ ዙሉ፣ ብሬይልን RTL ቋንቋታትን ሓዊሱ።

### ከመይ ትርጉም ይሰርሕ

- ናይ መሰረት ቋንቋ ፋይል: `src/renderer/src/i18n/en.json`
- ኩሎም 254 ናይ ቋንቋ ፋይላት ኣብ ሓደ ዳይረክቶሪ ኣለዉ
- ትርጉም ብ`scripts/translate-patch.js` (GPT-4o-mini API) ይግበር

### ከመይ ትርጉም ተበርክት

#### ኣማራጺ 1: ፍሉይ ትርጉም ኣእርም

1. ናይ ቋንቋ ፋይል ርኸብ: `src/renderer/src/i18n/{lang-code}.json`
2. ጌጋ ዝኾነ ትርጉም ኣእርም
3. ምስ ለውጢ PR ኣቕርብ

#### ኣማራጺ 2: ዝጎድሉ ቁልፍታት ወስኽ

```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```

#### ኣማራጺ 3: ናይ ማሽን ትርጉማት ገምግም

ብዙሓት ካብ 254 ቋንቋታትና ብማሽን ዝተተርጎሙ እዮም። ናይ ወዲ ቋንቋ ምግምጋም ኣዝዩ ክቡር እዩ!

1. ናይ ቋንቋኻ ፋይል ምረጽ
2. ትርጉማት ገምግም
3. ዘይምቹእ ወይ ጌጋ ዝኾኑ ትርጉማት ኣእርም
4. PR ኣቕርብ

### ኮዳት ቋንቋ

ስታንዳርድ ISO 639-1 ኮዳት ንጥቀም (ንኣብነት `ko`፣ `en`፣ `ja`፣ `ar`፣ `hi`) ምስ ዘድሊ ናይ ከባቢ ፍልልያት (ንኣብነት `zh-CN`፣ `pt-BR`)።
