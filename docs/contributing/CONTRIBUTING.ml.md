## നടപടികളുടെ കോഡ്

എല്ലാവർക്കും സ്വാഗതം ചെയ്യുന്ന, ഉൾക്കൊള്ളുന്ന അനുഭവം നൽകാൻ ഞങ്ങൾ പ്രതിജ്ഞാബദ്ധരാണ്.

- **ആദരിക്കുക.** എല്ലാവരെയും മാന്യമായി പെരുമാറുക.
- **നിർമ്മാണാത്മകമാകുക.** തകർപ്പൻ വിമർശനങ്ങൾക്കുപകരം സഹായകരമായ പ്രതികരണം നൽകുക.
- **ഉൾക്കൊള്ളുന്നവനാകുക.** 254 ഭാഷകൾ ഞങ്ങൾ പിന്തുണയ്ക്കുന്നു, ഭൂമിയിലെ എല്ലാ രാജ്യങ്ങളിൽ നിന്നുള്ള സംഭാവനക്കാരെ സ്വാഗതം ചെയ്യുന്നു.
- **ഹരാസ്മെന്റ് ഇല്ല.** ഏതെങ്കിലും തരത്തിലുള്ള വിവേചനത്തിന് ശൂന്യമായ സഹിഷ്ണുത.

## 🔌 പ്ലഗിൻ എങ്ങനെ സമർപ്പിക്കാം

WIA SOOM-ൽ ശക്തമായ പ്ലഗിൻ സംവിധാനം ഉണ്ട് — നിങ്ങൾക്ക് 5 മിനിറ്റിൽ നിങ്ങളുടെ സ്വന്തം പ്ലഗിൻ നിർമ്മിക്കാം.

### സമ്പൂർണ്ണ ഗൈഡ്

- സമ്പൂർണ്ണ API റഫറൻസ്
- പ്രവർത്തന ഉദാഹരണങ്ങൾ
- ഘട്ടം ഘട്ടമായി ട്യൂട്ടോറിയലുകൾ
- മികച്ച പ്രായോഗികതകളും സുരക്ഷാ നിയമങ്ങളും

### നിങ്ങളുടെ പ്ലഗിൻ സമർപ്പിക്കുക

3. ഒരു പുൾ റിക്വസ്റ്റ് സമർപ്പിക്കുക
4. അവലോകനത്തിന് ശേഷം, നിങ്ങളുടെ പ്ലഗിൻ എല്ലാ ഉപയോക്താക്കൾക്കായി പ്ലഗിൻ സ്റ്റോറിൽ പ്രത്യക്ഷപ്പെടും!

## 🌐 വിവർത്തന സംഭാവനകൾ (254 ഭാഷകൾ)

WIA SOOM **254 ഭാഷകൾ** പിന്തുണയ്ക്കുന്നു — അമഹാരിക് മുതൽ സൂലുവുവരെ, ബ്രെയിൽ, RTL ഭാഷകൾ ഉൾപ്പെടുന്നു.

### വിവർത്തനം എങ്ങനെ പ്രവർത്തിക്കുന്നു

- അടിസ്ഥാന ഭാഷ ഫയൽ: `src/renderer/src/i18n/en.json`
- എല്ലാ 254 ഭാഷാ ഫയലുകളും ഒരേ ഡയറക്ടറിയിൽ ഉണ്ട്
- വിവർത്തനം `scripts/translate-patch.js` (GPT-4o-mini API) വഴി ചെയ്യുന്നു

### വിവർത്തനങ്ങൾ എങ്ങനെ സംഭാവന നൽകാം

#### ഓപ്ഷൻ 1: പ്രത്യേക വിവർത്തനം പരിഹരിക്കുക

1. ഭാഷാ ഫയൽ കണ്ടെത്തുക: `src/renderer/src/i18n/{lang-code}.json`
2. തെറ്റായ വിവർത്തനം പരിഹരിക്കുക
3. മാറ്റം ഉൾപ്പെടുന്ന PR സമ���പ്പിക്കുക

#### ഓപ്ഷൻ 2: നഷ്ടമായ കീകൾ ചേർക്കുക
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### ഓപ്ഷൻ 3: യന്ത്ര വിവർത്തനങ്ങൾ അവലോകനം ചെയ്യുക

ഞങ്ങളുടെ 254 ഭാഷകളിൽ പലതും യന്ത്രവിവർത്തനം ചെയ്തിരിക്കുന്നു. നാട്ടുകാരുടെ അവലോകനങ്ങൾ വളരെ വിലമതിക്കപ്പെടുന്നു!

1. നിങ്ങളുടെ ഭാഷാ ഫയൽ തിരഞ്ഞെടുക്കുക
2. വിവർത്തനങ്ങൾ അവലോകനം ചെയ്യുക
3. ഏതെങ്കിലും അസ്വാഭാവികമായ അല്ലെങ്കിൽ തെറ്റായ വിവർത്തനങ്ങൾ പരിഹരിക്കുക
4. PR സമർപ്പിക്കുക

### ഭാഷാ കോഡുകൾ

ഞങ്ങൾ സാധാരണ ISO 639-1 കോഡുകൾ (ഉദാഹരണത്തിന്, `ko`, `en`, `ja`, `ar`, `hi`) പ്രാദേശിക വ്യത്യാസങ്ങളോടൊപ്പം ഉപയോഗിക്കുന്നു (ഉദാഹരണത്തിന്, `zh-CN`, `pt-BR`).
