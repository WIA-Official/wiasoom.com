## 🌐 การมีส่วนร่วมในการแปล (254 ภาษา)

WIA SOOM สนับสนุน **254 ภาษา** — ตั้งแต่ภาษาอัมฮาริกถึงซูลู รวมถึงภาษาบราล์และภาษาที่เขียนจากขวาไปซ้าย

### วิธีการทำงานของการแปล

- ไฟล์ภาษาหลัก: `src/renderer/src/i18n/en.json`
- ไฟล์ภาษาทั้ง 254 ไฟล์อยู่ในไดเรกทอรีเดียวกัน
- การแปลทำผ่าน `scripts/translate-patch.js` (GPT-4o-mini API)

### วิธีการมีส่วนร่วมในการแปล

#### ตัวเลือก 1: แก้ไขการแปลที่เฉพาะเจาะจง

1. ค้นหาไฟล์ภาษา: `src/renderer/src/i18n/{lang-code}.json`
2. แก้ไขการแปลที่ไม่ถูกต้อง
3. ส่ง PR พร้อมการเปลี่ยนแปลง

#### ตัวเลือก 2: เพิ่มคีย์ที่ขาดหายไป
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### ตัวเลือก 3: ตรวจสอบการแปลด้วยเครื่อง

หลายภาษาของเราทั้ง 254 ภาษาได้รับการแปลโดยเครื่อง การตรวจสอบโดยเจ้าของภาษามีคุณค่ามาก!

1. เลือกไฟล์ภาษาของคุณ
2. ตรวจสอบการแปล
3. แก้ไขการแปลที่ไม่เหมาะสมหรือไม่ถูกต้อง
4. ส่ง PR

### รหัสภาษา

เราจะใช้รหัส ISO 639-1 มาตรฐาน (เช่น `ko`, `en`, `ja`, `ar`, `hi`) พร้อมตัวแปรภูมิภาคเมื่อจำเป็น (เช่น `zh-CN`, `pt-BR`)
