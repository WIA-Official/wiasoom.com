## គោលការណ៍អាកប្បកិរិយា

យើងមានការប្តេជ្ញាចិត្តក្នុងការផ្តល់នូវបទពិសោធន៍ដែលស្វាគមន៍ និងរួមបញ្ចូលសម្រាប់អ្នកគ្រប់រូប។

- **គោរពគ្នា។** បង្ហាញការគោរពដល់គ្នាទាំងអស់។

- **រួមបញ្ចូល។** យើងគាំទ្រភាសា 254 ភាសា និងស្វាគមន៍អ្នករួមចំណែកពីប្រទេសគ្រប់ប្រទេសនៅលើពិភពលោក។

## 🌐 ការរួមចំណែកការប្រែសម្រួល (254 ភាសា)

WIA SOOM គាំទ្រភាសា **254 ភាសា** — ពីអាមហារិកទៅហ្សូឡូ, រួមមានប្រៃល និងភាសា RTL។

### របៀបដែលការប្រែសម្រួលធ្វើការងារ

- ឯកសភាសាមូលដ្ឋាន: `src/renderer/src/i18n/en.json`
- ឯកសារភាសា 254 ទាំងអស់នៅក្នុងថតដូចគ្នា
- ការប្រែសម្រួលត្រូវបានធ្វើតាម `scripts/translate-patch.js` (GPT-4o-mini API)

### របៀបរួមចំណែកការប្រែសម្រួល

#### ជម្រើស 1: ជួសជុលការប្រែសម្រួលជាក់លាក់

1. ស្វែងរកឯកសារភាសា: `src/renderer/src/i18n/{lang-code}.json`
2. ជួសជុលការប្រែសម្រួលដែលមិនត្រឹមត្រូវ
3. ដាក់ស្នើ PR ជាមួយការផ្លាស់ប្តូរ

#### ជម្រើស 2: បន្ថែមកូនសោដែលខ្វះ
§§§CHUNK_SEPARATOR§§§
#### ជម្រើស 3: ពិនិត្យការប្រែសម្រួលដោយម៉ាស៊ីន

ភាសា 254 ភាសាច្រើនរបស់យើងត្រូវបានប្រែសម្រួលដោយម៉ាស៊ីន។ ការពិនិត្យដោយអ្នកនិយាយដើមមានតម្លៃខ្លាំងណាស់!

1. ជ្រើសរើសឯកសារភាសារបស់អ្នក
2. ពិនិត្យការប្រែសម្រួល
3. ជួសជុលការប្រែសម្រួលដែលមានភាពអាក្រក់ឬមិនត្រឹមត្រូវ
4. ដាក់ស្នើ PR

### កូដភាសា

យើងប្រើកូដ ISO 639-1 ដែលស្តង់ដារ (ឧ. `ko`, `en`, `ja`, `ar`, `hi`) ជាមួយកំណែតំបន់នៅពេលដែលចាំបាច់ (ឧ. `zh-CN`, `pt-BR`).
