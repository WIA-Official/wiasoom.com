## အပြုအမူစည်းမျဉ်း

ကျွန်ုပ်တို့သည် လူတိုင်းအတွက် ကြိုဆိုသောနှင့် အပါအဝင်သော အတွေ့အကြုံကို ပံ့ပိုးရန် ကတိပြုထားပါသည်။

- **ဂုဏ်ယူပါ။** လူတိုင်းကို ဂုဏ်ယူစွာ ဆက်ဆံပါ။
- **တည်ငြိမ်စွာ ရေးသားပါ။** အထောက်အကူပြုသော အကြံပြုချက်များပေးပါ၊ ဖျက်ဆီးသော အပြစ်တင်ချက်များ မပေးပါနှင့်။
- **အပါအဝင်ပါ။** ကျွန်ုပ်တို့သည် 254 ဘာသာကို ပံ့ပိုးပြီး ကမ္ဘာ့တိုင်းပြည်မှ အထေ���က်အကူပေးသူများကို ကြိုဆိုပါသည်။
- **လိမ်လည်မှုမရှိပါ။** မည်သည့်အမျိုးအစားမှ အထိခိုက်မှုကို ငြင်းဆိုပါသည်။

## 🐛 အမှားများကို ဘယ်လို သတင်းပို့မလဲ

1. [GitHub Issues](https://github.com/WIA-Official/wiasoom.com/issues) သို့ သွားပါ
2. **"New Issue"** ကို နှိပ်ပါ
3. **"Bug Report"** ပုံစံကို ရွေးချယ်ပါ
4. အောက်ပါအချက်များကို ထည့်ပါ:
   - WIA SOOM ဗားရှင်း (Settings → About)
   - OS နှင့် ဗားရှင်း (Windows/macOS/Linux)
   - ပြန်လည်ထုတ်လုပ်ရန် အဆင့်များ
   - မျှော်မှန်းထားသော နှင့် အမှန်တကယ် ဖြစ်ရပ်
   - ရုပ်ပုံများ သို့မဟုတ် terminal output များ ရှိပါက ထည့်ပါ

## 🔌 ပလပ်ဂင်ကို ဘယ်လို တင်ပြမလဲ

WIA SOOM သည် အင်အားကြီးသော ပလပ်ဂင်စနစ်ရှိသည် — သင်သည် ၅ မိနစ်အတွင်း သင်၏ပလပ်ဂင်ကို တည်ဆောက်နိုင်သည်။

### အမြန်စတင်ခြင်း
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### အပြည့်အစုံ လမ်းညွှန်

**[Plugin Developer Guide](docs/PLUGIN_DEVELOPER_GUIDE.md)** ကို ဖတ်ပါ:
- API ကို အပြည့်အစုံ ရည်ညွှန်းချက်
- အလုပ်လုပ်သော ဥပမာများ
- အဆင့်ဆင့် သင်ခန်းစာများ
- အကောင်းဆုံး လုပ်ထုံးလုပ်နည်းများနှင့် လုံခြုံရေး စည်းမျဉ်းများ

### သင်၏ ပလပ်ဂင်ကို တင်ပြပါ

1. [Plugin Store](https://wiasoom.com) ကို Fork လုပ်ပါ
2. သင်၏ ပလပ်ဂင်ကို `plugins/{your-plugin-name}/` တွင် ထည့်ပါ
3. Pull Request တင်ပါ
4. ပြန်လည်သုံးသပ်ပြီးနောက် သင်၏ ပလပ်ဂင်သည် Plugin Store တွင် အသုံးပြုသူအားလုံးအတွက် ပေါ်လာသည်!

## 🌐 ဘာသာပြန် အထောက်အကူများ (254 ဘာသာ)

WIA SOOM သည် **254 ဘာသာ** ကို ပံ့ပိုးသည် — Amharic မှ Zulu အထိ၊ Braille နှင့် RTL ဘာသာများပါဝင်သည်။

### ဘာသာပြန်မှု ဘယ်လို လုပ်ဆောင်သလဲ

- အခြေခံ ဘာသာစကား ဖိုင်: `src/renderer/src/i18n/en.json`
- 254 ဘာသာစကား ဖိုင်များသည် အထက်ပါ ဒိုင်ရက်ထရီတွင်ရှိသည်
- ဘာသာပြန်မှုသည် `scripts/translate-patch.js` (GPT-4o-mini API) မှတဆင့် ပြုလုပ်သည်

### ဘာသာပြန်မှုများကို ဘယ်လို အထောက်အကူပြုမလဲ

#### ရွေးချယ်မှု ၁: သတ်မှတ်ထားသော ဘာသာပြန်မှုကို ပြင်ဆင်ပါ

1. ဘာသာစကား ဖိုင်ကို ရှာပါ: `src/renderer/src/i18n/{lang-code}.json`
2. မမှန်ကန်သော ဘာသာပြန်မှုကို ပြင်ဆင်ပါ
3. ပြင်ဆင်မှုနှင့်အတူ PR တင်ပါ

#### ရွေးချယ်မှု ၂: လျော့နည်းသော key များကို ထည့်ပါ
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### ရွေးချယ်မှု ၃: စက်မှ ဘာသာပြန်မှုများကို ပြန်လည်သုံးသပ်ပါ

ကျွန်ုပ်တို့၏ 254 ဘာသာများစွာသည် စက်မှ ဘာသာပြန်ထားသည်။ သဘာဝစကားပြောသူများ၏ ပြန်လည်သုံးသပ်မှုများသည် အလွန်တန်ဖိုးရှိသည်!

1. သင်၏ ဘာသာစကား ဖိုင်ကို ရွေးချယ်ပါ
2. ဘာသာပြန်မှုများကို ပြန်လည်သုံးသပ်ပါ
3. မလွယ်ကူသော သို့မဟုတ် မမှန်ကန်သော ဘာသာပြန်မှုများကို ပြင်ဆင်ပါ
4. PR တင်ပါ

### ဘာသာစကား ကုဒ်များ

ကျွန်ုပ်တို့သည် စံ ISO 639-1 ကုဒ်များကို အသုံးပြုသည် (ဥပမာ၊ `ko`, `en`, `ja`, `ar`, `hi`) ��ှင့် လိုအပ်သော ဒေသဆိုင်ရာ အမျိုးအစားများ (ဥပမာ၊ `zh-CN`, `pt-BR`) ကို အသုံးပြုသည်။
