## ລະບຽບບິດ

ພວກເຮົາມຸ່ງມຸ່ນທີ່ຈະໃຫ້ປະສົບການທີ່ຕ້ອງການແລະລວມລວມສໍາລັບທຸກຄົນ.

- **ເປັນຄວາມເຄົາລົບ.** ປະຕິບັດທຸກຄົນດ້ວຍຄວາມສົມບູນ.
- **ເປັນສໍາລັບການສໍາລັບ.** ໃຫ້ຄວາມຄິດໃນການສໍາລັບ, ບໍ່ເປັນການຕິຊິນສຽງ.
- **ເປັນສໍາລັບຄວາມລວມ.** ພວກເຮົາສະໜອງ 254 ພາສາ ແລະຕ໭ອບຮັບຜູ້ລົງບັດຈາກທຸກປະເທດໃນໂລກ.
- **ບໍ່ມີການລົງບັດ.** ບໍ່ມີຄວາມບໍ່ສົມບູນສໍາລັບການລົງບັດທຸກປະເທດ.

## 🐛 ວິທີລາຍງານບັກ

1. ເຂົ້າໄປທີ່ [GitHub Issues](https://github.com/WIA-Official/wiasoom.com/issues)
2. ຄລິກ **"New Issue"**
3. ເລືອກແບບ **"Bug Report"**
4. ລວມເຂົ້າ:
   - ສຽງສົມບັດ WIA SOOM (Settings → About)
   - OS ແລະເວີຊັນ (Windows/macOS/Linux)
   - ຂະບວນການສໍາລັບການສໍາລັບ
   - ຄາດວ່າກັບຄວາມຈິງ
   - ຮູບພາບຫຼືຜົນລະບຽບຖ້າເປັນໄດ້

## 💡 ວິທີແນະນຳຄຸນສົມບັດ

   - ວິທີທີ່ທ່ານຈິງສົມບັດສົມບັດ
   - ທຸກສິ່ງທີ່ທ່ານໄດ້ພິຈາລະນາ

## 🔌 ວິທີສົ່ງປລັກກິນ

WIA SOOM ມີລະບຽບປລັກກິນທີ່ສະດວກ — ທ່ານສາມາດສ້າງປລັກກິນສໍາລັບຕົວເອງໃນ 5 ນາທີ.

### ການເລີ່ມຕົ້ນດ່ວນ
```bash

./scripts/soom-create-plugin.sh
```
### ຄູ່ມືສົບທຽບ

ອ່ານ **[Plugin Developer Guide](docs/PLUGIN_DEVELOPER_GUIDE.md)** ສໍາລັບ:
- ການອໍ່ອິງ API ສົບທຽບ
- ຕົວຢ່າງທີ່ໃຊ້ງານ
- ບົດສຶກສາດ່ວນ
- ຄວາມດີທີ່ສຸດ ແລະ ກົດລະບຽບຄວາມປອດໄພ

### ສົ່ງປລັກກິນຂອງທ່ານ

2. ເພີ່ມປລັກກິນຂອງທ່ານໃນ `plugins/{your-plugin-name}/`
3. ສົ່ງ Pull Request
4. ຫຼັງຈາກການທົດສອບ, ປລັກກິນຂອງທ່ານຈະປິ່ນໃນ Plugin Store ສໍາລັບທຸກຜູ້ໃຊ້!

## 🌐 ການລົງບັດແປພາສາ (254 ພາສາ)

WIA SOOM ສະໜອງ **254 ພາສາ** — ຈາກ Amharic ຫາ Zulu, ລວມທັງ Braille ແລະ ພາສາ RTL.

### ວິທີທີ່ການແປເຮັດວຽກ

- ແຟມພາສາສູງ: `src/renderer/src/i18n/en.json`
- ຟາຍພາສາ 254 ຟາຍຢູ່ໃນເອກະສານແດ່ໃດເດີມ
- ການແປເຮັດຜ່ານ `scripts/translate-patch.js` (GPT-4o-mini API)

### ວິທີລົງບັດແປພາສາ

#### ຕົວເລືອກ 1: ແກ້ໄຂການແປເພີ່ມສົມບັດ

1. ຊອກຟາຍພາສາ: `src/renderer/src/i18n/{lang-code}.json`
2. ແກ້ໄຂການແປເທີ່ຜິດ
3. ສົ່ງ PR ກັບການປ່ອນ

#### ຕົວເລືອກ 2: ເພີ່ມສະຖານທີ່ສູນສົມບັດ
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### ຕົວເລືອກ 3: ກວດສອບການແປສຽງ

ຫຼາຍສຽງຂອງພາສາ 254 ພາສາຖືກແປສຽງໂດຍຄອມພິວເຕີ. ການກວດສອບຈາກຜູ້ສຽງເປັນສິ່ງທີ່ມີຄ່າສູງ!

1. ເລືອກຟາຍພາສາຂອງທ່ານ
2. ກວດສອບການແປ
3. ແກ້ໄຂການແປທີ່ສຽງບໍ່ສົມບັດ
4. ສົ່ງ PR

### ລະຄຽງພາສາ

ພວກເຮົາໃຊ້ລະຄຽງ ISO 639-1 ສະດັດ (ຕົວຢ່າງ, `ko`, `en`, `ja`, `ar`, `hi`) ກັບຄວາມປ່ອນສົມບັດໃສ່ຄວາມຈິງ (ຕົວຢ່າງ, `zh-CN`, `pt-BR`).
