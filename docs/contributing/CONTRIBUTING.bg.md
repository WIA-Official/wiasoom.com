## Кодекс на поведение

Ние сме ангажирани да предоставим приветлива и приобщаваща среда за всички.

- **Бъдете уважителни.** Отнасяйте се към всички с достойнство.
- **Бъдете конструктивни.** Предлагайте полезна обратна връзка, а не разрушителна критика.
- **Бъдете приобщаващи.** Подкрепяме 254 езика и приветстваме участници от всяка страна на Земята.
- **Без тормоз.** Нулева толерантност към всякаква форма на дискриминация.

## 🐛 Как да докладвате грешки

1. Отидете на [GitHub Issues](https://github.com/WIA-Official/wiasoom.com/issues)
2. Кликнете на **"New Issue"**
3. Изберете шаблона **"Bug Report"**
4. Включете:
   - Версия на WIA SOOM (Настройки → За програмата)
   - Операционна система и версия (Windows/macOS/Linux)
   - Стъпки за възпроизвеждане
   - Очаквано срещу действително поведение
   - Скриншотове или изход от терминала, ако е възможно

## 🔌 Как да подадете плъгин

WIA SOOM разполага с мощна система за плъгини — можете да изградите свой собствен плъгин за 5 минути.

### Бързо начало
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### Пълен наръчник

Прочетете **[Наръчника за разработчици на плъгини](docs/PLUGIN_DEVELOPER_GUIDE.md)** за:
- Пълна API справка
- Работещи примери
- Стъпка по стъпка уроци
- Най-добри практики и правила за сигурност

### Подайте своя плъгин

1. Форкнете [Plugin Store](https://wiasoom.com)
2. Добавете своя плъгин в `plugins/{your-plugin-name}/`
3. Подайте Pull Request
4. След преглед, вашият плъгин ще се появи в Plugin Store за всички потребители!

## 🌐 Приноси за превод (254 езика)

WIA SOOM поддържа **254 езика** — от амхарски до зулу, включително Брайл и езици с RTL.

### Как работи преводът

- Основен езиков файл: `src/renderer/src/i18n/en.json`
- Всички 254 езикови файла са в същата директория
- Преводът се извършва чрез `scripts/translate-patch.js` (GPT-4o-mini API)

### Как да допринесете с преводи

#### Опция 1: Поправете конкретен превод

1. Намерете езиковия файл: `src/renderer/src/i18n/{lang-code}.json`
2. Поправете неправилния превод
3. Подайте PR с промените

#### Опция 2: Добавете липсващи ключове
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### Опция 3: Прегледайте машинни преводи

Много от нашите 254 езика са машинно преведени. Прегледите от носители на езика са изключително ценни!

1. Изберете своя езиков файл
2. Прегледайте преводите
3. Поправете всякакви неуместни или неправилни преводи
4. Подайте PR

### Кодове на езици

Използваме стандартни ISO 639-1 кодове (например, `ko`, `en`, `ja`, `ar`, `hi`) с регионални варианти, когато е необходимо (например, `zh-CN`, `pt-BR`).
