## Conduct قاعدىسى

بىز ھەممە ئۈچۈن قوبۇل قىلىش ۋە قوشۇلۇش تەجرىبىسىنى تەمىنلەش ئۈچۈن مەسئۇل.

- **ھۆرمەت قىلىڭ.** ھەممىنى شەرەپ بىلەن مۇعاملە قىلىڭ.
- **قۇرۇلما بولۇڭ.** ياردەمچى پىكىر بىرىڭ، يىقىلما پىكىر ئەمەس.
- **قوشۇلۇشچان بولۇڭ.** بىز 254 تىلنى قوللايمىز ۋە دۇنيادىكى ھەر دۆلەتتىن قوشۇلۇشچىلارنى خۇشاللىق بىلەن قوبۇل قىلىمىز.
- **تەھدىت قىلماڭ.** ھېچ قانداق تۈردىكى ئايرىمچىلىققا زېرو سەۋىيەدە تاقابىل تۇرۇش.

## 🔌 پلگىننى قانداق يوللاش

WIA SOOMدا كۈچلۈك پلگىن سىستېمىسى بار — سىز 5 مىنۇتتا ئۆز پلگىنىڭىزنى قۇرالايسىز.

### تىز باشلاش
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### تولۇق قوللانما

**[Plugin Developer Guide](docs/PLUGIN_DEVELOPER_GUIDE.md)** نى ئوقۇڭ:
- تولۇق API نى كۆرسىتىش
- ئىشلىتىش مەسىلىلىرى
- قەدەم بويىچە دەرسلىك
- ئەڭ ياخشى ئەمەلىيەتلەر ۋە بىخەتەرلىك قاعدىلىرى

### پلگىنىڭىزنى يوللاڭ

1. [Plugin Store](https://wiasoom.com) نى فورك قىلىڭ
2. پلگىنىڭىزنى `plugins/{your-plugin-name}/` غا قوشۇڭ
3. Pull Request يوللاڭ
4. تەكشۈرۈلگەندىن كېيىن، پلگىنىڭىز بارلىق قوللانغۇچىلار ئۈچۈن پلگىن دۇكىنىدا كۆرۈنىدۇ!

## 🌐 تەرجىمە قوشۇلۇشلىرى (254 تىل)

WIA SOOM **254 تىل** نى قوللايدۇ — ئامھارچەدىن زۇلۇغا، بىرىنچى قېتىملىق ۋە RTL تىللارنى ئۆز ئىچىگە ئالىدۇ.

### تەرجىمە قانداق ئىشلەيدۇ

- ئاساسلىق تىل فايلى: `src/renderer/src/i18n/en.json`
- بارلىق 254 تىل فايلى بىرلا بۆلۈمدە
- تەرجىمە `scripts/translate-patch.js` ئارقىلىق قىلىنىدۇ (GPT-4o-mini API)

### تەرجىمە قوشۇش قانداق

#### تاللاش 1: بەلگىلىك تەرجىمەنى توغرىلاش

1. تىل فايلىنى تاپىڭ: `src/renderer/src/i18n/{lang-code}.json`
2. خاتا تەرجىمەنى توغرىلاڭ
3. ئۆزگىرىش بىلەن PR يوللاڭ

#### تاللاش 2: يەتكەن كىلىتلەرنى قوشۇش
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### تاللاش 3: ماشىنا تەرجىمەلىرىنى تەكشۈرۈش

بىزنىڭ 254 تىلنىڭ كۆپلىكى ماشىنا تەرجىمە قىلىنغان. تىلغا قوشۇلغانلارنىڭ تەكشۈرۈشى بەك قىممەتlidir!

1. تىل فايلىڭىزنى تاللاڭ
2. تەرجىمەلىرىنى تەكشۈرۈڭ
3. قىيىن ياكى خاتا تەرجىمە بولسا توغرىلاڭ
4. PR يوللاڭ

### تىل كودلىرى

بىز ISO 639-1 كودلىرىنى (مەسىلەن، `ko`, `en`, `ja`, `ar`, `hi`) ئىشلىتىمىز، زۆرۈر بولغاندا رايونلۇق ئۆزگىرىشلەر بىلەن (مەسىلەن، `zh-CN`, `pt-BR`).
