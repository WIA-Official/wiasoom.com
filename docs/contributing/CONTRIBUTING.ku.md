## 🔌 چۆنیەتی ناردنی پلەگین

WIA SOOM سیستەمی پلەگینەکی پەیوەندیدار هەیە — دەتوانیت پلەگینی خۆت دروست بکەیت لە 5 خولەکدا.

### شێوەی خێرا
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### ڕێنمایی پڕ

بەخێرە بۆ **[بەشداریکردنی پلەگین](docs/PLUGIN_DEVELOPER_GUIDE.md)** بۆ:
- پەیوەندیدانی API پڕ
- نموونەی کارکردن
- فێرکاریەکان بەرز بەرەوپێش
- باشترین شێوەکان و یاساکانی پاراستن

### ناردنی پلەگینەکەت

1. Fork [Plugin Store](https://wiasoom.com)
2. پلەگینی خۆت بەرز بەرەوپێش `plugins/{your-plugin-name}/`
3. ناردنی پەیوەندیدانی پەیوەندیدان
4. پاش چاوپێکەوتن، پلەگینی تۆ لە فەرمی پلەگین بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش بەرز بەرەوپێش.

| `plugin:` | گۆڕینەوەی پلەگین |

## 🌐 بەشداریکردنەکان بۆ وەرگێڕانی (254 زمان)

WIA SOOM **254 زمان** پشتیوانی دەکات — لە ئامەریکا بۆ زولۆ، لەگەڵ بڕەی و زمانەکانەی RTL.

### چۆنیەتی کارکردنی وەرگێڕانی

- فایلی زمانە بنچینەیی: `src/renderer/src/i18n/en.json`
- هەموو 254 فایلی ��مان لە هەمان پەیوەندیدانە
- وەرگێڕانی لە ڕووی `scripts/translate-patch.js` (GPT-4o-mini API) دەکرێت

### چۆنیەتی بەشداریکردنی وەرگێڕانی

#### هەڵبژاردنی 1: ڕووکاری تایبەتی وەرگێڕانی

1. فایلی زمان بگەڕێنەوە: `src/renderer/src/i18n/{lang-code}.json`
2. ڕووکاری نادروست بگۆڕە
3. PR بەرز بەرەوپێش ناردن

#### هەڵبژاردنی 2: کلیلەکان نادروست بەرز بەرەوپێش

#### هەڵبژاردنی 3: ڕووکاری وەرگێڕانی مێشکی

زۆر لە 254 زمانەکانمان وەرگێڕانی مێشکی کردووە. ڕووکاری نیشتیمانی زۆر بەرز بەرەوپێشە!
