## ଆଚରଣ ସଂହିତା

ଆମେ ସମସ୍ତଙ୍କ ପାଇଁ ଏକ ସ୍ୱାଗତଜନକ ଏବଂ ସାମ୍ମିଳିତ ଅନୁଭବ ପ୍ରଦାନ କରିବାକୁ ପ୍ରତିବଦ୍ଧ।

- **ସମ୍ମାନିତ ହୁଅନ୍ତୁ।** ସମସ୍ତଙ୍କୁ ଗରିମା ସହିତ ବ୍ୟବହାର କରନ୍ତୁ।
- **ନିର୍ମାଣାତ୍ମକ ହୁଅନ୍ତୁ।** ଧ୍ୟାନ ଦିଆଯାଇଥିବା ପ୍ରତିକ୍ରିୟା ଦିଅନ୍ତୁ, ବିନା ନଷ୍ଟକାରୀ ଆଲୋଚନା।
- **ସାମ୍ମିଳିତ ହୁଅନ୍ତୁ।** ଆମେ 254 ଭାଷାକୁ ସମର୍ଥନ କରୁଛୁ ଏବଂ ପୃଥିବୀର ପ୍ରତିଟି ଦେଶରୁ ଯୋଗଦାନକାରୀଙ୍କୁ ସ୍ୱାଗତ କରୁଛୁ।
- **କୌଣସି ହରାସ୍ମେଣ୍ଟ ନାହିଁ।** କୌଣସି ପ୍ରକାରର ଭେଦଭାବ ପାଇଁ ଶୂନ୍ୟ ସହିତ ଧୃଷ୍ଟିକୋଣ।

## 🌐 ଅନୁବାଦ ଯୋଗଦାନ (254 ଭାଷା)

WIA SOOM **254 ଭାଷା** କୁ ସମର୍ଥନ କରେ — ଅମ୍ହାରିକରୁ ��ୁଲୁ ଯାଏ, ବ୍ରେଇଲ୍ ଏବଂ RTL ଭାଷାଗୁଡିକୁ ସମେତ।

### କିପରି ଅନୁବାଦ କାମ କରେ

- ମୌଳିକ ଭାଷା ଫାଇଲ୍: `src/renderer/src/i18n/en.json`
- ସମସ୍ତ 254 ଭାଷା ଫାଇଲ୍ ସେହି ଡିରେକ୍ଟରୀରେ ଅଛି
- ଅନୁବାଦ `scripts/translate-patch.js` (GPT-4o-mini API) ଦ୍ୱାରା କରାଯାଇଛି

### କିପରି ଅନୁବାଦ ଯୋଗଦାନ କରିବେ

#### ବିକଳ୍ପ 1: ଏକ ବିଶେଷ ଅନୁବାଦ ସଂଶୋଧନ କରନ୍ତୁ

1. ଭାଷା ଫାଇଲ୍ ଖୋଜନ୍ତୁ: `src/renderer/src/i18n/{lang-code}.json`
2. ତ୍ରୁଟି ଅନୁବାଦ ସଂଶୋଧନ କରନ୍ତୁ
3. ପରିବର୍ତ୍ତନ ସହିତ PR ସମ୍ପ୍ରେଷଣ କରନ୍ତୁ

#### ବିକଳ୍ପ 2: ଅନୁପସ୍ଥିତ କୀଗୁଡିକୁ ଯୋଗ କରନ୍ତୁ
§§§CHUNK_SEPARATOR§§§
#### ବିକଳ୍ପ 3: ମେସିନ୍ ଅନୁବାଦଗୁଡିକୁ ସମୀକ୍ଷା କରନ୍ତୁ

ଆମ 254 ଭାଷାର ବହୁତ ଗୁଡିକୁ ମେସିନ୍ ଅନୁବାଦ କରାଯାଇଛି। ନେଟିଭ୍ ସ୍ପୀକର ସମୀକ୍ଷା ଅତ୍ୟନ୍ତ ମୂଲ୍ୟବାନ!

1. ଆପଣଙ୍କର ଭାଷା ଫାଇଲ୍ ବାଛନ୍ତୁ
2. ଅନୁବାଦଗୁଡିକୁ ସମୀକ୍ଷା କରନ୍ତୁ
3. କୌଣସି ଅସୁବିଧା ଅଥବା ତ୍ରୁଟି ଅନୁବାଦ ସଂଶୋଧନ କରନ୍ତୁ
4. PR ସମ୍ପ୍ରେଷଣ କରନ୍ତୁ

### ଭାଷା କୋଡ୍

ଆମେ ସାଧାରଣ ISO 639-1 କୋଡ୍ ବ୍ୟବହାର କରୁଛୁ (ଉଦାହରଣ ସ୍ୱରୂପ, `ko`, `en`, `ja`, `ar`, `hi`) ଆବଶ୍ୟକ ହେଲେ ଅଞ୍ଚଳୀୟ ପ୍ରକାରରେ (ଉଦାହରଣ ସ୍ୱରୂପ, `zh-CN`, `pt-BR`)।
