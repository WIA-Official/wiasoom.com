## 🔌 Як подати плагін

WIA SOOM має потужну систему плагінів — ви можете створити свій власний плагін за 5 хвилин.

### Швидкий старт
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### Повний посібник

Прочитайте **[Посібник для розробників плагінів](docs/PLUGIN_DEVELOPER_GUIDE.md)** для:
- Повної документації API
- Робочих прикладів
- Покрокових навчальних посібників
- Найкращих практик та правил безпеки

### Подайте свій плагін

1. Зробіть форк [Plugin Store](https://wiasoom.com)
2. Додайте свій плагін до `plugins/{your-plugin-name}/`
3. Подайте запит на злиття
4. Після перевірки ваш плагін з'явиться в Магазині плагінів для всіх користувачів!

## 🔀 Як подати запит на злиття

### Для основного додатку (wia-soom)

1. Зробіть форк репозиторію
2. Створіть гілку функції: `git checkout -b feat/my-feature`
3. Зробіть свої зміни
4. Протестуйте локально:
   ```bash
   ```
5. Зафіксуйте з чітким повідомленням:
   ```
   feat: add dark mode toggle to settings
   ```
6. Вишліть та відкрийте PR проти `main`

### Конвенція повідомлень комітів

| Префікс | Використовується для |
|--------|---------|
| `feat:` | Нова функція |
| `fix:` | Виправлення помилки |
| `docs:` | Тільки документація |
| `refactor:` | Переструктурування коду (без зміни поведінки) |
| `i18n:` | Оновлення перекладів |
| `plugin:` | Зміни, пов'язані з плагінами |

### Контрольний список PR

- [ ] Код працює без помилок
- [ ] Немає зашитих рядків (використовуйте ключі i18n)
- [ ] Немає `console.log`, залишених у виробничому коді
- [ ] Існуючі тести все ще проходять

## 🌐 Внески в переклади (254 мови)

WIA SOOM підтримує **254 мови** — від амхарської до зулуської, включаючи шрифт Брайля та мови з RTL.

### Як працює переклад

- Файл базової мови: `src/renderer/src/i18n/en.json`
- Усі 254 файли мов знаходяться в одній директорії
- Переклад виконується через `scripts/translate-patch.js` (GPT-4o-mini API)

### Як внести внески в переклади

#### Варіант 1: Виправити конкретний переклад

1. Знайдіть файл мови: `src/renderer/src/i18n/{lang-code}.json`
2. Виправте неправильний переклад
3. Подайте PR зі зміною

#### Варіант 2: Додати відсутні ключі
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### Варіант 3: Переглянути машинні переклади

Багато з наших 254 мов були машинно перекладені. Відгуки носіїв мови є надзвичайно цінними!

1. Виберіть свій файл мови
2. Перегл��ньте переклади
3. Виправте будь-які незручні або неправильні переклади
4. Подайте PR

### Коди мов

Ми використовуємо стандартні коди ISO 639-1 (наприклад, `ko`, `en`, `ja`, `ar`, `hi`) з регіональними варіантами, де це необхідно (наприклад, `zh-CN`, `pt-BR`).
