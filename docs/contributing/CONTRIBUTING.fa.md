1. به [GitHub Issues](https://github.com/WIA-Official/wiasoom.com/issues) بروید
2. روی **"New Issue"** کلیک کنید
3. الگوی **"Bug Report"** را انتخاب کنید
4. شامل کنید:
   - نسخه WIA SOOM (تنظیمات → درباره)
   - سیستم‌عامل و نسخه (Windows/macOS/Linux)
   - مراحل بازتولید
   - رفتار مورد انتظار در مقابل رفتار واقعی
   - اسکرین‌شات‌ها یا خروجی ترمینال در صورت امکان

## 🔌 چگونه یک پلاگین ارسال کنیم

WIA SOOM دارای یک سیستم پلاگین قدرتمند است — شما می‌توانید پلاگین خود را در 5 دقیقه بسازید.

### شروع سریع
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### راهنمای کامل

راهنمای **[توسعه‌دهنده پلاگین](docs/PLUGIN_DEVELOPER_GUIDE.md)** را برای:
- مرجع کامل API
- مثال‌های کاربردی
- آموزش‌های مرحله به مرحله
- بهترین شیوه‌ها و قوانین امنیتی بخوانید

### پلاگین خود را ارسال کنید

1. [Plugin Store](https://wiasoom.com) را فورک کنید
2. پلاگین خود را به `plugins/{your-plugin-name}/` اضافه کنید
3. یک درخواست کشش ارسال کنید
4. پس از بررسی، پلاگین شما در فروشگاه پلاگین برای تمام کاربران ظاهر می‌شود!

4. به صورت محلی تست کنید:

   ```

   ```
6. تغییرات را پوش کنید و یک PR در برابر `main` باز کنید

### کنوانسیون پیام کامیت

| پیشوند | برای استفاده |
|--------|---------------|
| `feat:` | ویژگی جدید |
| `fix:` | رفع اشکال |
| `docs:` | فقط مستندات |
| `refactor:` | بازسازی کد (بدون تغییر رفتار) |
| `i18n:` | به‌روزرسانی‌های ترجمه |
| `plugin:` | تغییرات مربوط به پلاگین |

### چک لیست PR

- [ ] کد بدون خطا اجرا می‌شود
- [ ] هیچ رشته‌ای به صورت سخت‌کد نشده است (از کلیدهای i18n استفاده کنید)

- [ ] تست‌های موجود هنوز پاس می‌شوند

## 🌐 مشارکت‌های ترجمه (254 زبان)

WIA SOOM از **254 زبان** پشتیبانی می‌کند — از آماری به زولو، شامل بریل و زبان‌های RTL.

### نحوه کار ترجمه

- فایل زبان پایه: `src/renderer/src/i18n/en.json`
- تمام 254 فایل زبان در همان دایرکتوری هستند
- ترجمه از طریق `scripts/translate-patch.js` (GPT-4o-mini API) انجام می‌شود

### چگونه می‌توان به ترجمه‌ها کمک کرد

#### گزینه 1: اصلاح یک ترجمه خاص

1. فایل زبان را پیدا کنید: `src/renderer/src/i18n/{lang-code}.json`
2. ترجمه نادرست را اصلاح کنید
3. یک PR با تغییر ارسال کنید

#### گزینه 2: افزودن کلیدهای گمشده
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### گزینه 3: بررسی ترجمه‌های ماشینی

بسیاری از 254 زبان ما به صورت ماشینی ترجمه شده‌اند. بررسی‌های سخنرانان بومی بسیار ارزشمند است!

1. فایل زبان خود را انتخاب کنید
2. ترجمه‌ها را بررسی کنید
3. هر ترجمه نامناسب یا نادرست را اصلاح کنید
4. یک PR ارسال کنید

### کدهای زبان

ما از کدهای استاندارد ISO 639-1 (به عنوان مثال، `ko`, `en`, `ja`, `ar`, `hi`) با واریانت‌های منطقه‌ای در صورت نیاز استفاده می‌کنیم (به عنوان مثال، `zh-CN`, `pt-BR`).
