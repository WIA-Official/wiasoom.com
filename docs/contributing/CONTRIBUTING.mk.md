## Кодекс на однесување

Ние сме посветени на обезбедување на добредојдена и инклузивна средина за сите.

- **Бидете почитувани.** Третирајте ги сите со достоинство.
- **Бидете конструктивни.** Понудете корисни повратни информации, а не деструктивна критика.
- **Бидете инклузивни.** Поддржуваме 254 јазици и ги поздравуваме придонесувачите од секоја земја на Земјата.
- **Нема вознемирување.** Нулта толеранција за каква било дискриминација.

## 🐛 Како да пријавите грешки

1. Оди на [GitHub Issues](https://github.com/WIA-Official/wiasoom.com/issues)
2. Кликнете **"Нова грешка"**
3. Изберете **"Шаблон за пријава на грешка"**
4. Вклучете:
   - Верзија на WIA SOOM (Поставки → За)
   - ОС и верзија (Windows/macOS/Linux)
   - Чекори за репродукција
   - Очекувано спротивно на фактичкото однесување
   - Слики од екранот или излез од терминалот ако е можно

## 🔌 Како да поднесете плугин

WIA SOOM има моќен систем за плугини — можете да изградите свој плугин за 5 минути.

### Брз старт
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### Полн водич

Прочитајте го **[Водичот за развивачи на плугини](docs/PLUGIN_DEVELOPER_GUIDE.md)** за:
- Комплетна API референца
- Работни примери
- Упатства чекор по чекор
- Најдобри практики и правила за безбедност

### Поднесете го вашиот плугин

1. Форкирајте [Plugin Store](https://wiasoom.com)
2. Додадете го вашиот плугин во `plugins/{your-plugin-name}/`
3. Поднесете Pull Request
4. По прегледот, вашиот плугин ќе се појави во Plugin Store за сите корисници!

## 🌐 Придонеси за превод (254 јазици)

WIA SOOM поддржува **254 јазици** — од амхарски до зулу, вклучувајќи Брајл и јазици со РТЛ.

### Како функционира преводот

- Основен јазичен фајл: `src/renderer/src/i18n/en.json`
- Сите 254 јазични фајлови се во истата директориум
- Преводот се прави преку `scripts/translate-patch.js` (GPT-4o-mini API)

### Како да придонесете со преводи

#### Опција 1: Поправете специфичен превод

1. Најдете го јазичниот фајл: `src/renderer/src/i18n/{lang-code}.json`
2. Поправете го неточниот превод
3. Поднесете PR со промената

#### Опција 2: Додадете недостасувачки клучеви
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### Опција 3: Прегледајте машински преводи

Многу од нашите 254 јазици се машински преведени. Прегледите од носители на јазикот се неверојатно вредни!

1. Изберете го вашиот јазичен фајл
2. Прегледајте ги преводите
3. Поправете ги сите неугодни или неточни преводи
4. Поднесете PR

### Јазични кодови

Користиме стандардни ISO 639-1 кодови (на пр., `ko`, `en`, `ja`, `ar`, `hi`) со регионални варијанти каде што е потребно (на пр., `zh-CN`, `pt-BR`).
