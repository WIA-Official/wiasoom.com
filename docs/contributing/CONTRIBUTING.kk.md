## 🔌 Плагинді қалай жіберуге болады

WIA SOOM қуатты плагин жүйесіне ие — сіз 5 минут ішінде өз плагиніңізді жасай аласыз.

### Жылдам бастау
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### Толық нұсқаулық

**[Плагин әзірлеуші нұсқаулығын](docs/PLUGIN_DEVELOPER_GUIDE.md)** оқыңыз:
- Толық API анықтамасы
- Жұмыс істейтін мысалдар
- Қадамдық оқулықтар
- Ең жақсы тәжірибелер мен қауіпсіздік ережелері

### Плагиніңізді жіберіңіз

1. [Plugin Store](https://wiasoom.com) репозиторийін форк жасаңыз
2. Плагиніңізді `plugins/{your-plugin-name}/` папкасына қосыңыз
3. Pull Request жіберіңіз
4. Шолу аяқталғаннан кейін, плагиніңіз барлық пайдаланушылар үшін Плагин Дүкенінде пайда болады!


### Коммит хабарламасы конвенциясы

| Префикс | Пайдалану үшін |
|---------|----------------|
| `feat:` | Жаңа функция |
| `fix:` | Қате түзету |
| `docs:` | Тек құжаттама |
| `refactor:` | Код құрылымын өзгерту (мінез-құлық өзгеріссіз) |
| `i18n:` | Аударма жаңартулары |
| `plugin:` | Плагинмен байланысты өзгерістер |

### PR Чек-парағы

## 🌐 Аударма үлестері (254 тіл)

WIA SOOM **254 тіл** қолдайды — Амхар тілінен Зулу тіліне дейін, Брайль және RTL тілдерін қоса.

### Аударма қалай жұмыс істейді

- Негізгі тіл файлы: `src/renderer/src/i18n/en.json`
- Барлық 254 тіл файлы бір каталогта
- Аударма `scripts/translate-patch.js` (GPT-4o-mini API) арқылы жүзеге асырылады

### Аудармаға үлес қосу жолдары

#### 1-ші нұсқа: Белгілі бір аударманы түзету

1. Тіл файлын табыңыз: `src/renderer/src/i18n/{lang-code}.json`
2. Дұрыс емес аударманы түзетіңіз
3. Өзгерісті PR арқылы жіберіңіз

#### 2-ші нұсқа: Жоғалған кілттерді қосу
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### 3-ші нұсқа: Машинамен аударылған аудармаларды тексеру

Біздің 254 тілдің көпшілігі машинамен аударылған. Туған тілде сөйлейтіндердің тексеруі өте құнды!

1. Тіл файлыңызды таңдаңыз
2. Аудармаларды тексеріңіз
3. Қиын немесе дұрыс емес аудармаларды түзетіңіз
4. PR жіберіңіз

### Тіл кодтары

Біз стандартты ISO 639-1 кодтарын (мысалы, `ko`, `en`, `ja`, `ar`, `hi`) қажетті жерлерде аймақтық нұсқалармен (мысалы, `zh-CN`, `pt-BR`) қолданамыз.
