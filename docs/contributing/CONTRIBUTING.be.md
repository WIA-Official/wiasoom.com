## Код паводзінаў

Мы імкнемся забяспечыць прыязны і інклюзіўны досвед для ўсіх.

- **Будзьце паважлівымі.** Ставяцеся да ўсіх з годнасцю.
- **Будзьце канструктыўнымі.** Падавайце карысныя водгукі, а не разбуральную крытыку.
- **Будзьце інклюзіўнымі.** Мы падтрымліваем 254 мовы і вітаем укладчыкаў з кожнай краіны на Зямлі.
- **Без пераследу.** Нулявая талерантнасць да дыскрымінацыі любога кшталту.

## 🐛 Як паведаміць пра памылкі

1. Перайдзіце на [GitHub Issues](https://github.com/WIA-Official/wiasoom.com/issues)
2. Націсніце **"New Issue"**
3. Выберыце шаблон **"Bug Report"**
4. Уключыце:
   - Версію WIA SOOM (Настройки → Аб праграме)
   - АС і версію (Windows/macOS/Linux)
   - Крокі для аднаўлення
   - Чаканае і фактычнае паводзіны
   - Скрыншоты або вывад з тэрмінала, калі магчыма

## 🔌 Як прадставіць плагін

WIA SOOM мае магутную сістэму плагінаў — вы можаце стварыць свой уласны плагін за 5 хвілін.

### Хуткі старт
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### Поўны даведнік

Чытайце **[Даведнік распрацоўніка плагінаў](docs/PLUGIN_DEVELOPER_GUIDE.md)** для:
- Поўнай даведкі па API
- Працоўных прыкладаў
- Пакрокавых навучанняў
- Лепшых практык і правілаў бяспекі

### Прадстаўце свой плагін

1. Скапіруйце [Plugin Store](https://wiasoom.com)
2. Дадайце свой плагін у `plugins/{your-plugin-name}/`
3. Прадстаўце Pull Request
4. Пасля агляду ваш пла��ін з'явіцца ў Plugin Store для ўсіх карыстальнікаў!

### Для асноўнага прыкладання (wia-soom)

1. Скапіруйце рэпазіторый
2. Стварыце галіна функцыі: `git checkout -b feat/my-feature`
3. Унясеце змены
4. Праверце лакальна:
   ```bash
   ```
5. Зафіксуйце з ясным паведамленнем:
   ```
   feat: add dark mode toggle to settings
   ```
6. Запушчыце і адкрыйце PR супраць `main`

### Правілы паведамлення аб каміце

| Прэфікс | Выкарыстоўваецца для |
|---------|---------------------|
| `feat:` | Новая функцыя |
| `fix:` | Выпраўленне памылкі |
| `docs:` | Толькі дакументацыя |
| `refactor:` | Рэструктурызацыя кода (без змены паводзін) |
| `i18n:` | Абнаўленні перакладаў |
| `plugin:` | Змены, звязаныя з плагінамі |

### Чэк-ліст PR

- [ ] Код працуе без памылак
- [ ] Няма зафіксаваных радкоў (выкарыстоўвайце ключы i18n)
- [ ] Няма `console.log` у вытворчым кодзе
- [ ] Існуючыя тэсты па-ранейшаму праходзяць

## 🌐 Уклады ў пераклад (254 мовы)

WIA SOOM падтрымлівае **254 мовы** — ад амхарскай да зулускай, уключаючы Брайль і мовы з RTL.

### Як працуе пераклад

- Файл базавай мовы: `src/renderer/src/i18n/en.json`
- Усе 254 файлы моў знаходзяцца ў адной дырэкторыі
- Пераклад выконваецца праз `scripts/translate-patch.js` (GPT-4o-mini API)

### Як унесці ўклад у пераклады

#### Варыянт 1: Выпраўце канкрэтны пераклад

1. Знайдзіце файл мовы: `src/renderer/src/i18n/{lang-code}.json`
2. Выпраўце няправільны пераклад
3. Прадстаўце PR з зменай

#### Варыянт 2: Дадайце адсутныя ключы
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### Варыянт 3: Праверце машынныя пераклады

Многія з нашых 254 моў былі перакладзены машынай. Агляд носьбітаў мовы вельмі каштоўны!

1. Выберыце свой файл мовы
2. Праверце пераклады
3. Выпраўце любыя нязручныя або няправільныя пераклады
4. Прадстаўце PR

### Коды моў

Мы выкарыстоўваем стандартныя коды ISO 639-1 (напрыклад, `ko`, `en`, `ja`, `ar`, `hi`) з рэгіянальнымі варыянтамі, дзе гэта неабходна (напрыклад, `zh-CN`, `pt-BR`).
