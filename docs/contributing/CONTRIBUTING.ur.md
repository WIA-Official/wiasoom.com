## Conduct کا ضابطہ

ہم ہر ایک کے لیے ایک خوش آمدید اور شمولیتی تجربہ فراہم کرنے کے لیے پرعزم ہیں۔

- **احترام کریں۔** ہر ایک کے ساتھ عزت سے پیش آئیں۔
- **تعمیراتی بنیں۔** مددگار فیڈبیک فراہم کریں، تخریبی تنقید نہیں۔
- **شمولیتی بنیں۔** ہم 254 زبانوں کی حمایت کرتے ہیں اور دنیا کے ہر ملک سے شراکت داروں کا خیرمقدم کرتے ہیں۔
- **ہراسانی نہیں۔** کسی بھی قسم کی تفریق کے لیے صفر برداشت۔

## 🔌 پلگ ان جمع کرنے کا طریقہ

WIA SOOM میں ایک طاقتور پلگ ان سسٹم ہے — آپ 5 منٹ میں اپنا پلگ ان بنا سکتے ہیں۔

### فوری آغاز
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### مکمل رہنما

**[پلگ ان ڈویلپر گائیڈ](docs/PLUGIN_DEVELOPER_GUIDE.md)** پڑھیں:
- مکمل API حوالہ
- کام کرنے کی مثالیں
- مرحلہ وار سبق
- بہترین طریقے اور سیکیورٹی کے اصول

### اپنا پلگ ان جمع کریں

1. [Plugin Store](https://wiasoom.com) کو فورک کریں
2. اپنے پلگ ان کو `plugins/{your-plugin-name}/` میں شامل کریں
3. ایک پول ریکویسٹ جمع کریں
4. جائزے کے بعد، آپ کا پلگ ان تمام صارفین کے لیے پلگ ان اسٹور میں ظاہر ہوتا ہے!

## 🌐 ترجمے کی شراکت (254 زبانیں)

WIA SOOM **254 زبانوں** کی حمایت کرتا ہے — امہاریق سے زولو تک، بشمول بریل اور RTL زبانیں۔

### ترجمہ کیسے کام کرتا ہے

- بنیادی زبان کی فائل: `src/renderer/src/i18n/en.json`
- تمام 254 زبان کی فائلیں اسی ڈائریکٹری میں ہیں
- ترجمہ `scripts/translate-patch.js` (GPT-4o-mini API) کے ذریعے کیا جاتا ہے

### ترجمے میں شراکت کیسے کریں

#### آپشن 1: مخصوص ترجمہ درست کریں

1. زبان کی فائل تلاش کریں: `src/renderer/src/i18n/{lang-code}.json`
2. غلط ترجمہ درست کریں
3. تبدیلی کے ساتھ ایک PR جمع کریں

#### آپشن 2: غائب کیز شامل کریں
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### آپشن 3: مشین ترجموں کا جائزہ لیں

ہماری 254 زبانوں میں سے بہت سی مشین کے ذریعے ترجمہ کی گئی ہیں۔ مقامی بولنے والوں کے جائزے انتہائی قیمتی ہیں!

1. اپنی زبان کی فائل منتخب کریں
2. ترجموں کا جائزہ لیں
3. کسی بھی عجیب یا غلط ترجمے کو درست کریں
4. ایک PR جمع کریں

### زبان کے کوڈز

ہم معیاری ISO 639-1 کوڈز (جیسے `ko`, `en`, `ja`, `ar`, `hi`) کا استعمال کرتے ہیں جہاں ضرورت ہو علاقائی متغیرات (جیسے `zh-CN`, `pt-BR`) کے ساتھ۔
