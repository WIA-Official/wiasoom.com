## 🌐 অনুবাদৰ অৱদান (২৫৪ ভাষা)

WIA SOOM **২৫৪ ভাষা** সমৰ্থন কৰে — আমহাৰিকৰ পৰা জুলু, ব্ৰেইল আৰু RTL ভাষাসমূহ অন্তৰ্ভুক্ত।

### অনুবাদ কেনেকৈ কাম কৰে

- বেচ ভাষাৰ ফাইল: `src/renderer/src/i18n/en.json`
- সকলো ২৫৪ ভাষাৰ ফাইল একে ডিৰেক্টৰিত আছে
- অনুবাদ `scripts/translate-patch.js` (GPT-4o-mini API)ৰ জৰিয়তে কৰা হয়

### অনুবাদত অৱদান কেনেকৈ জনাব

#### বিকল্প ১: এটা নিৰ্দ���ষ্ট অনুবাদ মাৰ্জ কৰক

1. ভাষাৰ ফাইল বিচাৰক: `src/renderer/src/i18n/{lang-code}.json`
2. ভুল অনুবাদ মাৰ্জ কৰক
3. পৰিৱৰ্তনৰ সৈতে এটা PR জমা দিয়ক

#### বিকল্প ৩: মেচিন অনুবাদ পৰ্যালোচনা কৰক

আমাৰ ২৫৪ ভাষাৰ বহুতো মেচিন-অনুবাদিত। স্থানীয় বক্তাৰ পৰ্যালোচনা অত্যন্ত মূল্যবান!

3. যিকোনো অস্বস্তিকৰ বা ভুল অনুবাদ মাৰ্জ কৰক
4. এটা PR জমা দিয়ক

### ভাষাৰ ক'ডসমূহ
