## 🔌 plugin ᠪᡝ ᡝᠯᡝᠮᠪᡳ ᠪᡠᡵᡝ

WIA SOOM ᡩᡝ ᡝᡵᡩᡝᠮᡠ ᡥᡡᠰᡠᠨᡤᡤᠠ ᡝᡵᡳᠨ plugin ᡶᡠᠨᡩᠠᠯᡳᠨ ᠪᡳ — ᠰᡳ ᡠᠰᡠᠨ ᡳ ᡩᠣᡵᡤᡳᡩᡝ ᠪᡝᠶᡝᡳ plugin ᠪᡝ ᠠᡵᠠᠮᡝ ᠮᡠᡨᡝᠪᡠᠮᠪᡳ.

### ᡥᡠᡩᡠᠨ ᡩᡝᡵᡳᠪᡠᡵᡝ

```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```

### ᡤᡝᡵᡝᠨ ᠵᡠᡵᡤᠠᠨ

**[Plugin Developer Guide](docs/PLUGIN_DEVELOPER_GUIDE.md)** ᠪᡝ ᡨᡠᠸᠠ, ᡝᡵᡝ ᠪᠠᡳᡨᠠᠯᠠᡵᠠ ᠪᡳ:
- ᡤᡝᡵᡝᠨ API ᡳ ᡩᠠᡥᠠᠨ
- ᡶᡠᠨᡩᡝᠯᡝᡵᡝ ᡳ ᡩᡠᡵᡠᠰᡠᠨ
- ᡝᠮᡠ ᡝᠮᡠ ᡳ ᡨᠠᠴᡳᡵᠠ
- ᠰᠠᡳᠨ ᡩᠣᡵᠣ ᠵᠠᡴᠠ ᠠᡴᡩᡠᠨ ᡳ ᡴᠣᠣᠯᡳ

### plugin ᠪᡝ ᡝᠯᡝᠮᠪᡳ ᠪᡠ

1. [Plugin Store](https://wiasoom.com) ᠪᡝ fork ᠠᡵᠠ
2. ᠰᡳᠨᡳ plugin ᠪᡝ `plugins/{your-plugin-name}/` ᡩᡝ ᡨᡝᠪᡠ
3. Pull Request ᠪᡝ ᡝᠯᡝᠮᠪᡳ ᠪᡠ
4. ᡴᡳᠮᠴᡳᠮᡝ ᠪᡝ ᡤᡳᠮᡝ, ᠰᡳᠨᡳ plugin ᡤᡝᡵᡝᠨ ᠪᠠᡳᡨᠠᠯᠠᡵᠠ ᡳ ᠵᠠᠯᡳᠨ Plugin Store ᡩᡝ ᡨᡠᠴᡳᠮᠪᡳ!

## 🔀 Pull Request ᠪᡝ ᡝᠯᡝᠮᠪᡳ ᠪᡠᡵᡝ

### ᡠᠵᡠᡳ ᠠᡶᠠᡥᠠ ᡩᡝ (wia-soom)

1. ᡥᡡᠰᡠᠨᡤᡤᠠ ᡝᡵᡳᠨ ᠪᡝ fork ᠠᡵᠠ
2. ᡳᠴᡝ ᡤᠠᡵᡤᠠᠨ ᠠᡵᠠ: `git checkout -b feat/my-feature`
3. ᡥᠠᠯᡥᡡᠨ ᠪᡝ ᡩᠠᠰᡳᠮᠪᡠ
4. ᠪᡝᠶᡝᡳᡩᡝ ᡤᡳᠮᡳ:
   ```bash
   ```
5. ᡤᡝᠯᡳᠨ ᡤᡳᠰᡠᠨ ᡳ commit ᠪᡝ ᠠᡵᠠ:
   ```
   feat: add dark mode toggle to settings
   ```
6. Push ᠠᡵᠠᠮᡝ `main` ᡩᡝ PR ᠪᡝ ᠨᡝᡳ

### Commit ᡳ ᡤᡳᠰᡠᠨ ᡳ ᡴᠣᠣᠯᡳ

| ᡶᡝᠶᡝᡵᡤᡳ | ᠪᠠᡳᡨᠠᠯᠠᡵᠠ ᡳ ᡶᡠᠨᡩᡝᠯᡝᠨ |
|--------|---------|
| `feat:` | ᡳᠴᡝ ᡥᠠᡴᡳᠯᠠᡵᠠ |
| `fix:` | ᡝᠨᡩᡠᡵᡳᠩᡤᡝ ᡝᠨᡩᡝᠪᡠᡵᡝ ᡳ ᡩᠠᠰᡳᡥᠠ |
| `docs:` | ᡩᠠᠨᡤᠰᡝ ᡩᡝᡵᡳᠪᡠᡵᡝ ᡨᡝᡳᠯᡝ |
| `refactor:` | ᡶᡠᠨᡩᠠᠯᡳᠨ ᡳ ᡩᠠᠰᡳᡥᠠ (ᡶᡠᠨᡩᡝᠯᡝᠨ ᡥᠠᠯᡥᡡᡵᠠᡴᡡ) |
| `i18n:` | ᡠᠪᠠᠯᡳᠶᠠᠮᠪᡠᡵᡝ ᡳ ᡧᡳᠨᡝᡩᠠᠰᡳᡥᠠ |
| `plugin:` | plugin ᡩᡝ ᡥᠠᠪᡧᠠᡥᠠ ᡥᠠᠯᡥᡡᠨ |

## 🌐 ᡠᠪᠠᠯᡳᠶᠠᠮᠪᡠᡵᡝ ᡳ ᠠᠴᠠᠪᡠᡥᠠ (254 ᡤᡳᠰᡠᠨ)

WIA SOOM **254 ᡤᡳᠰᡠᠨ** ᠪᡝ ᡩᠣᠰᡳᠮᠪᡠᠮᡝ — Amharic ᠴᡳ Zulu ᡩᡝ ᡳᠰᡳᠨᠠᠮᡝ, Braille ᠵᠠᡴᠠ RTL ᡤᡳᠰᡠᠨ ᠪᡝ ᡩᠣᠰᡳᠮᠪᡠᡥᠠ ᠪᡳ.

### ᡠᠪᠠᠯᡳᠶᠠᠮᠪᡠᡵᡝ ᡤᡝᠯᡳ ᡶᡠᠨᡩᡝᠯᡝᠮᠪᡳ

- ᡶᡠᠯᡤᡳᠶᠠᠨ ᡤᡳᠰᡠᠨ ᡳ ᡩᠠᠨᡤᠰᡝ: `src/renderer/src/i18n/en.json`
- 254 ᡤᡳᠰᡠᠨ ᡳ ᡩᠠᠨᡤᠰᡝ ᡤᡝᡵᡝᠨᡳ ᡝᡵᡝ ᡩᡝᡵᡳᡥᡡᠨ ᡩᡝ ᠪᡳ
- ᡠᠪᠠᠯᡳᠶᠠᠮᠪᡠᡵᡝ ᠪᡝ `scripts/translate-patch.js` (GPT-4o-mini API) ᡳ ᠮᡠᡩᠠᠨ ᡩᡝ ᠠᡵᠠᠮᠪᡳ

### ᡠᠪᠠᠯᡳᠶᠠᠮᠪᡠᡵᡝ ᡩᡝ ᠠᠴᠠᠪᡠᡵᡝ

#### ᡝᠮᡠᠴᡳ ᠰᡝᠯᡝᠨ: ᡝᠮᡠ ᡠᠪᠠᠯᡳᠶᠠᠮᠪᡠᡵᡝ ᠪᡝ ᡩᠠᠰᡳᡥᠠ

1. ᡤᡳᠰᡠᠨ ᡳ ᡩᠠᠨᡤᠰᡝ ᠪᡝ ᠪᠠᡳ: `src/renderer/src/i18n/{lang-code}.json`
2. ᡝᡴᡝ ᠠᡴᡡ ᡠᠪᠠᠯᡳᠶᠠᠮᠪᡠᡵᡝ ᠪᡝ ᡩᠠᠰᡳ
3. ᡥᠠᠯᡥᡡᠨ ᠪᡝ PR ᡳ ᠮᡠᡩᠠᠨ ᡩᡝ ᡝᠯᡝᠮᠪᡳ ᠪᡠ

#### ᠵᠠᡳᠴᡳ ᠰᡝᠯᡝᠨ: ᡝᡴᡝᡥᡝᡴᡡ ᡥᡝᠰᡝᠨ ᠪᡝ ᠨᡝᠮᡝ

```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```

#### ᡳᠯᠠᠴᡳ ᠰᡝᠯᡝᠨ: ᠰᡝᠵᡝᠨ ᡳ ᡠᠪᠠᠯᡳᠶᠠᠮᠪᡠᡵᡝ ᠪᡝ ᡴᡳᠮᠴᡳ

ᠮᡠᠰᡝᡳ 254 ᡤᡳᠰᡠᠨ ᡤᡝᡵᡝᠨᡳ ᠰᡝᠵᡝᠨ ᡳ ᡠᠪᠠᠯᡳᠶᠠᠮᠪᡠᡥᠠᠨ. ᡥᡝᠨᡳ ᡤᡳᠰᡠᠨ ᡳ ᠨᡳᠶᠠᠯᠮᠠ ᡳ ᡴᡳᠮᠴᡳᡵᡝ ᡝᡵᡩᡝᠮᡠ ᡥᡡᠰᡠᠨᡤᡤᠠ ᡝᡵᡳᠨ!

1. ᠰᡳᠨᡳ ᡤᡳᠰᡠᠨ ᡳ ᡩᠠᠨᡤᠰᡝ ᠪᡝ ᠰᠣᠨᠵᠣ
2. ᡠᠪᠠᠯᡳᠶᠠᠮᠪᡠᡵᡝ ᠪᡝ ᡴᡳᠮᠴᡳ
3. ᡝᡴᡝ ᠠᡴᡡ ᠶᠠ ᠵᡠᡵᡤᠠᠨ ᠠᡴᡡ ᡠᠪᠠᠯᡳᠶᠠᠮᠪᡠᡵᡝ ᠪᡝ ᡩᠠᠰᡳ
4. PR ᠪᡝ ᡝᠯᡝᠮᠪᡳ ᠪᡠ

### ᡤᡳᠰᡠᠨ ᡳ ᡴᠣᡩᠠᠯᡳ

ᠮᡠᠰᡝ ISO 639-1 ᡳ ᡶᡠᠯᡤᡳᠶᠠᠨ ᡴᠣᡩᠠᠯᡳ ᠪᡝ ᠪᠠᡳᡨᠠᠯᠠᠮᠪᡳ (ᡩᡠᡵᡠᠰᡠᠨ: `ko`, `en`, `ja`, `ar`, `hi`), ᠪᠠ ᡩᡝ ᠪᠠᡳᡨᠠᠯᠠᡵᠠ ᡳ ᡥᠠᠯᠪᠠᡵᡳ ᡤᡡᠨᡳᠨ ᠪᡳ (ᡩᡠᡵᡠᠰᡠᠨ: `zh-CN`, `pt-BR`).
