- **Төзек булыгыз.** Полезный фикерләр тәкъдим итегез, разрушительный критика түгел.
- **Инклюзив булыгыз.** Без 254 телне хуплыйбыз һәм Җирнең һәр иленнән өлеш кертүчеләрне каршы алабыз.

## 🔌 Плагинны ничек тапшырырга

WIA SOOM көчле плагин системасына ия — сез 5 минутта үз плагинны булдыра аласыз.

### Кыскача башлау
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### Тулы Гид

**[Плагин Разработчик Гиды](docs/PLUGIN_DEVELOPER_GUIDE.md)** укыгыз:
- Тулысынча API сылтамасы
- Эшләүче мисаллар
- Адым-адым дәреслекләр
- Иң яхшы практикалар һәм куркынычсызлык кагыйдәләре

### Плагинны тапшырмагыз

1. [Plugin Store](https://wiasoom.com) репозиторийын форклагыз
2. Плагинны `plugins/{your-plugin-name}/` папкасына өстәгез
3. Pull Request тапшырмагыз
4. Тикшерүдән соң, сезнең плагин Плагин Магазинында барлык кулланучылар өчен күренәчәк!

## 🌐 Тәрҗемә өлешләре (254 тел)

WIA SOOM **254 телне** хуплый — Амхариктан Зулу теленә, Брайль һәм RTL телләрен дә кертеп.

### Тәрҗемә ничек эшли

- Нигез тел файл: `src/renderer/src/i18n/en.json`
- Барлык 254 тел файллары бер үк директориядә
- Тәрҗемә `scripts/translate-patch.js` (GPT-4o-mini API) аша башкарыла

### Тәрҗемәләргә ничек өлеш кертергә

#### 1-нче вариант: Конкрет тәрҗемәне төзәтү

1. Тел файлларын табыгыз: `src/renderer/src/i18n/{lang-code}.json`
2. Дөрес булмаган тәрҗемәне төзәтегез
3. Үзгәреш белән PR тапшырмагыз

#### 2-нче вариант: Юклык ачкычларны өстәү
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### 3-нче вариант: Машина тәрҗемәләрен тикшерү

Б��знең 254 телнең күпчелеге машина тәрҗемәсе белән ясалган. Туган телдә сөйләшүчеләрнең тикшерүләре бик кыйммәтле!

1. Тел файлларын сайлагыз
2. Тәрҗемәләрне тикшерегез
3. Ничек булса да уңайсыз яки дөрес булмаган тәрҗемәләрне төзәтегез
4. PR тапшырмагыз

### Тел Кодлары

Без стандарт ISO 639-1 кодларын (мәсәлән, `ko`, `en`, `ja`, `ar`, `hi`) кулланабыз, кирәк булганда региональ вариантлар белән (мәсәлән, `zh-CN`, `pt-BR`).
