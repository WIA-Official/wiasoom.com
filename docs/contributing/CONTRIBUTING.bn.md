## আচার বিধি

আমরা সবার জন্য একটি স্বাগত এবং অন্তর্ভুক্তিমূলক অভিজ্ঞতা প্রদান করতে প্রতিশ্রুতিবদ্ধ।

- **সম্মানজনক হন।** সবার প্রতি মর্যাদা প্রদর্শন করুন।
- **গঠনমূলক হন।** সহায়ক প্রতিক্রিয়া দিন, ধ্বংসাত্মক সমালোচনা নয়।
- **অন্তর্ভুক্তিমূলক হন।** আমরা ২৫৪ ভাষাকে সমর্থন করি এবং পৃথিবীর প্রতিটি দেশের অবদানকারীদের স্বাগত জানাই।
- **কোনো হয়রানি নয়।** কোনো ধরনের বৈষম্যের জন্য শূন্য সহনশীলতা।

   - স্ক্রিনশট বা টার্মিনাল আউটপুট যদি সম্ভব হয়

## 🌐 অনুবাদ অবদান (২৫৪ ভাষা)

WIA SOOM **২৫৪ ভাষা** সমর্থন করে — আমহারিক থেকে জুলু, ব্রেইল এবং RTL ভাষাসহ।

### কিভাবে অনুবাদ কাজ করে

- বেস ভাষার ফাইল: `src/renderer/src/i18n/en.json`
- সমস্ত ২৫৪ ভাষার ফাইল একই ডিরেক্টরিতে রয়েছে
- অনুবাদটি `scripts/translate-patch.js` (GPT-4o-mini API) এর মাধ্যমে করা হয়

### কিভাবে অনুবাদে অবদান রাখবেন

#### বিকল্প ১: একটি নির্দিষ্ট অনুবাদ ঠিক করুন

1. ভাষার ফাইল খুঁজুন: `src/renderer/src/i18n/{lang-code}.json`
2. ভুল অনুবাদটি ঠিক করুন
3. পরিবর্তন ���হ একটি PR জমা দিন

#### বিকল্প ২: অনুপস্থিত কী যুক্ত করুন
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### বিকল্প ৩: মেশিন অনুবাদ পর্যালোচনা করুন

আমাদের ২৫৪ ভাষার অনেকগুলি মেশিন দ্বারা অনুবাদ করা হয়েছে। স্থানীয় বক্তার পর্যালোচনা অত্যন্ত মূল্যবান!

1. আপনার ভাষার ফাইলটি বেছে নিন
2. অনুবাদগুলি পর্যালোচনা করুন
3. যে কোনো অস্বাভাবিক বা ভুল অনুবাদ ঠিক করুন
4. একটি PR জমা দিন

### ভাষার কোড

আমরা মানক ISO 639-1 কোড (যেমন, `ko`, `en`, `ja`, `ar`, `hi`) ব্যবহার করি যেখানে প্রয়োজনীয় অঞ্চলের ভেরিয়েন্ট (যেমন, `zh-CN`, `pt-BR`) থাকে।
