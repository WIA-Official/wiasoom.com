## Жардам көрсөтүү кодекси

Биз ар бир адам үчүн жагымдуу жана инклюзивдүү тажрыйба берүүгө милдеттенебиз.

- **Урматтаңыз.** Ар бир адамды кадыр-барк менен караңыз.
- **Конструктивдүү болуңуз.** Жардамчы пикир бериңиз, бузуу сын эмес.
- **Инклюзивдүү болуңуз.** Биз 254 тилди колдойбуз жана Жер шарындагы ар бир өлкөдөн катышуучуларды кабыл алабыз.
- **Куугунтуктоо жок.** Ар кандай дискриминацияга нөлдүк толеранттуулук.

## 🐛 Каталарды кантип билдирүү керек

1. [GitHub Issues](https://github.com/WIA-Official/wiasoom.com/issues) барагына өтүңүз
2. **"Жаңы маселе"** баскычын басыңыз
3. **"Ката билдирүүсү"** шаблонуна тандаңыз
4. Керектүү маалыматтарды кошуңуз:
   - WIA SOOM версиясы (Настройки → Тууралуу)
   - ОС жана версия (Windows/macOS/Linux)
   - Кайталанган кадамдар
   - Күтүлгөн жана чындыктагы жүрүш
   - Сүрөттөр же терминалдын чыгышы мүмкүн болсо

WIA SOOM күчтүү плагин системасына ээ — сиз 5 мүнөттө өзүңүздүн плагинди түзө аласыз.

### Жылдам баштоо
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### Толук жетекчилик

**[Плагин иштеп чыгуучунун жетекчилиги](docs/PLUGIN_DEVELOPER_GUIDE.md)** боюнча окуңуз:
- Толук API справкасы
- Иштеп жаткан мисалдар
- Кадам-кадам боюнча окуу куралдары
- Эң жакшы практикалар жана коопсуздук эрежелери

### Өз плагиниңизди ��өнөтүңүз

1. [Plugin Store](https://wiasoom.com) репозиторийин форк кылыңыз
2. Өз плагиниңизди `plugins/{your-plugin-name}/` папкасына кошуңуз
3. Pull Request жөнөтүңүз
4. Текшерүүдөн кийин, плагиниңиз бардык колдонуучулар үчүн Плагин Дүкөнүндө пайда болот!

   ```bash
   ```


### Коммит билдирүүсүнүн конвенциясы

| Префикс | Колдонуу үчүн |
|---------|---------------|
| `feat:` | Жаңы функция |
| `fix:`  | Ката оңдоо |
| `docs:` | Тек гана документация |
| `refactor:` | Кодду кайра түзүү (жүрүш өзгөрбөйт) |
| `i18n:` | Котормо жаңыртуулары |
| `plugin:` | Плагинге байланыштуу өзгөртүүлөр |

### PR Чек-листи

## 🌐 Котормо катышуулар (254 тил)

WIA SOOM **254 тилди** колдойт — Амхар тилинен Зулу тилине чейин, Брайль жана RTL тилдерин камтыйт.

### Котормо кантип иштейт

- Негизги тил файлы: `src/renderer/src/i18n/en.json`
- Бардык 254 тил файлы бир папкада
- Котормо `scripts/translate-patch.js` аркылуу жүргүзүлөт (GPT-4o-mini API)

### Котормолорду кантип сунуштоо керек

#### Опция 1: Белгилүү котормону оңдоо

1. Тил файлын табыңыз: `src/renderer/src/i18n/{lang-code}.json`
2. Туура эмес котормону оңдоңуз
3. Өзгөртүү менен PR жөнөт��ңүз

#### Опция 2: Жоголгон ачкычтарды кошуу
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### Опция 3: Машина котормолорун текшерүү

Биздин 254 тилдин көпчүлүгү машина аркылуу которулган. Туура сүйлөгөндөрдүн текшерүүлөрү абдан баалуу!

1. Өз тилиңиздин файлын тандаңыз
2. Котормолорду текшериңиз
3. Кандайдыр бир кыйын же туура эмес котормолорду оңдоңуз
4. PR жөнөтүңүз

### Тил коддору

Биз стандарттык ISO 639-1 коддорун (мисалы, `ko`, `en`, `ja`, `ar`, `hi`) регионалдык варианттар менен колдонобуз (мисалы, `zh-CN`, `pt-BR`).
