## Әдеп кодексі

Біз барлығына қолайлы және инклюзивті тәжірибе ұсынуға міндеттіміз.

- **Құрметпен қарау.** Барлық адамдарды қадірмен қарау.
- **Құрылымды болу.** Пайдалы пікірлер ұсыныңыз, бұзушы сын емес.
- **Инклюзивті болу.** Біз 254 тілге қолдау көрсетеміз және Жердегі барлық елдерден қатысушыларды қарсы аламыз.
- **Зорлық-зомбылыққа жол бермеу.** Әр түрлілікке нөлдік төзімділік.

   - Қайталанатын қадамдар
   - Күтілетін және нақты мінез-құлық
   - Мүмкін болса, экран суреттері немесе терминал шығуы

## 🔌 Плагинді қалай жіберуге болады

WIA SOOM қуатты плагин жүйесіне ие — сіз 5 минутта өз плагиніңізді жасай аласыз.

### Жылдам бастау
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### Толық нұсқаулық

**[Плагин әзірлеуші нұсқаулығын](docs/PLUGIN_DEVELOPER_GUIDE.md)** оқыңыз:
- Толық API анықтамасы
- Жұмыс істейтін мысалдар
- Қадамдық оқулықтар
- Ең жақсы тәжірибелер мен қауіпсіздік ережелері

### Плагиніңізді жіберіңіз

1. [Plugin Store](https://wiasoom.com) репозиторийін форк жасаңыз
2. Плагиніңізді `plugins/{your-plugin-name}/` папкасына қосыңыз
3. Pull Request жіберіңіз
4. Тексеруден кейін, плагиніңіз барлық пайдаланушылар үшін Плагин Дүкенінде пайда болады!

5. Түсінікті хабарламамен коммит жасаңыз:

### Коммит хабарламасы ережесі

| Префикс | Пайдалану үшін |
|---------|----------------|
| `feat:` | Жаңа функция   |
| `fix:`  | Қате түзету    |
| `docs:` | Тек құжаттама  |
| `refactor:` | Кодты қайта құрылымдау (мінез-құлық өзгеріссіз) |
| `i18n:` | Аударма жаңартулары |
| `plugin:` | Плагинге қатысты өзгерістер |

### PR Тексеру тізімі

- [ ] Код қателерсіз жұмыс істейді

- [ ] Өндірістік кодта `console.log` қалмаған
- [ ] Барлық тесттер әлі де өтеді

## 🌐 Аударма үлестері (254 тіл)

WIA SOOM **254 тілге** қолдау көрсетеді — Амхар тілінен Зулу тіліне дейін, Брайль және RTL тілдерін қоса.

### Аударма қалай жұмыс істейді

- Негізгі тіл файлы: `src/renderer/src/i18n/en.json`
- Барлық 254 тіл файлы бір папкада
- Аударма `scripts/translate-patch.js` арқылы жүзеге асырылады (GPT-4o-mini API)

### Аударма үлестерін қалай қосуға болады

#### Опция 1: Белгілі бір аударманы түзету

1. Тіл файлын табыңыз: `src/renderer/src/i18n/{lang-code}.json`
2. Дұрыс емес аударманы түзетіңіз
3. Өзгерісті PR-мен жіберіңіз

#### Опция 2: Жоғалған кілттерді қосу
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### Опция 3: Машинамен аудармаларды тексеру

Біздің 254 тілдің көпшілігі машинамен аударылған. Туған т��лде сөйлейтіндердің тексерулері өте бағалы!

1. Тіл файлыңызды таңдаңыз
2. Аудармаларды тексеріңіз
3. Қиын немесе дұрыс емес аудармаларды түзетіңіз
4. PR-ді жіберіңіз

### Тіл кодтары

Біз стандартты ISO 639-1 кодтарын (мысалы, `ko`, `en`, `ja`, `ar`, `hi`) және қажет болған жағдайда аймақтық нұсқаларын (мысалы, `zh-CN`, `pt-BR`) қолданамыз.
