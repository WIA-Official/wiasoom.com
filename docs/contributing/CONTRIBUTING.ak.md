## Code of Conduct

Yɛyɛ no dɛ yɛbɛma ɔkwan a ɛda ho adi na ɛyɛ a ɛyɛ fɛ ma obiara.

- **Fa ɔdɔ yɛ adwuma.** Tɔ ɔdɔ ma obiara.
- **Fa nsɛm a ɛyɛ mmerɛ.** Ma nsɛm a ɛyɛ mmerɛ, na ɛnyɛ nsɛm a ɛyɛ bɔne.
- **Fa ɔkwan a ɛyɛ fɛ.** Yɛyɛ ɔkwan a ɛyɛ fɛ ma nsɛm 254 na yɛfrɛ mmoa fi ɔman biara a ɛwɔ Ɔsoro.
- **Mma ɔhaw.** Nni ɔhaw biara ho kwan.

## 🔌 Ɛkwan a yɛfa so de plugin to so

WIA SOOM wɔ plugin system a ɛyɛ den — wubetumi ayɛ wo plugin wɔ nnaanan mu.

### Ntɛm Nkyerɛkyerɛ
```bash
# Use the scaffold tool
./scripts/soom-create-plugin.sh
```
### Nkyerɛkyerɛ Kɛse

Kenkan **[Plugin Developer Guide](docs/PLUGIN_DEVELOPER_GUIDE.md)** fa ho nsɛm a ɛda ho adi:
- API nsɛm a ɛda ho adi nyinaa
- Nsɛm a ɛyɛ nokware
- Nkyerɛkyerɛ a ɛda ho adi
- Nkyerɛ a ɛyɛ papa ne ɔkwan a ɛyɛ fɛ

### Fa Wo Plugin To So

1. Fork [Plugin Store](https://wiasoom.com)
2. Fa wo plugin kɔ `plugins/{your-plugin-name}/`
3. Fa Pull Request to so
4. Ɛyɛ a wɔbɛhwɛ no, wo plugin bɛda ho adi wɔ Plugin Store ma ɔman nyinaa!

## 🌐 Nsɛm a wɔkyerɛ ase (254 Nsɛm)

WIA SOOM yɛ **254 nsɛm** — fi Amharic kɔ Zulu, ka Braille ne RTL nsɛm ho.

### Ɛkwan a Nsɛm a Wɔkyerɛ Ase yɛ Adwuma

- Base language file: `src/renderer/src/i18n/en.json`
- Nsɛm 254 no nyinaa wɔ baabi koro mu
- Nsɛm a wɔkyerɛ ase yɛ wɔ `scripts/translate-patch.js` (GPT-4o-mini API)

### Ɛkwan a yɛfa so yɛ nsɛm a wɔkyerɛ ase

#### Ɛkwan 1: Sɛ ɔkwan a ɛda ho adi a ɛyɛ mfomso

1. Hwehwɛ nsɛm file no: `src/renderer/src/i18n/{lang-code}.json`
2. Sɛ ɔkwan a ɛda ho adi a ɛyɛ mfomso no yɛ mfomso
3. Fa PR to so fa nsɛm a ɛda ho adi no

#### Ɛkwan 2: Fa nsɛm a ɛda ho adi a ɛyɛ foforɔ
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### Ɛkwan 3: Sɔ hwɛ nsɛm a wɔyɛ wɔ ɔman mu

Nnipa a wɔyɛ nsɛm 254 no yɛ nsɛm a wɔyɛ wɔ ɔman mu. Nsɛm a wɔyɛ no yɛ nsɛm a ɛyɛ fɛ paa!

1. Pɛ wo nsɛm file no
2. Sɔ hwɛ nsɛm a wɔkyerɛ ase
3. Sɛ ɔkwan a ɛda ho adi a ɛyɛ mfomso anaa ɛyɛ bɔne no yɛ mfomso
4. Fa PR to so

### Nsɛm Kɔd

Yɛde ISO 639-1 kɔd a ɛyɛ aban mu (e.g., `ko`, `en`, `ja`, `ar`, `hi`) fa nsɛm a ɛda ho adi a ɛyɛ foforɔ a ɛda ho adi (e.g., `zh-CN`, `pt-BR`).
