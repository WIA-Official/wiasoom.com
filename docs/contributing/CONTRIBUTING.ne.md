## 🌐 अनुवाद योगदान (254 भाषाहरू)

WIA SOOM ले **254 भाषाहरू** लाई समर्थन गर्दछ — अम्हारिकदेखि जुलु सम्म, ब्रेल र RTL भाषाहरू समावेश गर्दै।

### अनुवाद कसरी काम गर्छ

- आधार भाषा फाइल: `src/renderer/src/i18n/en.json`
- सबै 254 भाषा फाइलहरू एउटै निर्देशिकामा छन्
- अनुवाद `scripts/translate-patch.js` (GPT-4o-mini API) मार्फत गरिन्छ

### अनुवादमा योगदान कसरी दिने

#### विकल्प 1: विशेष अनुवाद सुधार गर्नुहोस्

1. भाषा फाइल खोज्नुहोस्: `src/renderer/src/i18n/{lang-code}.json`
2. गलत अनुवाद सुधार गर्नुहोस्
3. परिवर्तनसहित एक PR पेश गर्नुहोस्

#### विकल्प 2: हराइरहेका कुञ्जीहरू थप्नुहोस्
```bash
# Sync all languages with new English keys
npm run i18n:sync

# Translate only new/missing keys
node scripts/translate-patch.js
```
#### विकल्प 3: मेशिन अनुवादहरूको समीक्षा गर्नुहोस्

हाम्रा 254 भाषाहरू मध्ये धेरै मेशिन-अनुवादित छन्। मातृभाषीको समीक्षाहरू अत्यन्त मूल्यवान छन्!

1. आफ्नो भाषा फाइल चयन गर्नुहोस्
2. अनुवादहरूको समीक्षा गर्नुहोस्
3. कुनै पनि असहज वा गलत अनुवाद सुधार गर्नुहोस्
4. एक PR पेश गर्नुहोस्

### भाषा कोडहरू

हामी मानक ISO 639-1 कोडहरू प्रय��ग गर्छौं (जस्तै, `ko`, `en`, `ja`, `ar`, `hi`) आवश्यकताअनुसार क्षेत्रीय भिन्नतासहित (जस्तै, `zh-CN`, `pt-BR`)।
