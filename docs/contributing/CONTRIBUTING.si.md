- **හිතාමතා කටයුතු නොකරන්න.** ඕනෑම වර්ගයක ව්‍යාජය සඳහා ශුන්‍ය සහනශීලතාවයක්.

### පරිවර්තන සඳහා දායක වීමට කෙසේද

2. වැරදි පරිවර්තනය නිවැරදි කරන්න
3. වෙනස සමඟ PR එකක් ඉදිරිපත් කරන්න
